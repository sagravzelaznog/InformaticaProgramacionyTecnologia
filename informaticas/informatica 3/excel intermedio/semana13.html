Semana 13: Análisis de Datos en Excel

Sesión 13.1: Herramientas de análisis rápido

Objetivos de aprendizaje:

  • Utilizar las herramientas de análisis rápido de Excel
  • Crear tablas y gráficos con un solo clic
  • Aplicar formato condicional de manera efectiva

1. Análisis rápido (Quick Analysis)

Esta herramienta permite crear visualizaciones rápidas de tus datos con solo unos clics.

Acceder al análisis rápido:

  1. Selecciona los datos que deseas analizar
  2. Haz clic en el ícono de Análisis rápido que aparece en la esquina inferior derecha de la selección
  3. O usa el atajo: Ctrl + Q

2. Funciones principales

Formato

Aplica formato condicional rápidamente, como barras de datos, escalas de color y conjuntos de iconos.

Tablas dinámicas

Crea tablas dinámicas con diseños predefinidos para analizar tus datos.

Gráficos

Inserta gráficos recomendados basados en tus datos seleccionados.

Ejercicio práctico:

  1. Crea un conjunto de datos de ventas mensuales por producto y región
  2. Usa el análisis rápido para crear un gráfico de líneas que muestre la tendencia de ventas
  3. Aplica formato condicional para resaltar los valores por encima del promedio
  4. Crea una tabla dinámica que resuma las ventas por región

Consejos para el análisis rápido:

  • Selecciona solo los datos que necesitas analizar
  • Prueba diferentes opciones de visualización
  • Personaliza los gráficos generados según tus necesidades
  • Usa las pestañas en la parte superior del menú de análisis rápido para ver más opciones

Sesión 13.2: Escenarios y tablas de datos

Objetivos de aprendizaje:

  • Crear y administrar escenarios
  • Utilizar tablas de datos para análisis de sensibilidad
  • Comparar diferentes escenarios

1. Administrador de escenarios

Los escenarios son conjuntos de valores que Excel guarda y puede sustituir automáticamente en tu hoja de cálculo.

Crear un escenario:

  1. Ve a la pestaña Datos
  2. Haz clic en Análisis Y si > Administrador de escenarios
  3. Haz clic en Agregar para crear un nuevo escenario
  4. Asigna un nombre al escenario
  5. Especifica las celdas que cambiarán
  6. Ingresa los valores para este escenario
  7. Haz clic en Aceptar

2. Tablas de datos

Permiten ver cómo el cambio de una o dos variables afecta el resultado de una fórmula.

Ejercicio práctico:

Crea un modelo de préstamo que muestre cómo varían los pagos mensuales según:

  1. Diferentes tasas de interés (usando una tabla de datos de una variable)
  2. Diferentes montos de préstamo y plazos (usando una tabla de datos de dos variables)
  3. Crea escenarios para "Mejor caso", "Caso base" y "Peor caso"
  4. Genera un informe de resumen de escenarios

Sesión 13.3: Búsqueda de objetivos y Solver

Objetivos de aprendizaje:

  • Utilizar la herramienta Buscar objetivo
  • Configurar y resolver problemas con Solver
  • Interpretar los resultados de Solver

1. Buscar objetivo

Esta herramienta te permite encontrar el valor de entrada necesario para alcanzar un resultado deseado.

Usar Buscar objetivo:

  1. Ve a la pestaña Datos
  2. Haz clic en Análisis Y si > Buscar objetivo
  3. En Definir la celda, ingresa la referencia de la celda que contiene la fórmula
  4. En Con el valor, ingresa el resultado que deseas
  5. En Para cambiar la celda, ingresa la referencia de la celda que Excel puede cambiar
  6. Haz clic en Aceptar

2. Complemento Solver

Una herramienta poderosa para resolver problemas de optimización.

Habilitar Solver:

  1. Haz clic en Archivo > Opciones
  2. Selecciona Complementos
  3. En Administrar, selecciona Complementos de Excel y haz clic en Ir...
  4. Marca la casilla Solver Add-in y haz clic en Aceptar

Ejercicio práctico:

Resuelve el siguiente problema de optimización:

  1. Crea un modelo de producción que maximice las ganancias considerando:
    • Recursos limitados (materia prima, horas de mano de obra)
    • Múltiples productos con diferentes márgenes de ganancia
    • Restricciones de demanda del mercado
  2. Configura Solver para encontrar la combinación óptima de producción
  3. Analiza el informe de sensibilidad generado

Sesión 13.4: Práctica guiada - Análisis de escenarios

Objetivos de la práctica:

  • Aplicar las herramientas de análisis de datos en un caso práctico
  • Crear un modelo financiero completo
  • Analizar diferentes escenarios y tomar decisiones basadas en datos

1. Caso de estudio: Plan de negocios

Desarrollarás un plan de negocios para una nueva empresa que incluye:

  • Proyecciones financieras a 5 años
  • Análisis de punto de equilibrio
  • Flujo de caja proyectado
  • Retorno de la inversión (ROI)

2. Análisis de sensibilidad

  1. Crea una tabla de datos que muestre cómo varía el VAN (Valor Actual Neto) con diferentes tasas de descuento y tasas de crecimiento de ingresos
  2. Usa Buscar objetivo para determinar la tasa de crecimiento necesaria para alcanzar un VAN de cero (punto de equilibrio)
  3. Configura Solver para maximizar el VAN ajustando las variables de marketing y producción

Ejercicio final:

Prepara un informe ejecutivo que incluya:

  1. Resumen ejecutivo con hallazgos clave
  2. Gráficos que muestren los diferentes escenarios
  3. Análisis de sensibilidad
  4. Recomendaciones basadas en el análisis
  5. Plan de acción propuesto

Entrega del proyecto:

Guarda tu archivo como "Analisis_Escenarios_TuNombre.xlsx" y asegúrate de que:

  • Todas las fórmulas estén correctamente configuradas
  • Los escenarios estén guardados y sean accesibles
  • Los informes de Solver estén incluidos
  • El diseño sea profesional y fácil de entender

Consejos para el análisis de escenarios:

  • Documenta tus suposiciones
  • Prueba diferentes combinaciones de variables
  • Incluye un rango amplio de posibilidades
  • Prepara respuestas para preguntas sobre tus suposiciones
  • Usa nombres descriptivos para tus escenarios
