Semana 2: Operaciones Básicas en Excel

Sesión 2.1: Fórmulas básicas (suma, resta, multiplicación, división)

Objetivos de aprendizaje:

  • Comprender la estructura básica de las fórmulas en Excel
  • Aplicar operadores aritméticos en fórmulas
  • Resolver problemas matemáticos básicos

Contenido detallado:

  1. Estructura de una fórmula en Excel
  2. Operadores aritméticos básicos:
    • Suma (+)
    • Resta (-)
    • Multiplicación (*)
    • División (/)
    • Porcentaje (%)
    • Exponenciación (^)
  3. Jerarquía de operaciones
  4. Uso de paréntesis para modificar el orden de las operaciones
  5. Corrección de errores comunes en fórmulas

Ejemplos prácticos:

Suma básica: =A1+B1

Multiplicación con porcentaje: =A1*10%

Fórmula con paréntesis: =(A1+B1)*C1

Actividad práctica:

Crear una hoja de cálculo que calcule el promedio de calificaciones de un estudiante en diferentes materias, aplicando fórmulas básicas.

Sesión 2.2: Referencias de celdas (absolutas y relativas)

Objetivos de aprendizaje:

  • Diferenciar entre referencias relativas y absolutas
  • Utilizar el símbolo $ para fijar filas o columnas
  • Aplicar referencias mixtas

Contenido detallado:

  1. Referencias relativas (ej: A1)
  2. Referencias absolutas (ej: $A$1)
    • Fijar columna ($A1)
    • Fijar fila (A$1)
    • Fijar ambas ($A$1)
  3. Cuándo usar cada tipo de referencia
  4. Métodos rápidos para cambiar entre tipos de referencia (tecla F4)
  5. Ejemplos prácticos de aplicación

Ejemplos de referencias:

Relativa: =A1 (cambia al copiarse)

Absoluta columna: =$A1 (la columna A se mantiene fija)

Absoluta fila: =A$1 (la fila 1 se mantiene fija)

Absoluta completa: =$A$1 (siempre referencia a A1)

Actividad práctica:

Crear una tabla de multiplicar utilizando referencias mixtas para que al arrastrar la fórmula se complete toda la tabla automáticamente.

Sesión 2.3: Funciones básicas (PROMEDIO, MÁX, MÍN, CONTAR)

Objetivos de aprendizaje:

  • Utilizar funciones estadísticas básicas
  • Comprender la sintaxis de las funciones
  • Aplicar funciones a rangos de celdas

Contenido detallado:

  1. Estructura de una función en Excel
    • Signo igual (=)
    • Nombre de la función
    • Argumentos entre paréntesis
  2. Funciones básicas:
    • SUMA: suma un rango de celdas
    • PROMEDIO: calcula la media aritmética
    • MÁX: devuelve el valor máximo
    • MÍN: devuelve el valor mínimo
    • CONTAR: cuenta celdas con númerosCONTARA: cuenta celdas no vacías
  3. Selección de rangos para funciones
  4. Anidamiento de funciones

Ejemplos de funciones:

SUMA: =SUMA(A1:A10)

PROMEDIO: =PROMEDIO(B2:B20)

MÁX y MÍN: =MÁX(C1:C100) / =MÍN(C1:C100)

CONTAR: =CONTAR(D1:D50)

Actividad práctica:

Analizar un conjunto de datos de ventas mensuales, calculando totales, promedios, venta máxima y mínima, y cantidad de meses con ventas.

Sesión 2.4: Práctica guiada - Cálculo de calificaciones

Objetivos de la práctica:

  • Aplicar fórmulas y funciones aprendidas
  • Crear un sistema de calificaciones funcional
  • Practicar el uso de referencias absolutas y relativas

Instrucciones:

  1. Crear un nuevo libro llamado "Registro de Calificaciones"
  2. En la primera hoja, crear una tabla con las siguientes columnas:
    • Nombre del estudiante
    • 5 calificaciones parciales
    • Promedio (usar PROMEDIO)
    • Calificación más alta (usar MÁX)
    • Calificación más baja (usar MÍN)
    • Total de calificaciones (usar SUMA)
    • Estado (Aprobado/Reprobado usando SI con promedio ≥ 6)
  3. Ingresar al menos 10 estudiantes con sus respectivas calificaciones
  4. Agregar al final de la tabla:
    • Promedio general del grupo
    • Calificación más alta del grupo
    • Calificación más baja del grupo
    • Total de aprobados (usar CONTAR.SI)
    • Total de reprobados
    • Porcentaje de aprobación
  5. Aplicar formatos adecuados a los números y porcentajes
  6. Agregar encabezados con formato y bordes a la tabla

Reto adicional (opcional):

Agregar una columna que asigne una letra (A, B, C, D, F) según el promedio usando la función SI anidada.

Entrega:

Guardar el archivo con el nombre "Apellido_Nombre_Calificaciones.xlsx" y entregarlo según las indicaciones del profesor.
