Semana 4: Funciones de Texto y Fecha en Excel

Sesión 4.1: Funciones de texto (IZQUIERDA, DERECHA, EXTRAE, CONCATENAR)

Objetivos de aprendizaje:

  • Manipular y extraer texto de celdas
  • Combinar texto de diferentes celdas
  • Realizar operaciones avanzadas con cadenas de texto

Contenido detallado:

  1. Función IZQUIERDA:
    • Sintaxis: =IZQUIERDA(texto, núm_de_caracteres)
    • Extrae caracteres desde el inicio del texto
    • Ejemplo: =IZQUIERDA("Excel", 2) devuelve "Ex"
  2. Función DERECHA:
    • Sintaxis: =DERECHA(texto, núm_de_caracteres)
    • Extrae caracteres desde el final del texto
    • Ejemplo: =DERECHA("Excel", 2) devuelve "el"
  3. Función EXTRAE:
    • Sintaxis: =EXTRAE(texto, posición_inicial, núm_de_caracteres)
    • Extrae caracteres desde cualquier posición del texto
    • Ejemplo: =EXTRAE("Excel", 2, 3) devuelve "xce"
  4. Función CONCATENAR y el operador &:
    • Sintaxis: =CONCATENAR(texto1, texto2, ...) o =texto1 & texto2
    • Combina múltiples cadenas de texto
    • Ejemplo: =CONCATENAR("Hola", " ", "Mundo") o ="Hola" & " " & "Mundo" devuelven "Hola Mundo"
  5. Otras funciones útiles:
    • LARGO: Devuelve la longitud de una cadena
    • MAYUSC: Convierte texto a mayúsculas
    • MINUSC: Convierte texto a minúsculas
    • NOMPROPIO: Pone en mayúscula la primera letra de cada palabra

Ejemplo práctico: Extraer códigos

Datos: EMP-001-John-Doe

Extraer ID: =EXTRAE(A1, 5, 3) → "001"

Extraer nombre: =EXTRAE(A1, 9, 4) → "John"

Extraer apellido: =DERECHA(A1, LARGO(A1)-13) → "Doe"

Actividad práctica:

Crear una hoja con una lista de códigos de productos (ej: "LAP-001-AZUL") y usar funciones de texto para extraer y organizar la información en columnas separadas (Categoría, Número, Color).

Sesión 4.2: Funciones de fecha y hora

Objetivos de aprendizaje:

  • Comprender cómo Excel maneja fechas y horas
  • Utilizar funciones para manipular fechas
  • Calcular diferencias entre fechas

Contenido detallado:

  1. Entendiendo las fechas en Excel:
    • Las fechas son números secuenciales (1 = 1/1/1900)
    • Las horas son fracciones de día (0.5 = 12:00 PM)
  2. Funciones básicas de fecha:
    • =HOY(): Devuelve la fecha actual
    • =AHORA(): Devuelve la fecha y hora actual
    • =FECHA(año, mes, día): Crea una fecha a partir de números
    • =DIA(fecha): Extrae el día de una fecha
    • =MES(fecha): Extrae el mes de una fecha
    • =AÑO(fecha): Extrae el año de una fecha
  3. Cálculos con fechas:
    • =DIAS(fecha_final, fecha_inicial): Días entre dos fechas
    • =DIAS.LAB(fecha_inicio, fecha_fin, [festivos]): Días laborables
    • =FIN.MES(fecha_inicio, meses): Último día del mes
    • =FECHA.MES(fecha_inicio, meses): Suma meses a una fecha
  4. Funciones de hora:
    • =HORA(serie_de_número): Extrae la hora
    • =MINUTO(serie_de_número): Extrae los minutos
    • =SEGUNDO(serie_de_número): Extrae los segundos
    • =TIEMPO(hora, minuto, segundo): Crea una hora

Ejemplo práctico: Cálculo de vencimientos

Fecha de compra: 15/07/2023

Días de crédito: 30

Fecha de vencimiento: =A1+30 o =FECHA.MES(A1,1)

Días restantes: =DIAS(B1, HOY())

Actividad práctica:

Crear un registro de préstamos con fechas de préstamo, devolución y calcular días transcurridos, días hábiles y estado (en tiempo, por vencer, vencido).

Sesión 4.3: Validación de datos

Objetivos de aprendizaje:

  • Restringir el tipo de datos que se pueden ingresar en una celda
  • Crear listas desplegables
  • Mostrar mensajes de entrada y error personalizados

Contenido detallado:

  1. Configuración de validación de datos:
    • Seleccionar el rango de celdas
    • Ir a la pestaña Datos > Validación de datos
    • Configurar los criterios de validación
  2. Tipos de validación:
    • Número entero o decimal
    • Lista (para menús desplegables)
    • Fecha u hora
    • Longitud del texto
    • Personalizada (usando fórmulas)
  3. Mensajes de entrada y error:
    • Mensaje de entrada: Guía al usuario sobre qué datos ingresar
    • Mensaje de error: Se muestra cuando los datos no cumplen con la validación
    • Estilo de error: Detener, Advertencia o Información
  4. Validación con fórmulas personalizadas:
    • Validar formato de correo electrónico
    • Validar que no haya duplicados
    • Validar según condiciones complejas

Ejemplo de validación personalizada

Validar que un código postal tenga 5 dígitos:

=Y(ESNUMERO(A1),LARGO(A1)=5)

Validar que una fecha sea futura:

=A1>HOY()

Actividad práctica:

Crear un formulario de registro de empleados con validaciones para cada campo (nombre, correo, teléfono, fecha de ingreso, departamento con lista desplegable).

Sesión 4.4: Práctica guiada - Control de inventario

Objetivos de la práctica:

  • Aplicar funciones de texto y fecha en un caso real
  • Implementar validaciones de datos
  • Crear un sistema de control de inventario funcional

Instrucciones:

  1. Crear un nuevo libro llamado "Control_Inventario"
  2. En la primera hoja, diseñar un formulario de entrada con los siguientes campos (todos con validación):
    • Código de producto (formato: AAA-###, ej: TEL-001)
    • Nombre del producto (texto)
    • Categoría (lista desplegable: Electrónica, Ropa, Alimentos, Hogar)
    • Precio unitario (número mayor que 0)
    • Cantidad en stock (número entero mayor o igual a 0)
    • Fecha de ingreso (fecha válida, no futura)
    • Proveedor (texto)
  3. Crear una tabla de inventario que se llene automáticamente al ingresar datos en el formulario
  4. Agregar columnas calculadas:
    • Valor total (Precio unitario × Cantidad)
    • Días en inventario (desde la fecha de ingreso)
    • Estado (Usar formato condicional: Rojo si cantidad < 5, Amarillo si < 10, Verde si ≥ 10)
  5. Crear un resumen que muestre:
    • Total de productos en inventario
    • Valor total del inventario
    • Productos por categoría
    • Productos con stock bajo (< 5)
  6. Agregar una hoja de "Movimientos" para registrar entradas y salidas de inventario

Requisitos adicionales:

  • Usar funciones de texto para formatear códigos de producto
  • Usar funciones de fecha para calcular antigüedad en inventario
  • Implementar al menos 3 validaciones de datos diferentes
  • Crear un botón para limpiar el formulario

Consejo adicional:

Usa la función SI.ERROR para manejar posibles errores en las fórmulas, especialmente en columnas calculadas que podrían tener celdas vacías.

Entrega:

Guardar el archivo con el nombre "Apellido_Nombre_Inventario.xlsx" y asegurarse de que todas las validaciones y fórmulas funcionen correctamente antes de enviar.
