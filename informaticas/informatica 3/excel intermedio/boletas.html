Sistema de Boletas Automatizadas

Aprende a conectar múltiples hojas de cálculo usando referencias dinámicas e INDIRECTO.

Objetivo del Curso

Vamos a transformar un libro de Excel estático en una "Aplicación" de Gestión Escolar. Aprenderás a separar los datos (Backend) de la visualización (Frontend) usando lógica relacional.

Fase 1: Arquitectura de Datos (Backend)

La consistencia es clave. Crearemos bases de datos estandarizadas para que las fórmulas puedan "viajar" entre ellas sin errores.

Paso 1: Configuración de Hojas

  1. Crea 6 pestañas nuevas.
  2. Nómbralas estrictamente: Semestre 1, Semestre 2... hasta Semestre 6.
Principio Pedagógico: Estandarización. Al mantener la misma estructura en todas las hojas (ej. Matemáticas siempre inicia en la columna F), reducimos la carga cognitiva y simplificamos la lógica de programación.

Paso 2: Estructura de Columnas

  • Fila 1 (Encabezados): A1: Número, B1: Alumno. Combina celdas C1-E1 para "Español", F1-H1 para "Matemáticas".
  • Fila 2 (Unidades): Debajo de cada materia, escribe P1, P2, P3.
  • Columna A: Llénala con números consecutivos (ID del alumno).

Fase 2: Interfaz de Usuario (Frontend)

Esta es la hoja "Boleta". Debe ser limpia y contener solo lo necesario para el usuario final.

Controles de Mando (Inputs)

Define celdas específicas donde el usuario introducirá los datos de búsqueda:

  • Celda E4: Para el número de Semestre.
  • Celda G4: Para el número de Lista (ID) del alumno.

Tabla de Resultados

Dibuja la tabla donde aparecerán las calificaciones. Asegúrate de listar las materias en la columna A en el mismo orden que en tus bases de datos.

Fase 3: El Motor Lógico

Usaremos la función INDIRECTO para construir referencias de texto que Excel interprete como direcciones reales.

1. Trayendo el Nombre

Buscaremos el ID (G4) en la hoja definida por el Semestre (E4).

=BUSCARV(G4, INDIRECTO("'Semestre "&E4&"'!A:B"), 2, FALSO)

2. Trayendo Calificaciones (Español - Unidad 1)

Supongamos que la materia Español está en las columnas C, D, E de las hojas de datos. Para traer la Unidad 1 (Columna C, que es la 3ra columna):

=BUSCARV($G$4, INDIRECTO("'Semestre "&$E$4&"'!A:W"), 3, 0)
Lógica de Programación: La función INDIRECTO convierte el texto "Semestre 1!A:W" en una referencia válida. Al cambiar la celda E4 a "2", el texto cambia dinámicamente a "Semestre 2!A:W", forzando a BUSCARV a leer otra hoja.

Fase 4: Control de Errores (UX)

Un buen desarrollador protege su código de entradas incorrectas.

Validación de Datos

  1. Selecciona la celda del Semestre (E4).
  2. Ve a Datos > Validación de Datos.
  3. Elige Lista y escribe: 1,2,3,4,5,6.

Limpieza Visual

Evita el error #N/A si el alumno no existe:

=SI.ERROR(BUSCARV(...), "-")
