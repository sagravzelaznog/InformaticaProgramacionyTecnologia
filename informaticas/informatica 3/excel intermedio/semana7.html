Semana 7: Funciones Lógicas en Excel

Sesión 7.1: Función SI y anidamiento

Objetivos de aprendizaje:

  • Comprender la sintaxis de la función SI
  • Crear fórmulas condicionales básicas
  • Anidar múltiples funciones SI para condiciones complejas

Contenido detallado:

  1. Sintaxis básica de la función SI:
    =SI(prueba_lógica, valor_si_verdadero, valor_si_falso)
    • Prueba lógica: Condición que se evalúa como VERDADERO o FALSO
    • Valor si verdadero: Resultado si la condición es VERDADERA
    • Valor si falso: Resultado si la condición es FALSA
  2. Operadores de comparación:
    • = (igual a)
    • > (mayor que)
    • < (menor que)
    • >= (mayor o igual que)
    • <= (menor o igual que)
    • <> (diferente de)
  3. Anidamiento de funciones SI:
    =SI(condición1, resultado1, SI(condición2, resultado2, resultado_por_defecto))
    • Límite de anidamiento en versiones recientes: 64 niveles
    • Alternativas para múltiples condiciones: BUSCARV, ELEGIR, BUSCAR
  4. Errores comunes y solución de problemas:
    • Paréntesis no coincidentes
    • Valores de texto sin comillas
    • Uso incorrecto de operadores

Ejemplo práctico 1: Calificación de exámenes

Dada una columna con calificaciones (0-100), crear una fórmula que devuelva: "Aprobado" si la calificación es >= 70, "Reprobado" en caso contrario.

=SI(B2>=70, "Aprobado", "Reprobado")

Ejemplo práctico 2: Sistema de calificaciones

Crear una fórmula que asigne letras según la siguiente escala:

  • 90-100: A
  • 80-89: B
  • 70-79: C
  • 60-69: D
  • 0-59: F
=SI(B2>=90, "A", SI(B2>=80, "B", SI(B2>=70, "C", SI(B2>=60, "D", "F"))))

Ejercicio práctico:

Crear una hoja de cálculo que calcule comisiones de ventas con las siguientes reglas:

  • Si las ventas son menores a $1,000: 5% de comisión
  • Si las ventas están entre $1,000 y $5,000: 7% de comisión
  • Si las ventas son mayores a $5,000: 10% de comisión

Incluir columnas para: Nombre del vendedor, Ventas totales, Porcentaje de comisión y Monto de comisión.

Sesión 7.2: Funciones Y, O, NO

Objetivos de aprendizaje:

  • Utilizar las funciones Y, O, NO en combinación con SI
  • Crear condiciones lógicas complejas
  • Simplificar fórmulas condicionales

Contenido detallado:

  1. Función Y (AND):
    =Y(condición1, condición2, ...)
    • Devuelve VERDADERO solo si TODAS las condiciones son verdaderas
    • Máximo 255 argumentos
  2. Función O (OR):
    =O(condición1, condición2, ...)
    • Devuelve VERDADERO si ALGUNA condición es verdadera
    • Máximo 255 argumentos
  3. Función NO (NOT):
    =NO(condición)
    • Invierte el valor lógico (VERDADERO a FALSO y viceversa)
  4. Combinaciones avanzadas:
    • Anidamiento de funciones lógicas
    • Uso con otras funciones de Excel
    • Tablas de verdad

Ejemplo 1: Validación de datos

Aprobar solicitudes de préstamo si el solicitante tiene ingresos mayores a $50,000 Y un puntaje crediticio mayor a 700.

=SI(Y(ingresos>50000, puntaje>700), "Aprobado", "Rechazado")

Ejemplo 2: Bonificación por desempeño

Otorgar bonificación si el empleado tiene más de 3 años de antigüedad O un puntaje de desempeño mayor a 90.

=SI(O(antiguedad>3, desempeño>90), "Con bonificación", "Sin bonificación")

Ejercicio práctico:

Crear un sistema de evaluación de préstamos con las siguientes reglas:

  1. El solicitante debe tener al menos 21 años
  2. Ingresos anuales superiores a $30,000
  3. Puntaje crediticio de al menos 650
  4. No tener préstamos vencidos (NO)

Mostrar "Aprobado" solo si se cumplen TODAS las condiciones, de lo contrario mostrar "Rechazado".

Sesión 7.3: Funciones SI.ERROR y SI.ND

Objetivos de aprendizaje:

  • Manejar errores en fórmulas
  • Mejorar la presentación de hojas de cálculo
  • Evitar cadenas de funciones SI anidadas

Contenido detallado:

  1. Función SI.ERROR:
    =SI.ERROR(valor, valor_si_error)
    • Devuelve el valor si no hay error, de lo contrario devuelve valor_si_error
    • Captura todos los tipos de errores (#N/A, #VALOR!, #REF!, #DIV/0!, #NÚM!, #NOMBRE?, #NULO!)
  2. Función SI.ND (SI.ERROR.ND en versiones en inglés):
    =SI.ND(valor, valor_si_es_nd)
    • Específica para manejar el error #N/A (valor no disponible)
    • Útil con funciones de búsqueda como BUSCARV, BUSCARH, INDICE/COINCIDIR
  3. Casos de uso comunes:
    • Manejo de divisiones por cero
    • Búsquedas que pueden no encontrar coincidencias
    • Fórmulas que dependen de celdas vacías
  4. Mejores prácticas:
    • No ocultar todos los errores (pueden indicar problemas en los datos)
    • Usar mensajes descriptivos
    • Documentar el manejo de errores

Ejemplo 1: División segura

Calcular el porcentaje de crecimiento evitando errores de división por cero:

=SI.ERROR((B2-A2)/A2, "N/A")

Ejemplo 2: Búsqueda con manejo de error

Buscar un producto en una tabla, mostrando "No encontrado" si no existe:

=SI.ERROR(BUSCARV(producto, tabla, 2, FALSO), "Producto no encontrado")

Ejemplo 3: Combinación con funciones lógicas

Calcular comisión solo si hay ventas, de lo contrario mostrar 0:

=SI.ERROR(SI(Y(ventas>0, ventas<=10000), ventas*0.1, ""), 0)

Ejercicio práctico:

Crear una hoja de cálculo que:

  1. Contenga una lista de productos con precios
  2. Permita buscar productos por nombre
  3. Maneje adecuadamente los casos donde el producto no existe
  4. Calcule el precio con IVA (16%)
  5. Incluya una columna de descuento que aplique 10% si el precio es mayor a $1,000
  6. Maneje todos los posibles errores con mensajes descriptivos

Sesión 7.4: Práctica guiada - Sistema de calificaciones

Objetivos de la práctica:

  • Aplicar las funciones lógicas aprendidas
  • Crear un sistema de calificaciones completo
  • Implementar validaciones y manejo de errores

Instrucciones:

Crear un libro de Excel para calificaciones de un grupo escolar con las siguientes características:

1. Hoja "Datos Alumnos"

  • Columnas: Matrícula, Nombre, Grupo, Asistencias, Calificación Examen
  • Ingresar al menos 10 registros de ejemplo

2. Hoja "Parámetros"

  • Asistencia mínima requerida: 80%
  • Calificación mínima aprobatoria: 6.0
  • Escala de calificaciones:
    RangoLetra
    9.0 - 10.0A
    8.0 - 8.9B
    7.0 - 7.9C
    6.0 - 6.9D
    0 - 5.9F

3. Hoja "Calificaciones"

Crear una tabla que incluya:

  • Datos básicos del alumno (de la hoja Datos Alumnos)
  • Columna "Asistencia" que calcule el porcentaje de asistencia
  • Columna "Estatus" que muestre:
    • "Aprobado" si la asistencia >= 80% Y calificación >= 6.0
    • "Reprobado por asistencia" si asistencia < 80%
    • "Reprobado por calificación" si calificación < 6.0
    • "Reprobado" si ambas condiciones fallan
  • Columna "Letra" que asigne la letra correspondiente según la escala
  • Columna "Mensaje" que muestre un mensaje personalizado según el estatus

4. Hoja "Resumen"

Crear un resumen estadístico que muestre:

  • Total de alumnos
  • Número de aprobados/reprobados
  • Promedio del grupo
  • Distribución de calificaciones por letra (gráfico de barras)
  • Porcentaje de asistencia promedio

Requisitos adicionales:

  • Usar referencias a celdas en lugar de valores fijos
  • Incluir validación de datos donde sea apropiado
  • Usar formato condicional para resaltar:
    • Calificaciones aprobatorias en verde
    • Calificaciones reprobatorias en rojo
    • Asistencias por debajo del mínimo en amarillo
  • Proteger las celdas con fórmulas

Consejo profesional:

Usa nombres de rango para hacer tus fórmulas más legibles. Por ejemplo, en lugar de =SI(B2>=6,"Aprobado","Reprobado"), podrías usar =SI(Calificacion>=Aprobacion_Minima,"Aprobado","Reprobado").

Entrega:

Guardar el archivo con el nombre "Sistema_Calificaciones_Apellido_Nombre.xlsx" y asegurarse de que todas las fórmulas funcionen correctamente. Incluir al menos 15 registros de ejemplo.
