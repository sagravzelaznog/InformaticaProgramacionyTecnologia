Semana 16: Proyecto Final y Evaluación

Sesión 16.1: Presentación del proyecto final

Objetivos de la sesión:

  • Comprender los requisitos del proyecto final
  • Conocer los criterios de evaluación
  • Planificar el desarrollo del proyecto

Descripción del Proyecto Final

Para el proyecto final, desarrollarás un libro de Excel completo que demuestre las habilidades adquiridas durante el curso. El proyecto debe incluir:

  • Mínimo 3 hojas de cálculo interconectadas
  • Uso de fórmulas y funciones avanzadas
  • Tablas dinámicas y gráficos
  • Elementos de automatización (macros o Power Query)
  • Interfaz de usuario amigable
  • Documentación del proyecto

Criterios de Evaluación

Funcionalidad (40%)

  • El proyecto cumple con todos los requisitos técnicos
  • Las fórmulas y funciones funcionan correctamente
  • La automatización funciona según lo esperado

Diseño y Usabilidad (30%)

  • Interfaz intuitiva y profesional
  • Organización lógica de la información
  • Uso efectivo de formatos y estilos

Documentación (20%)

  • Instrucciones claras de uso
  • Explicación de las funcionalidades implementadas
  • Comentarios en el código (para macros)

Presentación (10%)

  • Claridad en la exposición
  • Manejo del tiempo durante la presentación
  • Respuestas a preguntas del profesor

Actividad en Clase

En grupos de 2-3 personas, discutan y respondan:

  1. ¿Qué tipo de proyecto les gustaría desarrollar? (ej. sistema de inventario, control de gastos, planificador de eventos, etc.)
  2. ¿Qué funciones y características de Excel planean incluir?
  3. ¿Qué desafíos prevén en el desarrollo del proyecto?

Preparen una breve presentación (5 minutos) para compartir sus ideas con la clase.

Sesión 16.2: Desarrollo del proyecto

Objetivos de la sesión:

  • Implementar la solución propuesta
  • Recibir retroalimentación del profesor
  • Realizar ajustes según sea necesario

Estructura recomendada del proyecto

  1. Hoja de Inicio/Dashboard
    • Resumen ejecutivo
    • Navegación a otras secciones
    • Visualizaciones clave
  2. Hoja de Datos
    • Datos de entrada estructurados
    • Tablas de referencia
    • Fórmulas de cálculo
  3. Hoja de Análisis
    • Tablas dinámicas
    • Gráficos interactivos
    • Análisis de escenarios
  4. Hoja de Configuración (opcional)
    • Parámetros ajustables
    • Opciones de personalización

Consejos para el desarrollo

  • Comienza con una estructura clara de archivos
  • Guarda versiones de respaldo regularmente
  • Prueba cada función a medida que la implementas
  • Documenta tus avances
  • No dejes todo para el último momento

Lista de verificación del proyecto

Marca cada ítem a medida que lo completes:

  • Estructura básica del libro
  • Datos de entrada y validación
  • Fórmulas y funciones implementadas
  • Tablas dinámicas y gráficos
  • Elementos de automatización
  • Interfaz de usuario
  • Documentación
  • Pruebas de funcionamiento

Sesión 16.3: Presentaciones de proyectos

Objetivos de la sesión:

  • Presentar el proyecto final a la clase
  • Demostrar el funcionamiento de la solución
  • Recibir retroalimentación de compañeros y profesor

Estructura de la presentación

Cada presentación debe incluir:

  1. Introducción (1 minuto)
    • Nombre del proyecto
    • Objetivo principal
    • Integrantes del equipo
  2. Demostración (3-4 minutos)
    • Recorrido por las funcionalidades principales
    • Demostración de características especiales
  3. Reflexión (1-2 minutos)
    • Desafíos encontrados
    • Lecciones aprendidas
    • Mejoras futuras posibles

Consejos para una presentación exitosa

  • Practica la presentación varias veces
  • Prepara ejemplos para la demostración
  • Selecciona las características más relevantes para mostrar
  • Mantén el contacto visual con la audiencia
  • Administra bien el tiempo

Evaluación por pares

Durante las presentaciones, completa una evaluación para cada proyecto que veas, considerando:

  • Originalidad y relevancia del proyecto
  • Complejidad técnica demostrada
  • Calidad de la presentación
  • Respuestas a preguntas

Sesión 16.4: Evaluación final y cierre del curso

Objetivos de la sesión:

  • Completar la evaluación final del curso
  • Reflexionar sobre el aprendizaje obtenido
  • Recibir retroalimentación sobre el curso

Evaluación Final

La evaluación consta de dos partes:

  1. Examen teórico-práctico (60 minutos)
    • Preguntas de opción múltiple sobre conceptos del curso
    • Ejercicios prácticos para resolver en Excel
  2. Retroalimentación del proyecto
    • Revisión individual con el profesor
    • Explicación de la calificación recibida
    • Oportunidades de mejora

Reflexión Final

Responde las siguientes preguntas en un documento:

  1. ¿Cuáles fueron tus mayores logros durante el curso?
  2. ¿Qué habilidades de Excel crees que dominas mejor ahora?
  3. ¿Cómo planeas seguir mejorando tus habilidades en Excel?
  4. ¿Qué consejo le darías a alguien que está por comenzar a aprender Excel?

Próximos pasos

Para continuar tu aprendizaje en Excel, considera:

  • Tomar cursos avanzados de Power Query y Power Pivot
  • Aprender a programar en VBA para mayor automatización
  • Explorar la integración de Excel con otras herramientas como Power BI
  • Practicar con conjuntos de datos reales de tu área de interés

Entrega de materiales

Para completar el curso, asegúrate de haber entregado:

  • Proyecto final (archivo de Excel)
  • Documentación del proyecto
  • Reflexión final
  • Evaluación del curso (si aplica)

Todos los materiales deben enviarse antes de la fecha límite indicada por el profesor.
