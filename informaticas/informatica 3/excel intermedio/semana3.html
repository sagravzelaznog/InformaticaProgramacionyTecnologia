Semana 3: Formato de Celdas en Excel

Sesión 3.1: Formato de números, fuentes y alineación

Objetivos de aprendizaje:

  • Aplicar formatos numéricos avanzados
  • Personalizar fuentes y estilos de texto
  • Controlar la alineación del contenido en las celdas

Contenido detallado:

  1. Formatos numéricos:
    • Número (decimales, separador de miles)
    • Moneda y contabilidad
    • Porcentaje
    • Fecha y hora
    • Texto
    • Personalizado
  2. Formato de fuente:
    • Tipografía
    • Tamaño
    • Estilos (negrita, cursiva, subrayado)
    • Color de fuente
  3. Alineación:
    • Alineación horizontal y vertical
    • Orientación del texto
    • Ajuste de texto
    • Combinar y centrar

Ejemplos de formatos personalizados:

Números de teléfono: (###) ###-####

Códigos postales: #####-####

Números de serie: ABC-###-####

Actividad práctica:

Crear una hoja de cálculo con diferentes tipos de datos y aplicar los formatos aprendidos para mejorar su presentación.

Sesión 3.2: Bordes, rellenos y estilos de celda

Objetivos de aprendizaje:

  • Aplicar bordes a celdas y rangos
  • Utilizar colores de relleno
  • Crear y aplicar estilos de celda

Contenido detallado:

  1. Bordes:
    • Estilos de línea
    • Grosor de línea
    • Color de bordeBordes preestablecidos
    • Bordes personalizados
  2. Rellenos:
    • Colores sólidos
    • Degradados
    • Texturas
    • Efectos de relleno
  3. Estilos de celda:
    • Estilos predefinidos
    • Creación de estilos personalizados
    • Modificación de estilos
    • Eliminación de estilos

Consejo profesional:

Usa colores de relleno sutiles para las filas alternadas (bandas) para mejorar la legibilidad de tablas extensas.

Actividad práctica:

Diseñar una factura profesional aplicando bordes, rellenos y estilos de celda para mejorar su presentación.

Sesión 3.3: Formatos condicionales básicos

Objetivos de aprendizaje:

  • Comprender el concepto de formato condicional
  • Aplicar formatos condicionales predefinidos
  • Crear reglas de formato condicional personalizadas

Contenido detallado:

  1. Introducción al formato condicional
  2. Formatos predefinidos:
    • Barras de datos
    • Escalas de color
    • Conjuntos de iconos
  3. Reglas básicas:
    • Resaltar celdas que contengan...
    • Valores superiores/inferiores a la media
    • Valores únicos/duplicados
  4. Administración de reglas:
    • Editar reglas existentes
    • Eliminar reglas
    • Orden de precedencia

Casos de uso comunes:

Análisis de ventas: Resaltar los productos con ventas por debajo del objetivo.

Control de inventario: Marcar en rojo los productos con existencias bajas.

Calificaciones: Aplicar escala de colores según el rango de calificación.

Actividad práctica:

Crear un informe de ventas mensuales aplicando formatos condicionales para resaltar automáticamente los resultados más relevantes.

Sesión 3.4: Práctica guiada - Formateo de una factura

Objetivos de la práctica:

  • Aplicar todos los conceptos de formato aprendidos
  • Crear un documento profesional
  • Practicar la organización visual de información

Instrucciones:

  1. Crear un nuevo libro llamado "Factura_Formato"
  2. En la primera hoja, diseñar una factura que incluya:
    • Encabezado con logo, nombre de la empresa y datos de contacto
    • Sección de datos del cliente
    • Tabla de productos/servicios con columnas para:
      • Código
      • Descripción
      • Cantidad
      • Precio unitario
      • Subtotal
    • Sección de totales con:
      • Subtotal
      • IVA (16%)
      • Total
    • Notas al pie con términos y condiciones
  3. Aplicar formatos profesionales:
    • Formato de moneda a precios y totales
    • Bordes a la tabla de productos
    • Rellenos de color para encabezados
    • Formatos condicionales para resaltar montos altos
    • Estilos de celda consistentes
  4. Agregar al menos 5 productos de ejemplo
  5. Asegurar que las fórmulas de cálculo funcionen correctamente

Requisitos de formato:

  • Usar fuentes profesionales (Arial, Calibri, etc.)
  • Mantener una paleta de colores coherente
  • Alinear correctamente los datos numéricos y de texto
  • Incluir bordes y rellenos para mejorar la legibilidad
  • Usar formatos condicionales para resaltar información importante

Entrega:

Guardar el archivo con el nombre "Apellido_Nombre_Factura.xlsx" y entregarlo según las indicaciones del profesor.

Consejo adicional:

Prueba a imprimir la factura en vista previa para asegurarte de que se vea bien en papel y realiza los ajustes necesarios en los márgenes y la configuración de página.
