Semana 5: Gráficos Básicos en Excel

Sesión 5.1: Tipos de gráficos y cuándo usarlos

Objetivos de aprendizaje:

  • Identificar los diferentes tipos de gráficos disponibles en Excel
  • Comprender el propósito y uso adecuado de cada tipo de gráfico
  • Seleccionar el gráfico más apropiado según el tipo de datos

Contenido detallado:

  1. Gráficos de columnas y barras:
    • Comparación de valores entre categorías
    • Barras apiladas para mostrar la composición
    • Barras 100% para comparar proporciones
  2. Gráficos circulares y de anillo:
    • Mostrar proporciones de un todo
    • Límite recomendado de categorías (máx. 7-8)
    • Uso de gráficos de anillo para múltiples series
  3. Gráficos de líneas y áreas:
    • Tendencias a lo largo del tiempo
    • Múltiples series para comparación
    • Áreas apiladas para mostrar contribución total
  4. Gráficos de dispersión (XY):
    • Relaciones entre variables
    • Identificación de correlaciones
    • Líneas de tendencia
  5. Otros tipos de gráficos:
    • Gráficos de radar
    • Gráficos de superficieGráficos de cotizaciones
    • Gráficos combinados

Ejemplos de uso:

Ventas mensuales: Gráfico de columnas agrupadas

Distribución de gastos: Gráfico circular o de anillo

Tendencias anuales: Gráfico de líneas

Relación entre variables: Gráfico de dispersión

Actividad práctica:

Analizar diferentes conjuntos de datos y seleccionar el tipo de gráfico más adecuado para cada uno, justificando la elección.

Sesión 5.2: Creación y formato de gráficos

Objetivos de aprendizaje:

  • Crear gráficos a partir de datos en Excel
  • Personalizar la apariencia de los gráficos
  • Agregar y modificar elementos del gráfico

Contenido detallado:

  1. Creación de un gráfico básico:
    • Selección de datos
    • Inserción del gráfico
    • Cambio de tipo de gráfico
  2. Elementos del gráfico:
    • Título del gráfico y ejes
    • Leyenda
    • Etiquetas de datos
    • Líneas de cuadrícula
    • Ejes (formato, escala, unidades)
  3. Formato de elementos:
    • Estilos y colores
    • Efectos (sombras, reflejos, brillo)
    • Rellenos y bordes
  4. Herramientas de gráfico:
    • Diseño (agregar elementos, diseños rápidos)
    • Formato (estilos de forma y texto)

Ejercicio práctico:

1. Crear una tabla con ventas trimestrales por región

2. Insertar un gráfico de columnas agrupadas

3. Agregar títulos y etiquetas

4. Aplicar un estilo de diseño

5. Cambiar colores y efectos

Actividad práctica:

Crear un informe de ventas con al menos tres gráficos diferentes que muestren la información de ventas desde diferentes perspectivas (por producto, por vendedor, por región).

Sesión 5.3: Minigráficos

Objetivos de aprendizaje:

  • Comprender el propósito de los minigráficos
  • Crear y formatear minigráficos
  • Utilizar minigráficos para análisis rápido de datos

Contenido detallado:

  1. ¿Qué son los minigráficos?
    • Gráficos en miniatura dentro de una celda
    • Visualización rápida de patrones y tendencias
    • Tipos: Línea, Columna y Ganancia/Pérdida
  2. Creación de minigráficos:
    • Selección del rango de datos
    • Configuración de ubicación
    • Actualización automática
  3. Personalización:
    • Estilos y colores
    • Mostrar puntos altos/bajos
    • Cambiar tipo de minigráfico
    • Agrupar minigráficos
  4. Usos avanzados:
    • Análisis comparativo en tablas
    • Tableros de control
    • Informes resumidos

Ejemplo práctico:

Crear una tabla de ventas mensuales por producto y agregar minigráficos de línea en la última columna para mostrar la tendencia de ventas de cada producto.

Actividad práctica:

Crear un informe de rendimiento de acciones con minigráficos que muestren la tendencia de cada acción durante el último mes.

Sesión 5.4: Práctica guiada - Análisis de ventas

Objetivos de la práctica:

  • Aplicar los conocimientos de gráficos en un caso real
  • Crear visualizaciones efectivas para el análisis de datos
  • Desarrollar un informe ejecutivo con múltiples gráficos

Instrucciones:

  1. Crear un nuevo libro llamado "Analisis_Ventas"
  2. En la primera hoja, crear un conjunto de datos con las ventas trimestrales de los últimos 3 años para al menos 5 productos diferentes
  3. Crear las siguientes visualizaciones en hojas separadas:
    • Ventas Totales: Gráfico de columnas mostrando las ventas totales por trimestre
    • Comparación de Productos: Gráfico de barras apiladas mostrando la contribución de cada producto por trimestre
    • Tendencias: Gráfico de líneas mostrando la evolución de ventas de cada producto a lo largo del tiempo
    • Distribución: Gráfico circular mostrando el porcentaje de ventas por producto en el último trimestre
    • Tablero de Control: Crear un resumen ejecutivo en una nueva hoja que incluya:
      • Métricas clave (ventas totales, crecimiento interanual, producto más vendido)
      • Minigráficos mostrando tendencias por producto
      • Un gráfico combinado que muestre ventas y crecimiento
      • Filtros para seleccionar trimestre o producto
  4. Formatear profesionalmente cada gráfico:
    • Títulos descriptivos
    • Etiquetas de datos cuando sea necesario
    • Escalas apropiadas
    • Colores consistentes para cada producto en todos los gráficos

Requisitos adicionales:

  • Usar al menos un gráfico combinado (columnas y líneas)
  • Incluir un minigráfico en la tabla de datos original
  • Agregar una segmentación de datos para filtrar por producto o período
  • Crear un diseño de página profesional para impresión

Consejo profesional:

Usa las Herramientas de gráfico > Diseño > Seleccionar datos para ajustar el rango de datos de cada gráfico sin modificar la estructura de la tabla original.

Entrega:

Guardar el archivo con el nombre "Apellido_Nombre_AnalisisVentas.xlsx" y asegurarse de que todos los gráficos se actualicen correctamente al modificar los datos.
