Semana 14: Macros Básicas en Excel

Sesión 14.1: Introducción a macros

Objetivos de aprendizaje:

  • Comprender qué son las macros y para qué sirven
  • Habilitar la pestaña Desarrollador
  • Configurar la seguridad de macros

Nota importante sobre seguridad:

Las macros pueden contener código malicioso. Solo habilita macros de fuentes confiables.

1. ¿Qué es una macro?

Una macro es una secuencia de instrucciones que automatiza tareas repetitivas en Excel. Las macros se escriben en VBA (Visual Basic for Applications).

Ejemplos de tareas que se pueden automatizar:

  • Formatear informes
  • Importar y procesar datos
  • Generar informes periódicos
  • Automatizar cálculos complejos

2. Habilitar la pestaña Desarrollador

Paso a paso:

  1. Haz clic derecho en la cinta de opciones y selecciona Personalizar la cinta de opciones
  2. Marca la casilla Desarrollador en el panel derecho
  3. Haz clic en Aceptar

3. Configuración de seguridad de macros

Para habilitar macros:

  1. Ve a la pestaña Archivo > Opciones
  2. Selecciona Centro de confianza
  3. Haz clic en Configuración del Centro de confianza...
  4. Selecciona Configuración de macros
  5. Elige la opción que mejor se adapte a tus necesidades de seguridad
  6. Haz clic en Aceptar dos veces para guardar los cambios

Ejercicio práctico:

  1. Habilita la pestaña Desarrollador en tu Excel
  2. Configura la seguridad de macros para habilitar todas las macros con notificación
  3. Explora la pestaña Desarrollador y familiarízate con sus opciones

Consejos para trabajar con macros:

  • Guarda siempre una copia de seguridad de tus archivos antes de ejecutar macros
  • Documenta tus macros con comentarios
  • Prueba las macros en datos de prueba antes de usarlas en datos reales
  • Mantén habilitada la notificación de seguridad de macros

Sesión 14.2: Grabación de macros

Objetivos de aprendizaje:

  • Grabar una macro paso a paso
  • Asignar métodos de ejecución
  • Probar y depurar macros grabadas

1. Grabar una macro básica

Paso a paso:

  1. Ve a la pestaña Desarrollador
  2. Haz clic en Grabar macro
  3. Asigna un nombre descriptivo (sin espacios)
  4. Selecciona dónde quieres guardar la macro
  5. Opcionalmente, asigna un método abreviado de teclado
  6. Haz clic en Aceptar para comenzar a grabar
  7. Realiza las acciones que deseas grabar
  8. Haz clic en Detener grabación cuando termines

2. Ejecutar una macro grabada

Métodos para ejecutar una macro:

  1. Desde el cuadro de diálogo Macros: Desarrollador > Macros > Seleccionar macro > Ejecutar
  2. Método abreviado de teclado: Si lo configuraste durante la grabación
  3. Botón de la barra de herramientas de acceso rápido: Personalízala para incluir macros

Ejercicio práctico:

Crea una macro que:

  1. Formatee un título con fuente Arial 14, negrita y color azul
  2. Inserte la fecha actual en la celda A2
  3. Formatee la fecha con el formato "dd/mm/aaaa"
  4. Asigna un botón en la hoja para ejecutar la macro

Limitaciones de la grabadora de macros:

  • No graba todas las acciones del usuario
  • Puede incluir pasos innecesarios
  • No maneja la interacción del usuario (cuadros de diálogo, mensajes)
  • No incluye lógica condicional ni bucles

Sesión 14.3: Asignación de macros a botones

Objetivos de aprendizaje:

  • Insertar controles de formulario
  • Asignar macros a botones
  • Personalizar la interfaz del usuario

1. Insertar un botón de comando

Paso a paso:

  1. Ve a la pestaña Desarrollador
  2. Haz clic en Insertar en el grupo Controles
  3. Selecciona Botón (Control de formulario)
  4. Dibuja el botón en la hoja de cálculo
  5. Selecciona la macro que deseas asignar
  6. Haz clic en Aceptar
  7. Edita el texto del botón según sea necesario

2. Personalizar botones

Opciones de formato:

  • Formato de forma: Color de relleno, borde, efectos
  • Propiedades: Bloquear, imprimir objeto, mover y cambiar tamaño con celdas
  • Texto alternativo: Descripción para accesibilidad

Ejercicio práctico:

Crea un panel de control con tres botones que realicen las siguientes acciones:

  1. Formatear informe: Aplica formato a un rango de datos
  2. Calcular totales: Realiza cálculos automáticos
  3. Limpiar hoja: Prepara la hoja para un nuevo informe

Buenas prácticas para interfaces de usuario:

  • Usa nombres descriptivos para botones y controles
  • Agrupa controles relacionados
  • Usa colores consistentes
  • Incluye instrucciones claras
  • Prueba la interfaz con usuarios finales

Sesión 14.4: Práctica guiada - Automatización de tareas

Objetivos de la práctica:

  • Aplicar los conceptos de macros en un proyecto real
  • Automatizar un flujo de trabajo completo
  • Crear una interfaz de usuario amigable

1. Caso de estudio: Sistema de reportes

Desarrollarás un sistema automatizado para generar reportes de ventas que incluya:

  • Importación de datos desde una hoja de cálculo
  • Procesamiento y limpieza de datos
  • Generación de resúmenes y gráficos
  • Exportación del informe final

2. Planificación del proyecto

  1. Identifica las tareas repetitivas que se pueden automatizar
  2. Diseña la estructura de las hojas de cálculo
  3. Crea un diagrama de flujo del proceso
  4. Diseña la interfaz de usuario

Ejercicio práctico:

Desarrolla un libro de Excel con las siguientes características:

  1. Hoja de datos: Para ingresar información de ventas
  2. Hoja de resumen: Muestra totales y promedios
  3. Panel de control: Con botones para:
    • Importar datos
    • Procesar información
    • Generar informe
    • Exportar a PDF
  4. Validación de datos: Para asegurar la integridad de la información

Entrega del proyecto:

Prepara para entregar:

  1. El archivo de Excel con las macros habilitadas
  2. Un documento con instrucciones de uso
  3. Un informe que explique:
    • Las tareas que automatizaste
    • Los desafíos que enfrentaste
    • Las mejoras de eficiencia logradas

Consejos para el desarrollo de macros:

  • Empieza con versiones simples y ve añadiendo complejidad
  • Prueba cada función por separado
  • Documenta tu código con comentarios
  • Maneja los posibles errores
  • Considera crear una copia de seguridad de los datos antes de procesarlos
