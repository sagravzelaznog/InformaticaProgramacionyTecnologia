Semana 8: Repaso y Evaluación Básica de Excel

Sesión 8.1: Repaso de conceptos básicos

Objetivos de aprendizaje:

  • Revisar los conceptos fundamentales de Excel
  • Identificar áreas que requieren refuerzo
  • Prepararse para la evaluación final

1. Interfaz de Excel

  • Barra de herramientas de acceso rápido
  • Cinta de opciones y pestañas
  • Barra de fórmulas
  • Hojas de cálculo y pestañas
  • Barra de estado

2. Operaciones básicas

  • Crear, abrir y guardar archivos
  • Manejo de celdas, filas y columnas
  • Formato de celdas (fuente, alineación, bordes, relleno)
  • Copiar, cortar y pegar
  • Deshacer y rehacer

3. Fórmulas básicas

  • Operadores matemáticos (+, -, *, /, ^)
  • Referencias de celdas (relativas, absolutas, mixtas)
  • Funciones básicas (SUMA, PROMEDIO, MÁX, MÍN, CONTAR)

4. Formato de tablas

  • Convertir datos en tablas
  • Estilos de tabla
  • Filtros y ordenamiento

5. Gráficos básicos

  • Tipos de gráficos
  • Creación y formato
  • Elementos del gráfico

Ejercicio de repaso 1:

Crea una hoja de cálculo que incluya:

  1. Una tabla con ventas mensuales de tres productos diferentes
  2. Fórmulas para calcular totales, promedios y porcentajes
  3. Formato condicional para resaltar valores altos y bajos
  4. Un gráfico que muestre la comparación de ventas por producto

Sesión 8.2: Práctica guiada - Proyecto integrador

Objetivos:

  • Aplicar todos los conceptos aprendidos
  • Desarrollar un proyecto completo de principio a fin
  • Resolver problemas del mundo real

Proyecto: Control de gastos personales

Crea un libro de Excel para llevar el control de tus gastos personales con las siguientes características:

1. Hoja "Registro de Gastos"
  • Columnas: Fecha, Descripción, Categoría, Monto, Forma de pago
  • Validación de datos para Categoría y Forma de pago
  • Formato condicional para gastos altos
2. Hoja "Resumen por Categoría"
  • Tabla dinámica que muestre totales por categoría
  • Gráfico circular de distribución de gastos
  • Filtros por mes y año
3. Hoja "Presupuesto"
  • Límites de gasto por categoría
  • Comparativo entre presupuesto y gasto real
  • Indicadores visuales de cumplimiento
4. Hoja "Análisis"
  • Tendencias de gastos a lo largo del tiempo
  • Comparativo mes a mes
  • Recomendaciones de ahorro
Requisitos adicionales:
  • Fórmulas para cálculos automáticos
  • Formato profesional y consistente
  • Protección de celdas con fórmulas
  • Hipervínculos entre hojas

Consejos para el proyecto:

  • Planifica antes de empezar a crear el libro
  • Usa nombres de rango para hacer las fórmulas más legibles
  • Guarda versiones de respaldo de tu trabajo
  • Prueba todas las funcionalidades antes de dar por terminado

Sesión 8.3: Simulacro de evaluación

Objetivos:

  • Poner a prueba tus conocimientos
  • Identificar áreas de mejora
  • Practicar bajo condiciones similares al examen

Parte 1: Preguntas teóricas (30 minutos)

1. ¿Cuál es la diferencia entre una referencia de celda relativa y absoluta?
a) Las relativas cambian al copiarse, las absolutas no
b) Las absolutas cambian al copiarse, las relativas no
c) No hay diferencia, son lo mismo
d) Las relativas solo funcionan en la misma hoja
2. ¿Qué función usarías para contar el número de celdas que contienen números en un rango?
a) =CONTAR()
b) =CONTARA()
c) =CONTAR.SI()
d) =SUMA()
3. ¿Cuál es el orden correcto de las partes de una función SI?
a) =SI(acción, condición, valor_si_falso, valor_si_verdadero)
b) =SI(condición, valor_si_verdadero, valor_si_falso)
c) =SI(valor_si_verdadero, condición, valor_si_falso)
d) =SI(condición, valor_si_falso, valor_si_verdadero)

Parte 2: Ejercicios prácticos (60 minutos)

Ejercicio 1: Crea una tabla con los siguientes datos de empleados y calcula el bono anual (5% del salario si tiene más de 3 años de antigüedad, 3% en caso contrario).

Ejercicio 2: Usando los datos de ventas proporcionados, crea un resumen que muestre el total de ventas por región y por producto, con un gráfico de barras que lo represente visualmente.

Ejercicio 3: Crea una hoja de cálculo que calcule el pago mensual de un préstamo, permitiendo al usuario ingresar el monto, la tasa de interés y el plazo en meses.

Parte 3: Resolución de problemas (30 minutos)

Analiza el siguiente escenario y crea una solución en Excel:

"Eres el encargado de organizar un evento. Tienes un presupuesto limitado y necesitas controlar los gastos en diferentes categorías (alimentos, materiales, publicidad, etc.). Crea un sistema que te permita llevar el control del presupuesto, registrar gastos reales y mostrar un resumen del estado de cada categoría."
