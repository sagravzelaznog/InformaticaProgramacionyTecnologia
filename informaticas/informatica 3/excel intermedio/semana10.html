Semana 10: Funciones Avanzadas II en Excel

Sesión 10.1: Funciones de texto avanzadas

Objetivos de aprendizaje:

  • Dominar funciones avanzadas de manipulación de texto
  • Automatizar la limpieza y formato de datos de texto
  • Crear fórmulas complejas combinando funciones de texto

1. Funciones esenciales de texto

a) EXTRAE - Extraer partes de un texto

=EXTRAE(texto, posición_inicial, núm_caracteres)

Ejemplo: Extraer los primeros 3 caracteres de un código de producto

=EXTRAE(A2, 1, 3)

Si A2 contiene "PROD-001", devuelve "PRO"

b) ENCONTRAR y ENCONTRARB - Localizar texto dentro de otro

=ENCONTRAR(texto_buscado, texto_donde_buscar, [núm_inicial])

Ejemplo: Encontrar la posición del guión en un código

=ENCONTRAR("-", A2)

Si A2 contiene "PROD-001", devuelve 5

c) SUSTITUIR y SUSTITUIR.DEFINIDO - Reemplazar texto

=SUSTITUIR(texto, texto_antiguo, texto_nuevo, [núm_de_aparición])

Ejemplo: Cambiar guiones por espacios

=SUSTITUIR(A2, "-", " ")

Si A2 contiene "PROD-001", devuelve "PROD 001"

2. Funciones avanzadas de texto

a) UNICAR y UNICODECAR - Trabajar con caracteres especiales

=UNICAR(número)
=UNICODECAR(texto)

b) TEXTO - Formatear números como texto

=TEXTO(valor, formato_texto)

Ejemplo: Formatear una fecha

=TEXTO(AHORA(), "dddd, d \de mmmm \de yyyy")

Devuelve: "martes, 15 de julio de 2025"

c) VALOR - Convertir texto a número

=VALOR(texto)

3. Combinación de funciones para casos prácticos

Ejemplo 1: Extraer el primer nombre

Dado un nombre completo en A2 (ej. "Juan Pérez"):

=IZQUIERDA(A2, ENCONTRAR(" ", A2 & " ")-1)

Ejemplo 2: Extraer el dominio de un correo electrónico

Dado un correo en A3 (ej. "usuario@ejemplo.com"):

=DERECHA(A3, LARGO(A3)-ENCONTRAR("@", A3))

Ejercicio práctico:

Dada una lista de códigos de producto en el formato "PAIS-CODIGO-COLOR" (ej: "MEX-001-AZUL"):

  1. Extraer el código de país (primeros 3 caracteres después del primer guión)
  2. Extraer el número de producto (entre guiones)
  3. Extraer el color (después del segundo guión)
  4. Crear una descripción formateada: "Producto [código] de color [color]"

Consejos para trabajar con texto:

  • Usa MAYUSC(), MINUSC() y NOMPROPIO() para estandarizar texto
  • Combina ESPACIOS() con IZQUIERDA() para alinear texto
  • Usa REPETIR() para crear separadores visuales
  • Considera usar la herramienta "Texto en columnas" para tareas de extracción comunes

Sesión 10.2: Funciones de fecha y hora avanzadas

Objetivos de aprendizaje:

  • Dominar funciones avanzadas de fecha y hora
  • Calcular diferencias entre fechas
  • Trabajar con días laborables y festivos

1. Funciones esenciales de fecha y hora

a) FECHA - Crear una fecha a partir de componentes

=FECHA(año, mes, día)

b) DIA, MES, AÑO - Extraer componentes de una fecha

=DIA(fecha)
=MES(fecha)
=AÑO(fecha)

2. Cálculos con fechas

a) DIFERENCIA - Calcular días entre fechas

=DIAS(fecha_final, fecha_inicial)

b) DIA.LAB - Calcular fechas laborables

=DIA.LAB(fecha_inicio, días, [festivos])

Ejercicio práctico:

Calcular la fecha de vencimiento de un proyecto que comienza hoy y tiene una duración de 15 días laborables, excluyendo fines de semana y festivos.

Sesión 10.3: Funciones de base de datos

Objetivos de aprendizaje:

  • Utilizar funciones de base de datos en Excel
  • Realizar búsquedas y cálculos condicionales
  • Automatizar informes con tablas dinámicas

1. Funciones de base de datos esenciales

a) BDSUMA - Sumar valores que cumplen criterios

=BDSUMA(base_datos, campo, criterios)

b) BDPROMEDIO - Calcular promedio con criterios

=BDPROMEDIO(base_datos, campo, criterios)

Ejercicio práctico:

Crear un informe de ventas por región y producto utilizando funciones de base de datos.

Sesión 10.4: Práctica guiada - Análisis de datos temporales

Objetivos de la práctica:

  • Aplicar funciones avanzadas de texto, fecha y base de datos
  • Crear un panel de análisis de series temporales
  • Automatizar informes con fórmulas dinámicas

Instrucciones:

  1. Importar datos de ventas mensuales
  2. Limpiar y formatear los datos utilizando funciones de texto
  3. Calcular métricas clave utilizando funciones de fecha y base de datos
  4. Crear un panel de control interactivo

Proyecto final:

Desarrolla un sistema de seguimiento de proyectos que incluya:

  • Cálculo automático de fechas de vencimiento
  • Seguimiento de días hábiles transcurridos
  • Alertas de vencimiento próximos
  • Informes por departamento y estado
