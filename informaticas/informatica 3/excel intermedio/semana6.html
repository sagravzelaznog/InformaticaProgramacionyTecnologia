Semana 6: Tablas y Filtros en Excel

Sesión 6.1: Creación y formato de tablas

Objetivos de aprendizaje:

  • Convertir rangos de datos en tablas de Excel
  • Personalizar el formato de las tablas
  • Utilizar las ventajas de trabajar con tablas

Contenido detallado:

  1. Creación de una tabla:
    • Selección del rango de datos
    • Conversión a tabla (Ctrl + T)
    • Inclusión de encabezados
  2. Elementos de una tabla:
    • Encabezados de columna
    • Filas con bandas
    • Fila de totales
    • Botones de filtro
  3. Estilos y formato:
    • Estilos predefinidos
    • Personalización de colores y fuentes
    • Opciones de estilo de tabla
  4. Ventajas de usar tablas:
    • Expansión automática
    • Fórmulas estructuradas
    • Filtros integrados
    • Tablas dinámicas mejoradas

Ejemplo práctico:

Convertir un rango de datos de ventas en una tabla y aplicar formato profesional:

  1. Seleccionar los datos (incluyendo encabezados)
  2. Insertar > Tabla (o Ctrl + T)
  3. Verificar "La tabla tiene encabezados"
  4. Aplicar un estilo de tabla
  5. Activar la fila de totales

Actividad práctica:

Tomar un conjunto de datos sin formato, convertirlo en una tabla y aplicar un formato profesional que incluya bandas de fila, estilos de encabezado y una fila de totales con fórmulas básicas.

Sesión 6.2: Ordenamiento de datos

Objetivos de aprendizaje:

  • Ordenar datos en una tabla de Excel
  • Crear criterios de ordenamiento personalizados
  • Ordenar por color o formato

Contenido detallado:

  1. Ordenamiento básico:
    • Orden ascendente/descendente
    • Ordenamiento por una columna
    • Uso de los botones de ordenamiento
  2. Ordenamiento avanzado:
    • Ordenamiento por múltiples columnas
    • Ordenamiento personalizado (meses, días, etc.)
    • Ordenamiento por color de celda o fuente
    • Ordenamiento por formato condicional
  3. Consideraciones:
    • Mantener filas juntas al ordenar
    • Ordenamiento de rangos vs. tablas
    • Problemas comunes y soluciones

Ejercicio práctico:

Dada la siguiente tabla de ventas:

Vendedor Región Ventas Fecha
Ana Norte $1,250 15/03/2023
Carlos Sur $890 16/03/2023

Realizar los siguientes ordenamientos:

  1. Ordenar por Vendedor (A-Z)
  2. Ordenar por Ventas (de mayor a menor)
  3. Ordenar primero por Región y luego por Ventas

Actividad práctica:

Crear un informe de ventas con datos de todo el año y practicar diferentes tipos de ordenamiento para analizar los datos desde diferentes perspectivas.

Sesión 6.3: Filtros básicos y avanzados

Objetivos de aprendizaje:

  • Aplicar filtros a conjuntos de datos
  • Utilizar criterios de filtrado avanzados
  • Trabajar con filtros por color y formato

Contenido detallado:

  1. Filtros básicos:
    • Activación/desactivación de filtros
    • Filtrado por valores específicos
    • Búsqueda en filtros
  2. Criterios de filtrado avanzados:
    • Filtros de texto (contiene, comienza con, termina con)
    • Filtros numéricos (mayor que, entre, los 10 principales)
    • Filtros de fecha (hoy, esta semana, este mes, trimestre, año)
    • Filtros personalizados
  3. Filtros especiales:
    • Filtrado por color de celda o fuente
    • Filtrado por formato condicional
    • Filtros en tablas dinámicas
  4. Consejos avanzados:
    • Copiar datos filtrados
    • Contar y sumar datos filtrados
    • Uso de SUBTOTAL con filtros

Ejemplo práctico:

Dada una base de datos de empleados con las columnas: Nombre, Departamento, Salario, Fecha de Ingreso, Evaluación.

Crear los siguientes filtros:

  1. Mostrar solo empleados del departamento de Ventas
  2. Mostrar empleados con salario mayor a $50,000
  3. Mostrar empleados que ingresaron en el último año
  4. Mostrar empleados con evaluaciones altas (usando filtro por color)

Actividad práctica:

Tomar un conjunto de datos grande (más de 100 filas) y practicar diferentes técnicas de filtrado para extraer información específica, como ventas por región, productos con bajo inventario, o clientes inactivos.

Sesión 6.4: Práctica guiada - Análisis de base de datos

Objetivos de la práctica:

  • Aplicar los conocimientos de tablas y filtros en un caso real
  • Crear un sistema de análisis de datos completo
  • Extraer conclusiones a partir de datos filtrados

Instrucciones:

  1. Crear un nuevo libro llamado "Analisis_Base_Datos"
  2. En la primera hoja, importar o crear un conjunto de datos con al menos 100 registros que incluya:
    • Información de clientes (ID, nombre, ciudad, estado, código postal)
    • Información de productos (ID, categoría, precio, costo)
    • Registros de ventas (ID venta, ID cliente, ID producto, cantidad, fecha, descuento)
  3. Convertir cada conjunto de datos en una tabla con formato profesional
  4. Realizar las siguientes tareas de análisis:
    1. Crear una tabla de resumen que muestre las ventas totales por cliente
    2. Identificar los 5 productos más vendidos
    3. Calcular el margen de beneficio por producto
    4. Identificar patrones de compra por región geográfica
    5. Crear un análisis de ventas por período (mensual/trimestral)
  5. Para cada análisis:
    • Utilizar tablas para organizar los datos
    • Aplicar filtros para segmentar la información
    • Usar ordenamiento para identificar tendencias
    • Crear gráficos para visualizar los hallazgos

Requisitos adicionales:

  • Crear un panel de control con segmentación de datos para filtrar la información
  • Incluir al menos un filtro avanzado con criterios personalizados
  • Usar fórmulas como SUBTOTAL para trabajar con datos filtrados
  • Crear un resumen ejecutivo con los hallazgos más importantes

Consejo profesional:

Utiliza la función TABLAS DINÁMICAS junto con los filtros estándar para un análisis más potente. Las tablas dinámicas te permitirán resumir y analizar grandes cantidades de datos de manera eficiente.

Entrega:

Guardar el archivo con el nombre "Apellido_Nombre_AnalisisBD.xlsx" y asegurarse de que todas las tablas y filtros funcionen correctamente. Incluir una hoja de respuestas con las conclusiones del análisis.
