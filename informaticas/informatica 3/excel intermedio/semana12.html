Semana 12: Gráficos Avanzados en Excel

Sesión 12.1: Gráficos combinados

Objetivos de aprendizaje:

  • Comprender el concepto de gráficos combinados
  • Crear gráficos que combinan diferentes tipos de visualización
  • Personalizar ejes secundarios

1. ¿Qué son los gráficos combinados?

Los gráficos combinados permiten visualizar diferentes series de datos utilizando distintos tipos de gráficos en un solo gráfico, lo que facilita la comparación de datos con diferentes escalas o unidades de medida.

Ejemplo de uso:

Mostrar ventas en barras (eje primario) y porcentaje de crecimiento en línea (eje secundario).

2. Creación de un gráfico combinado

Paso 1: Preparar los datos

  • Organiza tus datos en columnas
  • Asegúrate de tener etiquetas para cada serie
  • Incluye los valores para cada categoría

Paso 2: Insertar gráfico combinado

  1. Selecciona los datos que deseas graficar
  2. Ve a la pestaña Insertar
  3. Haz clic en Grafíco recomendado
  4. Selecciona la pestaña Todos los gráficos
  5. Elige Combinado en la columna izquierdaSelecciona el tipo de combinación deseado
  6. Haz clic en Aceptar

Ejercicio práctico:

Crea un informe de ventas que muestre:

  1. Ventas mensuales en columnas agrupadas
  2. Porcentaje de crecimiento en línea con marcadores
  3. Personaliza los ejes para mejor legibilidad
  4. Agrega etiquetas de datos relevantes

Consejos para gráficos combinados:

  • Usa colores contrastantes para diferenciar las series
  • Considera usar un eje secundario para series con diferentes escalas
  • Etiqueta claramente cada eje
  • Usa títulos descriptivos

Sesión 12.2: Gráficos dinámicos

Objetivos de aprendizaje:

  • Crear gráficos que se actualizan automáticamente
  • Vincular gráficos a tablas dinámicas
  • Crear dashboards interactivos

1. Gráficos basados en tablas dinámicas

Crear un gráfico dinámico:

  1. Crea una tabla dinámica con tus datos
  2. Selecciona cualquier celda dentro de la tabla dinámica
  3. Ve a la pestaña Analizar
  4. Haz clic en Grafíco dinámico
  5. Selecciona el tipo de gráfico y haz clic en Aceptar

2. Actualización automática

Los gráficos dinámicos se actualizan automáticamente cuando:

  • Se modifican los datos de origen
  • Se cambian los filtros de la tabla dinámica
  • Se actualizan los campos mostrados

Ejercicio práctico:

Crea un panel de control interactivo que incluya:

  1. Una tabla dinámica con datos de ventas
  2. Un gráfico de barras que muestre ventas por región
  3. Un gráfico circular que muestre la participación de mercado
  4. Segmentaciones para filtrar por período y categoría

Sesión 12.3: Minigráficos

Objetivos de aprendizaje:

  • Crear y personalizar minigráficos
  • Utilizar minigráficos para análisis rápido
  • Combinar minigráficos con formato condicional

1. Tipos de minigráficos

  • Línea: Muestra tendencias a lo largo del tiempo
  • Columna: Compara valores individuales
  • Ganancias/pérdidas: Muestra valores positivos y negativos

Insertar minigráficos:

  1. Selecciona el rango de datos
  2. Ve a la pestaña Insertar
  3. En el grupo Minigráficos, selecciona el tipo deseado
  4. Especifica el rango de ubicación
  5. Haz clic en Aceptar

Ejercicio práctico:

Crea un informe de seguimiento de ventas que incluya:

  1. Ventas semanales por producto
  2. Minigráficos de línea que muestren la tendencia de cada producto
  3. Formato condicional para resaltar valores atípicos
  4. Filtros para analizar diferentes períodos

Sesión 12.4: Práctica guiada - Dashboard ejecutivo

Objetivos de la práctica:

  • Integrar diferentes tipos de gráficos avanzados
  • Crear un dashboard ejecutivo interactivo
  • Automatizar la presentación de informes

1. Preparación de datos

  1. Descarga el conjunto de datos proporcionado
  2. Limpia y organiza los datos según sea necesario
  3. Crea tablas dinámicas para diferentes análisis

2. Diseño del dashboard

Crea las siguientes secciones en tu dashboard:

  • Resumen ejecutivo: KPI principales
  • Análisis de ventas: Gráfico combinado de tendencias
  • Distribución por categoría: Gráfico circular o de anillo
  • Comparativo por región: Gráfico de columnas agrupadas
  • Tendencias mensuales: Minigráficos por línea de producto

3. Interactividad

  1. Agrega segmentaciones de datos para filtrar por período, región y categoría
  2. Configura los filtros para que afecten a todas las tablas y gráficos
  3. Agreba botones de control para mostrar/ocultar secciones

Ejercicio final:

Prepara una presentación ejecutiva que incluya:

  1. Una introducción a los datos y objetivos del análisis
  2. Hallazgos clave basados en el dashboard
  3. Recomendaciones estratégicas
  4. Un resumen ejecutivo con conclusiones

Entrega del proyecto:

Guarda tu archivo como "Dashboard_Ejecutivo_TuNombre.xlsx" y asegúrate de que:

  • Todos los gráficos se actualicen correctamente con los filtros
  • El diseño sea profesional y consistente
  • Incluyas una hoja con instrucciones de uso
  • El archivo esté protegido para evitar modificaciones accidentales

Consejos para presentaciones ejecutivas:

  • Usa una paleta de colores profesional
  • Mantén la consistencia en fuentes y estilos
  • Destaca los puntos clave con gráficos impactantes
  • Prepara versiones estáticas para impresión
  • Incluye un resumen ejecutivo en la primera hoja
