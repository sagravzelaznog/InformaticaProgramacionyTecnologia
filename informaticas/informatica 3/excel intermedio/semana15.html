Semana 15: Importación y Exportación de Datos en Excel

Sesión 15.1: Importación de datos desde archivos de texto

Objetivos de aprendizaje:

  • Importar datos desde archivos de texto (CSV, TXT)
  • Configurar correctamente el asistente de importación
  • Manejar diferentes formatos de datos durante la importación

1. Formatos de archivo compatibles

Archivos de texto plano (.txt, .csv)

Características:

  • CSV (Valores Separados por Comas)
  • Campos delimitados por comas, punto y coma o tabulaciones
  • Sin formato de texto enriquecido

2. Proceso de importación

Paso a paso para importar:

  1. Ve a la pestaña Datos
  2. Haz clic en Obtener datos > Desde archivo > Desde texto/CSV
  3. Navega hasta la ubicación del archivo y selecciónalo
  4. En la ventana de vista previa, configura:
    • Juego de caracteres (generalmente 65001: Unicode UTF-8)
    • Delimitador (coma, tabulador, etc.)
    • Formato de datos para cada columna
  5. Haz clic en Cargar o Transformar datos según necesites

Ejercicio práctico:

  1. Descarga un archivo CSV de datos de ejemplo (por ejemplo, datos meteorológicos o de ventas)
  2. Importa los datos a Excel, asegurándote de que:
    • Las fechas se importen correctamente
    • Los números con decimales usen el formato correcto
    • Los encabezados se reconozcan correctamente
  3. Aplica formato de tabla a los datos importados

Consejos para importación de datos:

  • Revisa siempre la vista previa antes de importar
  • Configura el tipo de datos correcto para cada columna
  • Considera usar "Transformar datos" para limpieza adicional
  • Guarda una copia de los datos originales

Sesión 15.2: Conexión a fuentes de datos externas

Objetivos de aprendizaje:

  • Conectar Excel a bases de datos externas
  • Importar datos desde la web
  • Actualizar conexiones de datos

1. Tipos de conexiones de datos

Fuentes de datos soportadas:

  • Bases de datos SQL (SQL Server, Access, MySQL, etc.)
  • Servicios web y API REST
  • Archivos de Excel y Access
  • Servicios de análisis (Analysis Services)
  • Otros orígenes OLE DB u ODBC

2. Conexión a una base de datos

Para conectar a una base de datos SQL:

  1. Ve a la pestaña Datos
  2. Haz clic en Obtener datos > Desde base de datos > Desde SQL Server
  3. Ingresa el nombre del servidor y las credenciales
  4. Selecciona la base de datos y la(s) tabla(s) que deseas importar
  5. Configura las opciones de carga (carga directa o modelo de datos)
  6. Haz clic en Cargar

3. Importar datos desde la web

Ejercicio práctico:

Importa datos de una página web a Excel:

  1. Ve a la pestaña Datos > Obtener datos > Desde la web
  2. Ingresa la URL de una página web con datos tabulares (por ejemplo, una tabla de tasas de cambio)
  3. En el navegador de consultas, selecciona la tabla que deseas importar
  4. Configura las opciones de carga y haz clic en Cargar
  5. Configura la actualización automática de los datos

Consideraciones de seguridad:

  • Nunca compartas archivos con conexiones a bases de datos que contengan credenciales sensibles
  • Usa la autenticación de Windows cuando sea posible
  • Considera usar consultas con parámetros para limitar la cantidad de datos recuperados

Sesión 15.3: Power Query básico

Objetivos de aprendizaje:

  • Introducción a Power Query Editor
  • Transformaciones básicas de datos
  • Combinar y anexar consultas

1. Interfaz de Power Query Editor

Componentes principales:

  • Cinta de opciones: Contiene todas las herramientas de transformación
  • Panel de consultas: Muestra todas las consultas en el libro actual
  • Vista previa de datos: Muestra los datos de la consulta seleccionada
  • Configuración de consulta: Muestra los pasos aplicados

2. Transformaciones comunes

Operaciones básicas:

  1. Eliminar filas: Filtrar, quitar duplicados, quinar filas en blanco
  2. Dividir columnas: Por delimitador, por número de caracteres
  3. Cambiar tipos de datos: Texto, números, fechas
  4. Reemplazar valores: Valores nulos o específicos
  5. Ordenar y filtrar: Orden ascendente/descendente, filtros básicos

Ejercicio práctico:

Crea una consulta que:

  1. Importe datos de un archivo CSV con información de ventas
  2. Limpie los datos:
    • Elimina filas con valores faltantes
    • Cambia los tipos de datos según corresponda
    • Divide la columna "Nombre completo" en "Nombre" y "Apellido"
  3. Crea una columna personalizada que calcule el total de ventas (cantidad * precio unitario)
  4. Agrupa los datos por categoría y calcula el total de ventas por categoría

Buenas prácticas en Power Query:

  • Nombra tus consultas de manera descriptiva
  • Documenta los pasos importantes
  • Usa la vista previa para verificar cada transformación
  • Considera el rendimiento al trabajar con grandes volúmenes de datos

Sesión 15.4: Práctica guiada - Flujo de trabajo de datos completo

Objetivos de la práctica:

  • Integrar múltiples fuentes de datos
  • Automatizar la actualización de informes
  • Crear un panel de control interactivo

1. Preparación del entorno

  1. Crea una carpeta para tu proyecto
  2. Descarga los siguientes archivos de ejemplo:
    • Un archivo CSV con datos de ventas
    • Un archivo Excel con información de productos
    • Un archivo de texto con datos de inventario

2. Importación y transformación de datos

Crea consultas para cada fuente de datos:

  1. Importa cada archivo a Power Query
  2. Aplica las transformaciones necesarias
  3. Combina las consultas según sea necesario
  4. Crea medidas calculadas

Ejercicio práctico:

Desarrolla un informe de análisis de ventas que incluya:

  1. Hoja de resumen: Con KPIs principales
  2. Análisis por producto: Ventas, márgenes, rendimiento
  3. Análisis temporal: Tendencias mensuales y estacionalidad
  4. Panel de control: Con gráficos interactivos
  5. Botones de actualización: Para actualizar todos los datos con un clic

Entrega del proyecto:

Prepara para entregar:

  1. El archivo de Excel con todas las conexiones configuradas
  2. Un documento con instrucciones de uso
  3. Un informe que explique:
    • Las fuentes de datos utilizadas
    • Las transformaciones aplicadas
    • Los hallazgos clave del análisis
    • Las limitaciones y posibles mejoras

Consejos para el flujo de trabajo de datos:

  • Mantén tus datos fuente organizados
  • Documenta tus procesos de ETL (Extracción, Transformación y Carga)
  • Prueba las actualizaciones de datos periódicamente
  • Considera la automatización con Power Automate para flujos de trabajo recurrentes
  • Implementa controles de calidad de datos
