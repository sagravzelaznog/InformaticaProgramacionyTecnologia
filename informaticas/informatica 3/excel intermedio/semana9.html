Semana 9: Funciones Avanzadas I en Excel

Sesión 9.1: Funciones BUSCARV y BUSCARH

Objetivos de aprendizaje:

  • Comprender el funcionamiento de BUSCARV y BUSCARH
  • Aplicar estas funciones en diferentes escenarios
  • Resolver problemas comunes al usar estas funciones

1. Función BUSCARV

=BUSCARV(valor_buscado, matriz_buscar_en, indicador_columnas, [ordenado])

Parámetros:

  • valor_buscado: El valor que deseas encontrar en la primera columna de la matriz
  • matriz_buscar_en: El rango de celdas que contiene los datos
  • indicador_columnas: El número de columna en la matriz que contiene el valor de retorno
  • ordenado: Opcional. VERDADERO (o 1) para búsqueda aproximada, FALSO (o 0) para búsqueda exacta

Ejemplo práctico:

Dada la siguiente tabla de productos:

ID Producto Precio Stock
P001 Lápiz $5.00 150
P002 Cuaderno $45.00 80

Para buscar el precio del producto con ID "P002":

=BUSCARV("P002", A2:D3, 3, FALSO)

Resultado: $45.00

2. Función BUSCARH

=BUSCARH(valor_buscado, matriz_buscar_en, indicador_filas, [ordenado])

Funciona igual que BUSCARV pero busca en la primera fila en lugar de la primera columna.

Ejemplo práctico:

Dada la siguiente tabla horizontal:

Dato Ene Feb Mar
Ventas $12,500 $15,300 $18,750

Para buscar las ventas de febrero:

=BUSCARH("Feb", A1:D2, 2, FALSO)

Resultado: $15,300

Ejercicio práctico:

Crea una hoja de cálculo con dos pestañas:

  1. En la primera pestaña, crea una base de datos de empleados con las columnas: ID, Nombre, Departamento, Salario, Fecha de Ingreso.
  2. En la segunda pestaña, crea un formulario de búsqueda donde puedas ingresar un ID y automáticamente se muestren todos los datos del empleado.
  3. Agrega validación para mostrar un mensaje si el empleado no se encuentra.

Consejos para BUSCARV y BUSCARH:

  • Usa referencias absolutas ($A$1:$D$100) para la matriz de búsqueda
  • Considera usar BUSCARV con FALSO para búsquedas exactas
  • Para evitar errores, usa SI.ERROR con BUSCARV: =SI.ERROR(BUSCARV(...), "No encontrado")
  • Ordena los datos si usas búsqueda aproximada (VERDADERO)

Sesión 9.2: Funciones INDICE y COINCIDIR

Objetivos de aprendizaje:

  • Comprender las funciones INDICE y COINCIDIR
  • Aprender a combinarlas para búsquedas más flexibles
  • Comparar con BUSCARV y entender cuándo usar cada una

1. Función INDICE

=INDICE(matriz, núm_fila, [núm_columna])

Parámetros:

  • matriz: Rango de celdas o constante de matriz
  • núm_fila: Número de fila en la matriz desde la que devolver un valor
  • núm_columna: Opcional. Número de columna en la matriz desde la que devolver un valor

2. Función COINCIDIR

=COINCIDIR(valor_buscado, matriz_buscar_en, [tipo_coincidencia])

Parámetros:

  • valor_buscado: El valor que deseas encontrar
  • matriz_buscar_en: Rango de celdas en el que buscar
  • tipo_coincidencia: 1 (menor que), 0 (exacto), -1 (mayor que)

3. Combinando INDICE y COINCIDIR

La combinación de estas funciones permite búsquedas más flexibles que BUSCARV.

Ejemplo práctico:

Dada la siguiente tabla de productos:

ID Producto Precio Categoría
P001 Lápiz $5.00 Escolar

Para buscar el precio de un producto por su nombre:

=INDICE(C2:C100, COINCIDIR("Lápiz", B2:B100, 0))

Resultado: $5.00

Ventajas sobre BUSCARV:

  • Puedes buscar en cualquier columna, no solo en la primera
  • Puedes buscar hacia la izquierda
  • Mayor flexibilidad en la estructura de datos

Ejercicio práctico:

Crea una hoja de cálculo con los siguientes datos:

  1. Una tabla con información de empleados (ID, Nombre, Departamento, Salario, Fecha de Ingreso)
  2. Crea un panel de búsqueda que permita buscar por cualquier campo (nombre, departamento, etc.)
  3. Muestra todos los datos del empleado encontrado
  4. Agrega validación para manejar casos donde no se encuentre el empleado

Cuándo usar INDICE/COINCIDIR vs BUSCARV:

  • Usa BUSCARV cuando:
    • La columna de búsqueda está a la izquierda de la columna de resultado
    • Necesitas una solución más simple y legible
    • El rendimiento es crítico (ligeramente más rápido que INDICE/COINCIDIR)
  • Usa INDICE/COINCIDIR cuando:
    • Necesitas buscar en columnas a la izquierda
    • Tu tabla de búsqueda no está ordenada
    • Necesitas más flexibilidad en tus búsquedas

Sesión 9.3: Funciones INDIRECTO y DESREF

Objetivos de aprendizaje:

  • Dominar las funciones INDIRECTO y DESREF
  • Crear referencias dinámicas en fórmulas
  • Construir informes y paneles de control flexibles

1. Función INDIRECTO

=INDIRECTO(ref_text, [a1])

Parámetros:

  • ref_text: Texto que representa una referencia de celda
  • a1: Opcional. Valor lógico que especifica el tipo de referencia (VERDADERO para referencia A1, FALSO para R1C1)

Ejemplo 1: Referencia simple

Si la celda A1 contiene el texto "B2" y la celda B2 contiene "Hola":

=INDIRECTO(A1)

Resultado: Hola

Ejemplo 2: Referencia a otra hoja

=INDIRECTO("'"&A1&"'!B2")

Donde A1 contiene el nombre de la hoja

2. Función DESREF

=DESREF(referencia, filas, columnas, [alto], [ancho])

Parámetros:

  • referencia: Punto de partida
  • filas: Número de filas a desplazarse (positivo abajo, negativo arriba)
  • columnas: Número de columnas a desplazarse (positivo a la derecha, negativo a la izquierda)
  • alto: Opcional. Alto del rango a devolver
  • ancho: Opcional. Ancho del rango a devolver

Ejemplo 1: Referencia a una celda

=DESREF(A1, 2, 3)

Devuelve el valor de la celda que está 2 filas abajo y 3 columnas a la derecha de A1 (es decir, D3)

Ejemplo 2: Referencia a un rango

=SUMA(DESREF(A1,1,1,3,2))

Suma un rango de 3 filas y 2 columnas que comienza una fila abajo y una columna a la derecha de A1 (B2:C4)

3. Usos avanzados

Tabla dinámica de resumen

Crea un resumen que cambia según la selección del usuario:

  1. Crea una lista desplegable con los meses del año
  2. Usa INDICE/COINCIDIR para encontrar la fila y columna correctas
  3. Usa DESREF para crear un rango dinámico alrededor de la celda encontrada

Dashboard con múltiples hojas

Crea un panel de control que consolide datos de múltiples hojas:

=INDIRECTO(A1&"!B2")

Donde A1 contiene el nombre de la hoja

Ejercicio práctico:

Crea un libro de Excel con:

  1. Una hoja por cada región (Norte, Sur, Este, Oeste) con ventas mensuales
  2. Una hoja de resumen que permita seleccionar una región y muestre un gráfico con las ventas de esa región
  3. Usa INDIRECTO para referenciar dinámicamente la hoja seleccionada
  4. Usa DESREF para crear rangos dinámicos que se ajusten automáticamente si se agregan más meses

Consejos para INDIRECTO y DESREF:

  • INDIRECTO es volátil (se recalcula con cada cambio en el libro), úsalo con moderación
  • DESREF también es volátil, pero es más eficiente que INDIRECTO para rangos grandes
  • Usa nombres de rango con INDIRECTO para hacer tus fórmulas más legibles
  • Considera usar tablas de Excel con INDIRECTO para referencias más robustas

Sesión 9.4: Práctica guiada - Sistema de inventario

Objetivos de la práctica:

  • Aplicar las funciones avanzadas aprendidas
  • Crear un sistema de inventario funcional
  • Implementar búsquedas y cálculos complejos

Instrucciones:

Crearás un sistema de control de inventario para una tienda minorista que permita:

1. Hoja "Productos"

Base de datos de todos los productos con las siguientes columnas:

  • ID de Producto (formato: P-0001)
  • Nombre del Producto
  • Categoría
  • Precio de Compra
  • Precio de Venta
  • Stock Mínimo
  • Stock Actual
  • Proveedor
  • Ubicación en Almacén

2. Hoja "Movimientos"

Registro de todos los movimientos de inventario:

  • Fecha y Hora
  • Tipo de Movimiento (Entrada/Salida)
  • ID de Producto (validado con lista desplegable)
  • Cantidad
  • Motivo (Compra, Venta, Ajuste, Devolución, etc.)
  • Número de Documento
  • Responsable

3. Hoja "Informes"

Panel de control con:

  1. Búsqueda de Productos:
    • Campo de búsqueda por ID o nombre
    • Muestra todos los detalles del producto
    • Gráfico de historial de movimientos
  2. Análisis de Inventario:
    • Productos por debajo del stock mínimo
    • Productos más vendidos
    • Valor total del inventario
  3. Informe de Movimientos:
    • Filtro por fecha
    • Filtro por tipo de movimiento
    • Resumen por categoría

Requisitos técnicos:

  1. Usa BUSCARV o INDICE/COINCIDIR para las búsquedas de productos
  2. Implementa validación de datos en todas las entradas
  3. Usa formato condicional para resaltar productos con stock bajo
  4. Crea tablas dinámicas para los informes
  5. Usa INDIRECTO para referencias dinámicas entre hojas
  6. Implementa DESREF para rangos dinámicos en los informes

Características avanzadas (opcional):

  • Generador automático de códigos de barras
  • Alerta por correo electrónico para productos con stock bajo
  • Histórico de precios
  • Cálculo automático de punto de reorden

Ejercicio de implementación:

Sigue estos pasos para construir el sistema:

  1. Crea la estructura básica de las tres hojas
  2. Ingresa al menos 20 productos de ejemplo
  3. Registra al menos 50 movimientos de inventario
  4. Configura las fórmulas de búsqueda en la hoja de informes
  5. Crea los gráficos de análisis
  6. Prueba el sistema con diferentes escenarios

Consejos para el proyecto:

  • Usa nombres de rango para hacer las fórmulas más legibles
  • Documenta tus fórmulas complejas con comentarios
  • Protege las celdas con fórmulas para evitar modificaciones accidentales
  • Considera usar tablas de Excel para rangos dinámicos
  • Guarda versiones de respaldo de tu trabajo

Entrega:

Guarda el archivo como "Sistema_Inventario_TuNombre.xlsx" y asegúrate de que:

  • Todas las funciones trabajen correctamente
  • Los cálculos sean precisos
  • La interfaz sea intuitiva
  • Incluyas al menos tres ejemplos de búsquedas complejas
