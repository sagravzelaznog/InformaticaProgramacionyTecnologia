Estructuras de Control en VBA

Las estructuras de control son fundamentales en programación, ya que permiten que tu código tome decisiones y repita acciones de manera controlada. En esta sesión, aprenderás a dominarlas.

Imagina que eres un semáforo:

Las estructuras de control son como las reglas que determinan cuándo el semáforo debe estar en rojo, amarillo o verde, y por cuánto tiempo debe permanecer en cada estado.

Condicionales: Tomando Decisiones

1. If...Then...Else

Permite ejecutar código solo si se cumple una condición.

Ejemplo Básico:

If Nota >= 6 Then
    MsgBox "¡Aprobado!"
Else
    MsgBox "Reprobado"
End If

2. Select Case

Útil cuando hay múltiples condiciones a evaluar.

Ejemplo:

Select Case DiaSemana
    Case 1
        MsgBox "Lunes"
    Case 2
        MsgBox "Martes"
    ' ... más casos ...
    Case Else
        MsgBox "Fin de semana"
End Select

Bucles: Repitiendo Acciones

1. For...Next

Ideal cuando sabes exactamente cuántas veces quieres que se repita el código.

Ejemplo: Sumar números del 1 al 10

Dim suma As Integer
suma = 0

For i = 1 To 10
    suma = suma + i
Next i

MsgBox "La suma es: " & suma

2. Do While...Loop

Se ejecuta mientras una condición sea verdadera.

Ejemplo: Ingresar números hasta que se ingrese 0

Dim numero As Integer
numero = 1 ' Inicialización

Do While numero <> 0
    numero = InputBox("Ingrese un número (0 para terminar):")
    ' Procesar el número...
Loop

Manejo de Errores

El manejo de errores evita que tu macro se detenga inesperadamente.

Estructura básica:

On Error GoTo ManejadorErrores

' Código que podría generar errores
' ...

Exit Sub ' Importante para salir antes del manejador de errores

ManejadorErrores:
    MsgBox "Ocurrió un error: " & Err.Description
    ' Código para manejar el error
    ' ...
End Sub

Ejercicio Práctico

Objetivo: Crear una macro que pida al usuario un número y muestre si es primo o no.

Paso a paso:

  1. Abre el Editor VBA (Alt + F11)
  2. Inserta un nuevo módulo
  3. Copia y pega el siguiente código:
Sub VerificarPrimo()
    Dim numero As Integer
    Dim esPrimo As Boolean
    Dim i As Integer
    
    On Error GoTo ManejadorErrores
    
    ' Pedir número al usuario
    numero = InputBox("Ingrese un número entero positivo:")
    
    ' Validar entrada
    If numero <= 1 Then
        MsgBox "Por favor ingrese un número mayor que 1."
        Exit Sub
    End If
    
    ' Verificar si es primo
    esPrimo = True
    For i = 2 To numero - 1
        If numero Mod i = 0 Then
            esPrimo = False
            Exit For
        End If
    Next i
    
    ' Mostrar resultado
    If esPrimo Then
        MsgBox numero & " es un número primo."
    Else
        MsgBox numero & " NO es un número primo."
    End If
    
    Exit Sub
    
ManejadorErrores:
    MsgBox "Error " & Err.Number & ": " & Err.Description
End Sub

¿Cómo funciona?

  1. Pide un número al usuario
  2. Verifica si es mayor que 1
  3. Comprueba si es divisible por algún número entre 2 y n-1
  4. Muestra si es primo o no
  5. Incluye manejo de errores básico

Actividad

Crea una macro que:

  1. Pida al usuario cuántos números desea ingresar
  2. Pida cada número uno por uno
  3. Muestre al final el mayor, el menor y el promedio de los números ingresados
  4. Incluya manejo de errores

💡 Pista:

Usa un array para almacenar los números y luego recórrelo para encontrar el mayor, el menor y calcular el promedio.

Resumen de la Sesión

  • Las estructuras de control permiten tomar decisiones y repetir acciones
  • If...Then...Else y Select Case son estructuras condicionales
  • Los bucles For...Next y Do While...Loop permiten repetir código
  • El manejo de errores con On Error evita que las macros fallen inesperadamente
  • Es importante validar las entradas del usuario

✅ Consejo profesional:

Practica creando pequeños programas que utilicen estas estructuras. Por ejemplo, intenta hacer una calculadora simple o un juego de adivinanzas.
