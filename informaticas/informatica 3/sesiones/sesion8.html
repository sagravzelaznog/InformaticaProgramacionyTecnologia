Sesión 8: Trabajando con Libros en Excel VBA

Objetivo: Aprender a manejar archivos de Excel (libros) mediante VBA, incluyendo su apertura, cierre, guardado y manipulación básica.

Introducción

En esta sesión exploraremos cómo trabajar con libros completos en Excel usando VBA. Aprenderás a abrir, cerrar, guardar y manipular múltiples archivos de Excel de manera programática.

1. Objeto Workbook

El objeto Workbook representa un archivo de Excel completo. Es uno de los objetos más importantes en la jerarquía de objetos de Excel VBA.

Referencias a libros:

' Referencia al libro activo
Dim wb As Workbook
Set wb = ActiveWorkbook

' Referencia a un libro específico por su nombre
Set wb = Workbooks("MiLibro.xlsx")

' Referencia al libro que contiene el código
Set wb = ThisWorkbook

💡 Diferencia importante

Usa ThisWorkbook para referirte al libro que contiene el código, y ActiveWorkbook para el libro actualmente activo.

2. Abrir y cerrar libros

Aprenderemos a abrir y cerrar archivos de Excel usando VBA.

Manejo de archivos:

' Abrir un libro existente
Workbooks.Open "C:\\Ruta\\Al\\Archivo.xlsx"

' Abrir con opciones adicionales
Workbooks.Open Filename:="C:\\Ruta\\Al\\Archivo.xlsx", ReadOnly:=True

' Cerrar un libro específico
Workbooks("Archivo.xlsx").Close SaveChanges:=False

' Cerrar todos los libros excepto el que contiene el código
Dim wb As Workbook
For Each wb In Workbooks
    If Not wb Is ThisWorkbook Then
        wb.Close SaveChanges:=False
    End If
Next wb

3. Guardar libros

Diferentes formas de guardar libros de Excel.

Opciones de guardado:

' Guardar el libro activo
ActiveWorkbook.Save

' Guardar como un nuevo archivo
ActiveWorkbook.SaveAs "C:\\Ruta\\NuevoArchivo.xlsx"

' Guardar una copia sin modificar el original
ActiveWorkbook.SaveCopyAs "C:\\Ruta\\CopiaDeSeguridad.xlsx"

' Verificar si el libro ha sido guardado previamente
If ActiveWorkbook.Path = "" Then
    ' El libro no ha sido guardado
    MsgBox "Por favor guarde el archivo primero"
End If

⚠️ Precauciones al guardar

Siempre verifica si el archivo ya existe antes de sobrescribirlo para evitar pérdida de datos.

4. Crear nuevos libros

Cómo crear nuevos libros de Excel mediante código.

Creación de libros:

' Crear un nuevo libro
Dim nuevoLibro As Workbook
Set nuevoLibro = Workbooks.Add

' Crear un libro basado en una plantilla
Set nuevoLibro = Workbooks.Add("C:\\Ruta\\Plantilla.xltx")

5. Propiedades útiles de los libros

Algunas propiedades útiles del objeto Workbook.

Propiedades comunes:

' Obtener el nombre del libro
Dim nombreArchivo As String
nombreArchivo = ActiveWorkbook.Name

' Obtener la ruta completa del libro
Dim rutaCompleta As String
rutaCompleta = ActiveWorkbook.FullName

' Obtener la ruta del directorio
Dim directorio As String
directorio = ActiveWorkbook.Path

' Verificar si el libro está protegido por contraseña
If ActiveWorkbook.HasPassword Then
    MsgBox "Este archivo está protegido con contraseña"
End If

Ejemplo Práctico

Ejercicio: Crear un informe mensual

Vamos a crear una macro que:

  1. Crea un nuevo libro
  2. Agrega datos de ejemplo
  3. Formatea el informe
  4. Guarda el archivo con la fecha actual

Código del informe mensual:

Sub CrearInformeMensual()
    ' Declarar variables
    Dim nuevoLibro As Workbook
    Dim hoja As Worksheet
    Dim rango As Range
    Dim nombreArchivo As String
    
    ' Crear un nuevo libro
    Set nuevoLibro = Workbooks.Add
    
    ' Referencia a la primera hoja
    Set hoja = nuevoLibro.Worksheets(1)
    hoja.Name = "Informe " & Format(Date, "mmmm yyyy")
    
    ' Agregar encabezados
    hoja.Range("A1").Value = "Informe Mensual - " & Format(Date, "mmmm yyyy")
    hoja.Range("A1").Font.Bold = True
    hoja.Range("A1").Font.Size = 14
    
    ' Agregar datos de ejemplo
    hoja.Range("A3").Value = "Producto"
    hoja.Range("B3").Value = "Cantidad"
    hoja.Range("C3").Value = "Precio Unitario"
    hoja.Range("D3").Value = "Total"
    
    ' Formato de encabezados de columna
    Set rango = hoja.Range("A3:D3")
    rango.Font.Bold = True
    rango.Interior.Color = RGB(200, 230, 255)
    
    ' Agregar datos de ejemplo
    hoja.Range("A4").Value = "Producto A"
    hoja.Range("B4").Value = 10
    hoja.Range("C4").Value = 150
    hoja.Range("D4").Formula = "=B4*C4"
    
    hoja.Range("A5").Value = "Producto B"
    hoja.Range("B5").Value = 5
    hoja.Range("C5").Value = 230
    hoja.Range("D5").Formula = "=B5*C5"
    
    ' Ajustar el ancho de las columnas
    hoja.Columns("A:D").AutoFit
    
    ' Agregar formato de moneda
    hoja.Range("C4:D5").NumberFormat = "$#,##0.00"
    
    ' Agregar totales
    hoja.Range("B6").Value = "Total:"
    hoja.Range("D6").Formula = "=SUM(D4:D5)"
    hoja.Range("D6").Font.Bold = True
    hoja.Range("D6").NumberFormat = "$#,##0.00"
    
    ' Crear nombre de archivo con la fecha actual
    nombreArchivo = "Informe_" & Format(Date, "yyyymm") & ".xlsx"
    
    ' Guardar el archivo en la misma ubicación que el libro actual
    On Error Resume Next ' En caso de que la carpeta no exista
    MkDir ThisWorkbook.Path & "\Informes"
    On Error GoTo 0
    
    ' Guardar el archivo
    nuevoLibro.SaveAs Filename:=ThisWorkbook.Path & "\Informes\" & nombreArchivo, _
                     FileFormat:=xlOpenXMLWorkbook
    
    ' Cerrar el libro después de guardar
    nuevoLibro.Close SaveChanges:=False
    
    MsgBox "Se ha creado el informe mensual: " & nombreArchivo, vbInformation
    
    ' Limpiar variables
    Set hoja = Nothing
    Set nuevoLibro = Nothing
    Set rango = Nothing
End Sub

💡 Consejo

Puedes personalizar este código agregando más formatos, gráficos o cálculos según tus necesidades específicas.

Resumen de la Sesión

  • El objeto Workbook es fundamental para trabajar con archivos de Excel en VBA
  • Podemos abrir, cerrar, guardar y crear nuevos libros de forma programática
  • Es importante manejar correctamente los errores al trabajar con archivos
  • Podemos acceder a propiedades útiles como el nombre, ruta y estado de protección de los libros
