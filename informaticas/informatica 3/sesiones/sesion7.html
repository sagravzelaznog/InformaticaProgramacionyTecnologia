Sesión 7: Trabajando con Hojas de Cálculo en Excel VBA

Objetivo: Aprender a manipular hojas de cálculo mediante programación VBA, incluyendo su creación, eliminación, ocultamiento y manipulación de datos.

Introducción

En esta sesión exploraremos cómo trabajar con hojas de cálculo en Excel usando VBA. Aprenderás a crear, eliminar, copiar y manipular hojas de cálculo de forma programática.

1. Referenciar Hojas de Cálculo

Existen varias formas de hacer referencia a una hoja de cálculo en VBA:

Por nombre:

Worksheets("Hoja1").Activate
Sheets("Hoja1").Select

Por índice:

Worksheets(1).Activate  ' Primera hoja
Sheets(2).Select     ' Segunda hoja

Hoja activa:

ActiveSheet.Name  ' Nombre de la hoja activa

Consejo

Es preferible usar Worksheets en lugar de Sheets cuando solo trabajas con hojas de cálculo, ya que Sheets también incluye otros tipos de hojas como gráficos.

2. Crear y eliminar hojas

Cómo crear y eliminar hojas de cálculo mediante código VBA.

Crear una nueva hoja:

Sub CrearHoja()
    ' Crear al final
    Sheets.Add After:=Sheets(Sheets.Count)
    ActiveSheet.Name = "NuevaHoja"
End Sub

3. Ocultar/Mostrar Hojas

Cómo ocultar y mostrar hojas de cálculo mediante VBA.

Ocultar hoja:

Sheets("Datos").Visible = xlSheetHidden

Ocultar completamente (no se puede mostrar desde la interfaz):

Sheets("Datos").Visible = xlSheetVeryHidden

Mostrar hoja:

Sheets("Datos").Visible = True

Ejercicio Práctico

Ejercicio: Organizador de Hojas

Vamos a crear una macro que:

  1. Crea 5 hojas nuevas con nombres específicos
  2. Las ordena alfabéticamente
  3. Oculta las hojas que no sean necesarias
  4. Aplica formato a todas las hojas visibles

Consejo

Puedes personalizar este código agregando más formatos, gráficos o cálculos según tus necesidades específicas.

Actividad Práctica

Crea una macro que:

  1. Pida al usuario que ingrese un nombre para una nueva hoja
  2. Verifique si la hoja ya existe
  3. Si no existe, cree la hoja con el nombre proporcionado
  4. Si existe, muestre un mensaje de error
  5. Ordene todas las hojas por nombre

Pista

Puedes usar una función para verificar si una hoja ya existe. Aquí tienes un ejemplo:

Function HojaExiste(nombreHoja As String) As Boolean
    On Error Resume Next
    HojaExiste = (Sheets(nombreHoja).Name = nombreHoja)
    On Error GoTo 0
End Function

Resumen de la Sesión

  • El objeto Worksheet es fundamental para trabajar con hojas de cálculo en VBA
  • Podemos crear, eliminar, copiar y organizar hojas de forma programática
  • Es importante manejar correctamente los errores al trabajar con hojas
  • Podemos controlar la visibilidad de las hojas según sea necesario

Desafío Adicional

Mejora la macro del ejercicio práctico para que también permita al usuario seleccionar la posición donde desea insertar la nueva hoja (al principio, al final o entre dos hojas existentes).
