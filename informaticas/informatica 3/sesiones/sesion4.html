Sesión 4: Fundamentos de VBA I

Objetivo: Aprender los elementos básicos del lenguaje VBA, incluyendo variables, tipos de datos y operadores.

Introducción

VBA (Visual Basic for Applications) es un lenguaje de programación que nos permite crear macros y automatizar tareas en Excel. Es como darle superpoderes a Excel para que haga cosas increíbles por nosotros.

¿Por qué aprender VBA?

  • Automatiza tareas repetitivas
  • Ahorra tiempo y reduce errores
  • Personaliza Excel a tus necesidades
  • Mejora tu productividad

Variables en VBA

Las variables son como cajas donde guardamos información. Cada caja tiene un nombre y un tipo de dato específico.

Cómo declarar variables

Dim nombreVariable As TipoDeDato

Ejemplos:

Dim edad As Integer
Dim nombre As String
Dim sueldo As Double
Dim esActivo As Boolean

  3. Promedio (número decimal)

Tipos de Datos en VBA

VBA tiene diferentes tipos de datos. Aquí están los más importantes:

Tipo Descripción Ejemplo Rango
Integer Números enteros 15, -3, 0 -32,768 a 32,767
Long Números enteros grandes 50000, -1000000 -2,147,483,648 a 2,147,483,647
Double Números decimales 3.1416, -0.5, 100.75 ±5.0 × 10^-324 a ±1.7 × 10^308
String Texto "Hola", "Excel" Hasta 2 mil millones de caracteres
Boolean Valores lógicos True, False True o False
Date Fechas y horas #01/01/2023# 1/1/100 al 31/12/9999

Consejo

Usa siempre el tipo de dato más adecuado. Por ejemplo, usa Integer para edades y Double para cálculos con decimales.

Operadores en VBA

Los operadores nos permiten realizar operaciones con variables y valores.

Operadores Aritméticos

  • + Suma
  • - Resta
  • * Multiplicación
  • / División
  • \ División entera (descarta decimales)
  • ^ Potencia
  • Mod Módulo (resto de la división)

📌 Ejemplo de operaciones

Dim resultado As Double
resultado = 10 + 5 * 2  ' resultado = 20
resultado = (10 + 5) * 2  ' resultado = 30
resultado = 10 / 3  ' resultado = 3.333...
resultado = 10 \ 3  ' resultado = 3 (división entera)
resultado = 10 Mod 3  ' resultado = 1 (resto de 10/3)

Operadores de Comparación

  • = Igual a
  • <> Diferente de
  • < Menor que
  • > Mayor que
  • <= Menor o igual que
  • >= Mayor o igual que

Operadores Lógicos

  • And Y lógico
  • Or O lógico
  • Not Negación lógica
