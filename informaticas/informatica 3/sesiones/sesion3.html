Sesión 3: El Editor de VBA

Objetivo: Familiarizarse con el entorno de desarrollo de VBA (Visual Basic for Applications).

Introducción

El Editor de VBA es el entorno donde podrás crear, modificar y depurar tus macros. Es como el "taller" donde darás vida a tus automatizaciones.

El Editor de VBA es el lugar donde podrás crear, modificar y depurar tus macros. Es como el "taller" donde darás vida a tus automatizaciones.

Dato curioso: VBA significa Visual Basic for Applications, y es el lenguaje de programación que usa Excel para crear macros.

Cómo abrir el Editor VBA

Método 1: Usando el teclado

Presiona Alt + F11 en tu teclado.

Método 2: Desde la cinta de opciones

  1. Ve a la pestaña Programador
  2. Haz clic en Visual Basic

Vista general del Editor de VBA

Partes principales del Editor VBA

1. Barra de menús

Contiene todos los comandos para trabajar con VBA, organizados en menús como Archivo, Editar, Ver, etc.

2. Barra de herramientas

Acceso rápido a funciones comunes como guardar, ejecutar código y depurar.

3. Explorador de proyectos

Muestra todos los libros y hojas de cálculo abiertos, así como sus módulos, formularios y referencias.

4. Ventana de propiedades

Muestra y permite editar las propiedades del objeto seleccionado.

5. Ventana de código

Área donde escribes y editas tu código VBA.

6. Ventana inmediato

Útil para probar líneas de código rápidamente y ver resultados al instante.

Creando tu primer procedimiento

Vamos a crear un procedimiento simple que muestre un mensaje en Excel:

  1. Abre el Editor VBA (Alt + F11)
  2. En el Explorador de proyectos, haz clic derecho en tu libro
  3. Selecciona Insertar > Módulo
  4. En la ventana de código, escribe lo siguiente: 
    Sub MiPrimerProcedimiento()
    MsgBox "¡Hola Mundo! Esta es mi primera macro con VBA."
End Sub
  5. Presiona F5 o haz clic en el botón Ejecutar (▶️) para probar tu código

🛠️ Actividad Práctica 1

Crea un procedimiento que:

  1. Se llame SaludoPersonalizado
  2. Pida al usuario su nombre utilizando InputBox
  3. Muestre un mensaje de bienvenida personalizado

Pista: Usa InputBox("¿Cuál es tu nombre?") para pedir datos al usuario.

Depuración básica

La depuración es esencial para encontrar y corregir errores en tu código. Aquí tienes algunas herramientas útiles:

1. Puntos de interrupción

Haz clic en el margen izquierdo junto a una línea de código para pausar la ejecución en ese punto.

2. Ejecución paso a paso

Usa F8 para ejecutar una línea a la vez y ver cómo se comporta tu código.

3. Ventana Inmediato

Escribe ?nombreVariable para ver su valor actual durante la depuración.

4. Inspección de variables

Selecciona una variable y presiona Mayús + F9 para ver su valor.

🛠️ Actividad Práctica 2

Depura este código:

Sub SumaErronea()
    Dim numero1 As Integer
    Dim numero2 As Integer
    Dim resultado As Integer
    
    numero1 = InputBox("Ingresa el primer número")
    numero2 = InputBox("Ingresa el segundo número")
    
    resultado = numero1 + numero2
    
    MsgBox "La suma es: " & resultado
End Sub

¿Puedes encontrar el error? Usa las herramientas de depuración para encontrarlo.

Buenas prácticas al trabajar con el Editor VBA

1. Organiza tu código

Usa módulos para agrupar procedimientos relacionados. Por ejemplo, crea un módulo para funciones de formato, otro para cálculos, etc.

2. Comenta tu código

Usa el apóstrofe (') para agregar comentarios que expliquen qué hace cada sección de tu código.

3. Usa nombres descriptivos

Nombra tus procedimientos y variables de manera que sea claro su propósito.

4. Guarda frecuentemente

El Editor VBA no tiene guardado automático. Usa Ctrl + S con frecuencia.

Resumen de la Sesión

  • El Editor VBA es el entorno donde se crean y modifican las macros
  • Puedes abrirlo con Alt + F11 o desde la pestaña Programador
  • Las partes principales son: barra de menús, barra de herramientas, explorador de proyectos, ventana de propiedades, ventana de código y ventana inmediato
  • La depuración es esencial para encontrar y corregir errores en tu código
  • Seguir buenas prácticas te ayudará a mantener tu código organizado y comprensible
