Sesión 9: Trabajando con Datos en Excel VBA

Objetivo: Aprender a manipular y analizar datos en Excel usando VBA, incluyendo filtrado, ordenamiento y validación de datos.

Introducción

En esta sesión, aprenderás a trabajar con conjuntos de datos en Excel usando VBA. Aprenderás a filtrar, ordenar y validar datos de manera eficiente, lo que te permitirá manejar grandes volúmenes de información de forma automatizada.

1. Filtrado de Datos

El filtrado de datos es una técnica poderosa para trabajar con subconjuntos específicos de información.

Ejemplo de filtrado básico:

Sub FiltrarDatos()
    ' Activar la hoja de trabajo
    Sheets("Datos").Activate
    
    ' Aplicar filtro
    Range("A1").AutoFilter Field:=1, Criteria1:=">100"
    
    ' Copiar datos filtrados
    Range("A1").CurrentRegion.SpecialCells(xlCellTypeVisible).Copy
    
    ' Pegar en nueva hoja
    Sheets.Add After:=ActiveSheet
    ActiveSheet.Paste
    
    ' Limpiar filtros
    Sheets("Datos").AutoFilterMode = False
End Sub

2. Ordenamiento de Datos

Ordenar datos es fundamental para el análisis y presentación de información.

Ejemplo de ordenamiento:

Sub OrdenarDatos()
    ' Ordenar por columna B (2) de forma ascendente
    Range("A1").CurrentRegion.Sort _
        Key1:=Range("B1"), _
        Order1:=xlAscending, _
        Header:=xlYes
End Sub

Ejercicio Práctico

Crear un informe de ventas

Vamos a crear una macro que:

  1. Ordene los datos de ventas por fecha
  2. Filtre solo las ventas del mes actual
  3. Cree un resumen en una nueva hoja

Solución:

Sub CrearInformeVentas()
    Dim wsDatos As Worksheet
    Dim wsResumen As Worksheet
    Dim ultimaFila As Long
    
    ' Referencia a la hoja de datos
    Set wsDatos = ThisWorkbook.Sheets("Ventas")
    
    ' Ordenar por fecha
    With wsDatos.Sort
        .SortFields.Clear
        .SortFields.Add Key:=Range("A2"), Order:=xlAscending
        .SetRange wsDatos.Range("A1").CurrentRegion
        .Header = xlYes
        .Apply
    End With
    
    ' Filtrar por mes actual
    wsDatos.Range("A1").AutoFilter Field:=1, _
        Criteria1:=">=" & DateSerial(Year(Date), Month(Date), 1), _
        Operator:=xlAnd, _
        Criteria2:="<" & DateSerial(Year(Date), Month(Date) + 1, 1)
    
    ' Crear hoja de resumen
    On Error Resume Next
    Application.DisplayAlerts = False
    ThisWorkbook.Sheets("Resumen").Delete
    Application.DisplayAlerts = True
    On Error GoTo 0
    
    Set wsResumen = ThisWorkbook.Sheets.Add(After:=wsDatos)
    wsResumen.Name = "Resumen"
    
    ' Copiar encabezados
    wsDatos.Range("A1:D1").Copy wsResumen.Range("A1")
    
    ' Copiar datos filtrados
    wsDatos.Range("A1").CurrentRegion.SpecialCells(xlCellTypeVisible).Copy _
        wsResumen.Range("A2")
    
    ' Aplicar formato
    With wsResumen
        .Columns("A").NumberFormat = "dd/mm/yyyy"
        .Columns("C:D").NumberFormat = "$#,##0.00"
        .Columns("A:D").AutoFit
        .Range("A1:D1").Interior.Color = RGB(200, 230, 255)
        .Range("A1:D1").Font.Bold = True
    End With
    
    ' Limpiar filtros
    wsDatos.AutoFilterMode = False
    
    MsgBox "Informe de ventas generado exitosamente", vbInformation
End Sub

Actividad de la Sesión

Crea una macro que:

  1. Pida al usuario que ingrese un rango de fechas
  2. Filtre los datos para mostrar solo ese rango
  3. Genere un resumen con el total de ventas y el promedio
  4. Incluya manejo de errores para entradas inválidas

Pista:

Usa Application.InputBox con Type:=1 para fechas y asegúrate de validar que la fecha final sea mayor o igual a la fecha inicial.

Resumen de la Sesión

  • El filtrado de datos permite trabajar con subconjuntos específicos de información
  • El ordenamiento es esencial para el análisis y presentación de datos
  • Podemos combinar filtros y ordenamiento para crear informes dinámicos
  • Es importante incluir manejo de errores al trabajar con datos del usuario
