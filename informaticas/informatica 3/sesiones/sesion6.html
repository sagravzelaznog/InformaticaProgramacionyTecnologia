Sesión 6: Funciones y Procedimientos en VBA

Objetivo: Aprender a crear y utilizar funciones y procedimientos personalizados en VBA para organizar y reutilizar código.

Introducción

En esta sesión, aprenderás a crear tus propias funciones y procedimientos en VBA para organizar mejor tu código y hacerlo más reutilizable. Las funciones y procedimientos son bloques de código que realizan tareas específicas y pueden ser llamados desde cualquier parte de tu programa.

💡 ¿Por qué usar funciones y procedimientos?

  • Reutilizar código sin duplicarlo
  • Hacer el código más legible y mantenible
  • Facilitar la depuración
  • Dividir problemas complejos en partes más pequeñas

1. Procedimientos Sub

Los procedimientos Sub (o subrutinas) son bloques de código que realizan acciones pero no devuelven un valor.

Sintaxis básica de un Sub

Sub NombreProcedimiento(param1 As Tipo, param2 As Tipo)
    ' Código del procedimiento
    MsgBox "¡Hola, " & param1 & "!"
End Sub

Ejemplo: Procedimiento simple

Sub SaludarUsuario()
    Dim nombre As String
    nombre = InputBox("¿Cuál es tu nombre?")
    MsgBox "¡Bienvenido/a " & nombre & "!"
End Sub

2. Funciones

Las funciones son similares a los procedimientos, pero devuelven un valor.

Sintaxis básica de una Función

Function NombreFuncion(param1 As Tipo, param2 As Tipo) As TipoRetorno
    ' Código de la función
    NombreFuncion = resultado
End Function

Ejemplo: Función para calcular el IVA

Function CalcularIVA(monto As Currency, ivaPorcentaje As Single) As Currency
    ' Calcula el IVA de un monto dado
    CalcularIVA = monto * (ivaPorcentaje / 100)
End Function

Uso de la función:

Sub UsarFuncionIVA()
    Dim total As Currency
    total = 1000
    MsgBox "El IVA de $" & total & " es: $" & CalcularIVA(total, 16)
End Sub

Ejercicio Práctico

Vamos a crear una función que convierta grados Celsius a Fahrenheit y viceversa.

Paso 1: Crear la función de conversión

Function ConvertirTemperatura(grados As Double, deUnidad As String) As Double
    If UCase(deUnidad) = "C" Then
        ' Convertir de Celsius a Fahrenheit
        ConvertirTemperatura = (grados * 9/5) + 32
    ElseIf UCase(deUnidad) = "F" Then
        ' Convertir de Fahrenheit a Celsius
        ConvertirTemperatura = (grados - 32) * 5/9
    Else
        ' Si la unidad no es válida, devolver un valor que indique error
        ConvertirTemperatura = -9999
    End If
End Function

Paso 2: Crear un procedimiento para probar la función

Sub ProbarConversion()
    Dim temp As Double
    Dim unidad As String
    
    temp = CDbl(InputBox("Ingrese la temperatura:"))
    unidad = InputBox("Ingrese la unidad (C para Celsius, F para Fahrenheit):")
    
    Dim resultado As Double
    resultado = ConvertirTemperatura(temp, unidad)
    
    If resultado = -9999 Then
        MsgBox "Unidad de temperatura no válida. Use 'C' o 'F'."
    Else
        If UCase(unidad) = "C" Then
            MsgBox temp & "°C son " & resultado & "°F"
        Else
            MsgBox temp & "°F son " & resultado & "°C"
        End If
    End If
End Sub

Resumen de la Sesión

  • Usa nombres descriptivos para funciones y procedimientos
  • Documenta el propósito de cada función y sus parámetros
  • Mantén las funciones cortas y con un solo propósito
  • Usa parámetros en lugar de variables globales cuando sea posible
  • Considera el manejo de errores en funciones críticas

Actividad de la Sesión

Crea las siguientes funciones en VBA:

  1. Una función que calcule el área de un círculo dado su radio
  2. Una función que determine si un número es primo
  3. Un procedimiento que use las dos funciones anteriores para mostrar en un mensaje el área de un círculo y si el radio es un número primo

Pista

Recuerda que el área de un círculo se calcula como π × radio². En VBA, puedes usar la constante WorksheetFunction.Pi() para obtener el valor de π.

Conceptos Clave

  • Los procedimientos Sub realizan acciones pero no devuelven valores
  • Las funciones Function realizan cálculos y devuelven un valor
  • Ambos pueden recibir parámetros para personalizar su comportamiento
  • Las funciones y procedimientos mejoran la organización y reutilización del código
  • Es importante seguir buenas prácticas de nomenclatura y documentación
