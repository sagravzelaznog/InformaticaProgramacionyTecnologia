Sesión 11: Formularios y Controles de Usuario

Objetivo: Aprender a crear y utilizar formularios y controles de usuario en Excel para mejorar la interacción con los usuarios.

Introducción

Los formularios y controles de usuario permiten crear interfaces amigables para que los usuarios interactúen con tus macros de manera más intuitiva. En esta sesión aprenderás a:

  • Agregar controles de formulario a tus hojas de cálculo
  • Crear formularios de usuario personalizados
  • Validar datos de entrada
  • Responder a eventos de los controles

1. Controles de Formulario

Excel proporciona una variedad de controles que puedes agregar a tus hojas de cálculo:

1.1 Botones de comando

Los botones permiten ejecutar macros con un solo clic.

Sub AsignarMacroABoton()
    Dim btn As Button
    Set btn = ActiveSheet.Buttons.Add(Left:=100, Top:=100, Width:=100, Height:=30)
    btn.OnAction = "MiMacro"
    btn.Caption = "Ejecutar"
End Sub

1.2 Cuadros de texto

Permiten al usuario ingresar texto.

Sub CrearCuadroTexto()
    Dim txtBox As OLEObject
    Set txtBox = ActiveSheet.OLEObjects.Add(ClassType:="Forms.TextBox.1", _
        Left:=100, Top:=150, Width:=150, Height:=20)
    txtBox.Name = "txtEntrada"
End Sub

1.3 Listas desplegables

Útiles para que el usuario seleccione entre varias opciones.

Sub CrearListaDesplegable()
    Dim lista As DropDown
    Set lista = ActiveSheet.DropDowns.Add(Left:=100, Top:=200, Width:=150, Height:=20)
    With lista
        .List = Array("Opción 1", "Opción 2", "Opción 3")
        .LinkedCell = "A1"
    End With
End Sub

2. Formularios de Usuario

Los UserForms permiten crear ventanas personalizadas con múltiples controles.

2.1 Crear un formulario básico

  1. Presiona Alt + F11 para abrir el Editor VBA
  2. Haz clic derecho en tu proyecto y selecciona Insertar > UserForm
  3. Personaliza el formulario usando el cuadro de herramientas

2.2 Mostrar un formulario

Sub MostrarFormulario()
    UserForm1.Show
End Sub

2.3 Ejemplo de formulario de registro

' Código en el módulo del formulario
Private Sub UserForm_Initialize()
    ' Inicializar controles al cargar el formulario
    With Me.cboPuesto
        .AddItem "Gerente"
        .AddItem "Analista"
        .AddItem "Asistente"
    End With
    dtpFecha.Value = Date
End Sub

Private Sub btnGuardar_Click()
    ' Validar datos
    If txtNombre.Text = "" Then
        MsgBox "Por favor ingrese un nombre", vbExclamation
        txtNombre.SetFocus
        Exit Sub
    End If
    
    ' Procesar datos
    Dim fila As Integer
    fila = Hoja1.Cells(Rows.Count, 1).End(xlUp).Row + 1
    
    Hoja1.Cells(fila, 1).Value = txtNombre.Text
    Hoje1.Cells(fila, 2).Value = txtEmail.Text
    Hoja1.Cells(fila, 3).Value = cboPuesto.Value
    Hoja1.Cells(fila, 4).Value = dtpFecha.Value
    
    ' Limpiar controles
    txtNombre.Text = ""
    txtEmail.Text = ""
    cboPuesto.ListIndex = -1
    
    MsgBox "Registro guardado exitosamente", vbInformation
End Sub

Ejercicio Práctico

Objetivo: Crear un formulario de registro de productos.

  1. Crea un nuevo UserForm llamado frmProducto
  2. Agrega los siguientes controles:
    • Etiquetas para cada campo
    • Cuadros de texto para Código, Nombre y Precio
    • Un ComboBox para la categoría (Electrónicos, Ropa, Alimentos, etc.)
    • Un CheckBox para indicar si el producto está en oferta
    • Dos botones: Aceptar y Cancelar
  3. Programa el botón Aceptar para validar los datos y guardar en la hoja "Productos"
  4. Programa el botón Cancelar para cerrar el formulario

Pista: Usa el evento UserForm_Initialize para cargar las categorías en el ComboBox.

Resumen de la Sesión

  • Los controles de formulario permiten crear interfaces interactivas en Excel.
  • Los UserForms ofrecen mayor flexibilidad para crear formularios personalizados.
  • Es importante validar los datos ingresados por el usuario.
  • Los eventos de los controles permiten responder a las acciones del usuario.
