Sesión 10: Formularios de Usuario I

Objetivo: Introducir los conceptos básicos para crear interfaces de usuario personalizadas en Excel mediante UserForms.

Introducción

Los UserForms son ventanas personalizables que permiten crear interfaces gráficas para que los usuarios interactúen con tus macros. En esta sesión, aprenderás a crear formularios básicos y agregar controles comunes para mejorar la experiencia del usuario.

Ventajas de los UserForms

  • Interfaz profesional y fácil de usar
  • Validación de datos integrada
  • Mejor experiencia de usuario que los cuadros de mensaje simples
  • Mayor control sobre la entrada de datos

Controles Básicos

Los controles son elementos que permiten al usuario interactuar con el formulario. Algunos controles comunes incluyen:

  • Cuadros de texto: Para entrada de texto
  • Etiquetas: Para mostrar texto descriptivo
  • Botones de comando: Para ejecutar acciones
  • Casillas de verificación: Para opciones sí/no
  • Botones de opción: Para selección única entre opciones
  • Cuadros combinados: Para seleccionar de una lista desplegable

1. Crear un UserForm

Para crear un nuevo UserForm:

  1. Presiona Alt + F11 para abrir el Editor VBA
  2. En el menú, selecciona Insertar > UserForm
  3. Se abrirá un formulario en blanco y aparecerá el Cuadro de herramientas

2. Agregar controles al formulario

Puedes arrastrar controles desde el Cuadro de herramientas al formulario:

Ejemplo: Formulario de registro simple

Registro de Estudiante

Nombre: [___________]

Edad: [___]

Carrera: [▼]

Intereses: [ ] Deportes [ ] Música [ ] Arte

[ Guardar ] [ Cancelar ]

3. Propiedades comunes

Cada control tiene propiedades que puedes configurar:

  • Name: Identificador único del control
  • Caption/Text: Texto que se muestra
  • BackColor/ForeColor: Colores de fondo y texto
  • Font: Fuente, tamaño y estilo del texto
  • Width/Height: Tamaño del control

Ejemplo: Configuración de propiedades

' En el editor VBA, selecciona un control y ve a la ventana de propiedades
' O configura propiedades mediante código:

Private Sub UserForm_Initialize()
    ' Configurar propiedades del formulario
    Me.Caption = "Registro de Estudiante"
    Me.Width = 300
    Me.Height = 250
    
    ' Configurar un botón
    CommandButton1.Caption = "Guardar"
    CommandButton1.Width = 80
    CommandButton1.Height = 24
    
    ' Configurar una etiqueta
    Label1.Caption = "Nombre:"
    Label1.Font.Bold = True
End Sub

4. Mostrar y ocultar formularios

Para mostrar un formulario desde un módulo estándar o desde otro formulario:

Mostrar un formulario

Sub MostrarFormulario()
    ' Crea una instancia del formulario
    Dim miFormulario As UserForm1
    Set miFormulario = New UserForm1
    
    ' Mostrar el formulario de forma modal (el usuario debe cerrarlo para continuar)
    miFormulario.Show
    
    ' O mostrar de forma no modal (el usuario puede interactuar con Excel)
    ' miFormulario.Show vbModeless
End Sub

Cerrar un formulario

' Para cerrar el formulario actual
Unload Me

' O cerrar un formulario específico
Unload UserForm1

Ejercicio Práctico

Crea un formulario de registro de estudiantes con los siguientes elementos:

  1. Un campo para el nombre (cuadro de texto)
  2. Un campo para la edad (cuadro numérico)
  3. Una lista desplegable para la carrera
  4. Casillas de verificación para intereses
  5. Botones para Guardar y Cancelar

Solución propuesta:

' Código para el formulario (UserForm1)

Private Sub UserForm_Initialize()
    ' Configurar el formulario
    Me.Caption = "Registro de Estudiante"
    
    ' Llenar el combo de carreras
    With ComboBox1
        .AddItem "Ingeniería en Sistemas"
        .AddItem "Administración"
        .AddItem "Contabilidad"
        .AddItem "Derecho"
        .ListIndex = 0  ' Seleccionar el primer elemento
    End With
    
    ' Configurar botones
    CommandButton1.Caption = "Guardar"
    CommandButton2.Caption = "Cancelar"
End Sub

Private Sub CommandButton1_Click()
    ' Validar que se ingresó un nombre
    If TextBox1.Text = "" Then
        MsgBox "Por favor ingrese un nombre", vbExclamation
        TextBox1.SetFocus
        Exit Sub
    End If
    
    ' Validar la edad
    If Not IsNumeric(TextBox2.Text) Or Val(TextBox2.Text) < 15 Or Val(TextBox2.Text) > 100 Then
        MsgBox "Por favor ingrese una edad válida (15-100)", vbExclamation
        TextBox2.SetFocus
        Exit Sub
    End If
    
    ' Procesar los datos (aquí podrías guardarlos en una hoja de Excel)
    Dim intereses As String
    If CheckBox1.Value Then intereses = intereses & "Deportes, "
    If CheckBox2.Value Then intereses = intereses & "Música, "
    If CheckBox3.Value Then intereses = intereses & "Arte, "
    
    ' Quitar la última coma y espacio
    If Len(intereses) > 0 Then intereses = Left(intereses, Len(intereses) - 2)
    
    ' Mostrar un resumen (en una aplicación real, guardarías estos datos)
    MsgBox "Registro exitoso:" & vbNewLine & _
           "Nombre: " & TextBox1.Text & vbNewLine & _
           "Edad: " & TextBox2.Text & vbNewLine & _
           "Carrera: " & ComboBox1.Text & vbNewLine & _
           "Intereses: " & IIf(intereses = "", "Ninguno", intereses), _
           vbInformation, "Registro Exitoso"
    
    ' Cerrar el formulario
    Unload Me
End Sub

Private Sub CommandButton2_Click()
    ' Botón Cancelar
    If MsgBox("¿Está seguro de que desea cancelar?", vbQuestion + vbYesNo) = vbYes Then
        Unload Me
    End If
End Sub

Actividad de la Sesión

Crea un formulario de contacto con los siguientes campos:

  1. Nombre (obligatorio)
  2. Correo electrónico (validar formato)
  3. Asunto (lista desplegable con opciones: Consulta, Reclamo, Sugerencia, Otro)
  4. Mensaje (área de texto multilínea)
  5. Botones para Enviar y Limpiar

El formulario debe validar que todos los campos obligatorios estén completos y que el correo electrónico tenga un formato válido.

Resumen de la Sesión

  • Los UserForms permiten crear interfaces gráficas personalizadas para las macros de Excel.
  • Los controles básicos incluyen cuadros de texto, etiquetas, botones, casillas de verificación y cuadros combinados.
  • Las propiedades de los controles se pueden configurar en tiempo de diseño o mediante código.
  • Es importante validar la entrada del usuario antes de procesar los datos.
  • Los formularios mejoran significativamente la experiencia del usuario al interactuar con las macros.
