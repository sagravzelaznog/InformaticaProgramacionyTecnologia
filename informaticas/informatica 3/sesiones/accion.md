# Accion

- Crea un archivo html con el nombre de "index.html" con el contenido de la pagina principal.
- Debe contener una cabecera con el titulo "Curso de Macros en Excel".
- Debe contener un pie de pagina "&copy; JMGV-PTEL-2025, CURSO DE MACROS EN EXCEL. Todos los derechos reservados.".
- Debe contener un enlace a la sesion anterior y la siguiente.
- El archivo se debe guardar en la carpeta sesiones.
- Debe contener una navegacion en la parte lateral izquierda con los enlaces a las sesiones y no debe ser de un ancho mayor al 10%.
- debe visualizarse correctamente en cualquier navegador y dispositivo.
- debe ser responsivo.
- debe ser accesible.
- debe ser seguro.
- debe ser optimizado.
- debe ser mantenible.
- debe ser escalable.
- debe ser compatible con las ultimas versiones de los navegadores.
- debe crearse utilizando las mejores practicas de desarrollo web con escritura de codigo limpio y mantenible.
- debe crearse archivo de estilos css externo con nombre "style.css" utilizable para todas las paginas.
- el tema de colores para la pagina debe ser azul claro con contraste con texto en esmeralda.
- debe crearse archivo de scripts js externo con nombre "script.js" utilizable para todas las paginas.
