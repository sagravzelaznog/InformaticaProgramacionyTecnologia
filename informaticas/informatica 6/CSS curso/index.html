¿Qué es CSS?

El CSS (siglas en inglés de Cascading Style Sheets, o en español, Hojas de Estilo en Cascada) es el lenguaje fundamental que se utiliza para diseñar y dar formato a las páginas web.

Si pensamos en la construcción de una casa, el HTML serían los cimientos y los ladrillos (la estructura principal), mientras que el CSS sería la pintura, los muebles y la decoración (el aspecto visual y la estética).
