📦 Sesión 2: El Modelo de Caja

La física de la web: Todo es un rectángulo

Objetivo de la Sesión

Comprender el modelo de caja de CSS, la base del diseño web, y aprender a controlar el espacio que ocupan los elementos en la página.

1. Anatomía del Rectángulo

En CSS, cada elemento es una caja rectangular con las siguientes partes:

Contenido

1. Contenido (Content)

El área donde se muestra el contenido (texto, imágenes, etc.). Sus dimensiones se controlan con width (ancho) y height (alto).

2. Relleno (Padding)

El espacio entre el contenido y el borde. Se controla con padding.

3. Borde (Border)

La línea que rodea el relleno. Se controla con border.

4. Margen (Margin)

El espacio exterior que separa el elemento de otros elementos. Se controla con margin.

/* Ejemplo de modelo de caja completo */
.caja {
    /* Dimensiones del contenido */
    width: 200px;
    height: 100px;
    
    /* Relleno */
    padding: 20px;
    
    /* Borde */
    border: 10px solid #64b5f6;
    
    /* Margen */
    margin: 20px;
    
    /* Fondo para visualizar mejor */
    background-color: #bbdefb;
}

💡 Propiedades abreviadas

Puedes definir los lados individualmente o usar la propiedad abreviada:

/* Establecer cada lado individualmente */
padding-top: 10px;
padding-right: 20px;
padding-bottom: 10px;
padding-left: 20px;

/* Propiedad abreviada (sentido de las agujas del reloj: arriba, derecha, abajo, izquierda) */
padding: 10px 20px 10px 20px;

/* Arriba y abajo 10px, izquierda y derecha 20px */
padding: 10px 20px;

/* Todos los lados iguales */
padding: 15px;

Lo mismo aplica para margin y border.

2. El Gran Truco: box-sizing: border-box

Por defecto, cuando estableces el width y height de un elemento, solo estás definiendo el tamaño del contenido. El padding y el borde se suman a estas dimensiones, lo que puede causar problemas de diseño.

box-sizing: content-box (por defecto)

Contenido
width: 150px + 20px padding + 4px borde = 174px total

El ancho total del elemento es mayor que el especificado en width.

box-sizing: border-box (recomendado)

Contenido
width: 150px (incluye padding y borde)

El ancho total del elemento es exactamente el especificado en width.

/* Aplicar border-box a todos los elementos */
*,
*::before,
*::after {
    box-sizing: border-box;
}

/* O solo a elementos específicos */
.mi-elemento {
    box-sizing: border-box;
    width: 200px;
    padding: 20px;
    border: 5px solid #000;
    /* El ancho total será de 200px, no 250px */
}

💡 ¿Por qué usar box-sizing: border-box?

  • Hace que el diseño sea más predecible.
  • Facilita los cálculos de ancho/alto.
  • Es el estándar en la mayoría de los frameworks CSS.
  • Evita problemas de diseño responsivo.

3. Dimensiones: width, height y Unidades

Podemos controlar el tamaño de los elementos usando diferentes unidades de medida:

Píxeles (px)

Unidad fija que no cambia con el tamaño de la pantalla.

200px × 100px
.caja {
    width: 200px;
    height: 100px;
}

Porcentaje (%)

Relativo al tamaño del contenedor padre.

50% del ancho del padre
.caja {
    width: 50%;
    height: 100px;
}

Otras unidades útiles:

  • vw/vh: 1% del ancho (viewport width) o alto (viewport height) de la ventana.
  • rem: Relativo al tamaño de la fuente del elemento raíz (html).
  • em: Relativo al tamaño de la fuente del elemento padre.
  • min-content/max-content: Tamaño mínimo/máximo necesario para el contenido.
/* Ejemplo de unidades responsivas */
.contenedor {
    width: 90%; /* 90% del ancho del padre */
    max-width: 1200px; /* No más ancho que 1200px */
    margin: 0 auto; /* Centrar el contenedor */
}

.columna {
    width: 100%; /* Ocupa todo el ancho en móviles */
    padding: 1rem; /* Espaciado relativo al tamaño de fuente */
}

@media (min-width: 768px) {
    .columna {
        width: 50%; /* 2 columnas en tablets */
        float: left;
    }
}

@media (min-width: 1024px) {
    .columna {
        width: 33.333%; /* 3 columnas en escritorio */
    }
}

🧩 Reto: "Tetris CSS"

Crea 3 cuadros de colores que se separen y respiren correctamente usando márgenes y rellenos.

Instrucciones:

  1. Crea un archivo HTML con 3 elementos <div>.
  2. Aplica estilos CSS para que cada uno tenga un color diferente.
  3. Usa márgenes y rellenos para espaciarlos correctamente:
    • Primer cuadrado: margen de 20px en todos los lados, relleno de 15px.
    • Segundo cuadrado: margen vertical de 30px, horizontal de 10px; relleno vertical de 10px, horizontal de 25px.
    • Tercer cuadrado: margen vertical de 10px, horizontal de 30px; relleno vertical de 25px, horizontal de 10px.
  4. Usa box-sizing: border-box para que los márgenes no afecten las dimensiones finales.
  5. ¡Abre el archivo en tu navegador para ver los resultados!

📝 Resumen de la Sesión

Lo que aprendimos hoy:

  • Modelo de Caja: Todo en CSS es una caja con contenido, padding, borde y margen.
  • Box Sizing: box-sizing: border-box hace que el ancho y alto incluyan el padding y el borde.
  • Unidades de Medida:
    • px: Píxeles (tamaño fijo).
    • %: Porcentaje del elemento padre.
    • vw/vh: Porcentaje del viewport.
    • rem/em: Relativas al tamaño de fuente.
  • Propiedades Abreviadas: margin: 10px 20px 10px 20px; (arriba, derecha, abajo, izquierda).
