👾 SESIÓN 3: Posicionamiento (Rompiendo la Gravedad)

Normalmente, las etiquetas HTML caen de arriba hacia abajo como si tuvieran gravedad. Hoy vamos a romper esas reglas.

1. El Comportamiento Natural (Display)

  • Block: Como un sillón VIP. Ocupan todo el ancho y no dejan que nadie se siente a su lado (ej. <h1>, <div>).
  • Inline: Como sillas plegables. Solo ocupan su espacio y se forman uno al lado del otro (ej. <a>, <span>).
  • Inline-block: Un híbrido. Se forman juntos, pero puedes controlar su ancho y alto.

2. Posicionamiento Mágico

  • Relative: Te mueves de tu silla original, pero dejas tu "fantasma" ahí. Nadie puede ocupar tu espacio.
  • Absolute: ¡Vuelas! Te sales de la fila y te mueves libremente dentro de tu contenedor padre (que debe ser relative).
  • Fixed: Te pegas a la pantalla de cristal del usuario. Aunque haga scroll, tú no te mueves.

🛠️ Ejemplo 1: El Sticker Perseguidor (Fixed)

Objetivo: Crear un botón de "Ayuda" que persiga al usuario.

HTML: <button class="sticker">💬 Ayuda</button>

CSS: 
.sticker {
    position: fixed; /* Te pegas a la pantalla */
    bottom: 20px;    /* A 20px del suelo */
    right: 20px;     /* A 20px de la derecha */
    background: #ff0055;
    color: white;
    padding: 15px;
    border-radius: 50px;
}

🧩 SESIÓN 4: Flexbox (El Layout Moderno)

Antes, alinear cosas en la web era una tortura. Hoy tenemos Flexbox: una caja mágica de goma. Solo le das órdenes al "Padre" y los "Hijos" obedecen.

Los Comandos Flex

Primero, activas el poder en el contenedor padre: display: flex;

  • justify-content (Eje X): center (al centro), space-between (a los extremos).
  • align-items (Eje Y): center (centrado vertical perfecto).
  • flex-direction: row (fila, por defecto) o column (columna).

🛠️ Ejemplo 2: El Centrado Divino

Objetivo: Centrar una tarjeta perfecta en medio de una sección.

HTML: <div class="padre"> <div class="hijo">Soy el centro del universo</div> </div>

CSS: 
.padre {
    display: flex;
    justify-content: center; /* Centra horizontalmente */
    align-items: center;     /* Centra verticalmente */
    height: 300px;           /* Le damos altura al padre */
    background: #222;
}

🛠️ Ejemplo 3: La Navbar Perfecta (Reto Final)

Objetivo: Logo a la izquierda, menú a la derecha.

HTML: <nav class="navbar"> <div class="logo">MiSitio</div> <div class="links">Inicio | Perfil</div> </nav>

CSS: 
.navbar {
    display: flex;
    justify-content: space-between; /* Uno a cada extremo */
    align-items: center;            /* Centrados verticalmente */
    background: #333;
    padding: 15px 30px;
    color: white;
}

🕵️‍♂️ Tips Pedagógicos para esta clase:

  • Psicología del Error: Los adolescentes se frustran rápido si la caja no se mueve a donde quieren. Antes de enseñarles código, haz que dibujen cajas de papel y las muevan con las manos simulando space-between o fixed.
  • Evita Float: No menciones la propiedad float a menos que pregunten. Es historia antigua y solo confunde la lógica limpia de Flexbox.
  • Gamificación: Al alumno que termine primero la Navbar, dale el título de "Arquitecto Web" de la sesión. El reconocimiento público a esta edad es un motor enorme.
  • El truco del borde rojo: Enséñales a poner border: 1px solid red; en todos sus contenedores cuando estén confundidos. Ver las líneas les ayuda a entender el "Modelo de Caja" instantáneamente.
