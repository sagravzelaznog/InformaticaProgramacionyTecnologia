🎯 Sesión 4: Flexbox - El Layout Moderno

Alinea elementos fácilmente sin sufrir con float

Objetivo de la Sesión

Aprender a usar Flexbox para crear diseños flexibles y responsivos de manera sencilla y eficiente, sin necesidad de trucos o soluciones alternativas.

¿Qué es Flexbox?

Flexbox es un modelo de diseño unidimensional que permite distribuir el espacio entre los ítems de una interfaz y mejorar las capacidades de alineación. Es especialmente útil cuando trabajamos con diseños que deben adaptarse a diferentes tamaños de pantalla.

Conceptos Básicos

  • Contenedor Flex: El elemento padre que contiene los ítems flexibles. Se crea con display: flex o display: inline-flex.
  • Ítems Flex: Los elementos hijos directos del contenedor flex.
  • Eje Principal (Main Axis): Por defecto es horizontal (de izquierda a derecha). Se controla con flex-direction.
  • Eje Transversal (Cross Axis): Es perpendicular al eje principal. Por defecto es vertical (de arriba a abajo).

Propiedades del Contenedor Flex

1. flex-direction

Define la dirección del eje principal y la dirección en que se apilan los ítems flexibles.

1
2
3
.contenedor {
    display: flex;
    flex-direction: row; /* row | row-reverse | column | column-reverse */
}

2. flex-wrap

Especifica si los ítems flexibles deben ajustarse en varias líneas o no.

1
2
3
4
5
6
.contenedor {
    display: flex;
    flex-wrap: nowrap; /* nowrap | wrap | wrap-reverse */
}

3. justify-content

Define la alineación a lo largo del eje principal.

1
2
3
.contenedor {
    display: flex;
    justify-content: flex-start; /* flex-start | flex-end | center | space-between | space-around | space-evenly */
}

4. align-items

Define la alineación predeterminada de los ítems a lo largo del eje transversal.

1
2
3
.contenedor {
    display: flex;
    align-items: stretch; /* stretch | flex-start | flex-end | center | baseline */
}

5. align-content

Alinea las líneas de un contenedor flex cuando hay espacio extra en el eje transversal.

1
2
3
4
5
6
.contenedor {
    display: flex;
    flex-wrap: wrap;
    align-content: stretch; /* stretch | flex-start | flex-end | center | space-between | space-around */
}

Propiedades de los Ítems Flex

1. order

Controla el orden en que aparecen los ítems dentro del contenedor flex.

1 (order: 1)
2 (order: 3)
3 (order: 2)
.item {
    order: 0; /* Valor por defecto, números enteros negativos o positivos */
}

2. flex-grow

Define la capacidad de un ítem para crecer si es necesario.

flex-grow: 1
flex-grow: 2
flex-grow: 1
.item {
    flex-grow: 0; /* Valor por defecto, sin unidad, determina la proporción de espacio que debe ocupar */
}

3. flex-shrink

Define la capacidad de un ítem para encogerse si es necesario.

1 (shrink: 1)
2 (shrink: 0)
3 (shrink: 1)
.item {
    flex-shrink: 1; /* Valor por defecto, sin unidad, determina la proporción de reducción */
}

4. flex-basis

Define el tamaño inicial de un ítem antes de que se distribuya el espacio restante.

basis: 100px
basis: 200px
basis: 100px
.item {
    flex-basis: auto; /* Valor por defecto, puede ser un tamaño como 100px, 20%, etc. */
}

5. flex (propiedad abreviada)

Es una propiedad abreviada para flex-grow, flex-shrink y flex-basis.

flex: 1 1 100px
flex: 2 1 100px
flex: 1 1 100px
.item {
    /* flex: flex-grow flex-shrink flex-basis */
    flex: 0 1 auto; /* Valor por defecto */
    
    /* Valores comunes */
    flex: 1; /* Equivale a flex: 1 1 0 */
    flex: auto; /* Equivale a flex: 1 1 auto */
    flex: none; /* Equivale a flex: 0 0 auto */
}

6. align-self

Permite sobrescribir la alineación predeterminada (o la especificada por align-items) para ítems individuales.

1 (por defecto)
2 (center)
3 (flex-end)
4 (stretch)
.item {
    align-self: auto; /* auto | flex-start | flex-end | center | baseline | stretch */
}

<style>
.gallery {
    display: flex;
    flex-wrap: wrap;
    gap: 15px;

    flex: 1 1 200px; /* Crecer, encoger, ancho base */

    overflow: hidden;
    border-radius: 8px;

.gallery-item img {
    width: 100%;
    height: 100%;
    object-fit: cover;
    transition: transform 0.3s;

.gallery-item:hover img {
    transform: scale(1.05);
}
</style>

🧩 Reto: La Navbar Perfecta

Crea una barra de navegación que cumpla con los siguientes requisitos:

  1. Estructura:
    • Un logotipo a la izquierda que redirija a la página de inicio.
    • Un menú de navegación a la derecha con al menos 4 enlaces.
    • Un botón de "Iniciar sesión" en la esquina superior derecha.
  2. Diseño:
    • Usa Flexbox para la alineación.
    • La barra debe tener un fondo oscuro con texto claro.
    • Los enlaces deben tener un efecto hover que cambie su color de fondo.
    • El botón de inicio de sesión debe destacarse con un color de acento.
  3. Responsive (opcional):
    • En pantallas pequeñas, los enlaces de navegación deben ocultarse y mostrarse un botón de menú (hamburguesa).
    • Al hacer clic en el botón de menú, se debe mostrar/ocultar el menú de navegación en una columna.

💡 Pista:

Puedes usar la siguiente estructura HTML como punto de partida:

<nav class="navbar">
    <a href="#" class="logo">MiSitio</a>
    
    <button class="menu-toggle" aria-label="Menú">
        <span></span>
        <span></span>
        <span></span>
    </button>
    
    <ul class="nav-links">
        <li><a href="#">Inicio</a></li>
        <li><a href="#">Servicios</a></li>
        <li><a href="#">Acerca de</a></li>
        <li><a href="#">Contacto</a></li>
    </ul>
    
    <a href="#" class="login-btn">Iniciar sesión</a>
</nav>

💡 Consejo para el menú hamburguesa:

Puedes usar JavaScript para alternar una clase que muestre/oculte el menú en dispositivos móviles. Aquí tienes un ejemplo:

document.querySelector('.menu-toggle').addEventListener('click', function() {
    document.querySelector('.nav-links').classList.toggle('active');
});

📝 Resumen de la Sesión

Lo que aprendimos hoy:

  • Conceptos básicos de Flexbox:
    • Contenedor flex e ítems flexibles
    • Eje principal y eje transversal
    • Dirección de los elementos
  • Propiedades del contenedor flex:
    • display: flex - Crea un contenedor flex
    • flex-direction - Establece la dirección del eje principal
    • flex-wrap - Controla si los ítems se envuelven en varias líneas
    • justify-content - Alinea los ítems en el eje principal
    • align-items - Alinea los ítems en el eje transversal
    • align-content - Alinea las líneas de un contenedor flex
    • gap - Espacio entre ítems
  • Propiedades de los ítems flexibles:
    • order - Controla el orden de los ítems
    • flex-grow - Capacidad de crecimiento de un ítem
    • flex-shrink - Capacidad de reducción de un ítem
    • flex-basis - Tamaño inicial de un ítem
    • flex - Propiedad abreviada para grow, shrink y basis
    • align-self - Alineación individual de un ítem
  • Casos de uso comunes:
    • Barras de navegación
    • Galerías de imágenes
    • Tarjetas con pie de página alineado
    • Cuadrículas de precios
    • Diseños de formularios
