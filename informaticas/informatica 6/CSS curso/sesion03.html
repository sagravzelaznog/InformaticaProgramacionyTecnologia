🧭 Sesión 3: Posicionamiento y Flujo

Rompiendo la gravedad del diseño web

Objetivo de la Sesión

Aprender a controlar la posición de los elementos en la página, rompiendo el flujo normal del documento cuando sea necesario.

1. El Comportamiento Natural: display

Antes de hablar de posicionamiento, es importante entender cómo los elementos se comportan por defecto:

1.1. Elementos de Bloque (display: block)

Ocupan todo el ancho disponible y comienzan en una nueva línea.

Caja de bloque 1
Caja de bloque 2
Caja de bloque 3
div {
    display: block; /* Valor por defecto para div, p, h1-h6, section, etc. */
    width: 200px;   /* Podemos definir un ancho */
    height: 50px;   /* Y un alto */
}

1.2. Elementos en Línea (display: inline)

Ocupan solo el espacio necesario y fluyen en la misma línea.

En línea 1 En línea 2 En línea 3 No respetan width/height ni márgenes verticales 
span {
    display: inline; /* Valor por defecto para span, a, strong, em, etc. */
    /* width y height no tienen efecto */
    /* margin-top y margin-bottom no tienen efecto */
}

1.3. Elementos en Línea-Bloque (display: inline-block)

Combinan lo mejor de ambos: fluyen en línea pero respetan dimensiones.

Caja 1
Caja 2
Caja 3
button, input, select, textarea {
    display: inline-block; /* Muchos elementos de formulario usan esto por defecto */
    width: 150px;  /* Ahora sí funciona */
    height: 40px;  /* También */
    margin: 10px;  /* Y los márgenes verticales también */
}

2. Posicionamiento en CSS

La propiedad position nos permite cambiar cómo se posicionan los elementos en la página:

static
relative
absolute
fixed
sticky
/* Posicionamiento Relativo */
.relativo {
    position: relative;
    top: 20px;    /* Se mueve 20px desde su posición original */
    left: 30px;   /* Se mueve 30px desde la izquierda */
    /* El espacio original que ocupaba se mantiene reservado */
}

/* Posicionamiento Absoluto */
.absoluto {
    position: absolute;
    top: 50px;    /* 50px desde el borde superior del contenedor posicionado más cercano */
    right: 20px;  /* 20px desde el borde derecho */
    /* El espacio original NO se mantiene */
}

/* Posicionamiento Fijo */
.fijo {
    position: fixed;
    bottom: 20px;  /* 20px desde el borde inferior de la ventana */
    right: 20px;   /* 20px desde el borde derecho de la ventana */
    /* Se mantiene en la misma posición aunque se haga scroll */
}

/* Posicionamiento Pegajoso */
.pegajoso {
    position: sticky;
    top: 0;  /* Se pega al borde superior cuando el scroll lo alcanza */
    /* Útil para encabezados de tabla o menús de navegación */
}

💡 Punto de Referencia

Para elementos con position: absolute, el punto de referencia (el elemento desde el que se miden las distancias) es el primer ancestro que tenga una posición definida (que no sea static). Si no hay ninguno, será el <html>.

.contenedor {
    position: relative; /* Establece el contexto de posicionamiento */
    width: 300px;
    height: 200px;
    border: 2px solid #333;
}

.hijo-absoluto {
    position: absolute;
    bottom: 10px;
    right: 10px;
    /* Se posiciona 10px desde la esquina inferior derecha de .contenedor */
}

3. El Eje Z: z-index

Controla el orden de apilamiento de los elementos posicionados. Mayor valor = más cerca del frente.

z-index: 1
z-index: 2
z-index: 3
.caja-1 {
    position: relative;
    z-index: 1;  /* Por debajo de caja-2 */
}

.caja-2 {
    position: relative;
    z-index: 2;  /* Por encima de caja-1 */
    margin-top: -50px;  /* Para que se superpongan */
    margin-left: 50px;
}

/* z-index solo funciona en elementos posicionados (position: relative, absolute, fixed, sticky) */
/* Los valores pueden ser positivos, negativos o 0 (valor por defecto) */

.contenedor-flotante::after {

.contenedor-flotante {
    overflow: auto;
}

💡 ¿Cuándo usar float hoy en día?

  • Para hacer que el texto fluya alrededor de una imagen.
  • Para diseños muy simples de columnas (aunque Flexbox/Grid son mejores opciones).
  • En combinación con shape-outside para diseños de texto creativos.

🧩 Reto: "Menú Flotante"

Crea un menú de navegación que se mantenga fijo en la parte inferior de la pantalla en dispositivos móviles y que tenga un botón flotante de "volver arriba" en la esquina inferior derecha.

Instrucciones:

  1. Crea un menú de navegación con al menos 3 enlaces.
  2. Usa position: fixed para fijarlo en la parte inferior de la pantalla.
  3. Añade un botón con position: fixed en la esquina inferior derecha que lleve al usuario al principio de la página.
  4. Usa z-index para asegurarte de que el menú esté por encima del contenido.
  5. Haz que el menú sea responsivo (puedes usar @media si lo deseas).

Consejos:

  • Usa bottom: 0 y left: 0 para el menú inferior.
  • Usa bottom: 20px y right: 20px para el botón flotante.
  • Puedes usar flexbox para distribuir los elementos del menú.
  • No olvides agregar un padding-bottom al cuerpo para que el contenido no quede oculto detrás del menú fijo.

Extras (opcional):

  • Añade una transición suave al botón de volver arriba.
  • Oculta el botón de volver arriba hasta que el usuario haga scroll.
  • Agrega un efecto de sombra al menú para darle profundidad.

📝 Resumen de la Sesión

Lo que aprendimos hoy:

  • Tipos de Display: block, inline, inline-block y cómo afectan al flujo del documento.
  • Posicionamiento:
    • static: Comportamiento normal (valor por defecto).
    • relative: Se mueve respecto a su posición original.
    • absolute: Se posiciona respecto al ancestro posicionado más cercano.
    • fixed: Se posiciona respecto a la ventana del navegador.
    • sticky: Híbrido entre relative y fixed.
  • z-index: Controla el orden de apilamiento de elementos posicionados.
  • Floats: Para hacer que el texto fluya alrededor de elementos.
  • Casos prácticos: Menús pegajosos, etiquetas de oferta, tooltips, etc.
