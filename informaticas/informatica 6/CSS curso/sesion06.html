✨ Sesión 6: Variables y Animaciones

Dale vida a tus diseños con CSS moderno

Objetivo de la Sesión

Aprender a usar variables CSS para un mantenimiento más sencillo y crear animaciones fluidas que mejoren la experiencia del usuario.

1. Variables CSS (Custom Properties)

Las variables CSS te permiten almacenar valores que puedes reutilizar en toda tu hoja de estilos, facilitando el mantenimiento y la consistencia del diseño.

1.1. Declaración y Uso de Variables

--primary
--secondary
--accent
--dark
/* Definir variables en el elemento :root para que estén disponibles globalmente */
:root {
    --primary: #4a90e2;
    --secondary: #00a86b;
    --accent: #f5a623;
    --dark: #2c3e50;
    --light: #f8f9fa;
    --transition: all 0.3s ease;
    --shadow: 0 4px 6px rgba(0, 0, 0, 0.1);
    --border-radius: 8px;
}

/* Usar las variables */
.boton {
    background-color: var(--primary);
    color: white;
    padding: 10px 20px;
    border: none;
    border-radius: var(--border-radius);
    box-shadow: var(--shadow);
    transition: var(--transition);
}

.boton:hover {
    background-color: var(--secondary);
    transform: translateY(-2px);
}

1.2. Cambio de Tema con Variables

Podemos usar JavaScript para cambiar los valores de las variables en tiempo real y crear temas dinámicos.

Selecciona un tema:

// JavaScript para cambiar el tema
const root = document.documentElement;
const themeButtons = document.querySelectorAll('.theme-btn');

themeButtons.forEach(button => {
    button.addEventListener('click', () => {
        const theme = button.dataset.theme;
        
        // Cambiar las variables según el tema seleccionado
        if (theme === 'default') {
            root.style.setProperty('--primary', '#4a90e2');
            root.style.setProperty('--secondary', '#00a86b');
            root.style.setProperty('--accent', '#f5a623');
        } else if (theme === 'green') {
            root.style.setProperty('--primary', '#2ecc71');
            root.style.setProperty('--secondary', '#27ae60');
            root.style.setProperty('--accent', '#f1c40f');
        }
        // ... más temas
    });
});

1.3. Editor de Variables en Tiempo Real

¡Vista Previa!

// JavaScript para el editor de variables
const root = document.documentElement;
const inputs = document.querySelectorAll('.variable-control input');

inputs.forEach(input => {
    input.addEventListener('input', (e) => {
        const value = e.target.value;
        const variable = e.target.dataset.variable;
        
        if (e.target.type === 'range') {
            document.getElementById('radius-value').textContent = `${value}px`;
            root.style.setProperty(variable, `${value}px`);
        } else {
            root.style.setProperty(variable, value);
        }
    });
});

2. Transiciones CSS

Las transiciones permiten cambiar los valores de las propiedades de forma suave durante un período de tiempo determinado.

2.1. Propiedades Básicas de Transición

Hover Me
Con Retraso
Solo Transform
Efecto Especial
/* Transición básica */
.transition-box {
    width: 100px;
    height: 100px;
    background-color: var(--primary);
    transition: all 0.3s ease;
    /* Propiedad abreviada: property duration timing-function delay */
}

/* Cambios al pasar el ratón */
.transition-box:hover {
    transform: translateY(-5px) rotate(5deg);
    box-shadow: 0 10px 20px rgba(0,0,0,0.2);
    background-color: var(--secondary);
}

/* Transición con retraso */
.transition-delay {
    transition-delay: 0.2s;
}

/* Transición solo para transform */
.transition-transform {
    transition-property: transform;
}

/* Función de temporización personalizada */
.transition-all {
    transition: all 0.5s cubic-bezier(0.68, -0.55, 0.27, 1.55);
}

2.2. Propiedades Animables

No todas las propiedades CSS son animables. Aquí tienes algunas de las más comunes que sí lo son:

  • Dimensión: width, height, padding, margin, border-width
  • Posición: top, right, bottom, left, transform
  • Color: color, background-color, border-color
  • Texto: font-size, line-height, letter-spacing
  • Visual: opacity, visibility, box-shadow

💡 Consejo: Para un mejor rendimiento, anima las propiedades opacity y transform siempre que sea posible, ya que son más eficientes para el navegador.

3. Animaciones CSS

Las animaciones CSS te permiten crear secuencias de animación más complejas que las transiciones simples.

3.1. Animaciones con @keyframes

Bounce
Pulse
Spin
Shake
/* Definir la animación con @keyframes */
@keyframes bounce {
    from {
        transform: translateY(0);
    }
    to {
        transform: translateY(-20px);
    }
}

@keyframes pulse {
    0% { transform: scale(1); }
    50% { transform: scale(1.1); }
    100% { transform: scale(1); }
}

@keyframes spin {
    from { transform: rotate(0deg); }
    to { transform: rotate(360deg); }
}

@keyframes shake {
    0%, 100% { transform: translateX(0); }
    25% { transform: translateX(-10px); }
    75% { transform: translateX(10px); }
}

/* Aplicar la animación a un elemento */
.animation-box {
    width: 100px;
    height: 100px;
    background-color: var(--accent);
    animation: bounce 2s infinite alternate;
    /* Propiedad abreviada: name duration timing-function delay iteration-count direction fill-mode */
}

.pulse {
    animation: pulse 2s infinite;
}

.spin {
    animation: spin 3s linear infinite;
}

.shake:hover {
    animation: shake 0.5s;
}

3.2. Control de Animaciones con JavaScript

// Obtener el elemento a animar
const box = document.getElementById('animated-box');

// Agregar la clase con la animación
document.getElementById('start-animation').addEventListener('click', () => {
    box.style.animation = 'bounce 2s infinite alternate';
});

// Pausar la animación
document.getElementById('pause-animation').addEventListener('click', () => {
    box.style.animationPlayState = 'paused';
});

// Reiniciar la animación
document.getElementById('reset-animation').addEventListener('click', () => {
    // Eliminar y volver a agregar la animación
    box.style.animation = 'none';
    box.offsetHeight; // Forzar el reflow
    box.style.animation = 'bounce 2s infinite alternate';
});

// Eventos de animación
box.addEventListener('animationstart', () => {
    console.log('La animación ha comenzado');});

// Efecto de carga suave
document.addEventListener('DOMContentLoaded', () => {
    // Agregar clase de carga a la tarjeta
    const profileCard = document.querySelector('.profile-card');
    profileCard.style.opacity = '0';
    
    // Mostrar con transición
    setTimeout(() => {
        profileCard.style.transition = 'opacity 0.6s ease-out';
        profileCard.style.opacity = '1';
    }, 100);
    
    // Efecto al pasar el ratón sobre los enlaces sociales
    const socialLinks = document.querySelectorAll('.social-link');
    
    socialLinks.forEach(link => {
        link.addEventListener('mouseenter', (e) => {
            // Pequeña animación al pasar el ratón
            e.target.style.transform = 'translateY(-5px) rotate(5deg)';
        });
        
        link.addEventListener('mouseleave', (e) => {
            e.target.style.transform = 'translateY(0) rotate(0)';
        });
        
        // Efecto de clic
        link.addEventListener('mousedown', (e) => {
            e.target.style.transform = 'scale(0.9)';
        });
        
        link.addEventListener('mouseup', (e) => {
            e.target.style.transform = 'translateY(-5px) rotate(5deg)';
        });
    });
});

// Cambiar tema de la tarjeta
function changeCardTheme(theme) {
    const root = document.documentElement;
    
    switch(theme) {
        case 'dark':
            root.style.setProperty('--primary', '#2c3e50');
            root.style.setProperty('--secondary', '#34495e');
            root.style.setProperty('--accent', '#e74c3c');
            break;
        case 'ocean':
            root.style.setProperty('--primary', '#3498db');
            root.style.setProperty('--secondary', '#2ecc71');
            root.style.setProperty('--accent', '#f1c40f');
            break;
        case 'sunset':
            root.style.setProperty('--primary', '#e67e22');
            root.style.setProperty('--secondary', '#e74c3c');
            root.style.setProperty('--accent', '#f39c12');

            root.style.setProperty('--primary', '#4a90e2');
            root.style.setProperty('--secondary', '#00a86b');

Crea tu propia tarjeta de perfil personalizada con los siguientes requisitos:

  1. Diseño:
