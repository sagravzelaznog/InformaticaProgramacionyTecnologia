🎨 Sesión 1: Conexión y Estética Básica

Dando el primer golpe de estilo a tu página web

Objetivo de la Sesión

Aprender a conectar CSS con HTML, entender la sintaxis básica de CSS, y aplicar estilos de texto y color para dar vida a tus páginas web.

1. ¿Cómo conectar HTML y CSS?

Existen tres formas de conectar CSS con HTML, pero solo una es la recomendada:

1.1. Estilo en línea (NO recomendado)

El estilo se aplica directamente en el elemento HTML con el atributo style.

<p style="color: blue; font-size: 16px;">Este es un párrafo con estilo en línea.</p>
💡 No recomendado: Dificulta el mantenimiento y la reutilización de estilos.

1.2. Estilo interno (Poco recomendado)

El estilo se coloca dentro de la etiqueta <style> en el <head> del documento HTML.

<!DOCTYPE html>
<html>
<head>
    <style>
        p {
            color: blue;
            font-size: 16px;
        }
    </style>
</head>
<body>
    <p>Este es un párrafo con estilo interno.</p>
</body>
</html>
💡 Poco recomendado: Mejor que el estilo en línea, pero aún así mezcla estructura con presentación.

1.3. Estilo externo (RECOMENDADO)

El estilo se escribe en un archivo separado con extensión .css que se enlaza al HTML.

archivo.html

<!DOCTYPE html>
<html>
<head>
    <link rel="stylesheet" href="estilos.css">
</head>
<body>
    <p>Este es un párrafo con estilo externo.</p>
</body>
</html>

estilos.css

p {
    color: blue;
    font-size: 16px;
}
✅ Recomendado: Separa claramente la estructura (HTML) de la presentación (CSS), permitiendo reutilizar estilos en múltiples páginas.

2. Selectores CSS: La Trinidad

Los selectores son patrones que nos permiten seleccionar elementos HTML para aplicarles estilos.

2.1. Selector de Etiqueta

Selecciona todos los elementos de un tipo específico.

/* Selecciona TODOS los párrafos */
p {
    color: blue;
}

Afectará a todos los elementos <p> de la página.

2.2. Selector de Clase (.)

Selecciona elementos con un atributo class específico.

<!-- HTML -->
<p class="destacado">Este párrafo es importante.</p>
<p>Este párrafo es normal.</p>

/* CSS */
.destacado {
    font-weight: bold;
    color: #2e7d32; /* Verde esmeralda */
}

Solo el párrafo con class="destacado" tendrá el estilo aplicado.

2.3. Selector de ID (#)

Selecciona un elemento con un atributo id específico.

<!-- HTML -->
<p id="principal">Este es el párrafo principal.</p>

/* CSS */
#principal {
    font-size: 20px;
    color: #1565c0; /* Azul */
}

Recuerda que los IDs deben ser únicos en una página.

2.4. Especificidad: ¿Quién gana la pelea?

Cuando varios estilos compiten por un mismo elemento, gana el más específico:

  1. !important (Evítalo si puedes)
  2. Estilo en línea (style="...")
  3. Selectores de ID (#mi-id)
  4. Selectores de clase (.mi-clase) y pseudo-clases (:hover)
  5. Selectores de etiqueta (div, p, etc.)
<div id="contenedor" class="caja">¡Hola!</div>

/* CSS */
div { color: black; }          /* Menos específico */
.caja { color: blue; }         /* Más específico */
#contenedor { color: red; }    /* El más específico */
/* El texto se verá en rojo */

3. Tipografía y Color

3.1. Propiedades de Texto

p {
    /* Familia tipográfica */
    font-family: 'Arial', sans-serif;
    
    /* Tamaño de fuente */
    font-size: 16px; /* o 1em, 100%, 1rem */
    
    /* Grosor de la fuente */
    font-weight: normal; /* o bold, 100-900 */
    
    /* Estilo de la fuente */
    font-style: normal; /* o italic, oblique */
    
    /* Transformación de texto */
    text-transform: none; /* o uppercase, lowercase, capitalize */
    
    /* Decoración de texto */
    text-decoration: none; /* o underline, line-through, overline */
    
    /* Alineación de texto */
    text-align: left; /* o center, right, justify */
    
    /* Altura de línea */
    line-height: 1.5;
    
    /* Espaciado entre letras */
    letter-spacing: 1px;
    
    /* Espaciado entre palabras */
    word-spacing: 2px;
}

3.2. Colores en CSS

Existen varias formas de definir colores en CSS:

/* Palabras clave */
color: blue;

/* Código hexadecimal (6 dígitos) */
color: #4a90e2; /* Azul claro */

/* Código hexadecimal (3 dígitos) */
color: #4ae; /* Equivale a #44aaee */

/* RGB (Red, Green, Blue) */
color: rgb(74, 144, 226);

/* RGBA (con transparencia) */
color: rgba(74, 144, 226, 0.7); /* 0.7 es la opacidad (70%) */

/* HSL (Hue, Saturation, Lightness) */
color: hsl(210, 75%, 59%);

/* HSLA (con transparencia) */
color: hsla(210, 75%, 59%, 0.7);

/* Color de fondo */
background-color: #f0f7ff; /* Azul muy claro */

/* Color de borde */
border: 1px solid #2e7d32; /* Verde esmeralda */
#4a90e2 (Azul principal)
#2e7d32 (Verde esmeralda)
#f0f7ff (Fondo claro)

3.3. Ejemplo Práctico

<!DOCTYPE html>
<html>
<head>
    <link rel="stylesheet" href="estilos.css">
    <style>
        /* Estilos para el ejemplo */
        body {
            font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif;
            line-height: 1.6;
            max-width: 800px;
            margin: 0 auto;
            padding: 20px;
            color: #333;
        }
        
        h1 {
            color: #1565c0;
            border-bottom: 2px solid #4a90e2;
            padding-bottom: 10px;
        }
        
        .destacado {
            background-color: #e8f5e9;
            border-left: 4px solid #2e7d32;
            padding: 15px;
            border-radius: 0 4px 4px 0;
        }
        
        .codigo {
            font-family: 'Courier New', Courier, monospace;
            background-color: #f5f5f5;
            padding: 2px 5px;
            border-radius: 3px;
        }
    </style>
</head>
<body>
    <h1>Mi Primera Página con Estilo</h1>
    
    <p>Este es un párrafo normal con texto de ejemplo para mostrar cómo se aplican los estilos CSS a los elementos HTML.</p>
    
    <p class="destacado">¡Este párrafo está destacado gracias a una clase CSS! Observa cómo el fondo es verde claro y tiene un borde lateral.</p>
    
    <p>Podemos usar la etiqueta <code class="codigo">&lt;code&gt;</code> para mostrar código en línea, como <code class="codigo">color: blue;</code>.</p>
</body>
</html>

🧩 Reto: "El Camaleón"

Crea un documento HTML con 3 párrafos y aplica estilos diferentes a cada uno usando clases CSS:

Instrucciones:

  1. Crea un archivo HTML básico con 3 párrafos.
  2. Agrega una clase única a cada párrafo (ej: parrafo1, parrafo2, parrafo3).
  3. En una hoja de estilos CSS externa, define estilos diferentes para cada clase:
    • Primer párrafo: Texto en azul, fuente Arial, tamaño 18px
    • Segundo párrafo: Fondo amarillo claro, texto en rojo, cursiva
    • Tercer párrafo: Borde verde, relleno de 10px, fuente Georgia
  4. Enlaza la hoja de estilos a tu documento HTML.
  5. ¡Abre el archivo en tu navegador para ver los resultados!

Consejos:

  • Usa selectores de clase (.) para apuntar a cada párrafo.
  • Experimenta con diferentes propiedades CSS como color, background-color, font-family, font-size, border, padding, etc.
  • Recuerda que los colores pueden ser palabras clave (blue, red) o códigos hexadecimales (#0000ff, #ff0000).

📝 Resumen de la Sesión

Lo que aprendimos hoy:

  • Conexión de CSS con HTML: La mejor práctica es usar archivos CSS externos con la etiqueta <link> en el <head>.
  • Selectores CSS:
    • Etiqueta: p { } (selecciona todos los párrafos)
    • Clase: .destacado { } (selecciona elementos con class="destacado")
    • ID: #principal { } (selecciona el elemento con id="principal")
  • Especificidad: Los estilos más específicos tienen prioridad (ID > Clase > Etiqueta).
  • Propiedades de texto: font-family, font-size, font-weight, text-align, etc.
  • Colores: Palabras clave, hexadecimal, RGB, RGBA, HSL, HSLA.
