Enlaces y Navegación en HTML

Objetivo de la Sesión

Aprender a crear enlaces entre documentos HTML y entender la gestión de rutas para una navegación efectiva.

Introducción Teórica: La Etiqueta de Anclaje

El elemento más importante para la navegación web es la etiqueta <a> (ancla).

Sintaxis Básica:

<a href="destino.html">Texto del enlace</a>

Atributos importantes:

  • href: Especifica la URL del enlace
  • target: Especifica dónde abrir el enlace
  • title: Información adicional
  • rel: Relación entre documentos

Ejemplos Visuales

Tipos de Rutas

1. Rutas Relativas

Referencias desde la ubicación actual:

./carpeta/archivo.html - Mismo nivel
../carpeta/archivo.html - Un nivel arriba

2. Rutas Absolutas

Referencias completas:

/carpeta/archivo.html
https://www.ejemplo.com/ruta/archivo.html

3. Rutas de Protocolo

Para correos o teléfonos:

<a href="mailto:correo@ejemplo.com">Enviar correo</a>

Navegación Interna

Puedes enlazar a secciones específicas usando IDs:

<h2 id="seccion1">Primera Sección</h2>
<a href="#seccion1">Ir a la primera sección</a>

Ejercicio Práctico

Crea un pequeño sitio web de 3 páginas sobre un tema de tu elección que incluya:

  • Página principal con introducción y menú de navegación
  • Dos páginas adicionales con contenido relacionado
  • Enlaces entre todas las páginas
  • Al menos un enlace a una sección específica
  • Un enlace externo y de correo

Estructura de Carpetas

proyecto/
├── index.html
├── pagina1/
│ └── pagina1.html
└── pagina2/
└── pagina2.html
