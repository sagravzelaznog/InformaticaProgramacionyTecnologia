📋 Sesión 7: Interacción Humano-Computadora

Formularios en HTML: Recopilando Datos de Usuario

Objetivo de la Sesión

Aprender a crear formularios interactivos que permitan a los usuarios enviar información de manera estructurada y accesible.

Conceptos Básicos de Formularios

Los formularios son la principal forma de recopilar información de los usuarios en la web. Permiten desde búsquedas simples hasta el envío de datos complejos.

Estructura Básica de un Formulario

<form action="/procesar" method="POST">
    <div class="form-group">
        <label for="nombre">Nombre:</label>
        <input type="text" id="nombre" name="nombre" required>
    </div>
    
    <div class="form-group">
        <label for="email">Correo electrónico:</label>
        <input type="email" id="email" name="email" required>
    </div>
    
    <button type="submit">Enviar</button>
</form>

📌 Importancia de la Accesibilidad en Formularios

  • Usa siempre etiquetas <label> asociadas a sus controles con el atributo for
  • Agrupa controles relacionados con <fieldset> y usa <legend> para el título del grupo
  • Proporciona instrucciones claras y mensajes de error descriptivos
  • Asegúrate de que los formularios sean navegables con teclado

Grupo de Opciones (Radio Buttons)

    <label>Género:</label>
    <div class="radio-option">

        <label for="masculino">Masculino</label>
    </div>
    <!-- Más opciones -->
</div>

        <label for="deportes">Deportes</label>

    <!-- Más opciones -->

Validación de Formularios

HTML5 introdujo atributos de validación integrados que funcionan sin JavaScript:

Atributos de Validación

El nombre de usuario es requerido y debe tener al menos 3 caracteres.
Por favor, introduce un correo electrónico válido.
La edad debe estar entre 13 y 120 años.
Por favor, introduce una URL válida.
<!-- Ejemplo de validación HTML5 -->
<input type="text" required minlength="3">  <!-- Requerido, mínimo 3 caracteres -->
<input type="email" required>             <!-- Requerido, formato de email -->
<input type="number" min="13" max="120">  <!-- Valor entre 13 y 120 -->
<input type="url">                       <!-- Formato de URL válida -->
<input pattern="[A-Za-z]{3}">           <!-- Patrón personalizado -->

💡 Consejos de UX para Formularios

  • Agrupa campos relacionados lógicamente
  • Usa etiquetas claras y descriptivas
  • Marca claramente los campos obligatorios
  • Proporciona ejemplos de formato esperado
  • Muestra mensajes de error claros y específicos
  • Usa el atributo autocomplete para ayudar a los usuarios
  • Considera el uso de campos de entrada con máscaras para formatos específicos

Actividad Práctica

Crea un formulario de registro de usuario con las siguientes características:

Requisitos:

  1. Sección de Información Personal:
    • Nombre completo (obligatorio)
    • Correo electrónico (obligatorio, formato válido)
    • Fecha de nacimiento (obligatorio, mayor de 13 años)
    • Género (opcional, radio buttons)
  2. Sección de Cuenta:
    • Nombre de usuario (obligatorio, mínimo 4 caracteres)
    • Contraseña (obligatorio, mínimo 8 caracteres)
    • Confirmar contraseña (debe coincidir con la contraseña)
  3. Preferencias (opcional):
    • Intereses (checkboxes: Deportes, Música, Tecnología, Viajes, etc.)
    • Notificaciones por correo (toggle sí/no)
    • Biografía (área de texto, máximo 500 caracteres)
  4. Validación:
    • Todos los campos obligatorios deben estar marcados
    • Validación en tiempo real de formato de correo
    • Confirmación de contraseña
    • Mensajes de error claros y específicos
  5. Diseño:
    • Organizado en secciones lógicas
    • Diseño responsive
    • Estilos CSS para mejorar la experiencia de usuario

💡 Consejos:

  • Usa el atributo required para los campos obligatorios
  • Usa type="email" y type="password" para una mejor experiencia en móviles
  • Agrega el atributo autocomplete para ayudar a los usuarios
  • Considera usar fieldset y legend para agrupar elementos relacionados
  • No olvides el botón de envío y el botón para restablecer el formulario

Resumen de la Sesión

  • Los formularios son la principal forma de recopilar información de los usuarios en la web
  • Elementos principales: <form>, <input>, <label>, <button>, <select>, <textarea>
  • Tipos de entrada: texto, correo, contraseña, número, fecha, radio, checkbox, etc.
  • Validación HTML5: atributos como required, min, max, pattern
  • Agrupación de controles: <fieldset> y <legend>
  • La accesibilidad es crucial: etiquetas asociadas, agrupación lógica, navegación por teclado
