🕸️ Sesión 3: La Telaraña

Enlaces y Navegación en HTML

Objetivo de la Sesión

Aprender a crear enlaces entre documentos HTML y entender la gestión de rutas para una navegación efectiva.

La Etiqueta de Anclaje <a>

El elemento más importante para la navegación web es la etiqueta <a> (ancla).

Sintaxis Básica:

<a href="destino.html">Texto del enlace</a>

Atributos importantes:

  • href: Especifica la URL del enlace (puede ser absoluta o relativa)
  • target: Especifica dónde abrir el enlace (ej: _blank para nueva pestaña)
  • title: Proporciona información adicional (se muestra al pasar el cursor)
  • rel: Especifica la relación entre el documento actual y el enlace

Tipos de Rutas

1. Rutas Relativas

Referencias desde la ubicación actual del archivo:

./carpeta/archivo.html - Mismo nivel ../carpeta/archivo.html - Un nivel arriba recursos/imagen.jpg - Dentro de una carpeta

2. Rutas Absolutas

Referencias completas desde la raíz del sitio:

/carpeta/archivo.html

O direcciones web completas:

https://www.ejemplo.com/ruta/archivo.html

3. Rutas de Protocolo

Para enlaces a correos o teléfonos:

<a href="mailto:correo@ejemplo.com">Enviar correo</a> <a href="tel:+525551234567">Llamar al 555-123-4567</a>

Navegación Interna

Puedes crear enlaces a secciones específicas dentro de la misma página usando IDs:

Paso 1: Asigna un ID al elemento destino

<h2 id="seccion1">Primera Sección</h2>

Paso 2: Crea un enlace al ID

<a href="#seccion1">Ir a la primera sección</a>

También puedes enlazar a secciones en otras páginas:

<a href="otrapagina.html#seccion-especifica">Ver más detalles</a>

Buenas Prácticas de Navegación

📌 Menú de Navegación

Crea una barra de navegación consistente en todas las páginas:

<nav>
    <ul>
        <li><a href="index.html">Inicio</a></li>
        <li><a href="acerca.html">Acerca de</a></li>
        <li><a href="contacto.html">Contacto</a></li>
    </ul>
</nav>

🔗 Enlaces Accesibles

  • Usa texto descriptivo en los enlaces
  • Incluye el atributo title cuando sea necesario
  • Mantén la consistencia en la navegación
  • Prueba todos los enlaces antes de publicar

Ejemplo Práctico: El Laberinto

Vamos a crear 3 páginas HTML que se enlacen entre sí:

Estructura de Carpetas:

proyecto/
├── index.html
├── habitacion1/
│   └── habitacion1.html
└── habitacion2/
    └── habitacion2.html

Instrucciones:

  1. Crea la estructura de carpetas mostrada arriba
  2. En cada archivo HTML, incluye un título y descripción de la habitación
  3. Crea enlaces entre las páginas para navegar entre ellas
  4. Incluye un enlace de "volver al inicio" en cada página

Actividad Práctica

Crea un pequeño sitio web de 3 páginas sobre un tema de tu elección (por ejemplo, tu banda favorita, un lugar que te gustaría visitar, etc.) que incluya:

Requisitos:

  • Página principal (index.html) con introducción y menú de navegación
  • Dos páginas adicionales con contenido relacionado
  • Enlaces entre todas las páginas
  • Al menos un enlace a una sección específica dentro de una página
  • Un enlace externo a un recurso relacionado
  • Un enlace de correo electrónico

💡 Consejo:

Organiza tus archivos en carpetas lógicas y usa rutas relativas para los enlaces.

Resumen de la Sesión

  • La etiqueta <a> con el atributo href crea enlaces
  • Las rutas pueden ser relativas (desde la ubicación actual) o absolutas (desde la raíz o URL completa)
  • Usa id para crear anclas dentro de una página
  • Los enlaces pueden apuntar a páginas web, secciones específicas, correos o números de teléfono
  • La navegación debe ser consistente y accesible en todo el sitio
