🖼️ Sesión 4: Multimedia y Accesibilidad

Imágenes, Figuras y Contenido Inclusivo

Objetivo de la Sesión

Aprender a incorporar elementos multimedia de manera accesible y semánticamente correcta en nuestras páginas web.

Imágenes en HTML

La etiqueta <img> nos permite insertar imágenes en nuestras páginas web. Es una etiqueta auto-cerrada que requiere al menos dos atributos:

Sintaxis Básica:

<img src="ruta/a/la/imagen.jpg" alt="Descripción de la imagen">

Atributos Importantes:

  • src: Ruta al archivo de imagen (requerido)
  • alt: Texto alternativo (requerido para accesibilidad)
  • width y height: Dimensiones de la imagen
  • loading: Controla la carga perezosa (lazy para cargar solo cuando sea visible)

📌 Importancia del Texto Alternativo

El atributo alt es obligatorio por varias razones:

  • Permite a los usuarios con discapacidad visual entender el contenido de la imagen a través de lectores de pantalla
  • Se muestra si la imagen no puede cargarse
  • Mejora el SEO de tu sitio web

Formatos de Imagen

🖼️ JPG/JPEG

Mejor para: Fotografías e imágenes con muchos colores

Ventajas: Buena compresión, amplia compatibilidad

Desventajas: Pérdida de calidad, sin transparencia

🎨 PNG

Mejor para: Gráficos, logotipos, imágenes con transparencia

Ventajas: Soporta transparencia, sin pérdida de calidad

Desventajas: Archivos más grandes que JPG

✨ SVG

Mejor para: Iconos, logotipos, gráficos vectoriales

Ventajas: Escalable sin pérdida de calidad, archivos pequeños

Desventajas: No es adecuado para fotografías

🏞️ WebP

Mejor para: Reemplazo moderno de JPG/PNG

Ventajas: Mejor compresión manteniendo calidad

Desventajas: Soporte limitado en navegadores antiguos

Elementos Semánticos para Multimedia

La Figura y su Leyenda

El elemento <figure> representa contenido independiente, como ilustraciones, diagramas, fotos, listados de código, etc., con una leyenda opcional (<figcaption>).

Ejemplo de Uso:

<figure>
    <img src="paisaje.jpg" alt="Hermoso paisaje montañoso al atardecer">
    <figcaption>Fotografía tomada en los Alpes Suizos durante el atardecer.</figcaption>
</figure>

Accesibilidad en Imágenes

📌 Texto Alternativo Efectivo

Un buen texto alternativo debe ser:

  • Descriptivo: Explica lo que muestra la imagen
  • Conciso: Generalmente una oración corta
  • Útil: Proporciona el mismo contexto que la imagen

Ejemplos de Textos Alternativos

❌ Mal

alt="foto"

Demasiado vago, no proporciona información útil.

✅ Bien

alt="Perro labrador dorado jugando con un frisbee en el parque"

Describe la imagen de manera clara y concisa.

❌ Demasiado Largo

alt="Esta es una imagen de un perro, específicamente un labrador dorado, que está en un parque soleado. El perro está saltando para atrapar un frisbee que está en el aire. Hay árboles verdes al fondo y el cielo está despejado."

Demasiado detallado, la mayoría es información innecesaria.

📌 Imágenes Decorativas

Para imágenes puramente decorativas que no aportan información:

alt="" (texto vacío)

Los lectores de pantalla ignorarán estas imágenes.

Ejemplo Práctico: Galería de Arte Digital

Vamos a crear una galería de imágenes accesible:

Instrucciones:

  1. Crea una carpeta llamada galeria
  2. Dentro, crea un archivo index.html con la estructura básica
  3. Agrega un título principal y una breve descripción
  4. Crea una sección con la clase gallery
  5. Dentro, añade al menos 4 elementos figure con imágenes y sus respectivas leyendas
  6. Asegúrate de que cada imagen tenga un texto alternativo descriptivo

Ejemplo de Estructura:

<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <title>Mi Galería de Arte Digital</title>
    <style>
        .gallery {
            display: grid;
            grid-template-columns: repeat(auto-fill, minmax(250px, 1fr));
            gap: 20px;
            padding: 20px;
        }
        .gallery figure {
            margin: 0;
        }
        .gallery img {
            width: 100%;
            height: 200px;
            object-fit: cover;
            border-radius: 8px;
        }
    </style>
</head>
<body>
    <h1>Mi Galería de Arte Digital</h1>
    <div class="gallery">
        <!-- Repite este bloque para cada imagen -->
        <figure>
            <img src="imagen1.jpg" alt="Descripción detallada de la imagen">
            <figcaption>Título de la obra</figcaption>
        </figure>
        <!-- Fin del bloque -->
    </div>
</body>
</html>

Actividad Práctica

Crea una página web que incluya:

Requisitos:

  • Un encabezado con título y descripción
  • Una galería con al menos 4 imágenes relacionadas con un tema de tu elección
  • Cada imagen debe tener un texto alternativo descriptivo
  • Cada imagen debe tener una leyenda con <figcaption>
  • Usa el elemento <figure> para agrupar cada imagen con su leyenda
  • Asegúrate de que la galería sea responsive
  • Incluye una imagen decorativa con alt=""

💡 Consejo:

Puedes usar imágenes de Unsplash o Picsum para tu galería.

Resumen de la Sesión

  • Usa la etiqueta <img> con los atributos src y alt obligatorios
  • Elige el formato de imagen adecuado según el uso (JPG para fotos, PNG para gráficos con transparencia, SVG para vectores)
  • Agrupa imágenes con sus leyendas usando <figure> y <figcaption>
  • Escribe textos alternativos descriptivos y significativos
  • Usa alt="" para imágenes puramente decorativas
  • Considera siempre la accesibilidad en el contenido multimedia
