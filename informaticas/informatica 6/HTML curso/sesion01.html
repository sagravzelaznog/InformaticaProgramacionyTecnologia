¿Qué es HTML?

HTML (HyperText Markup Language) es el lenguaje estándar que estructura el contenido web.

  • HyperText: Texto con vínculos (hipervínculos) entre documentos
  • Markup: Lenguaje de etiquetas para marcar/estructurar contenido
  • Language: Conjunto de reglas y símbolos estandarizados

El DOM (Document Object Model)

El DOM es una representación estructurada de un documento HTML en forma de árbol:

📄 document
📦 <html>
📦 <head>
📦 <body>

Sintaxis Básica de HTML

Las Etiquetas HTML

HTML utiliza etiquetas para estructurar y dar significado al contenido:

HTML 
<etiqueta>Contenido</etiqueta>

Una etiqueta de apertura marca el inicio, el contenido va en el medio, y una etiqueta de cierre marca el final.

Atributos HTML

Las etiquetas pueden tener atributos que proporcionan información adicional:

HTML 
<etiqueta atributo="valor">Contenido</etiqueta>

Los atributos siempre van en la etiqueta de apertura y modifican el comportamiento o apariencia del elemento.

Etiquetas Autofrenadas

Algunas etiquetas no tienen contenido y se "cierran a sí mismas":

HTML 
<meta charset="UTF-8">
<br>
<img src="imagen.jpg" alt="Descripción">

La Plantilla Maestra

Todo documento HTML debe seguir esta estructura básica estándar:

HTML5 
<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Título de la Página</title>
</head>
<body>
    <!-- Contenido visible de la página -->
</body>
</html>

Desglose de la Plantilla:

<!DOCTYPE html>

Declara que este es un documento HTML5

<html>

Elemento raíz que contiene todo el documento

<head>

Metadatos y configuración (invisible para el usuario)

<meta charset>

Define el conjunto de caracteres (UTF-8 para español)

<meta viewport>

Configura la página para dispositivos móviles

<title>

Título que aparece en la pestaña del navegador

<body>

Contiene todo el contenido visible de la página

Ejemplo Práctico: "Hola Mundo"

Vamos a crear tu primera página web paso a paso:

1

Abre tu editor de código

Utiliza Visual Studio Code, Sublime Text, Notepad++, o cualquier editor de texto plano

2

Crea un nuevo archivo

Crea un nuevo archivo y guárdalo con el nombre: hola-mundo.html

3

Copia el siguiente código

HTML 
<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Mi Primera Página</title>
</head>
<body>
    <h1>¡Hola Mundo!</h1>
    <p>¡Esta es mi primera página web!</p>
</body>
</html>
4

Guarda el archivo

Usa Ctrl+S (Windows/Linux) o Cmd+S (Mac) para guardar

5

Abre en tu navegador

Arrastra el archivo a una ventana del navegador o haz doble clic en él para verlo en acción

📺 Resultado Esperado:

● ● ● file:///hola-mundo.html

Actividad Práctica

Ahora es tu turno. Crea una página web personal que incluya:

1️⃣

Título Principal

Un encabezado (<h1>) con tu nombre completo

2️⃣

Párrafo de Presentación

2-3 líneas presentándote (edad, ciudad, pasión por la programación)

3️⃣

Lista de Intereses

Una lista (ordenada o desordenada) con tus 3 comidas, películas o deportes favoritos

4️⃣

Un párrafo con el símbolo © y el año actual (2026)

Agrega un segundo párrafo con tu comida favorita y por qué te gusta. Usa etiquetas <strong> para resaltar palabras importantes.
