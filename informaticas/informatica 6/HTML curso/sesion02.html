Introducción Teórica

¿Qué es la Jerarquía de Contenidos?

La jerarquía de contenidos es la estructura lógica que organiza la información en niveles de importancia. En HTML, esto se logra mediante los encabezados (<h1> hasta <h6>).

<h1> Título Principal

El más importante - Uno por página

<h2> Sección Principal

Temas principales dentro del documento

<h3> Subsección

Subtemas dentro de una sección

<h4> Sub-subsección

Detalles dentro de un subtema

<h5> Nivel 5

Información muy específica

<h6> Nivel 6

El nivel menos importante

Importancia de la Jerarquía Correcta

  • SEO (Posicionamiento): Los motores de búsqueda usan los encabezados para entender la estructura
  • Accesibilidad: Los lectores de pantalla dependenden de la jerarquía
  • Mantenibilidad: Código más fácil de entender y modificar
  • Experiencia del Usuario: Interfaz visualmente clara y navegable

Estructura Correcta vs Incorrecta

Estructura Correcta

HTML 
<h1>Inicio</h1>
<h2>Sección 1</h2>
<h3>Subsección 1.1</h3>
<h3>Subsección 1.2</h3>
<h2>Sección 2</h2>

Estructura Incorrecta

HTML 
<h1>Inicio</h1>
<h3>Sección 1</h3> ← Salta a h3
<h2>Subsección</h2> ← Saltea h2
<h6>Pequeño Detalle</h6> ← Demasiado salto

Elementos de Texto en HTML

Párrafos <p>

El elemento <p> define un bloque de texto. Los navegadores agregan automáticamente espacio (margin) antes y después.

HTML 
<p>Este es el primer párrafo del documento.</p>
<p>Este es el segundo párrafo, separado del anterior.</p>
<p>Los párrafos son fundamentales para la legibilidad.</p>

📺 Resultado:

● ● ● file:///parrafos.html

Este es el primer párrafo del documento.

Este es el segundo párrafo, separado del anterior.

Los párrafos son fundamentales para la legibilidad.

Saltos de Línea <br>

La etiqueta <br> inserta un salto de línea. Es una etiqueta autofrenada (no necesita cierre).

HTML 
<p>Esta es una dirección:<br>
Calle Principal 123<br>
Ciudad, País<br>
CP: 12345</p>

Nota: Usa <br> ocasionalmente. Para espaciar contenido, es mejor usar CSS.

Línea Horizontal <hr>

La etiqueta <hr> crea una línea divisoria temática. También es autofrenada.

HTML 
<h2>Sección 1</h2>
<p>Contenido de la sección 1...</p>

<hr>

<h2>Sección 2</h2>
<p>Contenido de la sección 2...</p>

Énfasis y Importancia

Existen diferentes formas de destacar texto:

<strong>
Indica importancia (generalmente en negrita)
Texto importante
<em>
Énfasis (generalmente en itálica)
Texto con énfasis
<b>
Negrita solo visual (no semántica)
Texto en negrita
<i>
Itálica solo visual (no semántica)
Texto en itálica
<mark>
Marca/resalta texto
Texto marcado
HTML 
<p>Este es <strong>muy importante</strong>.</p>
<p>Este texto tiene <em>énfasis especial</em>.</p>
<p>Debes <mark>recordar esto</mark> para el examen.</p>

Listas en HTML

Listas Desordenadas <ul>

Usa <ul> (unordered list) cuando el orden no importa. Por ejemplo: lista de compras, características, elementos similares.

HTML 
<h3>Frutas Favoritas</h3>
<ul>
    <li>Manzanas rojas</li>
    <li>Plátanos amarillos</li>
    <li>Naranjas jugosas</li>
    <li>Fresas dulces</li>
</ul>

📺 Resultado:

● ● ● file:///listas.html

Frutas Favoritas

  • Manzanas rojas
  • Plátanos amarillos
  • Naranjas jugosas
  • Fresas dulces

Listas Ordenadas <ol>

Usa <ol> (ordered list) cuando el orden es importante. Por ejemplo: pasos, ranking, instrucciones.

HTML 
<h3>Pasos para Hacer Pasta</h3>
<ol>
    <li>Hervir agua en una olla grande</li>
    <li>Agregar sal al agua</li>
    <li>Verter la pasta cuando el agua hierva</li>
    <li>Cocinar por 8-10 minutos</li>
    <li>Colar el agua y servir</li>
</ol>

📺 Resultado:

● ● ● file:///listas.html

Pasos para Hacer Pasta

  1. Hervir agua en una olla grande
  2. Agregar sal al agua
  3. Verter la pasta cuando el agua hierva
  4. Cocinar por 8-10 minutos
  5. Colar el agua y servir

Listas Anidadas

Las listas pueden contener otras listas dentro. Esto es útil para crear estructuras jerárquicas complejas.

HTML 
<ul>
    <li>Frutas
        <ul>
            <li>Manzanas</li>
            <li>Naranjas</li>
        </ul>
    </li>
    <li>Vegetales
        <ul>
            <li>Zanahorias</li>
            <li>Brócoli</li>
        </ul>
    </li>
</ul>

📺 Resultado:

● ● ● file:///listas-anidadas.html
  • Frutas
    • Manzanas
    • Naranjas
  • Vegetales
    • Zanahorias
    • Brócoli

Listas de Definición <dl>

Usa <dl> (definition list) para pares término-definición. Útil para glosarios, diccionarios, etc.

HTML 
<h3>Glosario de Términos Web</h3>
<dl>
    <dt>HTML</dt>
    <dd>Lenguaje de marcado para estructurar contenido web.</dd>
    
    <dt>CSS</dt>
    <dd>Lenguaje para dar estilo y apariencia a las páginas web.</dd>
    
    <dt>JavaScript</dt>
    <dd>Lenguaje de programación para hacer páginas interactivas.</dd>
</dl>

📺 Resultado:

● ● ● file:///definiciones.html

Glosario de Términos Web

HTML
Lenguaje de marcado para estructurar contenido web.
CSS
Lenguaje para dar estilo y apariencia a las páginas web.
JavaScript
Lenguaje de programación para hacer páginas interactivas.

Ejemplo Práctico: Página de Receta

Vamos a crear una página completa de receta usando todos los elementos aprendidos:

1

Crea el archivo receta.html

En tu editor de código, crea un nuevo archivo llamado receta.html

2

Agrega la estructura básica

Usa la plantilla HTML5 estándar que aprendiste en la sesión anterior

3

Copia este código completo

HTML 
<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Receta: Pasta Carbonara</title>
</head>
<body>
    <h1>Pasta Carbonara</h1>
    
    <h2>Descripción</h2>
    <p>La Pasta Carbonara es un clásico de la cocina italiana, 
    originaria de Roma. Es un plato simple pero delicioso, 
    perfecto para cualquier ocasión.</p>
    
    <h2>Ingredientes</h2>
    <ul>
        <li>400 gramos de pasta (preferentemente spaghetti)</li>
        <li>200 gramos de panceta o guanciale</li>
        <li>4 huevos grandes</li>
        <li>100 gramos de queso parmesano rallado</li>
        <li>Sal y pimienta negra al gusto</li>
    </ul>
    
    <h2>Instrucciones</h2>
    <ol>
        <li>Hierve agua en una olla grande con suficiente sal</li>
        <li>Cocina la pasta según las instrucciones del paquete</li>
        <li>Mientras tanto, pica la panceta en cubos pequeños</li>
        <li>En una sartén, fríe la panceta hasta que esté crujiente</li>
        <li>En un tazón, bate los huevos con el queso parmesano</li>
        <li>Cuando la pasta esté al dente, cuélala (guarda agua)</li>
        <li>Agrega la pasta caliente a la panceta</li>
        <li>Retira del fuego y agrega la mezcla de huevo</li>
        <li>Mezcla rápidamente y sirve de inmediato</li>
    </ol>
    
    <h2>Notas Importantes</h2>
    <p><strong>��No hiervas los huevos!</strong> Agrega la mezcla 
    de huevo fuera del fuego para obtener una salsa cremosa.</p>
    
    <h2>Variaciones</h2>
    <ul>
        <li>Usa diferentes pastas (penne, rigatoni, etc.)</li>
        <li>Agrega pimienta roja para un toque picante</li>
        <li>Sustituye parte del queso por pecorino romano</li>
    </ul>
    
    <p><em>¡Buen provecho!</em></p>
</body>
</html>
4

Guarda y visualiza

Guarda el archivo y abre en tu navegador para ver el resultado

Actividad Práctica

Crea una página web sobre tu película, libro o videojuego favorito que incluya:

1️⃣

Título Principal

Un <h1> con el nombre de la película/libro/videojuego

2️⃣

Descripción

Una sección <h2> "Sinopsis" con 2-3 párrafos describiendo la trama

3️⃣

Personajes Principales

Una sección <h2> con una lista desordenada de al menos 5 personajes principales

4️⃣

Top Momentos

Una lista ordenada con tus 5 momentos favoritos o más importantes

5️⃣

Términos Clave

Una lista de definición con 3-4 términos importantes y sus explicaciones

6️⃣

Formato de Texto

Usa <strong> y <em> para resaltar información importante

Desafío Extra (Opcional):

Agrega una sección de "Banda Sonora" o "Curiosidades" con una lista anidada que incluya categorías y subcategorías.
