📊 Sesión 6: Organización de Datos

Tablas en HTML: Estructura y Accesibilidad

Objetivo de la Sesión

Aprender a crear tablas accesibles y bien estructuradas para presentar datos tabulares de manera clara y organizada.

Conceptos Básicos de Tablas

Las tablas en HTML se utilizan para mostrar datos tabulares, como información financiera, calendarios, horarios, etc. No deben usarse para el diseño de páginas web.

Estructura Básica de una Tabla

<table>
    <tr>
        <th>Encabezado 1</th>
        <th>Encabezado 2</th>
    </tr>
    <tr>
        <td>Dato 1</td>
        <td>Dato 2</td>
    </tr>
</table>
Encabezado 1 Encabezado 2
Dato 1 Dato 2

Elementos de una Tabla

<table>

El contenedor principal que define la tabla.

<caption>

Proporciona un título o descripción para la tabla. Debe ir justo después de la etiqueta <table>.

<table>
    <caption>Horario de Clases</caption>
    <!-- Contenido de la tabla -->
</table>

<thead>, <tbody>, <tfoot>

Agrupan filas en secciones de encabezado, cuerpo y pie de tabla.

<table>
    <thead>
        <tr><th>Encabezados</th></tr>
    </thead>
    <tfoot>
        <tr><td>Resumen</td></tr>
    </tfoot>
    <tbody>
        <tr><td>Datos</td></tr>
    </tbody>
</table>

<tr>

Define una fila de celdas en una tabla.

<th>

Define una celda de encabezado. Por defecto, el texto está en negrita y centrado.

<td>

Define una celda de datos estándar.

Atributos Importantes

  • colspan="numero": Extiende una celda a través de varias columnas
  • rowspan="numero": Extiende una celda a través de varias filas
  • scope="col|row|colgroup|rowgroup": Especifica a qué celdas afecta un encabezado

Código de la Tabla de Ejemplo:

<table>
    <caption>Horario de Clases - Segundo Semestre</caption>
    <thead>
        <tr>
            <th scope="col">Hora</th>
            <th scope="col">Lunes</th>
            <!-- Más encabezados -->
        </tr>
    </thead>
    <tbody>
        <tr>
            <th scope="row">8:00 - 9:00</th>
            <td rowspan="2">Matemáticas<br><small>Salón 201</small></td>
            <!-- Más celdas -->
        </tr>
        <!-- Más filas -->
    </tbody>
    <tfoot>
        <tr>
            <td colspan="6">Horario sujeto a cambios...</td>
        </tr>
    </tfoot>
</table>

Accesibilidad en Tablas

📌 Mejores Prácticas de Accesibilidad

  • Usa <th> para encabezados de columna y fila
  • Usa el atributo scope para indicar si un encabezado es para una columna (col), fila (row), o grupo
  • Proporciona un <caption> descriptivo
  • Usa <thead>, <tbody>, y <tfoot> para agrupar el contenido
  • Evita tablas anidadas cuando sea posible

❌ Poco Accesible

<table border="1">
    <tr>
        <td><b>Nombre</b></td>
        <td><b>Edad</b></td>
    </tr>
    <tr>
        <td>María</td>
        <td>25</td>
    </tr>
</table>

✅ Accesible

<table>
    <caption>Información de Estudiantes</caption>
    <thead>
        <tr>
            <th scope="col">Nombre</th>
            <th scope="col">Edad</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <th scope="row">María</th>
            <td>25</td>
        </tr>
    </tbody>
</table>

Tablas Responsivas

Para hacer que las tablas sean legibles en dispositivos móviles, podemos usar varias técnicas:

1. Contenedor con Desplazamiento Horizontal

<div style="overflow-x:auto;">
    <table>
        <!-- Contenido de la tabla -->
    </table>
</div>

2. Reorganización en Pantallas Pequeñas

Usando CSS, podemos cambiar la visualización de la tabla en pantallas pequeñas:

@media screen and (max-width: 600px) {
    table, thead, tbody, th, td, tr {
        display: block;
    }
    
    thead tr {
        position: absolute;
        top: -9999px;
        left: -9999px;
    }
    
    tr { margin-bottom: 1rem; }
    
    td {
        position: relative;
        padding-left: 50%;
    }
    
    td:before {
        position: absolute;
        left: 6px;
        content: attr(data-label);
        font-weight: bold;
    }
}

Instrucciones:

  4. Asegúrate de que la tabla sea accesible
  5. Hazla responsive

Actividad Práctica

Crea una página web que muestre un informe de calificaciones escolares con las siguientes características:

Requisitos:

  1. Un título principal y una breve descripción
  2. Una tabla con las siguientes columnas:
    • Nombre del estudiante
    • Matemáticas
    • Ciencias
    • Historia
    • Promedio
  3. Usa <thead>, <tbody>, y <tfoot> correctamente
  4. Incluye al menos 5 estudiantes con calificaciones de ejemplo
  5. Calcula el promedio de cada estudiante
  6. Agrega una fila al final con el promedio del grupo por materia
  7. Haz que la tabla sea accesible y responsive

💡 Consejo:

Puedes usar JavaScript para calcular los promedios automáticamente, pero por ahora puedes calcularlos manualmente.

Resumen de la Sesión

  • Las tablas se usan para mostrar datos tabulares, no para el diseño de páginas
  • Elementos principales: <table>, <tr>, <th>, <td>
  • Estructura semántica: <caption>, <thead>, <tbody>, <tfoot>
  • Atributos importantes: colspan, rowspan, scope
  • La accesibilidad es crucial: usa encabezados, descripciones y estructura lógica
  • Haz que las tablas sean responsive para dispositivos móviles
