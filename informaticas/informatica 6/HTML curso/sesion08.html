🏆 Sesión 8: Proyecto Final

Integración y Despliegue de un Sitio Web Completo

Objetivo de la Sesión

Consolidar todos los conocimientos adquiridos durante el curso para crear, optimizar y desplegar un sitio web completo y funcional.

Proyecto: Mi Portafolio Personal

Vamos a crear un portafolio personal de 3 secciones que muestre tus habilidades en HTML5. Este será tu proyecto final que integrará todo lo aprendido en el curso.

📋 Requisitos del Proyecto

  • Página de Inicio (index.html) - Presentación personal y resumen
  • Sección de Proyectos (proyectos.html) - Muestra de tus trabajos
  • Formulario de Contacto (contacto.html) - Para que los visitantes se pongan en contacto contigo
  • Navegación consistente - Menú de navegación en todas las páginas
  • Diseño responsive - Que se vea bien en todos los dispositivos
  • Elementos multimedia - Imágenes, videos o audio relevantes
  • Formulario funcional - Con validación HTML5

Limpieza y Optimización de Código

✅ Revisión de Código

Antes de desplegar tu sitio, asegúrate de que tu código esté limpio y optimizado:

  • Indentación consistente - Usa espaciado uniforme (2 o 4 espacios)
  • Comentarios - Agrega comentarios para explicar secciones complejas
  • Validación W3C - Usa el validador de W3C para encontrar errores
  • Optimización de imágenes - Comprime imágenes sin perder calidad
  • Minificación - Minifica CSS y JavaScript (puedes usar herramientas en línea)

🔍 Validador de HTML

Usa el Validador de HTML del W3C para asegurarte de que tu código no tenga errores.

📝 Ejemplo de Estructura HTML Limpia

<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <meta name="description" content="Portafolio personal de [Tu Nombre] - Desarrollador Web">
    <meta name="keywords" content="portafolio, desarrollo web, HTML5, CSS, JavaScript">
    <meta name="author" content="[Tu Nombre]">
    
    <title>[Tu Nombre] - Portafolio</title>
    
    <link rel="stylesheet" href="css/style.css">
    <link rel="icon" href="images/favicon.ico" type="image/x-icon">
</head>
<body>
    <!-- Contenido de la página -->
    
    <script src="js/script.js"></script>
</body>
</html>

Metadatos y SEO Básico

Los metadatos son esenciales para el SEO y la experiencia del usuario. Asegúrate de incluir:

  • Descripción (description) - Un resumen de 150-160 caracteres de la página
  • Palabras clave (keywords) - Términos relevantes separados por comas
  • Autor (author) - Tu nombre o el nombre de tu organización
  • Viewport - Para diseño responsive
  • Favicon - Un ícono para tu sitio
