Estructura y Sintaxis Básica de HTML

Objetivo de la Sesión

Comprender la lógica del DOM y crear tu primer documento HTML funcional.

Introducción Teórica: ¿Cómo funciona la web?

La web se basa en un modelo cliente-servidor:

  • Cliente (navegador): Solicita y muestra contenido web
  • Servidor: Almacena y envía los archivos solicitados

HTML (HyperText Markup Language) es el lenguaje que estructura el contenido web.

Ejemplos Visuales

Sintaxis Básica

HTML utiliza etiquetas para estructurar el contenido:

<etiqueta>Contenido</etiqueta>

Las etiquetas pueden tener atributos que proporcionan información adicional:

<etiqueta atributo="valor">Contenido</etiqueta>

La Plantilla Maestra

Todo documento HTML debe seguir esta estructura básica:

<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Título de la Página</title>
</head>
<body>
    <!-- Contenido visible de la página -->
</body>
</html>

Ejercicio Práctico

Crea una página web que incluya:

  • Un título principal con tu nombre
  • Un párrafo de presentación
  • Una lista de tus tres comidas favoritas
  • Un pie de página con el símbolo de copyright y el año actual

Plantilla de Código

<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <title>Mi Página</title>
</head>
<body>
    <h1>Tu Nombre</h1>
    <p>Presentación</p>
    <ul>
        <li>Comida 1</li>
        <li>Comida 2</li>
        <li>Comida 3</li>
    </ul>
    <footer>&copy; 2026</footer>
</body>
</html>
