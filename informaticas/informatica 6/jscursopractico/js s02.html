🚪 Sesión 02: Condicionales Lógicos

Aprendiendo a darle "cerebro" a tu código para tomar decisiones.

⚖️ ¿Qué es un Condicional?

En la vida real, siempre tomas decisiones: "SI tengo hambre, ENTONCES como". En programación, el if es nuestro cadenero que decide quién pasa y quién no.

La Sintaxis del Hechizo

Para que un condicional funcione, necesitamos una comparación:

  • === : Igualito a...
  • > o < : Mayor o menor que...
  • !== : Diferente a...

🛠️ Ejemplo: El Cadenero del Antro

Vamos a programar la lógica de un guardia que revisa la edad para dejar entrar a alguien a un club.

let edad = 19;

1. Declaramos la variable con la edad del usuario.

if (edad >= 18) {

2. La condición: "¿Es la edad mayor o igual a 18?".

  alert("¡Bienvenido! Puedes pasar.");

3. Si la condición es VERDADERA, se ejecuta este código.

} else {

4. Si NO se cumplió lo anterior (FALSO), saltamos aquí.

  alert("Lo siento, eres muy joven.");

5. Respuesta final para los que no cumplen la regla.

}

6. Cerramos la llave para terminar la estructura.
