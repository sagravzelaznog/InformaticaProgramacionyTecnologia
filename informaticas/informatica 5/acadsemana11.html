Sesión 41: Herramientas de consulta y medición avanzada

En esta sesión dominaremos las herramientas de consulta para extraer información precisa de nuestros dibujos.

Objetivos de aprendizaje:

  • Utilizar herramientas de medición avanzada
  • Calcular áreas y propiedades de masa
  • Extraer información detallada de objetos

Taller Práctico: Análisis de Planos con Herramientas de Consulta (120 min)

Objetivo: Dominar las herramientas de medición y consulta para extraer información precisa de planos técnicos.

Parte 1: Técnicas de Medición (40 min)
  1. Medidas Básicas
    • Uso de DIST con referencias a objetos
    • Medición de ángulos con precisión decimal
    • Uso de MEASUREGEOM para múltiples mediciones
  2. Cálculo de Áreas
    • Áreas simples con AREA
    • Áreas restadas (huecos)
    • Uso de BOUNDARY para crear regiones
Parte 2: Consultas Avanzadas (50 min)
  1. Análisis de Propiedades
    • MASSPROP para inercias y centros de gravedad
    • Uso de LIST con filtros de selección
    • Extracción de datos con DATAEXTRACTION
  2. Automatización de Consultas
    • Macros para consultas frecuentes
    • Uso de campos dinámicos
    • Exportación de datos a hojas de cálculo

Proyecto: Análisis de Vivienda Unifamiliar

Objetivo: Realizar un análisis completo de un plano de vivienda utilizando herramientas de consulta avanzadas.

Parámetros a Medir:
  • Área útil total
  • Dimensiones de vanos (puertas/ventanas)
  • Distancias entre elementos estructurales
  • Porcentaje de superficie acristalada
Consultas a Realizar:
  • Listado de todos los bloques utilizados
  • Propiedades de capas y estilos
  • Verificación de cotas
Entregables:
  1. Informe Técnico con:
    • Tabla de áreas por ambiente
    • Listado de elementos constructivos
    • Verificación de normativas
  2. Archivo DWG con:
    • Capas de análisis
    • Tablas de datos
    • Notas de verificación

Rúbrica de Evaluación (100 puntos)

1. Precisión en Mediciones (35 puntos)

  • Exactitud de las medidas (15pts)
  • Uso apropiado de unidades (10pts)
  • Redondeo y formato (10pts)

2. Análisis de Datos (35 puntos)

  • Profundidad del análisis (15pts)
  • Organización de la información (10pts)
  • Extracción de conclusiones (10pts)

3. Documentación (30 puntos)

  • Claridad del informe (10pts)
  • Presentación de datos (10pts)
  • Organización del DWG (10pts)
Consejo Profesional: Crea una plantilla con estilos de tabla predefinidos para informes de análisis. Usa FIELDS para datos dinámicos que se actualicen automáticamente cuando el dibujo cambie. Mantén un registro de todas las consultas frecuentes en un archivo de texto para referencia futura.

Sesión 42: Personalización de tipos de línea y sombreados

Aprenderemos a crear nuestros propios tipos de línea y patrones de sombreado para cumplir con estándares específicos o añadir un toque personalizado a nuestros dibujos.

Objetivos de aprendizaje:

  • Crear tipos de línea personalizados con texto y formas
  • Crear patrones de sombreado personalizados

Taller Práctico: Creación de Elementos Gráficos Personalizados (120 min)

Objetivo: Dominar la creación de tipos de línea y patrones de sombreado personalizados para mejorar la calidad gráfica de los planos técnicos.

  3. Incluye símbolos de gota de agua antes y después del texto
  4. Prueba el tipo de línea en diferentes escalas

Parte 2: Patrones de Sombreado (50 min)
Ejercicio 2: Patrón de Piso Flotante
  1. Crea un archivo .pat con un patrón de tablones de madera
  2. Incluye variaciones de ancho para simular tablones naturales

Sesión 43: Introducción a AutoLISP

Daremos nuestros primeros pasos en la automatización de AutoCAD mediante AutoLISP, el lenguaje de programación integrado.

Objetivos de aprendizaje:

  • Entender qué es AutoLISP y para qué sirve
  • Aprender la sintaxis básica y funciones comunes
  • Cargar y ejecutar rutinas LISP

Taller Práctico: Automatización con AutoLISP (120 min)

Objetivo: Desarrollar habilidades básicas de programación en AutoLISP para automatizar tareas comunes en AutoCAD.

Parte 1: Fundamentos de AutoLISP (40 min)
Ejercicio 1: Entorno de Desarrollo
  1. Crea una carpeta para tus archivos LISP
  2. Configura la ruta de soporte de archivos en AutoCAD
  3. Instala un editor de código (VS Code con extensión LISP)
; Estructura básica de una función AutoLISP
(defun c:MI_COMANDO ()
  ; Código de la función
  (princ) ; Retorno limpio
)
Parte 2: Comandos Básicos (40 min)
Ejercicio 2: Dibujo Automatizado
  1. Crea un comando para dibujar una ventana estándar
  2. Implementa entrada de usuario para dimensiones
  3. Agrega validación de datos
; Ejemplo: Comando para dibujar una ventana
(defun c:VENTANA ()
  (setq pt1 (getpoint "\nSeleccione esquina inferior izquierda: "))
  (setq ancho (getdist pt1 "\nAncho de la ventana: "))
  (setq alto (getdist pt1 "\nAlto de la ventana: "))
  
  (command "_rectang" "_non" pt1 
           "_non" (list (+ (car pt1) ancho) (+ (cadr pt1) alto)))
  (princ)
)

Proyecto: Herramienta de Anotación Automática

Objetivo: Crear un comando LISP que automatice el etiquetado de áreas en planos arquitectónicos.

Funcionalidades Requeridas:
  • Seleccionar un espacio cerrado
  • Calcular automáticamente el área
  • Insertar una etiqueta con el área
  • Formatear el texto según estándares
Parámetros Configurables:
  • Precisión decimal
  • Prefijo/sufijo de texto
  • Estilo de texto
  • Color y capa
Guía de Implementación:
; Estructura básica del comando ETIQUETAR_AREA
(defun c:ETIQUETAR_AREA (/ ss pt area_texto)
  (setq ss (ssget "_+.:E:S" '((0 . "LWPOLYLINE,REGION,ELLIPSE,CIRCLE"))))
  (if ss
    (progn
      (setq pt (getpoint "\nPunto de inserción de la etiqueta: "))
      (setq area_texto (rtos (vla-get-area (vlax-ename->vla-object (ssname ss 0))) 2 2))
      (command "_text" pt "" "" (strcat area_texto " m²"))
    )
    (alert "No se seleccionó un objeto válido")
  )
  (princ)
)

Rúbrica de Evaluación (100 puntos)

1. Funcionalidad (40 puntos)

  • Ejecución sin errores (15pts)
  • Manejo de entradas inválidas (10pts)
  • Precisión de resultados (10pts)
  • Eficiencia del código (5pts)

2. Código (30 puntos)

  • Estructura y formato (10pts)
  • Comentarios documentación (10pts)
  • Buenas prácticas (10pts)

3. Aplicación Práctica (30 puntos)

  • Utilidad en proyectos reales (10pts)
  • Facilidad de uso (10pts)
  • Personalización (10pts)
Consejo Profesional: Comienza con rutinas pequeñas y específicas. Documenta cada función con comentarios que expliquen su propósito, parámetros y valores de retorno. Crea una biblioteca personal de funciones reutilizables. Prueba exhaustivamente tus rutinas con diferentes tipos de entradas para asegurar su robustez.

Sesión 44: Gestión de estándares de CAD

Aprenderemos a crear y aplicar estándares de CAD para asegurar la consistencia y calidad en los proyectos, especialmente en entornos colaborativos.

Objetivos de aprendizaje:

  • Comprender la importancia de los estándares de CAD
  • Crear y configurar un archivo de estándares (.dws)
  • Auditar dibujos para verificar el cumplimiento de los estándares

Taller Práctico: Implementación de Estándares CAD (120 min)

Objetivo: Desarrollar e implementar un sistema de estándares CAD completo para garantizar la consistencia en proyectos de dibujo técnico.

Parte 1: Creación de Estándares (40 min)
Ejercicio 1: Estructura de Capas
  1. Crea un nuevo archivo de plantilla (.dwt)
  2. Establece las capas estándar según la siguiente nomenclatura:
    • A-ANNO-DIMS (anotaciones y cotas)
    • A-WALL (muros)
    • A-DOOR (puertas)
    • A-FURN (mobiliario)
    • A-TEXT (textos)
  3. Asigna colores, tipos de línea y grosores apropiados
Parte 2: Configuración de Estilos (40 min)
Ejercicio 2: Estándares de Texto y Cotas
  1. Crea estilos de texto:
    • Estándar: Arial, Altura 2.5mm
    • Títulos: Arial Black, Altura 5.0mm
  2. Configura estilos de cota:
    • Arquitectónicas: Flecha arquitectónica
    • Mecánicas: Flecha cerrada

Proyecto: Manual de Estándares CAD

Objetivo: Crear un manual completo de estándares CAD para un estudio de arquitectura.

Contenido Requerido:
  • Estructura de capas y nomenclatura
  • Estilos de texto y cotas
  • Configuración de trazado
  • Bloques estándar
  • Plantillas de presentación
Archivos a Entregar:
  • Plantilla .dwt con estándares
  • Archivo .dws para auditoría
  • Documento PDF del manual
  • Biblioteca de bloques estándar
Guía de Implementación:
  1. Configuración Inicial
    • Crear estructura de carpetas del proyecto
    • Configurar rutas de soporte en AutoCAD
    • Establecer unidades y precisión
  2. Desarrollo de Estándares
    • Definir convenciones de nomenclatura
    • Crear paleta de colores estándar
    • Configurar estilos de trazado
  3. Automatización
    • Crear scripts de inicio
    • Configurar plantillas de hoja
    • Automatizar la carga de estándares

Rúbrica de Evaluación (100 puntos)

1. Estándares Técnicos (40 puntos)

  • Completitud de la estructura de capas (10pts)
  • Consistencia en estilos (10pts)
  • Documentación clara (10pts)
  • Facilidad de implementación (10pts)

2. Organización (30 puntos)

  • Estructura lógica (10pts)
  • Nomenclatura consistente (10pts)
  • Facilidad de mantenimiento (10pts)

3. Aplicación Práctica (30 puntos)

  • Utilidad en proyectos reales (10pts)
  • Escalabilidad (10pts)
  • Compatibilidad con flujos de trabajo existentes (10pts)
Consejo Profesional: Implementa un sistema de control de versiones para tus estándares. Crea un comité de estándares en tu oficina para revisar y actualizar periódicamente las normas. Desarrolla herramientas personalizadas para auditar y corregir automáticamente dibujos que no cumplan con los estándares.
