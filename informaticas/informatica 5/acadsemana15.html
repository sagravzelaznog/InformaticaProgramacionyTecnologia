Sesión 57: Definición del proyecto final

Taller de Definición del Proyecto Final

Duración: 4 horas (sesión extendida)

Objetivos de Aprendizaje:

  • Definir los requisitos técnicos y funcionales del proyecto
  • Establecer estándares de calidad y normativas aplicables
  • Planificar la estructura de trabajo y cronograma
  • Documentar el proceso de diseño y decisiones técnicas

Ejercicio 1: Análisis de Requisitos (60 min)

Objetivo: Definir las especificaciones técnicas del proyecto residencial.

  1. Determina las dimensiones del terreno (mínimo 15x30m)
  2. Establece el área construida máxima permitida (60% del terreno)
  3. Define la altura máxima permitida (2 niveles + azotea)
  4. Identifica las normativas de construcción locales aplicables
  5. Especifica los servicios básicos requeridos (agua, luz, drenaje)
Entregable: Documento de requisitos técnicos (máx. 2 páginas)

Ejercicio 2: Diseño Conceptual (90 min)

Objetivo: Desarrollar la propuesta conceptual del proyecto.

;; Código de ejemplo para configuración inicial
(defun c:INICIAR-PROYECTO ()
  (setq *proyecto* (getstring "\nNombre del proyecto: "))
  (setq *escala* (getint "\nEscala del plano (ej: 50): "))
  (cargar-plantilla-estandar)
  (configurar-entorno)
  (crear-estructura-carpetas)
  (princ))
  1. Realiza bocetos a mano alzada de la distribución de espacios
  2. Define la zonificación del proyecto (social, privada, servicio)
  3. Establece las circulaciones principales y secundarias
  4. Considera la orientación y asoleamiento
  5. Integra áreas verdes y espacios exteriores
Consejo: Usa referencias de proyectos similares y normativas de construcción.

Sesión 58: Desarrollo del proyecto - Fase 1

Ejercicio 1: Configuración del Entorno (45 min)

Objetivo: Establecer la configuración inicial del proyecto.

;; Configuración inicial del proyecto
(defun c:CONFIGURAR-PROYECTO ()
  (setvar "OSMODE" 35) ; Puntos finales, medios, centros, intersecciones
  (setvar "ORTHOMODE" 1) ; Líneas ortogonales activadas
  (setvar "SNAPANG" 0) ; Ángulo de referencia 0 grados
  (setvar "DIMSCALE" 50) ; Escala de cotas
  (command "-LAYER" "M" "A-WALL" "C" "7" "" "L" "CONTINUOUS" "" "")
  (princ "\nConfiguración del proyecto completada."))
  1. Crea un nuevo archivo basado en la plantilla estándar
  2. Configura las unidades (métricas, precisión 0.00)
  3. Establece los límites del dibujo según el tamaño del terreno
  4. Crea las capas necesarias (muros, puertas, ventanas, mobiliario, etc.)
  5. Configura estilos de texto y cotas

Ejercicio 2: Trazo de Muros (90 min)

Objetivo: Desarrollar la estructura básica del proyecto.

;; Función para crear muros con espesor variable
(defun c:MURO ()
  (setq espesor (getdist "\nEspesor del muro (cm): "))
  (setq pt1 (getpoint "\nPunto inicial: "))
  (setq pt2 (getpoint pt1 "\nPunto final: "))
  (command "_PLINE" pt1 "_WIDTH" espesor 0 pt2 "")
  (princ))
  1. Traza el perímetro exterior del edificio
  2. Dibuja los muros interiores según la distribución espacial
  3. Asegura que todos los muros estén en la capa correcta
  4. Verifica que las esquinas estén correctamente unidas
  5. Usa la función de offset para crear muros dobles cuando sea necesario
Consejo: Usa referencias externas (XREF) para mantener organizado el proyecto.

Ejercicio 1: Generación de Elevaciones (90 min)

Objetivo: Crear elevaciones precisas a partir de la planta arquitectónica.

;; Función para generar elevaciones automáticas
(defun c:ELEVACION-AUTOMATICA ()
  (command "_PROPERTIES")
  (command "_LAYER" "_M" "A-ELEV" "_C" "3" "" "_L" "CONTINUOUS" "" "_LW" "0.30" "" "")
  (setq ss (ssget "_X" '((0 . "LWPOLYLINE")(8 . "A-WALL"))))
  (command "_PROJECTGEOMETRY" "_V" ss "")
  (princ "\nElevaciones generadas. Ajusta los detalles manualmente."))
  1. Prepara la planta arquitectónica (asegúrate de que esté en coordenadas 0,0)
  2. Crea las líneas de proyección (90° desde la planta)
  3. Genera las elevaciones principales (Norte, Sur, Este, Oeste)
  4. Ajusta alturas de ventanas, puertas y elementos arquitectónicos
  5. Agrega detalles como cornisas, molduras y texturas
Consejo: Usa la herramienta de sección (SECTION) para verificar la relación entre plantas y elevaciones.

Ejercicio 3: Uso de Referencias Externas (60 min)

;; Gestión de XREFs
(defun c:MANEJO-XREFS ()
  (command "_XREF")
  (princ "\nPanel de referencias externas abierto."))

;; Actualizar todas las referencias
(defun c:ACTUALIZAR-XREFS ()
  (command "_-XREF" "_RELOAD" "*")
  (princ "\nTodas las referencias han sido actualizadas."))
  1. Crea un archivo maestro para las elevaciones
  2. Enlaza la planta como XREF (solo lectura)
  3. Organiza las capas de referencia (capa XREF/0)
  4. Configura las rutas relativas
  5. Prueba la actualización de referencias

Ejercicio 1: Configuración de Layouts (90 min)

Objetivo: Crear presentaciones profesionales de planos.

;; Configuración automática de Layout
(defun c:CONFIG-LAYOUT ()
  (command "_TILEMODE" "0")
  (command "_PAGESETUP")
  (command "_PLOTSTYLE" "MODE" "1")
  (command "_UNITS" "2" "2" "2" "2" "0" "N")
  (princ "\nConfiguración de Layout lista. Ajusta las escalas según sea necesario."))
  1. Crea un layout para cada tipo de plano (plantas, elevaciones, cortes)
  2. Configura los viewports con escalas apropiadas
  3. Establece estilos de trazado personalizados
  4. Agrega cajetines con información del proyecto
  5. Incluye marcas de plegado y doblez
Consejo: Usa estilos de tabla para mantener consistencia en los cajetines.

Ejercicio 2: Documentación Técnica (90 min)

;; Generar índice automático de planos
(defun c:INDICE-PLANOS ()

  2. Crea un índice general de planos

;; Script para exportar a PDF
