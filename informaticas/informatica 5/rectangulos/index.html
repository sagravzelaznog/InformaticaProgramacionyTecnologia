Dibujar un Rectángulo en AutoCAD

Método Básico: Comando RECTANG

  1. Escribe RECTANG en la línea de comandos y presiona Enter.
  2. Haz clic en el punto de inicio (esquina inferior izquierda).
  3. Arrastra el cursor para definir el tamaño del rectángulo.
  4. Haz clic nuevamente para establecer la esquina opuesta.

Ejemplo:

Para dibujar un rectángulo de 10 unidades de ancho por 5 de alto:

  1. RECTANG → Enter
  2. Ingresa el punto (0,0)
  3. Escribe @10,5 → Enter

Método con Área

  1. Escribe RECTANG y presiona Enter.
  2. Especifica la primera esquina.
  3. Escribe Area para Área y presiona Enter.
  4. Ingresa el área total deseada y presiona Enter.
  5. Especifica si quieres definir el largo o el ancho primero.
  6. Ingresa la dimensión y presiona Enter.

Ejemplo:

Para un rectángulo con área de 50 unidades cuadradas:

  1. RECTANG → Enter
  2. Haz clic en el punto de inicio
  3. Area → Enter
  4. 50 → Enter
  5. Selecciona Largo o Ancho
  6. Ingresa la medida (ej. 10 para el largo)

Método con Cotas

  1. Usa RECTANG para dibujar el rectángulo.
  2. Selecciona la primera esquina
  3. Para agregar cotas, usa el comando Cotas.
  4. ingresa la primera cota correspondiente a la longitud.
  5. ingresa la segunda cota correspondiente a la altura.
  6. presiona enter.

Ejemplo de cotas:

  1. Usa RECTANG para dibujar el rectángulo.
  2. Selecciona la primera esquina
  3. Escribe Cotas → Enter
  4. Escribe 10 para longitud y presiona enter
  5. Escribe 5 para altura y presiona enter
  6. Haz click en cualquier punto del area de trabajo

Método con Rotación

  1. Escribe RECTANG y presiona Enter.
  2. Especifica la primera esquina.
  3. Escribe Rotacion para Rotación y presiona Enter.
  4. Ingresa el ángulo de rotación en grados y presiona Enter.
  5. Especifica las dimensiones como en los métodos anteriores.

Consejos Rápidos:

  • Usa FILLET para redondear las esquinas del rectángulo.
  • Presiona F3 para activar/desactivar el snap a la cuadrícula.
  • Usa CHAMFER para crear chaflanes en las esquinas.
  • Puedes editar un rectángulo existente con el comando PEDIT.

Nota Importante:

Recuerda que un rectángulo en AutoCAD es una polilínea cerrada. Puedes usar el comando EXPLODE para convertirlo en líneas individuales si es necesario.
