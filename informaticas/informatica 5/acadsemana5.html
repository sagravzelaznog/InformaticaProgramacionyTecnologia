Sesión 17: Introducción a bloques dinámicos

En esta sesión exploraremos los conceptos fundamentales de los bloques dinámicos y sus ventajas.

Objetivos de aprendizaje:

  • Comprender qué son los bloques dinámicos
  • Identificar cuándo usar bloques dinámicos
  • Crear un bloque dinámico básico

Contenido detallado:

  1. Conceptos básicos
    • ¿Qué es un bloque dinámico?
      • Definición y características
      • Ventajas sobre los bloques estáticos
      • Casos de uso comunes
    • Interfaz del Editor de bloques
      • Panel de parámetros
      • Panel de acciones
      • Barra de herramientas de edición
    • Creación de un bloque básico
      • Dibujar la geometría base
      • Convertir a bloque dinámico
      • Guardar el bloque
  2. Parámetros básicos
    • Tipos de parámetros
      • Punto
      • Lineal
      • Polar
      • XY
    • Propiedades de los parámetros
      • Nombre
      • Descripción
      • Valores por defecto

Ejercicio práctico:

Crea un bloque dinámico básico de una puerta que incluya:

  • Geometría básica (rectángulo y arco)
  • Parámetro de punto para la ubicación
  • Parámetro lineal para el ancho
  • Parámetro de rotación
Consejo: Usa BEDIT para acceder al Editor de bloques y comienza con geometrías simples antes de añadir parámetros complejos.

Ejercicio Práctico: Creación de un Bloque Dinámico Básico

Objetivo: Desarrollar habilidades en la creación y configuración de bloques dinámicos básicos.

Parte 1: Configuración Inicial (30 min)

  1. Preparación del entorno
    • Crea un nuevo dibujo con unidades en centímetros
    • Configura capas para diferentes elementos del bloque
    • Establece el estilo de texto y cotas adecuados
  2. Dibujo de la geometría base
    1. Dibuja un rectángulo de 90x210cm (puerta estándar)
    2. Añade un arco para representar el movimiento de apertura
    3. Incluye una línea que represente el marco de la puerta

Parte 2: Creación del Bloque Dinámico (60 min)

  1. Conversión a bloque dinámico
    • Selecciona todos los elementos y usa BMAKE
    • Asigna un nombre descriptivo (ej: "PUERTA_DINAMICA")
    • Selecciona la opción "Abrir en el editor de bloques"
  2. Configuración de parámetros
    1. Añade un parámetro de Punto Base
    2. Configura un parámetro Lineal para el ancho (de 60 a 120cm)
    3. Añade un parámetro de Rotación
    4. Configura un parámetro de Visibilidad para diferentes tipos de puerta
  3. Pruebas del bloque
    • Guarda el bloque y cierra el editor
    • Inserta varias instancias del bloque
    • Prueba los diferentes parámetros configurados

Actividad en Clase: Biblioteca de Bloques Dinámicos

Duración: 90 minutos

Objetivo: Crear una colección de bloques dinámicos básicos para uso en proyectos de diseño arquitectónico.

Instrucciones:

  1. Planificación (20 min)
    • Forma equipos de 2-3 personas
    • Seleccionen 5 elementos arquitectónicos comunes (ej: ventanas, puertas, muebles, equipos sanitarios)
    • Definan los parámetros dinámicos necesarios para cada elemento
  2. Desarrollo (60 min)
    1. Cada equipo desarrolla los 5 bloques dinámicos
    2. Documenta cada bloque con instrucciones de uso
    3. Prueba cada bloque en diferentes escenarios
  3. Presentación (10 min por equipo)
    • Muestra los bloques creados
    • Explica los parámetros implementados
    • Comparte los desafíos encontrados y cómo los resolvieron

Sesión 18: Parámetros de bloques

Profundizaremos en los diferentes tipos de parámetros y cómo configurarlos para crear bloques dinámicos más potentes.

Objetivos de aprendizaje:

  • Dominar los diferentes tipos de parámetros
  • Configurar propiedades avanzadas de parámetros
  • Crear conjuntos de parámetros

Contenido detallado:

  1. Parámetros avanzados
    • Parámetro de alineación
      • Configuración de ángulos
      • Puntos de inserción
    • Parámetro de visibilidad
      • Estados de visibilidad
      • Control de objetos visibles
    • Parámetro de búsqueda
      • Crear listas de búsqueda
      • Asignar valores
  2. Propiedades de parámetros
    • Valores fijos vs. variables
      • Establecer valores mínimos/máximos
      • Incrementos
    • Expresiones y fórmulas
      • Sintaxis básica
      • Variables predefinidas
      • Operadores matemáticos

Ejercicio Práctico: Configuración Avanzada de Parámetros

Objetivo: Dominar la configuración de parámetros avanzados en bloques dinámicos.

Parte 1: Parámetros de Alineación (45 min)

  1. Crear un bloque de silla de oficina
    • Dibuja los componentes básicos (asiento, respaldo, base)
    • Añade un parámetro de alineación al centro de la base
    • Configura el ángulo de inclinación del respaldo
  2. Pruebas de alineación
    1. Inserta el bloque cerca de una pared
    2. Observa cómo se ajusta automáticamente
    3. Modifica el ángulo de inclinación

Parte 2: Parámetros de Visibilidad (45 min)

  1. Crear estados de visibilidad
    • Para un bloque de ventana, crea estados para:
      • Vista en planta
      • Vista en alzado
      • Vista en 3D
  2. Configuración avanzada
    1. Asigna objetos a cada estado de visibilidad
    2. Prueba los diferentes estados
    3. Ajusta la configuración según sea necesario

Sesión 19: Acciones de bloques

Aprenderemos a añadir acciones a los parámetros para hacer que los bloques dinámicos sean verdaderamente interactivos.

Objetivos de aprendizaje:

  • Agregar acciones a parámetros
  • Configurar propiedades de acciones
  • Crear interacciones complejas

Contenido detallado:

  1. Tipos de acciones
    • Estirar
      • Selección de geometría
      • Puntos de estiramiento
      • Áreas de estiramiento
    • Mover
      • Selección de objetos
      • Dirección del movimiento
    • Escalar
      • Punto base
      • Factor de escala
    • Rotar
      • Centro de rotación
      • Ángulo de rotación
  2. Acciones avanzadas
    • Matriz
      • Configuración de filas y columnas
      • Distancias de separación
    • Barra
      • Personalización de la barra
      • Asignación de propiedades
    • Conjunto de acciones
      • Agrupar acciones
      • Secuenciar acciones

Ejercicio Práctico: Dominio de Acciones en Bloques Dinámicos

Objetivo: Aprender a implementar y configurar acciones avanzadas en bloques dinámicos.

Parte 1: Acciones Básicas (60 min)

  1. Acción de Estiramiento
    • Crea un bloque de ventana corrediza básica
    • Añade un parámetro lineal para el ancho
    • Configura la acción de estiramiento para las hojas de la ventana
    • Prueba el ajuste del ancho manteniendo las proporciones
  2. Acción de Matriz
    1. Agrega un parámetro de matriz al bloque de ventana
    2. Configura la acción para duplicar las hojas
    3. Establece la distancia fija entre hojas
    4. Prueba la funcionalidad de matriz

Parte 2: Acciones Avanzadas (60 min)

  1. Barra de Herramientas Personalizada
    • Crea una barra de herramientas con opciones comunes
    • Asigna acciones a cada botón
    • Personaliza los íconos y descripciones
  2. Conjunto de Acciones
    1. Agrupa acciones relacionadas
    2. Configura la secuencia de ejecución
    3. Prueba la interacción entre acciones

Ejercicio Práctico: Proyecto Integrador de Bloques Dinámicos

Objetivo: Aplicar todos los conocimientos adquiridos para crear un sistema completo de bloques dinámicos interconectados.

Parte 1: Mueble Modular (90 min)

  1. Configuración Inicial
    • Crea un bloque base de 60x30x80 cm
    • Añade parámetros para ancho, profundidad y altura
    • Configura acciones de estiramiento para cada dimensión
  2. Componentes Modulares
    1. Estantes ajustables con espaciado automático
    2. Cajones deslizantes con guías visibles
    3. Opciones de puertas (corredizas, abatibles, sin puerta)
    4. Soportes y herrajes ocultos/mostrables

Parte 2: Escalera Paramétrica (90 min)

  1. Parámetros Principales
    • Altura total (80-300 cm)
    • Ancho de huella (25-35 cm)
    • Altura de contrahuella (15-20 cm)
    • Número de escalones (3-20)
  2. Opciones Avanzadas
    1. Diferentes estilos de barandilla
    2. Materiales y texturas
    3. Opciones de iluminación
    4. Dimensiones automáticas según normativa

Actividad en Clase: Taller de Resolución de Problemas

Objetivo: Desarrollar habilidades para identificar y solucionar problemas comunes en bloques dinámicos.

Instrucciones:

  1. Análisis de Casos (30 min)

    • Identifica los errores y posibles soluciones
    • Documenta tu análisis
  2. Corrección de Errores (60 min)
    1. Repara los bloques defectuosos
    2. Optimiza su rendimiento
    3. Documenta los cambios realizados
  3. Presentación (30 min)
    • Explica los problemas encontrados
    • Muestra cómo los resolviste
    • Comparte consejos para evitar errores similares
