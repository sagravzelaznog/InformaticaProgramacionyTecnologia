Crear un Stickman en AutoCAD

1. Configuración Inicial

  1. Abre AutoCAD y crea un nuevo dibujo.
  2. Asegúrate de que las unidades estén configuradas correctamente: UNIDADES → Establecer a "Decimal" y precisión de 0.00.
  3. Activa el modo ORTO (presiona F8).
  4. Activa el modo SNAP (presiona F9).

2. Dibujar la Cabeza (Círculo)

Vamos a dibujar un círculo para la cabeza en las coordenadas (0,0):

Comando: CIRCULO → Enter

Especificar punto central: 0,0 → Enter

Especificar radio: 10 → Enter

3. Dibujar el Cuerpo (Línea Vertical)

Dibujaremos una línea desde el centro de la cabeza hacia abajo:

Comando: LINEA → Enter

Primer punto: 0,-10 → Enter

Siguiente punto: 0,-50 → Enter

Presiona Enter para terminar

4. Dibujar los Brazos (Líneas Diagonales)

Dibujaremos dos líneas desde el centro del cuerpo hacia los lados:

Comando: LINEA → Enter

Primer punto: 0,-25 → Enter

Siguiente punto: -30,-15 → Enter (brazo izquierdo)

Presiona Enter

Comando: LINEA → Enter

Primer punto: 0,-25 → Enter

Siguiente punto: 30,-15 → Enter (brazo derecho)

Presiona Enter

5. Dibujar las Piernas (Líneas Diagonales)

Dibujaremos dos líneas desde la parte inferior del cuerpo:

Comando: LINEA → Enter

Primer punto: 0,-50 → Enter

Siguiente punto: -20,-80 → Enter (pierna izquierda)

Presiona Enter

Comando: LINEA → Enter

Primer punto: 0,-50 → Enter

Siguiente punto: 20,-80 → Enter (pierna derecha)

Presiona Enter

6. Agregar Detalles a la Cara (Opcional)

Para hacer el stickman más expresivo, podemos agregar ojos y una sonrisa:

Ojo Izquierdo (Círculo Pequeño)

Comando: CIRCULO → Enter

Especificar punto central: -3,3 → Enter

Especificar radio: 1.5 → Enter

Ojo Derecho (Círculo Pequeño)

Comando: CIRCULO → Enter

Especificar punto central: 3,3 → Enter

Especificar radio: 1.5 → Enter

Sonrisa (Arco)

Comando: ARC → Enter

Especificar punto inicial: -5,-5 → Enter

Segundo punto: 0,-8 → Enter

Punto final: 5,-5 → Enter

7. Resumen de Coordenadas

Elemento Punto Inicial Punto Final/Radio
Cabeza 0,0 Radio: 10
Cuerpo 0,0 0,-50
Brazo Izquierdo 0,-25 -30,-15
Brazo Derecho 0,-25 30,-15
Pierna Izquierda 0,-50 -20,-80
Pierna Derecha 0,-50 20,-80
Ojo Izquierdo -3,3 Radio: 1.5
Ojo Derecho 3,3 Radio: 1.5
Sonrisa -5,-5 a 0,-8 a 5,-5 Arco

Consejos Adicionales:

  • Puedes usar ZOOM EXTENTS para ver todo el dibujo.
  • Usa SAVE para guardar tu trabajo.
  • Puedes modificar las coordenadas para cambiar la posición o tamaño del stickman.
  • Experimenta con diferentes grosores de línea usando PEDIT.
