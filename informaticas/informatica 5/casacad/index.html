Dibujar una Casa Sencilla en AutoCAD

Vista Previa

1. Configuración Inicial

  1. Abre AutoCAD y crea un nuevo dibujo.
  2. Configura las unidades: UNIDADES → Decimal, precisión 0.00.
  3. Activa ORTO (F8) y SNAP (F9).

2. Base de la Casa

Comando: REC → Enter

Primera esquina: 50,100 → Enter

Esquina opuesta: @200,120 → Enter

3. Techo

Comando: L → Enter

Puntos: 50,220 → 150,290 → 250,220

Escribe C → Enter para cerrar

4. Puerta

Comando: REC → Enter

Primera esquina: 130,100 → Enter

Esquina opuesta: @40,50 → Enter

5. Ventanas

Ventana Izquierda:

REC → 80,160 → @30,30

Líneas divisorias: L → 95,160 → 95,190

L → 80,175 → 110,175

Ventana Derecha:

REC → 190,160 → @30,30

Líneas divisorias: L → 205,160 → 205,190

L → 190,175 → 220,175

6. Chimenea (Opcional)

Base: REC → 180,260 → @20,30

Parte superior: REC → 175,285 → @30,10

7. Guardar el Dibujo

Guarda tu trabajo con CTRL + S o escribe SAVE.
