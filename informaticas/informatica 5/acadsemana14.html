Sesión 53: Introducción a la automatización en AutoCAD

Taller Práctico: Automatización en AutoCAD (120 min)

Objetivo: Dominar las herramientas de automatización básicas de AutoCAD para optimizar flujos de trabajo repetitivos.

Ejercicio 1: Creación de Macros Básicas
  1. Abre el Administrador de grabación de acciones (ACTRECORD)
  2. Graba una macro que:
    • Cree una capa llamada "Muros" con color rojo
    • Establezca el grosor de línea a 0.50mm
    • Dibuje un rectángulo de 5x3m
  3. Guarda la macro como "MuroExterior"

Comandos clave:

ACTRECORD - Iniciar grabación de acciones

-LAYER - Crear y configurar capas

RECTANG - Dibujar rectángulo

Ejercicio 2: Scripts Básicos

OFFSET 5 0,0 0,70
OFFSET 5 0,70 150,70
OFFSET 5 150,70 150,0

    Ejercicio 1: Función Avanzada de Muro con Aberturas
    
    
    Crea una función que dibuje un muro con aberturas para puertas y ventanas:
    
    
    
        
    (defun c:MuroConAberturas ( / pt1 pt2 altura ancho_puerta alto_puerta)
  ; Obtener parámetros del usuario
  (setq pt1 (getpoint "\nPunto inicial del muro: "))
  (setq pt2 (getcorner pt1 "\nPunto final del muro: "))
  (setq altura (getdist pt1 "\nAltura del muro: "))
  
  ; Dibujar contorno del muro
  (command "_RECTANG" "_non" pt1 "_non" (list (car pt2) (cadr pt2) (+ (caddr pt1) altura)))
  
  ; Bucle para agregar aberturas
  (while (setq pt_abertura (getpoint "\nSelecciona ubicación de abertura (Enter para terminar): "))
    (initget "Puerta Ventana")
    (setq tipo_abertura (getkword "\nTipo de abertura [Puerta/Ventana] : "))
    (if (null tipo_abertura) (setq tipo_abertura "Puerta"))
    
    (cond
      ((= tipo_abertura "Puerta")
        (setq ancho_puerta (getdist "\nAncho de puerta: "))
        (setq pt_puerta1 (polar pt_abertura 0 (/ ancho_puerta 2)))
        (setq pt_puerta2 (polar pt_abertura 0 (- 0 (/ ancho_puerta 2))))
        (command "_LINE" pt_puerta1 pt_puerta2 "")
      )
      ((= tipo_abertura "Ventana")
        (setq ancho_ventana (getdist "\nAncho de ventana: "))
        (setq alto_ventana (getdist "\nAlto de ventana: "))
        (setq pt_ventana1 (polar pt_abertura (angle pt1 pt2) (/ ancho_ventana 2)))
        (setq pt_ventana2 (polar pt_ventana1 (+ (angle pt1 pt2) (/ pi 2)) alto_ventana))
        (command "_RECTANG" "_non" (polar pt_ventana1 (angle pt1 pt2) (- 0 ancho_ventana)) 
                               "_non" (polar pt_ventana2 (angle pt1 pt2) ancho_ventana))
      )
    )
  )
  (princ)
)

  (princ))

(defun c:ACOTAR-AUTOMATICO ()
  (setq ss (ssget "_X" '((0 . "LINE,ARC,CIRCLE"))))
  (command "-DIMSTYLE" "R" "ANOTACIONES")
  (if ss
    (progn
      (command "-LAYER" "S" "A-ANNO-DIMS" "")
      (acotar-elementos ss)
    )
    (alert "No se encontraron elementos para acotar")
  )
  (princ))
