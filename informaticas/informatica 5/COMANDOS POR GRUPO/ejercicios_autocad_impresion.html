Presentación e Impresión en AutoCAD

Domina los Layouts, Viewports y Configuración de Impresión para Planos Profesionales

Introducción

El Espacio Modelo es donde dibujas tus objetos a escala 1:1. El Espacio Papel (Layout) es donde configuras el tamaño de la hoja de papel, el membrete y presentas tu dibujo a la escala correcta mediante Viewports.

Flujo de Trabajo Básico
Espacio Modelo (Dibujo a escala 1:1)
↓
Viewports (Ventanas al modelo)
↓

I. Conceptos Clave

Concepto Descripción Comando/Ubicación
Espacio Modelo Ambiente de dibujo infinito. Se dibuja siempre a escala real (1:1). Pestaña Model
Espacio Papel (Layout) Ambiente de impresión. Define el tamaño de la hoja y el marco de presentación. Pestañas Layout1, Layout2, etc.
Viewport Ventana flotante dentro del Espacio Papel que muestra una vista del Espacio Modelo. Comando VISTAS (MV o MVIEW)
Escala de Viewport La relación entre la unidad de papel y la unidad de dibujo (Ej: 1 unidad de papel = 50 unidades de dibujo). Propiedades de Viewport (Ventana)
Consejo Profesional

Mantén siempre tu dibujo a escala 1:1 en el Espacio Modelo y usa los Viewports en el Layout para establecer las escalas de presentación. Esto facilita las modificaciones posteriores y evita errores de escala.

II. Comando VISTAS (MVIEW) y Viewports

El comando VISTAS crea o manipula las ventanas que "miran" el Espacio Modelo desde el Espacio Papel.

Creación Básica
Zoom en Viewport

1. Creación Básica

Descripción: Configura una Viewport para ver el dibujo del Espacio Modelo.

Comando: VISTAS (MV)
1. Ve a la pestaña Layout1. 2. Borra el viewport existente (si lo hay). 3. Activa el comando VISTAS (MV). 4. Dibuja un rectángulo que defina el área de la Viewport (Ej: 10,10 hasta 20,15).

2. Zoom en Viewport

Descripción: Mueve y hace zoom dentro de la Viewport sin afectar la escala del papel.

Interacción con Viewport
1. Haz doble clic dentro del Viewport creado. El borde se resaltará. 2. Usa la rueda del ratón para hacer zoom o el comando ZOOM. 3. Haz clic y arrastra con la rueda del ratón para moverte por el dibujo. 4. Haz doble clic fuera del Viewport para volver al Espacio Papel.
Precaución

Evita usar el comando ZOOM desde la barra de comandos dentro de un Viewport, ya que esto puede alterar la escala. En su lugar, usa la rueda del ratón o la paleta de navegación.

III. Escalas de Viewport

Asegurar que el dibujo se imprima a la escala correcta es el paso más importante en la preparación.

Fórmula de Escala

1. Escala Arquitectónica 1:100

Descripción: Configura el Viewport para que el dibujo se imprima a escala 1:100.

Configuración de Escala
1. Selecciona el borde del Viewport (no hagas doble clic dentro). 2. Abre la ventana Propiedades (PR). 3. Busca la sección "Varios". 4. En la propiedad "Escala estándar", selecciona 1:100 de la lista desplegable. 5. Bloquea el Viewport (candado en la barra de estado) para evitar cambios accidentales.

2. Escala Detalle 1:25

Descripción: Configura un segundo Viewport para un detalle a escala 1:25.

Configuración de Escala para Detalle
1. Crea un segundo Viewport pequeño (MV). 2. Haz doble clic dentro del Viewport para activarlo. 3. Usa ZOOM para enfocar el área de detalle. 4. Haz doble clic fuera para salir. 5. Selecciona el borde del Viewport. 6. En Propiedades, en "Escala estándar", selecciona 1:25. 7. Bloquea el Viewport.
Buenas Prácticas

Usa diferentes escalas en el mismo Layout para mostrar tanto la vista general como los detalles. Asegúrate de que las escalas sean estándar (1:10, 1:20, 1:50, 1:100, etc.) y evita escalas personalizadas que puedan causar confusión.

Fórmula de Escala

La relación entre las unidades de papel y las unidades de dibujo se calcula con:

Fórmula General
Unidades de Papel = Unidades de Dibujo / Factor de Escala

Ejemplos:

Para escala 1:50 → 1/50 = 0.02

Para escala 1:20 → 1/20 = 0.05

Configuración Manual de Escala
1. Selecciona el Viewport. 2. Abre Propiedades (PR). 3. Busca "Escala personalizada". 4. Ingresa el factor de escala (ej: 0.02 para 1:50). 5. Presiona Enter para aplicar.

IV. Actividades Sugeridas (Preparación Final de Planos)

Estas actividades te ayudarán a dominar la creación de planos profesionales con múltiples escalas y estilos de trazado.

Actividad 1: El Plano con Detalles 🖼️

Objetivo: Crear un layout con dos viewports, uno para el plano general (escala 1:50) y otro para un detalle ampliado (escala 1:10).

Instrucciones Paso a Paso:

  1. Dibuja un Muro y un Bloque (Espacio Modelo):
    • Dibuja un muro de 20×10 unidades.
    • Crea un Bloque llamado Puerta_1 e insértalo en el muro.
  2. Configura el Layout:
    • Ve a Layout1 y configura el tamaño de la hoja (Ej: ISO A3).
  3. Crea Viewport General:
    • Crea un Viewport 1 (MV) que ocupe la mayor parte de la hoja.
    • Asigna la escala 1:50 a este Viewport (Propiedades).
  4. Crea Viewport Detalle:
    • Crea un Viewport 2 más pequeño al lado del primero.
    • Asigna la escala 1:10 a este Viewport (Propiedades).
    • Haz doble clic dentro del Viewport 2 y centra la vista en la Puerta_1.

Resultado: Debes tener un plano a escala 1:50 y un detalle legible de la puerta a escala 1:10.

Ver Solución (Verificación de Escala)

Si la Viewport General está a 1:50 y la Puerta mide 1 unidad, al medir en el papel esa unidad se representará con 1/50 de la unidad de papel.

Si la Viewport Detalle está a 1:10 y la Puerta mide 1 unidad, al medir en el papel esa unidad se representará con 1/10 de la unidad de papel, siendo cinco veces más grande que la vista general, demostrando la correcta aplicación de escalas.

Actividad 2: El Ploteo Final (CTB) 📝

Objetivo: Configurar un estilo de ploteo para que las capas se impriman con diferentes grosores, incluso si tienen el mismo color en pantalla.

Instrucciones Paso a Paso:

  1. Crea Capas con Grosores:
    • En el Espacio Modelo, dibuja una línea en la capa _Muro_Grueso (Grosor 0.50 mm, Color Rojo).
    • Dibuja otra línea en la capa _Muro_Ligero (Grosor 0.09 mm, Color Rojo).
  2. Activa el Cuadro de Ploteo:
    • Ve a Layout1.
    • Activa el comando PLOT (IMPRIMIR / PLOT).
  3. Crea una CTB (Tabla de Estilos de Trazado):
    • En el cuadro de Plot, en la opción "Tabla de estilos de trazado" (pen assignments), selecciona "Nuevo..." para crear una nueva tabla (Ej: MiEstilo.ctb).
  4. Asigna Propiedades por Color:
    • Edita la CTB recién creada.
    • Busca el Color Rojo (Color 1).
    • Configura la propiedad "Grosor de línea" (Lineweight) a 0.80 mm.
    • Guarda y cierra el editor de la CTB.
  5. Configura la Impresión:
    • Selecciona la impresora o PDF.
    • Establece el tamaño de papel (Ej: ISO A3).
    • Selecciona la CTB recién creada en "Estilo de trazado" o "Plot style table".
    • Haz clic en "Vista previa" para verificar.

Nota: Aunque las capas tenían grosores preestablecidos, la CTB sobrescribe la configuración por color.

Resultado: Ambas líneas (gruesa y ligera) se imprimirán con el mismo grosor de 0.80 mm, porque la CTB establece que todo objeto de color rojo se trace a 0.80 mm.

Ver Solución (Concepto de CTB)

El comando PLOT usa la tabla .CTB (Color-Dependent Plot Style) para definir cómo se verá el resultado final. En la mayoría de los estudios de diseño, la configuración de la CTB es crítica para que los diferentes colores usados en pantalla (rojo, amarillo, etc.) se traduzcan en diferentes grosores de línea (0.80, 0.40, 0.20 mm) en la impresión, asegurando la jerarquía visual del dibujo.

Configuración Avanzada de CTB

Además del grosor, las CTB te permiten configurar:

  • Escala de grises (útil para impresiones en blanco y negro)
  • Tipo de línea (continuo, punteado, etc.)
  • Transparencia
  • Relleno (para áreas sombreadas)

Guarda tus CTB personalizadas en una ubicación segura para usarlas en otros proyectos.

Consejos Adicionales

  • Usa PSPACE y MSPACE para alternar rápidamente entre Espacio Papel y Espacio Modelo dentro de un Viewport.
  • La variable de sistema PSLTSCALE controla si los tipos de línea se escalan según el Viewport o según el Espacio Papel.
  • Usa LAYERSTATE para guardar y restaurar configuraciones de capas específicas para diferentes presentaciones.
  • Configura un Page Setup por defecto para cada Layout para ahorrar tiempo en configuraciones repetitivas.
  • Usa PUBLISH para imprimir múltiples layouts a la vez o guardarlos como archivos PDF.
  • Recuerda que los textos deben tener un tamaño de impresión legible (2.5-3.5mm de altura) independientemente de la escala del Viewport.
Exportar a PDF

Para exportar tus planos a PDF con la mejor calidad:

  1. Selecciona la impresora "DWG To PDF.pc3" (o similar).
  2. Configura la resolución a un mínimo de 300 DPI para planos técnicos.
  3. Marca la opción "Publicar con estilos de trazado" para incluir tu CTB.
  4. Usa la opción "Ventana" para seleccionar exactamente qué área del Layout quieres exportar.
