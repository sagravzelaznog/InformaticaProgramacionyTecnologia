Práctica 12 U1: Diccionarios

Los diccionarios se definen con llaves `{}` y almacenan datos en pares **clave: valor**.

# practica09 u2: Diccionarios

persona = {
    "nombre": "Elena",
    "edad": 24,
    "ciudad": "Ciudad de México",
    "profesion": "Ingeniera"
}

print(f"Nombre: {persona['nombre']}")
print(f"Edad: {persona['edad']}")

# Añadir un nuevo par clave-valor
persona["email"] = "elena@mail.com"
print(f"Email añadido: {persona['email']}")

Práctica 13 U1: Recorriendo un Diccionario

Se puede usar el bucle `for` para iterar sobre las claves y/o los valores de un diccionario.

# practica10 u2: Iteración en Diccionarios

calificaciones = {
    "Matemáticas": 9.5,
    "Física": 8.0,
    "Programación": 10.0
}

# Iterar sobre las claves (materias)
print("Materias disponibles:")
for materia in calificaciones.keys():
    print(f"- {materia}")

# Iterar sobre claves y valores
print("\nCalificaciones:")
for materia, calificacion in calificaciones.items():
    print(f"La calificación de {materia} es {calificacion}")

Práctica 14 U1: Funciones (Sin retorno)

Una función es un bloque de código reusable que se define con la palabra clave `def`.

# practica11 u2: Función Simple

# Definición de la función con un parámetro (nombre)
def saludar(nombre):
    print(f"¡Hola, {nombre}!")
    print("Bienvenido a la clase de Python.")

# Llamada a la función
saludar("Carlos")
saludar("María")
