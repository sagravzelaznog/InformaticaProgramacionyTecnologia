Definición de Variables

En esta práctica, exploraremos los diferentes tipos de datos en Python y cómo trabajar con ellos. Cubriremos:

  • Tipos de datos básicos: enteros, flotantes, cadenas y booleanos
  • Operaciones comunes con variables
  • Conversión entre diferentes tipos de datos

Ejecuta cada sección del código y observa los resultados. Luego, intenta modificar los valores y experimenta con diferentes operaciones.

# Práctica 01 U2: Variables y Tipos de Datos

# ===== 1. Tipos de Datos Básicos =====
# Variable de tipo entero (int)
edad = 30

# Variable de tipo flotante (float)
precio = 19.99

# Variable de tipo cadena de texto (str)
nombre = "Ana García"

# Variable de tipo booleano (bool)
es_estudiante = True

# Variable de tipo NoneType
valor_nulo = None

# ===== 2. Estructuras de Datos =====
# Lista (mutable, ordenada, permite duplicados)
frutas = ["manzana", "banana", "cereza"]

# Tupla (inmutable, ordenada, permite duplicados)
coordenadas = (40.7128, -74.0060)

# Conjunto (mutable, no ordenado, no permite duplicados)
colores = {"rojo", "verde", "azul"}

# Diccionario (mutable, ordenado desde Python 3.7, pares clave-valor)
estudiante = {
    "nombre": "Carlos",
    "edad": 22,
    "carrera": "Informática"
}

# ===== 3. Operaciones con Variables =====
# Operaciones aritméticas
suma = 5 + 3.2
resta = 10 - 4
multiplicacion = 6 * 7
division = 15 / 3
potencia = 2 ** 3

# Operaciones con cadenas
saludo = "Hola, " + nombre + "!" 
longitud_nombre = len(nombre)
mayusculas = nombre.upper()

# Operaciones con listas
frutas.append("naranja")  # Añadir elemento
ultima_fruta = frutas[-1]  # Último elemento

# ===== 4. Conversión de Tipos =====
numero_texto = "123"
numero_entero = int(numero_texto)
numero_decimal = float("45.67")
texto_numero = str(123)

# ===== 5. Mostrar Resultados =====
print("\n=== Tipos Básicos ===")
print(f"Nombre: {nombre}, Tipo: {type(nombre)}")
print(f"Edad: {edad}, Tipo: {type(edad)}")
print(f"Precio: {precio}, Tipo: {type(precio)}")
print(f"¿Es estudiante?: {es_estudiante}, Tipo: {type(es_estudiante)}")

print("\n=== Estructuras de Datos ===")
print(f"Lista de frutas: {frutas}, Tipo: {type(frutas)}")
print(f"Coordenadas: {coordenadas}, Tipo: {type(coordenadas)}")
print(f"Colores: {colores}, Tipo: {type(colores)}")
print(f"Datos del estudiante: {estudiante}, Tipo: {type(estudiante)}")

print("\n=== Operaciones ===")
print(f"Suma: 5 + 3.2 = {suma}")
print(f"Saludo personalizado: {saludo}")
print(f"Longitud del nombre: {longitud_nombre} caracteres")
print(f"Última fruta añadida: {ultima_fruta}")

print("\n=== Conversión de Tipos ===")
print(f"'123' como entero: {numero_entero}, Tipo: {type(numero_entero)}")
print(f"'45.67' como float: {numero_decimal}, Tipo: {type(numero_decimal)}")
print(f"123 como texto: {texto_numero}, Tipo: {type(texto_numero)}")
