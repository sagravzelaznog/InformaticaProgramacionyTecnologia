5. Prácticas 06-08 U1: Condicionales y Bucle While

Aprende a controlar el flujo de ejecución del programa.

Instrucciones para la Actividad

Paso 2: Entrada de Datos | En la Práctica 04, al ejecutar la celda, aparecerá una casilla para que introduzcas el número.

Práctica 06 U1: Estructura Condicional `if/elif/else`

El código evalúa si un número es positivo, negativo o cero.

# practica06 u1: Condicionales

numero = 10

if numero > 0:
    print("El número es positivo.")
elif numero < 0:
    print("El número es negativo.")
else:
    print("El número es cero.")

Práctica 07 U1: Entrada de Datos (`input`)

El programa solicita un dato al usuario y luego determina si es mayor o menor a 50.

# practica07 u1: Entrada de Usuario
# Nota: La función input() lee un texto, por eso se usa int() para convertirlo a número.

try:
    dato = input("Introduce un número entero: ")
    numero_ingresado = int(dato)
    
    if numero_ingresado > 50:
        print(f"El número {numero_ingresado} es mayor que 50.")
    elif numero_ingresado < 50:
        print(f"El número {numero_ingresado} es menor que 50.")
    else:
        print("El número ingresado es exactamente 50.")
except ValueError:
    print("Error: Por favor, introduce un número entero válido.")

Práctica 08 U1: Bucle `while`

Usa el bucle `while` para repetir un bloque de código mientras se cumpla una condición.

# practica08 u1: Bucle While

contador = 1
limite = 5

while contador <= limite:
    print(f"Contando... {contador}")
    contador = contador + 1 # Incrementa el contador
    
print("Bucle finalizado.")
