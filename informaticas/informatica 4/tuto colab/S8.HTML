Práctica 15 U1: Funciones con Retorno (`return`)

La palabra clave `return` permite que la función devuelva un valor, que puede ser utilizado en otra parte del programa.

# practica12 u2: Función con Retorno

def sumar(a, b):
    # La función calcula la suma y la devuelve
    resultado = a + b
    return resultado

# Llamada a la función y almacenamiento del resultado
num1 = 50
num2 = 75
resultado_suma = sumar(num1, num2)

print(f"La suma de {num1} y {num2} es: {resultado_suma}")

Práctica 16 U1: Módulos y Librerías

Los módulos son archivos Python que contienen funciones y clases. La librería `math` contiene funciones matemáticas.

# practica13 u2: Módulos (Librería Math)
# Se necesita importar el módulo para usar sus funciones.

import math

# Calcular la raíz cuadrada
numero = 100
raiz = math.sqrt(numero)
print(f"La raíz cuadrada de {numero} es: {raiz}")

# Calcular el valor de PI
pi_val = math.pi
print(f"El valor de Pi es: {pi_val}")

# Calcular la potencia
pot = math.pow(5, 3) # 5 elevado a la 3
print(f"5 elevado a la 3 es: {pot}")
