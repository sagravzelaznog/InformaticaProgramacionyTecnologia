Tutorial Básico de Google Colab

Introducción a Google Colab

Google Colab es una herramienta gratuita de Google que te permite escribir y ejecutar código Python directamente en tu navegador web. Está basado en los Notebooks de Jupyter y es especialmente útil para tareas que requieren una gran capacidad de cómputo, como el aprendizaje automático, ya que te da acceso gratuito al potente hardware de Google (GPUs y TPUs).

La Interfaz de Colab: Celdas

El área de Trabajo principal en Colab se organiza en celdas. Hay dos tipos principales de celdas:

  1. Celdas de Código: Para escribir y ejecutar código Python.
  2. Celdas de Texto: Para añadir explicaciones, notas y texto formateado usando una sintaxis simple llamada Markdown.

Uso de Celdas de Código

  1. Crear una Celda de Código: Haz clic en el botón + Código en la barra de herramientas en la parte superior izquierda de tu notebook.
  2. Escribir Código: Escribe tu código Python en la celda. Por ejemplo: 
    print("¡Hola, Google Colab!")
  3. Ejecutar la Celda: Para ejecutar el código, puedes:
    • Presionar Shift + Enter en tu teclado.
    • Hacer clic en el botón de reproducción (▶) que aparece a la izquierda de la celda cuando pasas el cursor sobre ella.

La salida de tu código aparecerá directamente debajo de la celda.

Uso de Celdas de Texto

Las celdas de texto te permiten documentar tu código, añadir títulos, crear listas y más.

  1. Crear una Celda de Texto: Haz clic en el botón + Texto en la barra de herramientas.
  2. Escribir y Formatear Texto: Las celdas de texto usan Markdown para el formato. Aquí tienes algunos ejemplos básicos:
    • # Título: Crea un título principal.
    • ## Subtítulo: Crea un subtítulo más pequeño.
    • **texto en negrita**: Pone el texto en negrita.
    • *texto en cursiva*: Pone el texto en cursiva.
    • - Un elemento de la lista: Crea una lista con viñetas.

    Por ejemplo, podrías escribir:

    # Mi Primer Notebook en Colab

Este es un ejemplo de cómo usar celdas de texto.
Podemos usar **negritas** y también *cursivas*.
            
    Estructura Básica de un Notebook en Colab
    
            
    En Google Colab, existen dos tipos de celdas:
    
            
      
                
    1. **Celdas de Texto:** Útiles para redacción de texto, incluyendo formato **HTML** y **LaTeX**. Se agregan haciendo clic en el botón '+ Texto'.
      2. 
                
    2. **Celdas de Código:** Enfocadas en la ejecución de código en lenguaje de programación **Python**. Se agregan haciendo clic en el botón '+ Código'.
      3. 
            
    
            
    Para agregar un **comentario** en una celda de código, utiliza el símbolo **#** al inicio de la línea. El entorno omitirá esta línea al ejecutar el código.
    
            
    Para guardar los cambios, usa la combinación de teclas **[CTRL + S]** o el menú Archivo > Guardar. Para guardar una copia en tu Google Drive, ve a Archivo > Guardar una copia en Drive.

    Ejecutar y Modificar el Código
    
            
    Para ejecutar el código de una celda en Google Colab, localiza el **botón de reproducción** (un triángulo) en la parte superior izquierda de la celda de código y haz clic en él. El resultado se verá justo debajo de la celda ejecutada.
    
            
    Para **modificar** el código, simplemente selecciona la celda, realiza los cambios deseados y vuelve a **ejecutar la celda**.
    
            
    
                
    IMPORTANTE: Se recomienda ejecutar las celdas **consecutivamente desde el inicio**, ya que algunas celdas de código dependen de funciones o variables definidas en celdas anteriores. Ejecutarlas en orden evita errores de dependencia.
    
            
    
        
    

        
    

        
    
            
    ¿Cómo cargar códigos dependientes en Google Colab?
    
            
    Si un notebook depende de otros códigos, archivos o programas, tienes dos métodos para cargarlos en el ambiente de Google Colab:
    

            
    Método 1: Cargar archivos desde tu computadora
    
            
      
                
    1. En la barra lateral izquierda de Colab, selecciona la **carpeta de archivos** (icono de archivo).
      2. 
                
    2. Presiona el **icono de subir archivo** (flecha hacia arriba).
      3. 
                
    3. Se abrirá tu navegador de archivos para que puedas seleccionar el archivo deseado. Una vez cargado, el código estará disponible en el ambiente de Colab para su uso.
      4. 
            
    

            
    Método 2: Clonar un repositorio de GitHub
    
            
    Si el archivo deseado se encuentra en un repositorio de GitHub, puedes clonarlo directamente en tu sesión de Colab usando el comando !git clone en una celda de código:
    
            
    
                
    Ejemplo (Clonando el repositorio Prometeo):
    
                !git clone https://github.com/jugernaut/Prometeo.git
            
    
            
    Al ejecutar la celda, Google Colab clonará el repositorio completo, permitiendo utilizar los archivos dentro de esa sesión interactiva. Posteriormente, puedes importar y utilizar los archivos del repositorio clonado.
