1. Introducción a Google Colab y Markdown Básico

Guía de uso para celdas de texto y formato.

Instrucciones para la Actividad

Paso 1: Acceso | Abre Google Colab y crea un nuevo cuaderno (Notebook).

Paso 2: Formato | Añade una celda de Texto. Copia los códigos de formato (Markdown) en la celda.

Paso 3: Visualización | Ejecuta la celda de Texto (`Shift + Enter`) para ver cómo se aplica el formato.

Estructura de Documentación (Títulos)

Utiliza el símbolo `#` para definir la jerarquía de títulos, desde el más grande (`#`) hasta el más pequeño (`######`).

# Título ## Capítulo ### Subcapítulo #### Sección ##### Subsección ###### Contenido

Listas Ordenadas y No Ordenadas

Puedes crear listas numeradas o con viñetas para organizar el contenido.

Lista Ordenada

# LISTA 1. uno 2. dos 3. tres

Lista No Ordenada

Usa `*` o `-` para crear listas no ordenadas.

* Item A * Item B

Formato de Texto y Sangría

Aplica énfasis al texto y utiliza el símbolo `>` para crear sangrías (citas en bloque).

Formato de Texto

**texto negritas** *texto cursivo* `monospace`

Sangrado (Citas en Bloque)

# SANGRADO > sangría 1 >> doble sangría >>> triple sangría >>>> cuádruple sangría >>>>> quíntuple sangría
