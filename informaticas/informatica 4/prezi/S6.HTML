Práctica 06 U2: Bucle `for` y Listas

El bucle `for` se usa para iterar sobre una secuencia (como una lista) o un rango de números.

# practica06 u2: Bucle For

frutas = ["manzana", "banana", "cereza", "uva"]

print("Lista de frutas:")
# El bucle for recorre cada elemento de la lista
for fruta in frutas:
    print(f"- {fruta}")
    
# Iterar sobre un rango de números (0 a 4)
print("\nContando del 0 al 4:")
for i in range(5):
    print(i)

Práctica 07 U2: Listas (Modificables)

Las listas se definen con corchetes `[]` y son modificables (mutables).

# practica07 u2: Listas

numeros = [10, 20, 30, 40]
print(f"Lista original: {numeros}")

# Modificar un elemento (el índice inicia en 0)
numeros[1] = 25
print(f"Lista modificada: {numeros}")

# Agregar un nuevo elemento
numeros.append(50)
print(f"Lista con nuevo elemento: {numeros}")

Práctica 08 U2: Tuplas (Inmutables)

Las tuplas se definen con paréntesis `()` y NO se pueden modificar (inmutables).

# practica08 u2: Tuplas

coordenadas = (10.5, 20.3)
print(f"Tupla de coordenadas: {coordenadas}")

# Contar cuántas veces aparece un elemento
conteo = coordenadas.count(10.5)
print(f"El número 10.5 aparece {conteo} vez.")

# Descomentar la siguiente línea para probar un error (Tupla inmutable)
# coordenadas[0] = 5.0
