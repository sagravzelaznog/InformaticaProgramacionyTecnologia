Operaciones Básicas en Python

Se utilizan dos variables enteras para realizar las operaciones básicas y mostrar los resultados.

# practica02 u2: Operaciones Aritméticas

a = 15
b = 4

# Suma
suma = a + b
print(f"Suma de {a} + {b} = {suma}")

# Resta
resta = a - b
print(f"Resta de {a} - {b} = {resta}")

# Multiplicación
multiplicacion = a * b
print(f"Multiplicación de {a} * {b} = {multiplicacion}")

# División (Flotante)
division = a / b
print(f"División de {a} / {b} = {division}")

# Módulo (Residuo de la división)
modulo = a % b
print(f"Módulo de {a} % {b} = {modulo}")

# Potencia
potencia = a ** 2
print(f"Potencia de {a} ** 2 = {potencia}")
