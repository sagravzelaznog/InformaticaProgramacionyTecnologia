Sesión 05

Alineación, Agrupación y Material Didáctico

Estructurando visualmente el conocimiento complejo para facilitar el aprendizaje.

🎯 Objetivo de la Sesión

La mente humana (y los principios andragógicos) exigen orden para evitar la sobrecarga cognitiva. Hoy dejaremos de colocar elementos al azar y dominaremos las herramientas de Alineación y Agrupación de Canva. Aprenderemos a construir estructuras exactas, ideales para diseñar infografías educativas o fórmulas matemáticas paso a paso.

📏 El Caos vs. El Orden (Simulador)

Imagina que estás armando una ecuación visual. Si las partes están desalineadas, el alumno se confunde. Usa los botones para usar el "Orden Automático" que simula la función Posición > Ordenar de Canva.

3/4 x
+ 2/3 y
= 20/5

*En Canva, esto se logra seleccionando los elementos y yendo a Posición > Alinear elementos.

🛠️ Práctica: Diseñando un Sistema de Ecuaciones

Canva no tiene un editor de ecuaciones (LaTeX) nativo completo para gráficos complejos, por lo que los genios matemáticos debemos construir las fórmulas visualmente combinando textos y líneas.

El Reto: Diseña una diapositiva en Canva que muestre el siguiente sistema de ecuaciones y su resultado final de 'x'[cite: 7]:

(1) 3/4 x + 2/3 y = 20/5
(2) 5x - 3y = 13
-------------------------
Resultado: x = 248/67
  1. Abre una Presentación Educativa (16:9) en Canva.
  2. Presiona la tecla T para crear una caja de texto y escribe "3". Crea otra para el "4".
  3. Presiona la tecla L para crear una línea. Acórtala y ponla entre el 3 y el 4 para crear la fracción visualmente.
  4. LA CLAVE: Selecciona el 3, la línea y el 4. Haz clic derecho y selecciona Agrupar (o presiona Ctrl+G / Cmd+G). Ahora tu fracción se mueve como un solo bloque sólido.
  5. Repite el proceso para armar la ecuación alineada. Usa el panel Posición para asegurar que todos los signos "=" estén en una línea vertical perfecta.
