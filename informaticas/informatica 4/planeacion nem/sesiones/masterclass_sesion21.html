I. El Gran Malentendido

Objetivo: Diferenciar la infraestructura física (Internet) del servicio de información (Web).

🛤️ Las Vías vs Las Tiendas

Imagina una ciudad:

INTERNET

Infraestructura

Son las carreteras, cables y tuberías. Conecta las máquinas.

WWW

Servicio

Son las tiendas y bibliotecas que visitas usando esas carreteras.

"Puedes usar Internet sin usar la Web (ej. WhatsApp, Email, Netflix App). Pero no puedes usar la Web sin Internet."

⏱️ 10:00 - 35:00 min

II. El Lenguaje de la Web (HTTP)

🤝 Cliente-Servidor

La Web es una conversación constante:

  • Cliente (Tú): "Oye, pásame la foto del gato." (Request)
  • Servidor (Google): "Aquí tienes, código 200 OK." (Response)

📜 HTTP vs HTTPS

HyperText Transfer Protocol.

  • HTTP: Envía datos en texto plano (como una postal). Cualquiera puede leerla en el camino.
  • HTTPS: Envía datos cifrados (como una carta en caja fuerte). Solo tú tienes la llave.

🔒 ¿Por qué el Candadito importa?

Simulación de robo de datos en WiFi público:

HTTP (Inseguro)
> Hacker interceptando...
> Usuario: "123456"
> ¡CONTRASEÑA ROBADA!
🔓
HTTPS (Seguro)
> Hacker interceptando...
> Usuario: "a8#kL9@x2"
> ¡DATOS ILEGIBLES!
🔒

*Nunca pongas tu tarjeta de crédito si no ves la "S" en HTTPS.

⏱️ 35:00 - 45:00 min

III. La Magia de F12

Herramientas de Desarrollador

¿Sabías que puedes ver el esqueleto de cualquier página web?

Presiona F12 (o Clic derecho -> Inspeccionar). Verás el código HTML que tu navegador recibió y convirtió en imágenes bonitas.

Navegador vs Buscador

¿Chrome y Google son lo mismo?

NO. Chrome es el vehículo (Navegador). Google es el mapa (Buscador). Puedes usar Chrome para entrar a Bing, o usar Edge para entrar a Google.

👩‍💻 Misión del Día: Entra a tu página favorita, presiona F12 y trata de encontrar en el código dónde está escrito el título principal. ¡Siéntete hacker por un minuto!
