I. El Principio D.R.Y.

Objetivo: Comprender que copiar y pegar código es el pecado capital del programador.

🍝 Código Espagueti vs. 🧱 Código Modular

Imagina que quieres saludar a 3 amigos:

❌ Sin Funciones (Repetitivo)

print("Hola Juan")
print("Bienvenido al curso")
print("Hola Ana")
print("Bienvenida al curso")
print("Hola Pedro")
print("Bienvenido al curso")

Si quieres cambiar el mensaje, tienes que editar 3 líneas.

✅ Con Funciones (Modular)

def saludar(nombre):
  print("Hola " + nombre)
  print("Bienvenido/a")

saludar("Juan")
saludar("Ana")

Cambias una línea y se actualiza para todos.

II. Anatomía de una Función

🛠️ Definir (Construir)

Es crear la máquina, pero no encenderla.

def suma(a, b):
  return a + b

📞 Llamar (Usar)

Es usar la máquina con datos reales.

resultado = suma(5, 10)
# resultado ahora vale 15

III. Lo que pasa en Las Vegas... (Scope)

Variables Locales vs Globales

Si creas una variable DENTRO de una función, ¿existe afuera?

NO. Es una variable LOCAL.

Nace cuando la función arranca y muere cuando la función termina. "Lo que pasa en la función, se queda en la función".

El error de "None"

Si tu función no tiene return, ¿qué devuelve?

Devuelve "None" (Nada). La tostadora hizo ruido, pero no sacó pan. Siempre recuerda poner return si necesitas el resultado.
