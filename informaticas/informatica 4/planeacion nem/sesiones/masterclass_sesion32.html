I. El Reto del Programador

Objetivo: Unir todo lo aprendido (Variables, If, While, Input) para crear un software funcional que "piense".

🎲 La Misión: "Adivina el Número"

La computadora elegirá un número secreto entre 1 y 100. Tú tienes que adivinarlo.

La computadora te dará pistas: "Más alto" o "Más bajo".

Memoria

Variable para guardar el secreto.

Decisión

IF para comparar tu número vs secreto.

Repetición

WHILE para preguntar hasta que ganes.

⏱️ 10:00 - 35:00 min

II. Construyendo el Código (Paso a Paso)

1. El Cerebro (Random)

Necesitamos importar una librería para generar azar.

import random
secreto = random.randint(1, 100)

2. El Juego Eterno

Mientras NO adivines, el juego sigue.

adivinado = False
while adivinado == False:

📜 El Algoritmo Maestro

Analiza la lógica línea por línea.

import random
secreto = random.randint(1, 100)
intentos = 0

while True: // Bucle infinito hasta ganar
usuario = int(input("Dame un número: "))
intentos = intentos + 1

if usuario == secreto:
print("¡Ganaste en " + str(intentos) + " intentos!")
break // Rompe el ciclo
elif usuario < secreto:
print("Más alto ⬆️")
else:
print("Más bajo ⬇️")
⏱️ 35:00 - 45:00 min

III. Depuración (Debugging)

¿Qué pasa si nunca termina?

Si el jugador pone siempre el mismo número incorrecto...

Bucle Infinito Controlado. No es un error, el programa espera hasta que se cumpla la condición de victoria (`break`).

Mejorando el Juego

¿Cómo harías para que tenga un límite de vidas (5 intentos)?

Cambia el `while True` por while intentos < 5. Si se acaban los intentos, muestras un "Game Over" fuera del bucle.

🎮 Misión del Día: Copia este código en tu cuaderno o computadora. Juega con un compañero: uno ejecuta el programa y el otro intenta adivinar. ¿Quién lo logra en menos intentos?
