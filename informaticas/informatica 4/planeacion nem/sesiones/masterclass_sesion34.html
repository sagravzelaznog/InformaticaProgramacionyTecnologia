I. El Problema de la Variable Solitaria

Objetivo: Comprender que crear una variable para cada dato es ineficiente cuando tienes muchos datos relacionados.

🎒 La Mochila vs. Las Manos

Imagina que tienes que llevar 10 libros a la escuela.

Variables Sueltas

Llevas un libro en cada dedo, bajo el brazo, en la cabeza...

libro1 = "Mate"
libro2 = "Español"
libro3 = "Inglés"...

(Caos Total)

Lista (Array)

Metes todos los libros en UNA sola mochila.

mochila = ["Mate", "Español", "Inglés"]

(Ordenado y Limpio)

⏱️ 10:00 - 35:00 min

II. Anatomía de una Lista

📋 Crear una Lista

Usamos corchetes cuadrados [].

frutas = ["Manzana", "Pera", "Uva"]

Puede guardar texto, números o mezclas.

📍 El Índice (Index)

Es la "dirección" de cada elemento.

print( frutas[0] )

¡OJO! El primero siempre es el 0.

III. Operaciones Mágicas

Agregar al final (.append)

Llegó un alumno nuevo. ¿Cómo lo metes a la lista?

lista_alumnos.append("Daniel")

Ahora Daniel está en el índice 3.

El Poder del Ciclo FOR

¿Cómo imprimes todos los nombres sin escribir print 3 veces?

for alumno in lista_alumnos:
  print("Hola " + alumno)

El ciclo recorre la lista automáticamente.
