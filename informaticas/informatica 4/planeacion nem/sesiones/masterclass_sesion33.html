II. Los 3 Villanos del Código

🔴 Sintaxis (Gramática)

Escribiste mal el idioma. La computadora no entiende.

print "Hola" (Faltan paréntesis)

El programa NI SIQUIERA arranca.

🟡 Lógico (Semántica)

El programa funciona, pero hace lo que quiere, no lo que tú quieres.

area = base + altura (Era multiplicar *)

El más difícil de encontrar.

🩸 Disección de un Error en Python

Aprende a leer el mensaje rojo de la muerte.

Traceback (most recent call last):
  File "juego.py", line 10, in <module>
    if numero = 5:
SyntaxError: invalid syntax
1. ¿Dónde? (Línea 10)
2. ¿Qué pasó?

El error te dice exactamente dónde buscar. ¡Lee la línea!

III. Buenas Prácticas (Vacunas)

Los Comentarios (#)

¿Para qué sirve poner mensajes que la computadora ignora?

Para tu "Yo del Futuro". Dentro de 3 meses olvidarás qué hace tu código. El comentario # Esto calcula la vida te salvará.

Nombres de Variables

¿Qué es mejor: x = 10 o vidas_jugador = 10?

Siempre sé descriptivo. El código se lee más veces de las que se escribe. vidas_jugador se explica solo.
