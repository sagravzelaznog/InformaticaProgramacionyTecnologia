II. Bloques vs Texto

🧩 Blockly / Scratch

Programación visual. Arrastras piezas como un rompecabezas.

  • Ventaja: Imposible cometer errores de escritura.
  • Uso: Aprender lógica rápido.

🐍 Python

Programación real. Escribes comandos en inglés.

  • Ventaja: Potente. Se usa en IA, Netflix, NASA.
  • Reto: La Sintaxis (Gramática) es estricta.

🆚 Batalla Visual: "Hola Mundo"

III. Tu Primera Línea de Código

Sintaxis: El error #1

¿Qué pasa si escribes Print("Hola") con P mayúscula en Python?

NameError: name 'Print' is not defined.

Python distingue mayúsculas de minúsculas (Case Sensitive). La orden correcta es print (todo minúscula).

¿Por qué Python?

¿Por qué enseñamos Python y no C++ o Java?

Legibilidad. Python se lee casi como inglés. Menos llaves {} y puntos y comas ;, más enfoque en resolver problemas.
