I. La Vida no es una Línea Recta

Objetivo: Comprender que los programas inteligentes no solo siguen pasos (Secuenciales), sino que eligen caminos (Condicionales).

🚦 El Semáforo de la Lógica

Todo en computación se reduce a preguntas de Sí o No.

➡️ Secuencial

Paso 1, luego Paso 2, luego Paso 3.

(Como una receta de pastel. Siempre igual).

🔀 Condicional

Si pasa X, haz Y. Si no, haz Z.

(Como elegir ropa: ¿Llueve? Llevo paraguas).

⏱️ 10:00 - 35:00 min

II. La Estructura "SI... ENTONCES" (If-Else)

💎 El Rombo de Decisión

En un diagrama de flujo, el rombo es el juez.

  • Solo tiene una entrada.
  • Tiene OBLIGATORIAMENTE dos salidas: Verdadero y Falso.
  • Nunca puede haber un "tal vez".

💻 Código Real

if (bateria < 15) {
  activarAhorro();
} else {
  brilloMaximo();
}

🚪 Dinámica: El Portero del Antro

Vamos a programar la lógica de seguridad para entrar a un club.

👤 Llega Persona (Edad)
¿Edad >= 18?
SÍ (Verdadero)
✅ "Pásale, diviértete"
NO (Falso)
🚫 "A tu casa, niño"

III. Reto de Lógica

Ejercicio: Login de Facebook

¿Cuál es la condición para que Facebook te deje entrar?

SI (usuario == correcto Y password == correcta)
ENTONCES { MostrarPerfil() }
SINO { MostrarError("Datos incorrectos") }

Anidación (Uno dentro de otro)

¿Qué pasa si tienes 18 años pero no traes INE?

Necesitas un IF Anidado. Primero preguntas la edad, y SI pasa, entonces preguntas por la INE. Si falla cualquiera, vas para afuera.
