Laboratorio 03: Visualización Pasiva de Evidencia

Enciende tu máquina virtual Kali Linux. En este laboratorio aprenderemos a leer el contenido de los archivos sin abrirlos con programas gráficos. Esto garantiza que no alteraremos metadatos ni ejecutaremos código malicioso por accidente.

Paso 1: Generar un archivo de registro (Log) masivo

Para practicar, necesitamos un archivo grande. Volcaremos los mensajes del kernel de Linux (dmesg) en un archivo de texto dentro de nuestra carpeta de evidencia de la sesión anterior.

-(kali㉿kali)-[~]$ cd /home/kali/Desktop/evidencia_lab02
-(kali㉿kali)-[~/.../evidencia_lab02]$ dmesg > log_kernel.txt
-(kali㉿kali)-[~/.../evidencia_lab02]$ ls -lh log_kernel.txt

Paso 2: La manguera de bomberos (cat)

El comando cat (concatenate) escupe todo el contenido del archivo en la pantalla de golpe. Es útil para archivos pequeños (como contraseñas o hashes), pero terrible para logs enormes.

-(kali㉿kali)-[~/.../evidencia_lab02]$ cat log_kernel.txt

Notarás que el texto pasa demasiado rápido. El buffer de la terminal cortará el inicio.

Paso 3: Lectura controlada y búsqueda (less)

El investigador profesional usa less. Este comando pagina el archivo, permitiéndote subir, bajar y buscar sin cargar todo en la memoria RAM.

¡Atención Psicológica! Muchos principiantes entran en pánico porque no saben cómo salir de este comando. Memoriza esto: presiona la tecla Q para salir (Quit). 
-(kali㉿kali)-[~/.../evidencia_lab02]$ less log_kernel.txt
  • Flechas: Arriba / Abajo
  • Barra espaciadora: Avanzar una página entera.
  • /palabra: Escribe una barra diagonal seguida de una palabra para buscar (ej. /usb) y presiona Enter. Usa la tecla n para el siguiente resultado.
  • q: Salir y volver al prompt.

Paso 4: Disección de extremos (head y tail)

Si ocurre un ataque, generalmente nos interesa el final del registro de auditoría (lo más reciente). head lee el inicio y tail el final.

# Ver las primeras 5 líneas (inicio del arranque)
-(kali㉿kali)-[~/.../evidencia_lab02]$ head -n 5 log_kernel.txt

# Ver las últimas 10 líneas (eventos más recientes)
-(kali㉿kali)-[~/.../evidencia_lab02]$ tail -n 10 log_kernel.txt
