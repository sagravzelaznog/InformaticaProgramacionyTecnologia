Laboratorio 17: Automatización (Bash Scripting)

El tiempo es evidencia que se evapora. Cuando entras a un servidor comprometido, no tienes 20 minutos para escribir comandos uno por uno. Hoy aprenderemos a encapsular todo lo que aprendiste en los 16 laboratorios anteriores dentro de un solo archivo ejecutable: un Script de Primer Respondiente.

Paso 1: La Anatomía del Script (El Shebang)

Un script de Linux es solo un archivo de texto con comandos apilados. La magia ocurre en la primera línea: el Shebang (#!/bin/bash). Esto le dice al sistema operativo qué intérprete usar para leer el archivo.

# Creamos el archivo de nuestro script forense usando nano o touch
-(kali㉿kali)-[~]$ touch triaje_forense.sh
-(kali㉿kali)-[~]$ nano triaje_forense.sh

# Dentro del editor nano, escribimos:
#!/bin/bash
echo "Iniciando recolección de evidencia..."

Paso 2: El Aliento de Vida (Permisos de Ejecución)

Por defecto, Linux crea archivos de texto sin el permiso de ejecución (medida de seguridad). Para que nuestro script corra, debemos inyectarle la letra x (execute) usando nuestros conocimientos de la sesión 06.

# Agregamos el permiso de ejecución al dueño del archivo
-(kali㉿kali)-[~]$ chmod +x triaje_forense.sh

# Ejecutamos el script usando ./ (que significa "en esta carpeta")
-(kali㉿kali)-[~]$ sudo ./triaje_forense.sh

Paso 4: Variables y Redirección Total

En el nivel maestro, tu script no solo imprime en pantalla; guarda automáticamente la información en un archivo con la fecha exacta del incidente usando Variables.

El Código Maestro: Copia este bloque, pégalo en tu `triaje.sh` en Kali Linux, dale permisos y ejecútalo. Felicidades, has creado tu primera herramienta forense. 
#!/bin/bash
# Definimos una variable con la fecha y hora actual
FECHA=$(date +"%Y-%m-%d_%H-%M")
REPORTE="evidencia_$FECHA.txt"

echo "Recolectando evidencia en: $REPORTE"

# Usamos >> para anexar datos sin borrar lo anterior
echo "=== CONEXIONES DE RED ===" >> $REPORTE
ss -tulpn >> $REPORTE

echo "=== FIRMA DEL REPORTE ===" >> $REPORTE
sha256sum $REPORTE >> $REPORTE

echo "¡Triaje finalizado con éxito!"
