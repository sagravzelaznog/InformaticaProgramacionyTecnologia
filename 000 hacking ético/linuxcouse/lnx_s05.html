Laboratorio 05: Identidad y Escalada de Privilegios

En Linux, todo es un archivo y todo archivo pertenece a alguien. Para auditar un sistema comprometido, primero debemos entender las jerarquías. Hoy aprenderemos a identificar usuarios, leer registros de contraseñas y asumir el control total del sistema (Root) dentro de nuestro Sandbox.

Paso 1: Mapeo de Identidad (whoami & id)

Antes de actuar, verifica quién eres para el sistema. El comando id revela no solo tu nombre, sino los grupos a los que perteneces (lo que define qué puedes hacer).

-(kali㉿kali)-[~]$ whoami
-(kali㉿kali)-[~]$ id

Paso 2: La Puerta de los Secretos (/etc/passwd)

En análisis forense, revisamos este archivo para buscar usuarios "fantasma" creados por un atacante. A pesar de su nombre, hoy en día no guarda contraseñas, solo la lista de usuarios del sistema.

Táctica de Investigador: Los usuarios legítimos (humanos) suelen tener un ID (UID) de 1000 en adelante. Los menores a 1000 son usuarios del sistema. 
# Usamos less para leer el archivo con seguridad
-(kali㉿kali)-[~]$ less /etc/passwd

Paso 3: Escalada de Privilegios (sudo)

Para leer los hashes reales de las contraseñas, necesitamos ser el superusuario (Root). sudo (SuperUser DO) nos permite ejecutar un comando con el poder de Root. Nos pedirá nuestra contraseña (kali).

Transición Psicológica: Observa cómo cambia el símbolo final de tu terminal de un $ (usuario estándar) a un # (root). Conlleva responsabilidad absoluta. 
# Convertirnos en root en esta terminal interactiva
-(kali㉿kali)-[~]$ sudo su
-(root㉿kali)-[/home/kali]# whoami

Paso 4: Extracción de Hashes (/etc/shadow)

Ahora que somos Root, podemos leer el archivo más protegido del sistema. Aquí viven las contraseñas encriptadas. Un atacante roba este archivo para crackear las claves fuera de línea.

-(root㉿kali)-[/home/kali]# cat /etc/shadow
# Al terminar, SIEMPRE abandonamos los privilegios elevados
-(root㉿kali)-[/home/kali]# exit
-(kali㉿kali)-[~]$
