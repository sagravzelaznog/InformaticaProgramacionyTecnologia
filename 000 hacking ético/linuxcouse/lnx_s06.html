Laboratorio 06: La Matriz de Permisos (chmod/chown)

En el análisis forense, los permisos te dicen quién tuvo la oportunidad de modificar la evidencia. En el hacking, un permiso mal configurado es la puerta trasera hacia el control total. Hoy aprenderemos a descifrar y manipular el ADN de la seguridad en Linux.

Paso 1: Leer el ADN del Archivo (ls -l)

Vamos a crear un archivo en nuestro Sandbox y analizaremos su estructura de propiedad. Los primeros caracteres en la salida de ls -l representan los permisos para el Dueño (u), el Grupo (g) y Otros (o).

-(kali㉿kali)-[~]$ touch script_secreto.sh
-(kali㉿kali)-[~]$ ls -l script_secreto.sh
# Salida esperada: -rw-r--r-- 1 kali kali 0 Apr 21 10:00 script_secreto.sh

Paso 2: Herramienta Cognitiva (El Sistema Octal)

En lugar de usar letras, los profesionales usan números (Sistema Octal). Cada permiso tiene un peso: Lectura (r)=4, Escritura (w)=2, Ejecución (x)=1. Juega con el siguiente decodificador antes de avanzar al comando real:

Dueño (Owner)

0

Grupo (Group)

0

Otros (Others)

0
Comando: chmod 000 archivo

Paso 3: Modificación de Permisos y Propiedad (chmod/chown)

Ahora aplicaremos el conocimiento. Le daremos permisos totales al dueño y quitaremos todos los permisos a los demás (Octal 700). Luego, cambiaremos al dueño del archivo a root.

# Damos permisos 700 (rwx------)
-(kali㉿kali)-[~]$ chmod 700 script_secreto.sh

# Cambiar de dueño requiere privilegios de superusuario
-(kali㉿kali)-[~]$ sudo chown root:root script_secreto.sh
-(kali㉿kali)-[~]$ ls -l script_secreto.sh

Paso 4: El Ticket Dorado (Búsqueda de SUID)

El bit SUID permite a un usuario normal ejecutar un programa con los permisos de su creador (generalmente root). Si un atacante encuentra un binario vulnerable con SUID, el sistema está perdido. Así es como los peritos buscan este rastro:

Hacking Mindset: El flag -perm -4000 le dice al comando find que busque el bit SUID activo en todo el sistema. 
# Buscar binarios con SUID, enviando errores al vacío
-(kali㉿kali)-[~]$ find / -type f -perm -4000 2>/dev/null
