Laboratorio 08: La Ilusión de Normalidad (Gestión de Paquetes)

Un atacante comprometió tu servidor. ¿Cómo sabes que el comando ls que usas no fue reemplazado por una versión maliciosa que oculta los archivos del hacker? Hoy aprenderemos a instalar herramientas forenses de forma segura y a auditar la integridad de todo el software instalado en nuestro Sandbox.

Paso 1: El Origen de la Verdad (sources.list)

Linux descarga software desde repositorios oficiales. Un atacante podría modificar esta lista para que tu sistema descargue actualizaciones falsas desde un servidor controlado por él. Revisemos las fuentes de tu Kali Linux.

# Leemos el archivo donde se configuran los repositorios
-(kali㉿kali)-[~]$ cat /etc/apt/sources.list

Paso 2: Instalación de Arsenal Forense (apt)

Utilizaremos el gestor de paquetes de alto nivel, apt, para instalar dos herramientas vitales: debsums (para verificar la integridad de los archivos) y rkhunter (un buscador de rootkits).

Estrategia de Perito: Siempre actualiza el índice de repositorios (update) antes de instalar (install) para asegurar que descargas la última versión con parches de seguridad. 
# Actualizamos índices e instalamos (requiere sudo)
-(kali㉿kali)-[~]$ sudo apt update
-(kali㉿kali)-[~]$ sudo apt install debsums rkhunter -y

Paso 3: Instalación Offline (dpkg)

En un incidente real, el equipo comprometido estará desconectado de Internet para evitar que el malware se propague. Tendrás que instalar tus herramientas forenses transfiriéndolas en un USB y usando el instalador de bajo nivel dpkg.

# Sintaxis teórica para instalar un archivo .deb localmente
-(kali㉿kali)-[~]$ sudo dpkg -i mi_herramienta_forense.deb

# Para listar todo el software instalado en el sistema actualmente
-(kali㉿kali)-[~]$ dpkg -l

Paso 4: Auditoría de Integridad (La Caza del Troyano)

Aquí brilla el analista. debsums compara el hash (huella digital) de cada archivo instalado en tu sistema contra el hash oficial del creador. Si un atacante modificó un binario, este comando lo detectará.

Esperando ejecución...

Ahora ejecuta el comando real en tu máquina virtual. Al usar el flag -c (changed), el comando será silencioso a menos que encuentre un archivo corrupto o modificado.

# Ejecutamos la verificación de integridad en todo el sistema
-(kali㉿kali)-[~]$ sudo debsums -c
