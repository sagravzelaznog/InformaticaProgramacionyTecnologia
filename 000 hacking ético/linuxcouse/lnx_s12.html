Laboratorio 12: Radiografía Web y Extracción Ciega

Encontraste una URL sospechosa en el historial del servidor comprometido. Si la abres en un navegador, podrías ejecutar JavaScript malicioso o alertar al atacante. Hoy aprenderemos a interactuar con la web a ciegas, descargando evidencia de forma segura y leyendo los metadatos ocultos (cabeceras HTTP) que los navegadores te ocultan.

Paso 1: El Descargador Silencioso (wget)

wget (Web Get) es la herramienta estándar para descargar archivos desde la terminal. Es robusta y puede reanudar descargas interrumpidas. Descargaremos un archivo de texto de prueba para analizarlo localmente en nuestro Sandbox.

# Descargar un archivo directamente al directorio actual
-(kali㉿kali)-[~]$ wget http://example.com/index.html

# Leer el archivo descargado para ver el código fuente real
-(kali㉿kali)-[~]$ cat index.html

Paso 2: El Cuchillo Suizo de la Web (curl)

Mientras que wget está pensado para descargar archivos, curl (Client URL) está diseñado para interactuar. Por defecto, no guarda un archivo, sino que imprime el código fuente directamente en tu pantalla, ideal para análisis rápido sin dejar rastros en el disco.

# Imprimir el HTML crudo en la terminal (puedes usar pipes como | grep)
-(kali㉿kali)-[~]$ curl http://example.com

# Guardar la salida en un archivo (similar a wget) usando -o
-(kali㉿kali)-[~]$ curl -o evidencia_web.html http://example.com

Paso 3: Radiografía de Cabeceras (Simulador HTTP)

Aquí es donde el perito brilla. Usando curl -I (solo cabeceras), interrogamos al servidor sin descargar el contenido. Esto revela qué software usa (ej. Apache, Nginx), la fecha exacta y si hay redirecciones (Código 301/302). Juega con el interceptor antes de ejecutarlo.

Petición (Tú)

GET /api HTTP/1.1
Host: servidor-sospechoso.com
User-Agent: curl/7.88.1
Accept: */*

Respuesta (Servidor)


                            

                        

                    


                    
Ahora, audita un servidor real desde tu terminal para ver sus metadatos expuestos.

                    

                        
# Obtener solo las cabeceras HTTP (Header) de un sitio
-(kali㉿kali)-[~]$ curl -I https://www.google.com

                    

                

            


            

                

                    
Paso 4: Evasión Forense (Suplantación de User-Agent)

                    
                

                

                    
Los servidores maliciosos a menudo bloquean herramientas de línea de comandos como curl para evitar ser analizados. Podemos engañar al servidor modificando nuestra cabecera User-Agent para hacernos pasar por un navegador normal (como Firefox en Windows).

                    

                        Arte del Camuflaje: Modificar el User-Agent es una técnica básica de "OPSEC" (Seguridad de las Operaciones) para que tu investigación no alerte a los monitores del atacante.
                    

                    

                        
# Disfrazar nuestra petición curl como si fuera un navegador Firefox
-(kali㉿kali)-[~]$ curl -A "Mozilla/5.0 (Windows NT 10.0; Win64; x64) Firefox/115.0" http://example.com
