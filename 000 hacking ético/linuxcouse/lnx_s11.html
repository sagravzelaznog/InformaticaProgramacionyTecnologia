Laboratorio 11: Criptografía y Control Remoto (SSH / SCP)

Nunca analizamos una máquina comprometida sentándonos físicamente frente a ella; lo hacemos de forma remota para no alterar el entorno físico ni las memorias temporales. Hoy aprenderemos a establecer túneles encriptados de grado militar para controlar servidores y extraer evidencia sin que nadie pueda espiar la transferencia.

Paso 1: El Puente Seguro (ssh)

SSH (Secure Shell) reemplazó a protocolos antiguos como Telnet porque encripta todo el tráfico. Para conectarte, necesitas saber el nombre del usuario y la IP del servidor objetivo. (Para este laboratorio, asumiremos que tienes otra máquina en la IP 192.168.1.50).

Primer Contacto (Fingerprint): La primera vez que te conectas, SSH te preguntará si confías en la huella criptográfica (fingerprint) del servidor. Un perito siempre la verifica antes de escribir "yes". 
-(kali㉿kali)-[~]$ ssh investigador@192.168.1.50
Are you sure you want to continue connecting (yes/no/[fingerprint])? yes

Paso 2: Conciencia Espacial Remota

¡Peligro Psicológico! Una vez conectado, tu terminal se verá casi igual, pero ya no estás en tu máquina. Ejecutar rm aquí borrará archivos en el servidor remoto. Aprende a leer el prompt y usa comandos de ubicación.

# Observa cómo cambió el usuario y el nombre de la máquina en el prompt
investigador@servidor-comprometido:~$ hostname
investigador@servidor-comprometido:~$ pwd
# Para regresar a tu máquina segura (Kali), CIERRA la conexión
investigador@servidor-comprometido:~$ exit
-(kali㉿kali)-[~]$ # Has vuelto a casa

Paso 4: Copia Segura (scp)

scp (Secure Copy) usa el mismo túnel encriptado que SSH para transferir archivos. Su sintaxis requiere atención: scp [origen] [destino]. Si el destino es remoto, debes usar el formato usuario@ip:/ruta/.

Sintaxis Pericial: No olvides los DOS PUNTOS (:) después de la IP. Es lo que le indica a scp que lo que sigue es una ruta en el servidor remoto. 
# EXTRAER del servidor remoto hacia tu máquina local (punto actual '.')
-(kali㉿kali)-[~]$ scp investigador@192.168.1.50:/var/log/auth.log .

# ENVIAR un script tuyo hacia el servidor remoto
-(kali㉿kali)-[~]$ scp script_auditoria.sh investigador@192.168.1.50:/tmp/
