ESTADO: ESCANEO PROFUNDO INICIADO

Misión 11: La Geometría Oculta

Situación: Has asegurado la imagen del disco (Módulo 1). El sistema operativo dice que el disco está vacío, pero los cibercriminales rara vez guardan sus herramientas a simple vista. A menudo modifican la tabla de particiones para crear sectores "no asignados" donde ocultan su malware y datos exfiltrados.

Tu objetivo es utilizar herramientas de bajo nivel (como un bisturí forense) para leer la estructura bruta del disco. Encontrarás los mapas reales de los sectores y documentarás exactamente dónde comienza y termina la anomalía.

Laboratorio Hands-On: Extracción con `mmls`

Inicia tu máquina virtual con Kali Linux. Utiliza la suite The Sleuth Kit (TSK) para realizar una autopsia a la tabla de particiones de tu imagen de evidencia.

1. Extraer la Tabla de Particiones (`mmls`)

Despliega el mapa de particiones (Media Management Tools) para visualizar el layout real del volumen, ignorando lo que el SO intenta decirte.

# Reemplaza 'imagen_evidencia.dd' por tu clon bit a bit
mmls -t dos ~/DFIR/Casos/Caso_001/Evidencia/imagen_evidencia.dd

2. Identificar Particiones Ocultas

Analiza el output del comando anterior. Busca huecos en la estructura marcados como "Unallocated" (no asignados) que sean inusualmente grandes, o particiones con formatos desconocidos.

# Observa la columna 'Description' en tu terminal.
# Identifica la fila que muestra espacio no asignado (Unallocated).

3. Documentar Sectores (Inicio y Fin)

Un analista forense necesita precisión matemática. Documenta el sector exacto de inicio y fin (Start / End) del espacio oculto para poder extraerlo en la siguiente fase.

# Anexa los sectores clave al manifiesto del caso
echo "[ANOMALÍA DETECTADA] - Partición oculta encontrada." >> ~/DFIR/Casos/Caso_001/geometria.txt
echo "Sector Inicio: 2048 | Sector Fin: 4095" >> ~/DFIR/Casos/Caso_001/geometria.txt
cat ~/DFIR/Casos/Caso_001/geometria.txt

¡Geometría Mapeada con Éxito!

Has mirado más allá de las ilusiones del sistema operativo. Al identificar los sectores ocultos mediante The Sleuth Kit, tienes las coordenadas exactas para extraer el payload del atacante. El análisis forense profundo acaba de comenzar.
