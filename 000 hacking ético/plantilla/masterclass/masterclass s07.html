Módulo 1: Cadena de Custodia

ESTADO: EXTRACCIÓN CRÍTICA EN PROGRESO

Misión 07: La Evidencia Volátil

Situación: El equipo táctico acaba de recuperar un dispositivo USB del bolsillo del principal sospechoso antes de que pudiera destruirlo. Tienes información de inteligencia que sugiere que el dispositivo contiene un script destructivo (Bomba Lógica) diseñado para corromper el disco si el sistema operativo intenta montarlo.

Tu memoria muscular se pone a prueba nuevamente. Debes realizar una clonación bit a bit a ciegas, asegurando que ni un solo sector original sea tocado por tu kernel. El tiempo es crítico. Ejecuta el procedimiento de clonación que aprendiste en la Sesión 2, pero sin margen de error.

Laboratorio Hands-On: Clonación Bajo Fuego

Abre tu máquina virtual con Kali Linux. Supera estos tres nodos de extracción validando tu progreso.

1. Intercepción del Dispositivo

Conecta la unidad USB de prueba. Intercepta su designación en el sistema sin permitir el auto-montaje.

# Vigila los mensajes del kernel en tiempo real
dmesg -w

# Identifica el bloque de almacenamiento asignado (Ej. sdb)
lsblk -f

2. Extracción Quirúrgica (`dd`)

Inicia el proceso de clonación a bajo nivel hacia tu bóveda de evidencia segura creada en sesiones anteriores.

sudo dd if=/dev/sdX of=~/DFIR/Casos/Caso_003/Evidencia/usb_critico.dd bs=4M status=progress

3. Validación de Inmutabilidad (Bloqueo de Escritura)

Monta la imagen clonada (jamás el original) aplicando el flag de solo lectura para asegurar la cadena de custodia.

sudo mkdir -p /mnt/clon_critico
sudo mount -o ro,loop ~/DFIR/Casos/Caso_003/Evidencia/usb_critico.dd /mnt/clon_critico
# Intenta comprometer tu propio entorno para verificar el bloqueo
sudo touch /mnt/clon_critico/test.txt

¡Extracción Exitosa!

El error "Read-only file system" acaba de salvar tu peritaje. Has clonado exitosamente un dispositivo crítico mediante memoria muscular pura. La integridad del bit original está asegurada.
