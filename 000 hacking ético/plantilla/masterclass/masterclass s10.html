Misión 10: La Prueba de Fuego

Situación: Has llegado al final de tu entrenamiento básico. El Director de la Unidad Forense (DFIR) te ha entregado un disco duro con evidencia clasificada. Antes de darte acceso a las herramientas avanzadas de análisis (Módulo 2), debes demostrar que tu entorno es 100% estéril e impenetrable.

Esta es tu evaluación final de memoria muscular. Repite el protocolo de bloqueo de escritura de la Sesión 5. Si el sistema logra escribir un solo archivo temporal en la evidencia, reprobarás la certificación. Demuestra que dominas la inmutabilidad.

Laboratorio Hands-On: Lockdown Forense

Inicia tu máquina virtual con Kali Linux. Ejecuta los comandos de bloqueo y demuestra que la evidencia está a salvo[cite: 172].

1. Implementación de Write-Blockers

Configura las reglas de tu kernel y prepara las utilidades de software para ignorar peticiones de escritura automática.

# Identificar el dispositivo sin interactuar con él
sudo fdisk -l

# Verificar herramientas de lectura a bajo nivel
sudo disktype /dev/sdX

2. Montaje Estricto 'Read-Only'

Monta la partición aplicando los parámetros que garantizan que el sistema operativo actuará como un observador pasivo.

sudo mkdir -p /mnt/evidencia_examen
# Aplicar bandera de solo lectura
sudo mount -o ro /dev/sdX1 /mnt/evidencia_examen
mount | grep evidencia_examen

3. Prueba de Intrusión (Validación de Bloqueo)

Ataca tu propia defensa. Intenta inyectar un archivo en el disco montado para forzar el error de protección del sistema.

# Intentar escritura forzada
sudo touch /mnt/evidencia_examen/brecha_seguridad.txt

# Confirmar el error: Read-only file system
sudo umount /mnt/evidencia_examen

¡MÓDULO 1 SUPERADO! Certificación DFIR Aprobada.

Tu memoria muscular es impecable. El error "Read-only file system" confirma que has construido un entorno verdaderamente estéril. Estás listo para escalar de privilegios y comenzar el Módulo 2: Análisis de Sistemas de Archivos.
