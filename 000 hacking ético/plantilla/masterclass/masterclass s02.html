Módulo 1: Cadena de Custodia

Estado: Analista DFIR en Operación

Misión 02: Clonación en Frío

Situación: Tienes en tus manos un dispositivo USB sospechoso extraído de la Zona Cero. Contiene el payload que compromete a la organización, pero si lo abres directamente en tu máquina, podrías alterar los metadatos o desencadenar un ejecutable oculto.

Tu objetivo es realizar una copia exacta, bit a bit, a bajo nivel. Trabajarás sobre el clon, jamás sobre la evidencia original. El más mínimo error de escritura destruirá la cadena de custodia.

Laboratorio Hands-On: Extracción con `dd`

Abre tu máquina virtual con Kali Linux. Ejecuta los siguientes pasos con precisión quirúrgica y valida cada acción al completarla.

1. Conectar y Reconocer la Unidad USB

Conecta la unidad USB de prueba y verifica cómo el sistema la identifica (por ejemplo, /dev/sdb) sin montarla automáticamente.

# Listar los dispositivos de bloques conectados
lsblk

# Verificar mensajes del kernel para confirmar la conexión
dmesg | tail -n 10

2. Crear una Imagen Bit a Bit usando `dd`

Utiliza la herramienta Data Duplicator para extraer hasta el último sector (incluyendo espacio no asignado). Reemplaza sdX con tu dispositivo real.

# Ejecutar como root para tener acceso a los bloques crudos
sudo dd if=/dev/sdX of=~/DFIR/Casos/Caso_001/Evidencia/usb_clon.img bs=4M status=progress

3. Verificar Imagen y Bloquear Escritura

Asegúrate de que la imagen se haya creado correctamente y simula la protección contra escritura montando la imagen como Read-Only (solo lectura).

# Crear un punto de montaje
sudo mkdir -p /mnt/evidencia_clon

# Montar la imagen bloqueando cualquier intento de escritura (-o ro)
sudo mount -o ro,loop ~/DFIR/Casos/Caso_001/Evidencia/usb_clon.img /mnt/evidencia_clon

# Intentar crear un archivo para comprobar el bloqueo
touch /mnt/evidencia_clon/prueba.txt

¡Evidencia Capturada con Éxito!

Has creado una imagen forense perfecta y el dispositivo original permanece inalterado. La cadena de custodia está intacta. Estás listo para proceder a la fase de Hash.
