Curso: Git para Profesionales

Domina el control de versiones desde cero hasta niveles avanzados

Temario del Curso (10 Sesiones)

Aprenderás a crear repositorios vacíos con git init [1]. También cubriremos cómo configurar tu nombre de usuario y correo electrónico utilizando git config para asociar tu identidad correctamente antes de crear cualquier commit [2].

Aprenderás a mover tus cambios al área de preparación usando comandos como git add . o git add -A para preparar archivos [3]. Después, veremos cómo registrar esos cambios de manera permanente mediante git commit y las mejores prácticas para escribir un buen mensaje de commit [4, 5].

Exploraremos el comando git log para visualizar el historial cronológico de tu repositorio [6]. También utilizaremos git diff para comparar los cambios no preparados en tu directorio de trabajo frente al último commit [7].

Descubrirás cómo evitar rastrear archivos no deseados creando un archivo .gitignore para ignorar carpetas y extensiones específicas [8]. Además, aprenderás a usar git clean -f para eliminar archivos no rastreados [9].

Domina el uso de git branch <name> para crear nuevas líneas de desarrollo aisladas [10]. Aprenderás cómo unir diferentes ramas utilizando el comando git merge y a resolver los posibles conflictos resultantes [11].

Entenderás cómo vincular repositorios locales con remotos usando git remote [12]. Veremos cómo descargar cambios de un servidor con git pull [13] y cómo subir tus cambios locales usando git push [14].

Aprenderás a retroceder en el tiempo de forma segura con git reset (en sus modos soft y hard) [15]. Exploraremos el "salvavidas" de Git, git reflog, para recuperar commits perdidos en los últimos 90 días [16, 17].

Comprenderás cómo git rebase reescribe el historial aplicando tus commits encima de otra rama [18]. También practicaremos cómo combinar (squash) varios commits en uno solo para mantener un historial limpio [19, 20].

Utilizaremos git stash para guardar temporalmente cambios incompletos en una pila, permitiéndote cambiar de rama rápidamente sin perder trabajo [21]. Además, veremos git cherry-pick para copiar un commit específico de una rama a otra [22].

Analizaremos modelos de flujos de trabajo (Workflows) utilizados en la industria, desde el flujo Centralizado hasta modelos avanzados donde cada desarrollador tiene ramas de características o incluso sus propios repositorios clonados (Forking Workflow) [23, 24].
