Tema 14: Power Pivot: Modelado de datos

Power Pivot es una potente herramienta de modelado de datos que permite crear modelos de datos sofisticados directamente en Excel. En este tema, exploraremos cómo utilizar Power Pivot para analizar grandes conjuntos de datos, crear relaciones entre tablas y generar análisis avanzados con DAX (Data Analysis Expressions).

14.1 Introducción a Power Pivot

Power Pivot es un complemento de Excel que amplía las capacidades de análisis de datos, permitiendo trabajar con millones de filas de datos de múltiples fuentes.

¿Qué es Power Pivot?

Power Pivot es una herramienta de modelado de datos que te permite:

  • Importar millones de filas de datos de múltiples fuentes
  • Crear relaciones entre tablas sin necesidad de fórmulas VLOOKUP
  • Crear medidas y columnas calculadas con DAX
  • Generar análisis complejos con tablas dinámicas y gráficos

Ejemplo: Habilitar Power Pivot

Para comenzar a usar Power Pivot, sigue estos pasos:

  1. Abre Excel y ve a Archivo > Opciones > Complementos
  2. En el menú desplegable, selecciona Complementos de COM
  3. Busca Microsoft Power Pivot para Excel y haz clic en Ir...
  4. Marca la casilla y haz clic en Aceptar
  5. Reinicia Excel para ver la pestaña Power Pivot

14.2 Creación de un modelo de datos

Un modelo de datos en Power Pivot es una colección de tablas con relaciones entre ellas que forman la base para el análisis.

Componentes clave de un modelo de datos

Componente Descripción Ejemplo
Tablas Conjuntos de datos relacionados Ventas, Productos, Clientes
Relaciones Conexiones entre tablas Ventas[ID_Producto] → Productos[ID]
Medidas Cálculos dinámicos con DAX Ventas Totales = SUM(Ventas[Monto])
Jerarquías Niveles de navegación en datos Año > Trimestre > Mes > Día

Actividad: Crear un modelo de datos básico

Sigue estos pasos para crear tu primer modelo de datos:

  1. Importa dos tablas relacionadas (ej. Ventas y Productos)
  2. Crea una relación entre las tablas usando el campo común
  3. Agrega una medida para calcular el total de ventas
  4. Crea una tabla dinámica que muestre las ventas por categoría de producto

14.3 Fórmulas DAX avanzadas

DAX (Data Analysis Expressions) es el lenguaje de fórmulas utilizado en Power Pivot para crear cálculos personalizados.

Funciones DAX esenciales

// Ventas del año actual
Ventas Año Actual = TOTALYTD(SUM(Ventas[Monto]), Calendario[Fecha])

// Crecimiento interanual
Crecimiento Anual = 
VAR VentasActuales = SUM(Ventas[Monto])
VAR VentasAnoAnterior = 
    CALCULATE(
        SUM(Ventas[Monto]),
        SAMEPERIODLASTYEAR(Calendario[Fecha])
    )
RETURN
    DIVIDE(
        (VentasActuales - VentasAnoAnterior),
        VentasAnoAnterior,
        0
    )

// Clasificación de clientes
Clasificación Cliente = 
SWITCH(
    TRUE(),
    [Total Compras] > 10000, "Premium",
    [Total Compras] > 5000, "Estándar",
    "Básico"
)

Ejercicio: Crear medidas DAX

Crea las siguientes medidas en tu modelo de datos:

  1. Ventas totales del año actual
  2. Promedio de ventas por transacción
  3. Porcentaje de participación de cada producto en las ventas totales
  4. Variación porcentual mes a mes

14.4 Análisis con tablas dinámicas basadas en modelos

Las tablas dinámicas basadas en modelos de Power Pivot ofrecen capacidades avanzadas de análisis.

Consejos para tablas dinámicas avanzadas

  • Usa jerarquías para permitir el análisis por diferentes niveles de datos
  • Aprovecha los filtros de segmentación para crear dashboards interactivos
  • Utiliza KPI (Indicadores Clave de Rendimiento) para visualizar métricas importantes
  • Crea conjuntos de campos para agrupar elementos de manera lógica

Actividad: Crear un dashboard ejecutivo

Crea un dashboard ejecutivo con los siguientes elementos:

  • Un gráfico de líneas que muestre la tendencia de ventas mensuales
  • Una tabla dinámica con las ventas por región y categoría
  • Tarjetas con KPIs clave (ventas totales, crecimiento, margen)
  • Segmentaciones por período, región y categoría

  • Power Pivot permite crear modelos de datos avanzados en Excel.
  • Las relaciones entre tablas son fundamentales para un buen modelo de datos.
