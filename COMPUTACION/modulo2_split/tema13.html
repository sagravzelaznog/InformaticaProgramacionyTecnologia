Módulo 2: Excel de Office

Tema 13: Power Query: Importación y transformación de datos

Power Query es una poderosa herramienta de Microsoft Excel que permite importar, transformar y cargar datos de diversas fuentes. En este tema, exploraremos cómo utilizar Power Query para limpiar, transformar y preparar datos de manera eficiente, ahorrando tiempo y mejorando la calidad de tus análisis.

13.1 Introducción a Power Query

Power Query es una tecnología de conexión de datos que te permite descubrir, conectar, combinar y refinar orígenes de datos para satisfacer tus necesidades de análisis.

¿Qué es Power Query?

Power Query es una herramienta de extracción, transformación y carga (ETL) integrada en Excel que te permite:

  • Conectar a múltiples fuentes de datos (Excel, CSV, bases de datos, web, etc.)
  • Limpiar y transformar datos sin necesidad de fórmulas complejas
  • Automatizar procesos de preparación de datos
  • Crear flujos de trabajo reproducibles

Ejemplo: Importar datos desde la web

Vamos a importar datos de una tabla en una página web:

  1. Ve a la pestaña Datos y selecciona Obtener datos > De otras fuentes > Desde la web
  2. Ingresa la URL que contiene los datos
  3. Selecciona la tabla que deseas importar
  4. Haz clic en Transformar datos para limpiar los datos

13.2 Transformaciones básicas de datos

Power Query ofrece una amplia gama de transformaciones que puedes aplicar a tus datos:

Transformaciones comunes

Transformación Descripción Ejemplo de uso
Eliminar filas Elimina filas según condiciones específicas Eliminar filas con valores nulos o vacíos
Dividir columnas Divide una columna en varias según un delimitador Separar nombre completo en nombre y apellido
Cambiar tipo de datos Convierte el tipo de datos de una columna Cambiar texto a número o fecha
Rellenar hacia abajo/arriba Completa celdas vacías con valores adyacentes Rellenar categorías en informes jerárquicos

Actividad: Limpieza de datos con Power Query

Descarga el archivo de datos de ejemplo y realiza las siguientes transformaciones:

  1. Elimina filas con valores nulos
  2. Cambia el formato de fecha a dd/mm/aaaa
  3. Divide la columna "Nombre completo" en "Nombre" y "Apellido"
  4. Filtra solo los registros del año actual
  5. Guarda y carga los datos transformados a una nueva hoja

13.3 Combinación de consultas

Power Query te permite combinar datos de múltiples fuentes o tablas:

Ejercicio: Combinar datos de ventas

Tienes dos archivos: ventas_2023.xlsx y clientes.xlsx. Sigue estos pasos para combinarlos:

  1. Importa ambos archivos a Power Query
  2. Identifica la columna común (ID_Cliente)
  3. Usa la opción Combinar consultas para realizar un LEFT JOIN
  4. Expande las columnas necesarias de la tabla de clientes

Consejo profesional

Usa Consultas de solo conexión para crear tablas de referencia que puedas reutilizar en múltiples combinaciones sin duplicar datos.

13.4 Automatización con Power Query

Aprende a automatizar tareas recurrentes:

Ejemplo: Actualización automática

Configura la actualización automática de tus consultas:

  1. Haz clic derecho en la consulta y selecciona Propiedades
  2. Marca Actualizar al abrir el archivo
  3. Configura la actualización programada si es necesario

Resumen del tema

  • Power Query es una herramienta poderosa para la importación y transformación de datos en Excel.
  • Permite limpiar y transformar datos sin necesidad de fórmulas complejas.
  • Puedes combinar datos de múltiples fuentes usando diferentes tipos de uniones.
  • Las consultas se pueden actualizar automáticamente cuando cambian los datos de origen.
  • Es especialmente útil para automatizar procesos repetitivos de preparación de datos.
