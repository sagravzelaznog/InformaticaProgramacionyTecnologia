Módulo 2: Excel de Office

Tema 16: Proyecto Final: Aplicación de lo Aprendido

¡Felicidades por llegar al proyecto final! En este tema, tendrás la oportunidad de aplicar todos los conocimientos adquiridos a lo largo del curso en un proyecto integral que demuestre tus habilidades en el análisis de datos con Excel.

Objetivos del Proyecto

  • Integrar los conceptos aprendidos en un proyecto práctico
  • Demostrar competencia en el manejo de herramientas avanzadas de Excel
  • Desarrollar habilidades de análisis y presentación de datos
  • Recibir retroalimentación sobre tu trabajo

Descripción del Proyecto

Crearás un sistema de análisis de datos completo para una empresa ficticia, utilizando todas las herramientas avanzadas de Excel que hemos aprendido en el curso.

Fase 1: Preparación de Datos

Actividad 1.1: Importación y Limpieza de Datos

Utiliza Power Query para importar y limpiar los siguientes conjuntos de datos:

  • Datos de ventas históricas (archivo CSV)
  • Información de productos (desde una base de datos)
  • Datos de clientes (desde una hoja de cálculo web)
Actividad 1.2: Transformación de Datos

Realiza las siguientes transformaciones:

  1. Estandariza formatos de fechas y monedas
  2. Maneja valores faltantes y duplicados
  3. Crea columnas calculadas necesarias
  4. Combina tablas relacionadas

Fase 2: Modelado y Análisis

Actividad 2.1: Creación del Modelo de Datos

Usa Power Pivot para:

  • Crear relaciones entre tablas
  • Definir jerarquías (por ejemplo: Año > Trimestre > Mes)
  • Establecer categorías de datos apropiadas
Actividad 2.2: Cálculos con DAX

Crea las siguientes medidas con DAX:

// Ejemplo de medidas a crear
Ventas Totales = SUM(Ventas[Monto])
Crecimiento Interanual = 
    VAR VentasActuales = [Ventas Totales]
    VAR VentasAnoAnterior = 
        CALCULATE(
            [Ventas Totales],
            SAMEPERIODLASTYEAR(Calendario[Fecha])
        )
    RETURN
        DIVIDE(
            (VentasActuales - VentasAnoAnterior),
            VentasAnoAnterior,
            0
        )
Margen de Beneficio = DIVIDE([Beneficio], [Ventas Totales], 0)

Fase 3: Creación del Dashboard

Actividad 3.1: Diseño del Dashboard

Crea un dashboard interactivo que incluya:

Sección de KPIs Principales
  • Tarjeta de Ventas Totales
  • Porcentaje de Crecimiento
  • Margen de Beneficio
  • Número de Clientes Activos
Visualizaciones Principales
  • Gráfico de líneas: Tendencia de ventas
  • Gráfico de barras: Ventas por categoría
  • Gráfico de mapa: Desempeño por región
  • Tabla dinámica: Detalle de ventas
Actividad 3.2: Interactividad

Agrega los siguientes elementos interactivos:

  1. Segmentaciones de datos para filtrar por período, región y categoría
  2. Gráficos interactivos que respondan a los filtros
  3. Botones de reinicio de filtros
  4. Hipervínculos entre hojas de análisis

Entregables Requeridos

Para completar el proyecto, deberás entregar los siguientes elementos:

  1. Archivo de Excel con el proyecto completo (.xlsx o .xlsb)
  2. Documento con la descripción de tu análisis (máx. 2 páginas)
  3. Presentación de 5-7 diapositivas resumiendo tus hallazgos
  4. Archivo de video corto (3-5 min) explicando tu dashboard
