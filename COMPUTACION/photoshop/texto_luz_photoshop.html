✨ Efecto de Luz en Texto - Photoshop

📋 Requisitos previos:

  • Photoshop en modo RGB, 8 bits
  • Resolución recomendada: 72 ppp
  • Documento con fondo oscuro (negro o color oscuro)
Paso 1: Configuración Inicial
  1. Abre Photoshop y crea un nuevo documento: Ctrl + N
  2. Configura el documento:
    • Modo de color: RGB
    • Profundidad de bits: 8 bits
    • Resolución: 72 ppp
  3. Rellena el fondo con color negro:
    • Selecciona la herramienta Bote de pintura (G)
    • Asegúrate que el color frontal sea negro
    • Haz clic en el área de trabajo
Paso 2: Crear el Texto Base
  1. Selecciona la herramienta Texto (T)
  2. Haz clic en el documento y escribe tu texto (ej. "LUZ")
  3. En la barra de opciones superiores:
    • Elige una fuente gruesa y legible
    • Tamaño grande (ej. 120pt)
    • Color blanco
  4. Centra el texto en el documento
Paso 3: Duplicar la Capa de Texto
  1. En el panel de capas, haz clic derecho sobre la capa de texto
  2. Selecciona Duplicar capa...
  3. Nombra la nueva capa como "Luz 1"
  4. O usa el atajo: Ctrl + J
💡 Consejo: Mantén tus capas organizadas con nombres descriptivos para facilitar la edición.
Paso 4: Aplicar Desenfoque Radial
  1. Asegúrate de tener seleccionada la capa "Luz 1"
  2. Ve a Filtro > Desenfocar > Desenfoque radial...
  3. Configura los parámetros:
    • Cantidad: 100
    • Método: Zoom
    • Calidad: Buena
  4. Haz clic en Aceptar
Paso 5: Rellenar la Selección
  1. Presiona D para restablecer los colores por defecto (blanco/negro)
  2. Si es necesario, presiona X para intercambiar los colores (blanco debe ser el color frontal)
  3. Mantén presionada la tecla Ctrl (Windows) o ⌘ (Mac) y haz clic en la miniatura de la capa "Luz 1"
  4. Verás que se crea una selección alrededor del texto
  5. Presiona Alt + Supr (Windows) o Option + Delete (Mac) para rellenar con el color frontal (blanco)
  6. Deselecciona: Ctrl + D (Windows) o ⌘ + D (Mac)
Paso 6: Repetir el Efecto
  1. Repite los pasos 4 y 5 varias veces (3-5 veces) para intensificar los rayos de luz
  2. Cada vez que repitas, los rayos se harán más largos y definidos
  3. Puedes combinar Ctrl + F para repetir el último filtro
Nota: El número de repeticiones dependerá del tamaño de tu texto y del efecto deseado. Experimenta para obtener el mejor resultado.
Paso 7: Aplicar Color a los Rayos
  1. Haz doble clic en la capa "Luz 1" para abrir los estilos de capa
  2. En la ventana que aparece, activa Superposición de color
  3. Haz clic en el cuadro de color para elegir un tono vibrante (azul eléctrico, rosa neón, etc.)
  4. Prueba diferentes modos de fusión como Trama, Luz suave o Sobreexponer color
  5. Ajusta la opacidad según prefieras
  6. Haz clic en Aceptar cuando estés satisfecho
Paso 8: Añadir Fondo (Opcional)
  1. Para un mejor efecto, puedes añadir una imagen de fondo:
  2. Ve a Archivo > Colocar elemento incrustado...
  3. Selecciona una imagen de fondo (ej. espacio, textura oscura)
  4. Ajusta el tamaño y posición según necesites
  5. Asegúrate de que la capa de fondo esté debajo de las capas de texto
Paso 9: Ajustes Finales
  • Para intensificar el efecto, duplica la capa de luz y baja la opacidad
  • Prueba diferentes modos de fusión como Superponer o Luz fuerte
  • Añade una capa de ajuste de Brillo/Contraste para mejorar el impacto visual
  • Guarda tu trabajo como archivo PSD para conservar las capas
  • Exporta como JPG o PNG para compartir: Archivo > Exportar > Exportar como...

💡 Consejos adicionales:

  • Experimenta con diferentes colores para los rayos
  • Prueba a aplicar el efecto sobre diferentes fondos
  • Combina con otros efectos como resplandor exterior o brillo
  • Para un efecto más dramático, aumenta el número de repeticiones del desenfoque radial

⚠️ Solución de problemas:

  • Si el efecto no se ve bien, verifica que estés en modo RGB de 8 bits
  • Asegúrate de que el texto sea lo suficientemente grande
  • Si los rayos se ven pixelados, aumenta la resolución del documento
