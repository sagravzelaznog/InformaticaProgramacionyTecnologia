Introducción a las Publicaciones Web

En esta sesión aprenderás a transformar tus publicaciones de Publisher en sitios web completamente funcionales. Microsoft Publisher te permite crear publicaciones web atractivas sin necesidad de conocimientos avanzados de programación.

¿Qué son las publicaciones web en Publisher?

Son documentos de Publisher especialmente diseñados o convertidos para ser visualizados en navegadores web, permitiendo compartir tu contenido en Internet de manera accesible.

Ventajas:

  • Fácil creación sin necesidad de código HTML
  • Integración con otros elementos de Office
  • Diseño visual con herramientas familiares
  • Publicación directa desde el programa

Guardar Publicaciones como Páginas Web

Convertir tu publicación de Publisher en una página web es un proceso sencillo que te permite compartir tu trabajo en línea.

Paso a paso: Guardar como página web

1. Abre tu publicación en Microsoft Publisher.
2. Haz clic en Archivo > Guardar como.
3. Selecciona la ubicación donde deseas guardar los archivos.
4. En el menú desplegable Guardar como tipo, selecciona Página web (*.htm; *.html).
5. Haz clic en Cambiar título y escribe un título para tu página web.
6. Haz clic en Guardar.
Consejos para el guardado web:
  • Nombres de archivo: Usa solo letras minúsculas, números y guiones.
  • Ubicación: Crea una carpeta específica para los archivos web.
  • Imágenes: Publisher creará automáticamente una carpeta para las imágenes.
  • Enlaces: Verifica que todos los enlaces funcionen correctamente.

Insertar Elementos Web

Publisher ofrece varias herramientas para hacer tus publicaciones web más interactivas y atractivas.

Elementos web disponibles

1. Formularios

Incluye formularios de contacto, suscripción o comentarios.

2. Botones interactivos

Crea botones con efectos de desplazamiento.

Paso a paso: Insertar un formulario de contacto

1. Ve a la pestaña Insertar.
2. Haz clic en Formulario y selecciona Formulario de contacto.
3. Personaliza los campos según tus necesidades.
4. Establece la dirección de correo electrónico donde recibirás los mensajes.
5. Ajusta el diseño para que coincida con tu publicación.

Publicar en Línea

Una vez que tu publicación web está lista, es hora de compartirla con el mundo.

Opciones de publicación

1. Publicar en un servidor web

Sube tus archivos a un servicio de alojamiento web.

Subir archivos vía FTP

2. Publicar en OneDrive

Guarda y comparte directamente desde la nube.

Guardar en OneDrive

Paso a paso: Publicar en OneDrive

1. Haz clic en Archivo > Guardar como.
2. Selecciona OneDrive - Personal.
3. Elige una ubicación o crea una nueva carpeta.
4. Haz clic en Guardar.
5. Haz clic derecho en el archivo guardado y selecciona Compartir.

Práctica Guiada

Sigue estos pasos para crear y publicar una página web simple con Microsoft Publisher.

Paso 1: Crear una publicación web básica

1. Abre Microsoft Publisher y selecciona Publicación en blanco.
2. En la pestaña Diseño de página, selecciona Página web como tipo de publicación.
3. Establece el tamaño de página a 1024 x 768 píxeles.
4. Agrega un encabezado con el título "Mi Primera Página Web".
5. Inserta una imagen relevante desde tu computadora.

Paso 2: Agregar navegación

1. Crea una barra de navegación en la parte superior.
2. Agrega al menos tres enlaces (Inicio, Acerca de, Contacto).
3. Crea páginas adicionales para cada sección.
4. Vincula los botones de navegación a las páginas correspondientes.

Paso 3: Guardar y publicar

1. Haz clic en Archivo > Guardar como.
2. Selecciona Página web (*.htm; *.html) como tipo de archivo.
3. Elige una ubicación y haz clic en Guardar.
4. Abre el archivo index.html en tu navegador para probarlo.

Autoevaluación

1. ¿Cuáles son los pasos básicos para guardar una publicación como página web en Publisher?

Los pasos básicos son:
  1. Abrir la publicación en Publisher
  2. Hacer clic en Archivo > Guardar como
  3. Seleccionar Página web (*.htm; *.html) como tipo de archivo
  4. Elegir una ubicación para guardar los archivos
  5. Hacer clic en Guardar

2. ¿Qué elementos interactivos se pueden agregar a una publicación web en Publisher?

Se pueden agregar varios elementos interactivos, incluyendo:
  • Formularios de contacto
  • Botones con efectos de desplazamiento
  • Enlaces a páginas web externas
  • Vídeos incrustados
  • Galerías de imágenes interactivas
  • Mapas de Google
  • Botones de redes sociales

3. ¿Cuáles son las opciones para publicar una página web creada en Publisher?

Las principales opciones de publicación son:
  • Servidor web propio: Subir los archivos vía FTP a un servicio de alojamiento web.
  • OneDrive/SharePoint: Guardar en la nube y compartir el enlace.
  • Correo electrónico: Enviar los archivos como adjuntos.
  • CD/DVD: Grabar los archivos en un disco para distribución física.
  • Servicios de publicación web: Algunas versiones de Publisher ofrecen integración con servicios de publicación web.
