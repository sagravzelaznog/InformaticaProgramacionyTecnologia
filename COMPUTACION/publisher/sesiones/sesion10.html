Introducción a los Hipervínculos

Los hipervínculos son elementos fundamentales en las publicaciones digitales que permiten la navegación entre diferentes secciones de un documento o a recursos externos. En esta sesión aprenderás a crear y gestionar diferentes tipos de hipervínculos en Microsoft Publisher.

¿Qué es un hipervínculo?

Un hipervínculo es un enlace que conecta una parte de un documento con otro documento o con otra sección del mismo documento.

Ejemplo: Haz clic aquí para ver más información.

Tipos de Hipervínculos

En Microsoft Publisher, puedes crear varios tipos de hipervínculos:

1. Enlaces a páginas web

Conectan tu publicación con sitios web en Internet.

Ejemplo: Visita Microsoft

2. Enlaces a documentos

Conectan con archivos en tu computadora o red.

Ejemplo: Documento de referencia.pdf

3. Enlaces de correo electrónico

Permiten a los lectores enviar correos con un solo clic.

Ejemplo: Enviar correo

4. Enlaces internos

Navegan a diferentes secciones del mismo documento.

Ejemplo: Ir a la sección de ejercicios

Cómo Crear un Hipervínculo

Sigue estos pasos para crear un hipervínculo en Microsoft Publisher:

Paso a paso: Crear un hipervínculo

1. Selecciona el texto o el objeto que quieres convertir en hipervínculo.
2. Ve a la pestaña Insertar en la cinta de opciones.
3. Haz clic en el botón Hipervínculo en el grupo Vínculos.
4. En el cuadro de diálogo que aparece, selecciona el tipo de vínculo que deseas crear.
5. Completa la información requerida (URL, dirección de correo, etc.).
6. Haz clic en Aceptar para crear el hipervínculo.

Crear Enlaces Internos

Los enlaces internos son útiles para navegar dentro del mismo documento, especialmente en publicaciones largas.

Ejercicio: Crear un índice con enlaces internos

Sigue estos pasos para crear un índice interactivo:

1. Crea un cuadro de texto para el índice.
2. Escribe los títulos de las secciones.
3. Selecciona el primer título y haz clic en Insertar > Marcador.
4. Dale un nombre al marcador (sin espacios).
5. Selecciona el texto del índice que corresponde a esa sección.
6. Haz clic en Insertar > Hipervínculo.
7. Selecciona Lugar de este documento y elige el marcador.
8. Repite para las demás secciones.

Enlaces a Páginas Web y Documentos

Los enlaces externos conectan tu publicación con recursos en Internet o en tu red local.

Ejercicio: Crear un enlace a una página web

1. Selecciona el texto o imagen que será el enlace.
2. Haz clic en Insertar > Hipervínculo.
3. En Vincular a, selecciona Archivo o página web existente.
4. En Dirección, escribe la URL completa (incluyendo http:// o https://).
5. Haz clic en Aceptar.

Consejos para enlaces externos

  • Usa textos descriptivos para los enlaces en lugar de "Haz clic aquí".
  • Verifica que las URLs sean correctas y estén activas.
  • Considera abrir enlaces externos en una nueva pestaña para no sacar al lector de tu publicación.

Enlaces de Correo Electrónico

Los enlaces de correo permiten a los lectores contactarte fácilmente.

Ejercicio: Crear un enlace de correo

1. Selecciona el texto o imagen para el enlace.
2. Haz clic en Insertar > Hipervínculo.
3. En Vincular a, selecciona Dirección de correo electrónico.
4. Ingresa la dirección de correo y un asunto opcional.
5. Haz clic en Aceptar.

Ejemplo de enlace de correo: Enviar consulta

Práctica Guiada

Sigue estos pasos para crear una publicación con diferentes tipos de hipervínculos:

Paso 1: Crea un nuevo documento

1. Abre Microsoft Publisher.
2. Selecciona una plantilla en blanco o un diseño de boletín.

Paso 2: Añade contenido

1. Crea un encabezado con el título "Recursos Educativos".
2. Añade al menos tres secciones con títulos y contenido breve.

Paso 3: Añade hipervínculos

1. Crea un índice con enlaces a cada sección.
2. Añade al menos un enlace a una página web educativa.
3. Incluye un enlace de correo para contacto.

Paso 4: Prueba los enlaces

1. Guarda el documento.
2. Haz clic en cada enlace para verificar que funcionan correctamente.

Ejercicios Prácticos

Ejercicio 1: Crea un menú de navegación

Crea una publicación con al menos 3 páginas y un menú de navegación con enlaces a cada página.

Páginas a incluir:
  • Inicio
  • Servicios
  • Contacto
Pasos:
  1. Crea las páginas necesarias
  2. Añade un cuadro de texto en la parte superior de cada página
  3. Inserta los enlaces entre páginas
  4. Prueba la navegación

Ejercicio 2: Catálogo de productos

Crea un catálogo de productos con enlaces a páginas web externas para más información.

Elementos a incluir:
  • Imagen del producto
  • Descripción breve
  • Precio
  • Enlace a más información
Consejos:
  • Usa una cuadrícula para organizar los productos
  • Asegúrate de que los enlaces se abran en una nueva pestaña
  • Verifica que todas las URLs sean correctas

Autoevaluación

1. ¿Qué tipo de hipervínculo usarías para dirigir a un lector a una sección específica dentro del mismo documento?

Se debe usar un enlace interno que apunte a un marcador en el documento.

2. ¿Por qué es importante probar todos los hipervínculos antes de publicar un documento?

Para asegurar que todos los enlaces funcionen correctamente y lleven al destino deseado, mejorando la experiencia del usuario y la credibilidad del documento.

3. ¿Cómo harías para que un enlace a una página web se abra en una nueva pestaña del navegador?

Al crear el hipervínculo, debes configurarlo para que se abra en una nueva ventana o pestaña. En el cuadro de diálogo de hipervínculo, busca la opción "Marco de destino" o similar y selecciona "Nueva ventana" o "_blank".

4. ¿Qué información debe incluir un enlace de correo electrónico para que ya venga con un asunto predeterminado?

Debes incluir el parámetro "subject" en la URL del correo, por ejemplo: mailto:contacto@ejemplo.com?subject=Asunto%20del%20mensaje. Los espacios se reemplazan por %20.
