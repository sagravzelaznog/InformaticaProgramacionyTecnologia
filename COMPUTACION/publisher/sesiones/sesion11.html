Introducción a la Combinación de Correspondencia

La combinación de correspondencia es una herramienta que permite crear documentos personalizados en masa, como cartas, etiquetas o sobres, utilizando una lista de destinatarios.

¿Qué es la combinación de correspondencia?

Es un proceso que combina un documento principal con una fuente de datos para crear documentos personalizados para múltiples destinatarios.

Ejemplo de uso:

  • Cartas personalizadas para clientes
  • Etiquetas de envío
  • Certificados con nombres individuales
  • Invitaciones personalizadas

Principal Fuente de Datos Documentos Personalizados

Preparar el Documento Principal

Antes de comenzar con la combinación de correspondencia, necesitas tener listo tu documento principal en Publisher.

Paso a paso: Crear el documento principal

1. Abre Microsoft Publisher y crea un nuevo documento.
2. Diseña tu publicación (carta, etiqueta, sobre, etc.) dejando espacios para la información variable.
3. Guarda el documento con un nombre descriptivo, por ejemplo: Plantilla_Carta_Clientes.pub.

Preparar el Origen de Datos

La fuente de datos contiene la información que se insertará en tu documento. Puede ser un archivo de Excel, una tabla de Word, una base de datos o una lista de contactos de Outlook.

Crear una lista de destinatarios en Excel

1. Abre Microsoft Excel y crea una nueva hoja de cálculo.
2. En la primera fila, escribe los nombres de los campos (columnas).
3. Completa las filas con la información de cada destinatario.
4. Guarda el archivo con un nombre descriptivo.

Insertar Campos de Combinación

Una vez que tienes tu documento principal y tu fuente de datos, es hora de conectar ambos.

Paso a paso: Conectar con la fuente de datos

1. En Publisher, ve a la pestaña Correo.
2. Haz clic en Seleccionar destinatarios y elige Usar una lista existente.
3. Navega hasta tu archivo de Excel y selecciónalo.

Completar la Combinación

Una vez que hayas revisado y estés satisfecho con la vista previa, es hora de completar la combinación.

Paso a paso: Finalizar la combinación

1. En la pestaña Correo, haz clic en Finalizar y combinar.
2. Selecciona una opción:
  • Imprimir documentos
  • Editar documentos individuales
  • Enviar mensajes de correo electrónico

Autoevaluación

1. ¿Cuáles son los tres componentes principales necesarios para realizar una combinación de correspondencia?

Los tres componentes principales son:
  1. Documento principal (plantilla)
  2. Fuente de datos
  3. Documentos combinados resultantes

2. ¿Qué tipos de archivos se pueden utilizar como fuente de datos?

Se pueden utilizar:
  • Archivos de Excel (.xlsx, .xls)
  • Archivos de Access (.accdb, .mdb)
  • Archivos de texto (.csv, .txt)
  • Listas de contactos de Outlook
  • Bases de datos de SQL Server
