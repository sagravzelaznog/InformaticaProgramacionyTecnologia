Módulo 1: Introducción a la Computación

Tema 1: Introducción a la computación: conceptos básicos

Bienvenido al fascinante mundo de la computación. En este tema exploraremos los fundamentos que te permitirán comprender cómo funcionan las computadoras y su impacto en la sociedad actual.

¿Qué es la computación?

La computación es la ciencia que estudia los sistemas automatizados de manejo de información, lo cual incluye:

  • El procesamiento de datos
  • El almacenamiento de información
  • La transmisión de datos
  • La resolución de problemas mediante algoritmos

Historia de la computación

La computación moderna tiene sus raíces en varios hitos históricos:

  • Ábaco (3000 a.C.): Primera herramienta de cálculo
  • Máquina de Pascal (1642): Primera calculadora mecánica
  • Máquina Analítica de Babbage (1837): Precursora de las computadoras modernas
  • Primera generación (1940-1956): Válvulas de vacío
  • Segunda generación (1956-1963): Transistores
  • Tercera generación (1964-1971): Circuitos integrados
  • Cuarta generación (1971-actualidad): Microprocesadores
  • Quinta generación (futuro): Inteligencia artificial y computación cuántica

Conceptos fundamentales

1. Datos vs. Información

  • Datos: Son hechos crudos sin procesar (ejemplo: números, letras, símbolos).
  • Información: Son datos procesados y organizados que tienen significado y utilidad.

Ejemplo:

Datos: 25, 30, 28, 22, 35 (temperaturas en °C)

Información: "La temperatura promedio de la semana fue de 28°C, con una máxima de 35°C el viernes."

Software

Programas y aplicaciones:

Tema 2: Componentes del hardware de una computadora

El hardware de una computadora está compuesto por todos los componentes físicos y tangibles que permiten su funcionamiento. En este tema exploraremos en detalle cada uno de estos componentes, su función y cómo interactúan entre sí.

1. Unidad Central de Procesamiento (CPU)

El cerebro de la computadora, responsable de ejecutar instrucciones y procesar datos.

Características principales:
  • Núcleos (Cores): Unidades de procesamiento independientes
  • Frecuencia de reloj: Velocidad de procesamiento (GHz)
  • Caché: Memoria ultrarrápida para datos de uso frecuente
  • Hilos: Capacidad de procesamiento paralelo
Procesador moderno de múltiples núcleos

2. Memoria RAM

Memoria de acceso aleatorio que almacena temporalmente los datos que la CPU está utilizando activamente.

Características principales:
  • Capacidad: Medida en GB (8GB, 16GB, 32GB, etc.)
  • Tipo: DDR3, DDR4, DDR5 (más reciente)
  • Frecuencia: Velocidad de transferencia (MHz)
  • Latencia: Tiempo de respuesta (CL)

3. Almacenamiento

Dispositivos que almacenan datos de forma permanente (incluso cuando la computadora está apagada).

Tipos principales:
  • HDD (Disco Duro Mecánico): Mayor capacidad, menor velocidad
  • SSD (Unidad de Estado Sólido): Mayor velocidad, sin partes móviles
  • NVMe: Ultra rápido, se conecta directamente a la placa madre

4. Tarjeta Madre (Motherboard)

La placa base que conecta todos los componentes de la computadora.

Componentes principales:
  • Socket del procesador: Tipo de conexión para la CPU
  • Ranuras de memoria: Para módulos RAM
  • Ranuras de expansión: PCIe para tarjetas gráficas y otros dispositivos
  • Conectores SATA/M.2: Para almacenamiento
  • Chipset: Controla la comunicación entre componentes
Placa madre moderna con múltiples ranuras de expansión

5. Tarjeta Gráfica (GPU)

Procesador especializado en el manejo de gráficos y operaciones en paralelo.

Características principales:
  • GPU: Unidad de procesamiento gráfico
  • VRAM: Memoria de video dedicada
  • Salidas de video: HDMI, DisplayPort, DVI
  • Enfriamiento: Ventiladores o refrigeración líquida
Tarjeta gráfica de gama alta

6. Fuente de Alimentación (PSU)

Convierte la corriente alterna (AC) en corriente directa (DC) para alimentar los componentes.

Características principales:
  • Potencia: Medida en vatios (W)
  • Eficiencia: Certificación 80 Plus (Bronze, Silver, Gold, Platinum, Titanium)
  • Módularidad: Totalmente modular, semi-modular o fija
  • Conectores: ATX, EPS, PCIe, SATA, Molex
Fuente de alimentación modular

Sistemas que mantienen los componentes a temperaturas óptimas de funcionamiento.

Tipos de refrigeración:

  • Refrigeración pasiva: Sin partes móviles, solo disipadores
  • Pasta térmica: Mejora la transferencia de calor

8. Gabinete (Case)

Estructura que aloja y protege los componentes de la computadora.

Consideraciones al elegir un gabinete:
  • Factor de forma: ATX, Micro-ATX, Mini-ITX
  • Flujo de aire: Espacio para ventiladores y radiadores
  • Gestión de cables: Espacio y pasacables
  • Bahías: Para unidades de almacenamiento

Tema 3: Sistemas operativos: funciones y tipos

El sistema operativo es el software más importante de una computadora, actuando como intermediario entre el hardware y el usuario. En este tema exploraremos sus funciones principales, tipos y características distintivas.

1. ¿Qué es un sistema operativo?

Un sistema operativo (SO) es un conjunto de programas que gestiona los recursos del hardware y proporciona servicios a los programas de aplicación.

Características principales:
  • Interfaz de usuario: Permite la interacción humano-computadora
  • Gestión de recursos: Asigna y administra el hardware
  • Ejecución de programas: Carga y ejecuta aplicaciones
  • Seguridad: Protege los datos y recursos del sistema
Interacción entre hardware, sistema operativo y usuario

4. Evolución de los sistemas operativos

1950s
Sistemas por lotes (batch)

Primeros sistemas sin interacción del usuario, procesaban trabajos en secuencia.

1960s
Sistemas de tiempo compartido

Varios usuarios podían usar la misma computadora simultáneamente.

1970s
UNIX y los primeros sistemas multiusuario

Surgimiento de UNIX, que sentó las bases para muchos sistemas modernos.

1980s
Interfaces gráficas

Apple Lisa y Macintosh introducen las interfaces gráficas de usuario (GUI).

1990s
Sistemas operativos de red

Windows 95/98/NT y la popularización de Internet.

2000s
Sistemas móviles

iOS y Android revolucionan la computación móvil.

2010s-presente
Computación en la nube y sistemas distribuidos

Los sistemas operativos se integran con servicios en la nube.

4. Cifrado de archivos (EFS y BitLocker)

EFS (Sistema de cifrado de archivos)

Cifrado a nivel de archivo integrado en NTFS.

Características:
  • Cifrado transparente para el usuario
  • Basado en certificados
  • Solo disponible en ediciones Pro, Enterprise y Education
  • No protege contra el acceso físico al disco
Uso básico:
# Cifrar un archivo
cipher /e /a "C:\ruta\archivo.txt"

# Cifrar una carpeta (contenido existente)
cipher /e /s:"C:\carpeta"

# Cifrar una carpeta (contenido futuro)
cipher /e /s:"C:\carpeta" /i

# Ver estado de cifrado
cipher "C:\ruta\*"
BitLocker

Cifrado de disco completo para mayor seguridad.

Características:
  • Cifrado de volumen completo
  • Integrado con TPM
  • Protección de arranque
  • Requerimientos de hardware específicos
Comandos manage-bde:

1. Conceptos básicos de seguridad informática

Confidencialidad

Integridad

  • Firmas digitales
  • Hashes criptográficos
  • Controles de versión
Disponibilidad

Garantizar que la información y los recursos estén disponibles cuando se necesiten.

Tema 11: Administración de procesos

La administración de procesos es un aspecto fundamental de los sistemas operativos modernos. En este tema, exploraremos en profundidad cómo Windows gestiona los procesos, cómo monitorearlos, administrarlos y solucionar problemas comunes relacionados con ellos.

1. Conceptos fundamentales de procesos

Un proceso es un programa en ejecución que incluye su propio espacio de direcciones, recursos asignados y uno o más hilos de ejecución.

Componentes de un proceso
  • Identificador (PID): Número único que identifica al proceso
  • Estado: Ejecución, listo, bloqueado, terminado
  • Contador de programa: Siguiente instrucción a ejecutar
  • Registros de CPU: Estado actual de la CPU
  • Espacio de direcciones: Memoria asignada al proceso
Estados de un proceso
Nuevo → Listo → En ejecución → Terminado
   ↑         ↓
   └───── Espera ←──┘

Los procesos pueden cambiar de estado debido a:

  • Planificación del sistema operativo
  • Espera de E/S
  • Interrupciones
  • Llamadas al sistema

2. Herramientas de administración de procesos

Windows proporciona varias herramientas para administrar procesos:

Administrador de tareas

Interfaz gráfica para monitorear y administrar procesos.

Acceso rápido: Ctrl + Shift + Esc

Características principales:

  • Ver uso de CPU, memoria, disco y red
  • Finalizar tareas que no responden
  • Establecer prioridades de procesos
  • Ver historial de aplicaciones
Monitor de recursos

Herramienta avanzada para análisis detallado.

Acceso: Ejecutar → resmon

Pestañas principales:

  • General: Visión general del sistema
  • CPU: Uso detallado de CPU
  • Memoria: Uso de memoria física
  • Disco: Actividad de E/S del disco
  • Red: Actividad de red

  • Alta (13): Aplicaciones críticas
  • Por encima de lo normal (8): Aplicaciones de alto rendimiento

  • Por debajo de lo normal (4): Procesos en segundo plano
  • Baja (1): Procesos de baja prioridad

5. Automatización con PowerShell Workflow

PowerShell Workflow permite crear flujos de trabajo complejos que pueden incluir ejecución paralela, reintentos automáticos y manejo de errores.

Ejemplo de Workflow

workflow MantenimientoServidores {
    param(
        [string[]]$Servidores = @('SRV01', 'SRV02', 'SRV03'),
        [string]$CarpetaRespaldo = 'D:\Respaldos'
    )
    
    # Ejecución en paralelo para múltiples servidores
    foreach -parallel ($Servidor in $Servidores) {
        sequence {
            # Verificar si el servidor está en línea
            if (Test-Connection -ComputerName $Servidor -Count 1 -Quiet) {
                Write-Output "Iniciando respaldo en $Servidor..."
                
                # Crear carpeta de respaldo
                $CarpetaDestino = "$CarpetaRespaldo\$Servidor\$(Get-Date -Format 'yyyyMMdd')"
                New-Item -ItemType Directory -Path $CarpetaDestino -Force | Out-Null
                
                # Copiar archivos importantes
                Copy-Item -Path "\\$Servidor\C$\ArchivosImportantes\*" -Destination $CarpetaDestino -Recurse -Force
                
                # Verificar copia
                $archivosOrigen = Get-ChildItem -Path "\\$Servidor\C$\ArchivosImportantes" -Recurse | Where-Object { !$_.PSIsContainer }
                $archivosDestino = Get-ChildItem -Path $CarpetaDestino -Recurse | Where-Object { !$_.PSIsContainer }
                
                if ($archivosOrigen.Count -eq $archivosDestino.Count) {
                    Write-Output "Respaldo de $Servidor completado exitosamente"
                } else {
                    Write-Error "Error en el respaldo de $Servidor. Archivos faltantes."
                }
            } else {
                Write-Warning "No se pudo conectar a $Servidor. Omitiendo..."
            }
        }
    }
}

    $timestamp = Get-Date -Format "[yyyy-MM-dd HH:mm:ss]"
    "$timestamp $message" | Tee-Object -FilePath $logFile -Append
}

        @{Name = 'Router'; IP = '192.168.1.1'},
        @{Name = 'Servidor Local'; IP = '192.168.1.100'}
    )
    LogFile = "$env:USERPROFILE\network_monitor.log"
    AlertThreshold = 100  # ms de latencia para alerta
}

# Iniciar monitoreo
while ($true) {
    $results = @()
    $timestamp = Get-Date -Format "yyyy-MM-dd HH:mm:ss"
    
    foreach ($hostItem in $monitorConfig.CriticalHosts) {
        $ping = Test-Connection -ComputerName $hostItem.IP -Count 1 -ErrorAction SilentlyContinue
        $status = if ($ping) { "ACTIVO" } else { "INACTIVO" }
        $latency = if ($ping) { $ping.ResponseTime } else { $null }
        
        $result = [PSCustomObject]@{
            Timestamp = $timestamp
            HostName = $hostItem.Name
            IP = $hostItem.IP
            Status = $status
            Latency = $latency
        }
        
        $results += $result
        
        # Generar alerta si es necesario
        if ($status -eq "INACTIVO" -or ($latency -and $latency -gt $monitorConfig.AlertThreshold)) {
            $alertMessage = "ALERTA: $($hostItem.Name) ($($hostItem.IP)) - "
            $alertMessage += if ($status -eq "INACTIVO") { "NO RESPONDE" } else { "Alta latencia: ${latency}ms" }
            
            # Registrar alerta
            Add-Content -Path $monitorConfig.LogFile -Value "$timestamp - $alertMessage"
            
            # Opcional: Enviar notificación
            # Send-Notification -Message $alertMessage
        }
    }
    
    # Mostrar resultados en consola
    Clear-Host
    Write-Host "=== MONITOR DE RED ===" -ForegroundColor Cyan
    Write-Host "Última actualización: $timestamp\n"
    
    $results | Format-Table -AutoSize | Out-String | Write-Host
    
    # Esperar hasta la próxima verificación
    Start-Sleep -Seconds $monitorConfig.CheckInterval
}
