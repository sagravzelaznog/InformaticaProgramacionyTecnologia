Sesión 38: Preparación para Animación (SVG Nativo)

1. Conceptos Clave de Animación SVG

Inkscape no anima por sí mismo, pero su formato de archivo (SVG) permite la animación usando código (CSS o SMIL/JavaScript). El trabajo del diseñador en Inkscape es preparar el archivo para que el animador/desarrollador trabaje fácilmente.

El ID es Vital

Para animar un objeto, el código necesita saber *qué* animar. La propiedad **ID (Identificador)** es el nombre único del objeto. Debes asignar IDs claros (ej. circulo-rotacion) a todos los elementos que se moverán o cambiarán.

Transformaciones Simplificadas

La animación funciona mejor con movimientos simples. **Simplifica tus trayectos** (Ctrl + L) y utiliza formas básicas (círculos, rectángulos) siempre que sea posible para movimientos más fluidos.

2. Asignación de IDs (Identificadores)

El panel **Objetos (Shift + Ctrl + O)** es tu herramienta principal para esto.

Paso 1: Renombrar en el Panel

Selecciona el objeto que quieres animar. En el panel **Objetos**, haz doble clic en el nombre (ej. rect1234) y renómbralo (ej. **"BrazoDerecho"**). Este nuevo nombre es el ID que usará el código.

Paso 2: Renombrar Grupos

Si quieres que un conjunto de objetos se mueva como uno solo (ej. todo el cuerpo de un personaje), agrupa los objetos (**Ctrl + G**) y asigna un ID al grupo (ej. **"CuerpoPrincipal"**).

3. Preparación del Archivo para Exportación SVG

Un archivo limpio se traduce en una animación más fácil y rápida.

Paso 1: Eliminar Metadatos

Ve a Archivo > Limpiar metadatos. Esto elimina información de edición innecesaria del archivo.

Paso 2: Guardar como SVG Plano

Guarda el archivo. Ve a Archivo > Guardar como... y selecciona el tipo de archivo **SVG plano de Inkscape (\*.svg)**. Esto elimina las etiquetas propias de Inkscape, dejando solo el código vectorial limpio.

Paso 3: Convertir a Trayecto

Para asegurar que las formas se animen correctamente en todos los navegadores, selecciona todas las formas y ve a Trayecto > Objeto a Trayecto (Shift + Ctrl + C). Esto convierte todas las formas básicas (círculos, rectángulos) en trayectos editables, que son más fáciles de manipular con código.

Ejercicio Sugerido: Icono de Movimiento

Objetivo: Crear un objeto con IDs claros para animación.

  1. Diseña un icono simple de "Loading" o "Cargando" (ej. dos flechas girando o una serie de puntos).
  2. Identifica los 3 elementos clave que se moverán: el fondo, el objeto 1 y el objeto 2.
  3. Usa el panel **Objetos** para asignar IDs claros (ej. **"Fondo"**, **"FlechaSuperior"**, **"FlechaInferior"**).
  4. Aplica **Objeto a Trayecto** a todos los elementos.
  5. Guarda el archivo como **SVG Plano**.
