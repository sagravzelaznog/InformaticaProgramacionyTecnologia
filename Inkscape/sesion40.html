Sesión 40: Proyecto Final del Bloque II: Infografía

1. Concepto y Planificación del Proyecto

El objetivo es crear una infografía simple, limpia y vectorial sobre cualquier tema (ej. un proceso de 4 pasos, datos sobre un producto, un ciclo de vida). Esto integra todos los conocimientos del Bloque II.

Plan de Diseño

Define la estructura: **Título**, **Fondo/Base**, y **3-4 Elementos de Contenido** (pasos o datos). Usa la herramienta **Medir** y las **Guías** para planificar el espaciado y los márgenes.

2. Estructura y Organización del Documento

Capas y Panel Objetos

Crea las siguientes capas y bloquéalas/desbloquéalas según necesites:

  • **Fondo:** Para la base y el color de fondo.
  • **Conexiones:** Para flechas, espirales o conectores.
  • **Contenido:** Para los iconos y gráficos principales.
  • **Texto:** Para títulos y subtítulos.
Nomenclatura para el Futuro

Abre el panel **Objetos**. Renombra los elementos clave de la infografía (ej. **"GraficoBarra1"**, **"IconoUsuario"**, **"FlechaProceso"**) para que el archivo esté listo para una posible animación futura (Sesión 38).

3. Integración de Gráficos Avanzados

Uso de Iconos/Ilustraciones

Crea 3-4 iconos/ilustraciones simples que representen tus pasos/datos. Usa **Degradados** y/o **Malla** para dar volumen a las formas más importantes.

Flujo y Conexiones

Usa la herramienta **Conector (D)** para unir los pasos, o dibuja una **Espiral** suave para representar un proceso cíclico. Aplica el LPE **Engrosar** al trazo de la conexión para darle grosor sin convertirlo a trayecto.

Proyecto a Entregar: Infografía Vectorial

Requerimientos:

  1. Documento organizado en al menos 3 **Capas** nombradas y con diferentes opacidades/modos de fusión.
  2. Uso de **Guías** y **Ajuste** para una maquetación perfecta.
  3. Al menos 3 objetos con **ID** descriptivo en el panel Objetos.
  4. Uso de **Relleno de Malla (U)** o un **LPE (Perspectiva/Patrón)** en algún elemento visual.
  5. Guardar el archivo como **SVG plano** para garantizar la limpieza del código.

¡Felicidades! Completar este proyecto significa que has dominado la edición avanzada de Inkscape y estás listo para el Bloque III: Diseños de Interfaces y Web. 🎉
