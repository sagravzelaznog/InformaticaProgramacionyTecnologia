Sesión 48: Proyecto Final del Bloque III: Kit de Diseño UI

1. Concepto y Alcance del Kit de Diseño (UI Kit)

El proyecto final de este bloque es crear un pequeño **Kit de Componentes de Interfaz (UI Kit)**, un conjunto de activos vectoriales que un desarrollador web o móvil puede utilizar. Esto demuestra tu habilidad para diseñar componentes, manejar estados y exportar archivos limpios.

Elementos Requeridos:
  • **Botones:** Primario y Secundario, cada uno con estado *Normal* y *Hover*.
  • **Tarjetas:** Un componente de contenido (Card) con sombra o elevación.
  • **Iconos:** Un set de 4 iconos esenciales.
  • **Estructura:** Uso riguroso de **Capas** e **IDs** para la documentación.

2. Creación de Componentes Clave

Utiliza la herramienta Rectángulo y el panel Relleno y Borde para diseñar con precisión.

Botones con Estados (Normal y Hover)
  1. Dibuja un rectángulo con esquinas redondeadas (**Botón Primario**). Asigna un color vibrante.
  2. **Duplica (Ctrl + D)** este botón y modifícalo para simular el estado **Hover** (ej. un 10% más oscuro, o aplicando un ligero **Desenfoque Gaussiano** para simular un resplandor).
  3. Repite el proceso para el **Botón Secundario** (ej. color blanco con trazo de color primario).
  4. **Agrupa** cada par de botón y texto por separado (4 grupos en total).
Tarjeta de Contenido (Card Component)

Dibuja la tarjeta principal. Duplícala, rellena el duplicado de negro, aplícale un **Desenfoque Gaussiano** sutil y envíalo al fondo (**Av Pág**). Esto crea el efecto de elevación (sombra suave), crucial en las interfaces modernas.

Set de 4 Iconos

Diseña 4 iconos simples (ej. Home, Perfil, Mensaje, Ajustes). Asegúrate de que el **grosor del trazo** sea idéntico en todos, y que estén vectorialmente limpios (**Simplificar - Ctrl + L**).

3. Organización Estricta y Nomenclatura

La limpieza del archivo es tan importante como el diseño. Esto se logra con IDs claros y una estructura de capas lógica.

Paso 1: Estructura de Capas

Crea las siguientes capas en el panel **Capas (Shift + Ctrl + L)**:

  • **Componentes_Maestros** (Para los botones y la tarjeta).
  • **Iconos_Set** (Para los 4 iconos).
  • **Guías** (Para referencias de espaciado, luego se oculta).
Paso 2: Asignación de IDs para Desarrollo

Usa el panel **Objetos (Shift + Ctrl + O)** para renombrar los grupos finales. **Esto será el nombre del archivo en la exportación por lotes.**

  • Botones: `btn-primary-normal`, `btn-primary-hover`, `btn-secondary-normal`, `btn-secondary-hover`.
  • Tarjeta: `card-product-base`.
  • Iconos: `ico-home`, `ico-profile`, `ico-message`, `ico-settings`.

4. Entrega y Optimización Final

Exportación por Lotes de Iconos

Selecciona los 4 iconos. Abre el diálogo de **Exportar (Shift + Ctrl + E)**. Asegúrate de seleccionar **"Selección"** y haz clic en **Exportar lote**. Usa el factor de escala **2.0** o **3.0** para generar las versiones @2x o @3x de todos los iconos con un solo clic.

Optimización del SVG Fuente

Guarda el archivo principal. Ve a Archivo > Guardar como... y selecciona **SVG Plano de Inkscape**. Esto garantiza que el archivo fuente (`UI-Kit-Final.svg`) sea lo más ligero posible para el desarrollador.

Proyecto a Entregar: UI Kit Básico

Requerimientos:

  1. Diseño de **4 Botones** (Primario/Secundario en estado Normal/Hover), con IDs claros.
  2. Diseño de **1 Tarjeta** que use **Desenfoque Gaussiano** para la sombra.
  3. Set de **4 Iconos** vectorialmente limpios.
  4. Todos los componentes organizados en **Capas** y con **IDs** claros.
  5. Exportación de los 4 iconos a **PNG @2x** (Exportación por lote).
  6. El archivo fuente debe ser **SVG Plano**.

¡Has completado el Bloque III! Tienes el dominio completo sobre el flujo de trabajo para el diseño de interfaces.
