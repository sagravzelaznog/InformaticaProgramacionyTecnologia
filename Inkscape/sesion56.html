Sesión 56: Proyecto: Infografía Final (Gráficos y Flujo)

1. Planificación del Diseño: Integrando Arte y Datos

El objetivo de esta sesión es crear una infografía completa que combine de manera efectiva las técnicas de **ilustración orgánica** (Semana 13) y la **visualización precisa de datos** (Semana 14). Elige un tema simple (ej. "Ciclo de crecimiento de una planta", "Distribución de ingresos en una startup").

Contenido Requerido

Tu diseño debe incluir al menos un **Gráfico de Barra, Anillo o Línea** para mostrar porcentajes o cantidades. Además, debes integrar un **Diagrama de Flujo o Proceso** para mostrar una secuencia.

Estructura del Archivo

Abre el panel **Capas (Shift + Ctrl + L)** y crea tres capas esenciales:

  • **Fondo:** Para la base de color, texturas simples.
  • **Datos y Flujo:** Para gráficos, diagramas y conectores.
  • **Ilustración y Título:** Para el arte estilizado y el texto principal.

2. Construcción de Elementos de Datos

Aplica la precisión de Inkscape para construir tus gráficos.

Gráfico Estático (Anillo o Barra)

Construye tu gráfico (ej. un gráfico de anillo para la distribución de ingresos). Utiliza **círculos** y la operación **Diferencia (Ctrl + -)** para el agujero central. Aplica **Degradados Lineales** a las barras o porciones del anillo para darles un aspecto pulido y tridimensional.

Diagrama de Proceso (Conectores)

Diseña 3-4 nodos de proceso (cajas o círculos). Utiliza la herramienta **Conector (D)** para unirlos. Activa el modo de **línea recta en ángulo recto** y añade **Marcadores (Flechas)** en la pestaña Estilo de Trazo. Mueve los nodos para ver cómo las conexiones se ajustan automáticamente.

3. Integración Artística y Estilo de Línea

Añade los elementos ilustrativos para enriquecer la narrativa visual.

Ilustración Orgánica (Contorno)

Dibuja un elemento clave de tu tema (ej. una hoja, una flecha de flujo orgánica, un personaje). Utiliza la herramienta **Pluma (B)** con el principio del **mínimo de nodos** para asegurar la limpieza del trayecto.

Perfiles de Pincel (Powerstroke)

Aplica un perfil de trazo variable (**Powerstroke**) a la línea de contorno de tu elemento ilustrativo (usando el **Editor de Nodos - F2**). Esto le dará un grosor orgánico, simulando un dibujo a tinta o pincel.

Desenfoque y Sombra

Añade una sombra suave bajo el gráfico de datos (un óvalo con relleno oscuro y **Desenfoque Gaussiano**). Usa el modo de fusión **Multiplicar** en una capa separada si deseas sombras de color.

4. Revisión y Entrega Final

Paso 1: Limpieza del Archivo

Selecciona todo el texto y conviértelo a trayecto (**Shift + Ctrl + C**) para garantizar la compatibilidad de fuentes. Elimina cualquier mapa de bits de referencia si lo usaste. Simplifica los trayectos con demasiados nodos (**Ctrl + L**).

Paso 2: Exportación Final

Exporta una versión de vista previa en **PNG de alta resolución**. Guarda el archivo fuente como **SVG Plano** para eliminar metadatos innecesarios y optimizar el código vectorial.

Proyecto a Entregar: Infografía Vectorial Completa

Requerimientos:

  1. El diseño debe estar completamente **vectorial** (sin mapas de bits en la salida final).
  2. Inclusión de un **Gráfico de Barra, Anillo o Línea** estilizado.
  3. Inclusión de un **Diagrama de Flujo** usando la herramienta **Conector (D)**.
  4. Uso de **perfiles de trazo variable (Powerstroke)** en al menos un elemento ilustrativo.
  5. Uso de **Degradados** y **Desenfoque Gaussiano** para efectos de estilo.
  6. El archivo debe estar organizado en al menos 3 **Capas** nombradas.
