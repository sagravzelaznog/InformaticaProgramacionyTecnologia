Sesión 3: Creación de Formas Básicas

1. Herramienta Rectángulo (F4)

La herramienta **Rectángulo (F4)** es el punto de partida para muchas formas. Un rectángulo en Inkscape no es un trayecto simple, sino un objeto con propiedades editables.

Paso 1: Dibujar y Modificar

Haz clic en el lienzo y arrastra para dibujar. Usa la tecla **Ctrl** mientras dibujas para forzar un cuadrado perfecto.

Paso 2: Manejadores de Esquina

Al dibujar un rectángulo, verás dos manejadores con forma de círculo y uno cuadrado en la esquina superior derecha.

  • Arrastra el manejador cuadrado para cambiar la dimensión X o Y.
  • Arrastra el **manejador circular** (Rx/Ry) para redondear las esquinas.
Paso 3: Reiniciar el Rectángulo

Si las esquinas están redondeadas y quieres volver a un rectángulo recto, haz clic en el icono **"Hacer que las esquinas sean agudas"** en la Barra de Controles de Herramienta.

2. Herramienta Elipse (F5)

La herramienta **Elipse (F5)** crea círculos y óvalos.

Paso 1: Dibujar Elipses y Círculos

Arrastra para dibujar una elipse. Usa la tecla **Ctrl** para dibujar un círculo perfecto (misma altura y anchura).

Paso 2: Creación de Arcos y Segmentos

Al seleccionar la elipse con la herramienta Elipse, verás un manejador circular. Arrástralo hacia el interior del círculo para crear una **porción de tarta (segmento)**, o hacia afuera para un **arco (abierto)**. Puedes controlar esto en la Barra de Controles de Herramienta.

3. Estrella y Polígono (Shift + F9)

Esta herramienta crea formas con múltiples lados o puntas, con control preciso sobre sus atributos.

Paso 1: Alternar entre Estrella y Polígono

En la Barra de Controles de Herramienta, puedes elegir si quieres dibujar un **Polígono (lados rectos)** o una **Estrella (puntas)**.

Paso 2: Ajustar el Número de Esquinas

En el campo **Esquinas** (Corners), define el número de lados o puntas (ej. 5 para una estrella estándar, 8 para un octágono).

Paso 3: Redondez y Aleatorización

Para las estrellas, puedes ajustar la **Redondez** (redondea los lados) y el **Aleatorio** (Randomize) para crear efectos de estrellas irregulares o "explotadas".

Ejercicio Sugerido: Robot Modular

Objetivo: Usar las tres herramientas de forma con sus manejadores.

  1. Dibuja el cuerpo de un robot usando un **Rectángulo** con las esquinas ligeramente redondeadas.
  2. Dibuja la cabeza del robot usando un **Círculo** perfecto.
  3. Dibuja los ojos usando dos **Estrellas** de 4 puntas, dales un poco de redondez.
  4. Dibuja las manos con dos **Polígonos** de 6 lados.
  5. Usa la herramienta Selector (F1) para mover, escalar y ensamblar todas las piezas en el lienzo.
