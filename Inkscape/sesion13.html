Sesión 13: Trabajar con Texto

1. Herramienta Texto (T) y Creación

[Image of the Text Tool and its controls in Inkscape]

La herramienta **Texto (T)** te permite añadir texto editable a tu diseño, manteniendo su calidad vectorial. Hay dos maneras de crear texto:

Paso 1: Texto Artístico (Point Text)

Haz un **solo clic** en el lienzo y comienza a escribir. Este texto es ideal para títulos y logotipos. Crece horizontalmente sin límites.

Paso 2: Texto de Párrafo (Flowed Text)

Haz **clic y arrastra** para crear un marco de texto. El texto se ajustará automáticamente a este marco, ideal para bloques de texto largos o descripciones. Puedes redimensionar el marco con los manejadores.

2. Propiedades de Texto (Diálogo y Barra de Control)

Con la herramienta Texto activa, la **Barra de Controles de Herramienta** ofrece las opciones más importantes:

Fuentes y Tamaño

Selecciona la tipografía y el tamaño. Instalar nuevas fuentes en tu sistema las hace disponibles en Inkscape.

Espaciado y Interlineado

Ajusta el **Kerning** (espacio entre dos letras específicas), el **Tracking** (espacio general entre letras de una selección) y el **Interlineado** (espacio entre líneas de texto).

3. Texto a Trayecto: Vectorizar el Texto

Para manipular el texto con la herramienta Nodos o aplicarle operaciones booleanas, debes convertirlo a trayecto. **¡Advertencia!** Una vez vectorizado, el texto ya no es editable como texto.

Paso 1: Convertir

Selecciona el texto artístico. Ve a Trayecto > Objeto a Trayecto (Shift + Ctrl + C). Cada letra se convierte en un grupo de trayectos.

Paso 2: Edición de Nodos y Booleanas

Desagrupa (**Shift + Ctrl + G**) el texto vectorizado. Ahora puedes usar la herramienta **Nodo (F2)** para modificar las curvas de las letras o aplicar operaciones booleanas, por ejemplo, cortando una forma de corazón en medio de una letra 'O'.

Ejercicio Sugerido: Título Vectorial Modificado

Objetivo: Practicar la edición de texto vectorizado.

  1. Escribe tu nombre o un título corto (Texto Artístico).
  2. Elige una fuente sans-serif gruesa.
  3. Convierte el texto a trayecto (**Shift + Ctrl + C**) y desagrupa (**Shift + Ctrl + G**).
  4. Usa la herramienta **Nodo (F2)** para seleccionar una letra y modifica sus curvas para darle un estilo único (ej. hacer la parte superior de una 'M' puntiaguda).
  5. Dibuja un círculo pequeño (corte) y úsalo para aplicar **Diferencia (Ctrl + -)** en una de las letras, creando un agujero.
