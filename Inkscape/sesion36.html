Sesión 36: Proyecto: Diseño de un Icono Web (UI)

1. Concepto y Especificaciones del Icono

Diseñaremos un icono vectorial para una aplicación web (ej. un icono de "Configuración", "Home", o "Cesta de Compra"). Los iconos deben ser claros y escalables.

  • **Tamaño Físico:** Piensa en un tamaño final de 64x64px.
  • **Estilo:** Lineal (solo trazos) o Relleno (formas sólidas).
  • **Paleta:** 1-2 colores principales.

2. Construcción Geométrica y Capas

Usaremos la precisión geométrica de las herramientas básicas y la organización del panel Objetos.

Paso 1: Capas Base

Crea dos capas: **"Forma Base"** y **"Detalle/Corte"**. Bloquea la capa **"Detalle/Corte"** mientras trabajas en la base.

Paso 2: Construcción del Símbolo

Usa rectángulos redondeados y círculos. Aplica **Unión (Ctrl + +)** para ensamblar la forma principal. Utiliza la herramienta **Alinear y Distribuir** para centrar perfectamente todos los elementos.

Paso 3: Recorte de Detalle

Desbloquea la capa **"Detalle/Corte"**. Dibuja las formas que quieres quitar de la base (ej. el agujero central en un icono de engranaje). Aplica **Diferencia (Ctrl + -)** entre la forma base y la forma de corte.

3. Organización y Exportación Final

Antes de exportar, debemos garantizar que el icono está limpio y bien organizado.

Paso 1: Panel Objetos y Nomenclatura

Abre el panel **Objetos (Shift + Ctrl + O)**. Renombra el grupo final del icono (ej. **"Icono Cesta"**). Oculta todos los elementos de capa que no sean esenciales para el icono final.

Paso 2: Exportación para Web

Selecciona el icono final agrupado. Ve a Archivo > Exportar... (Shift + Ctrl + E). Selecciona la opción **Selección**. Define un tamaño de **64x64px** o **128x128px** y asegúrate de que el fondo sea **Transparente**. Exporta como **PNG**.

Paso 3: Exportación Vectorial

Guarda el archivo SVG. Ve a Archivo > Guardar como... y selecciona la opción **SVG plano de Inkscape**. Esto elimina metadatos innecesarios, haciendo el archivo lo más ligero posible para uso web.

Proyecto a Entregar: Icono Vectorial para UI

Requerimientos:

  1. El icono debe usar al menos 3 formas geométricas base.
  2. Debe haber al menos 1 operación booleana (Unión, Diferencia o Intersección).
  3. El diseño final debe estar **Agrupado** y tener un nombre descriptivo en el panel **Objetos**.
  4. Exporta el icono a **PNG transparente** en 64x64px y el archivo fuente **SVG plano**.
