Sesión 14: Texto en Trayecto

1. Adaptar Texto a un Trayecto

Esta técnica es fundamental para el diseño de sellos, logotipos circulares o cualquier composición donde el texto debe seguir una curva o una forma compleja.

Paso 1: Crear el Trayecto Base

Dibuja un trayecto que servirá de guía (ej. un círculo, un trazo con la Pluma). Es mejor que no tenga relleno ni trazo si solo es una guía.

Paso 2: Seleccionar Elementos

Escribe tu texto (debe ser Texto Artístico, no de Párrafo). Selecciona **primero el texto** y, manteniendo **Shift**, selecciona **luego el trayecto guía**.

Paso 3: Aplicar Adaptar a Trayecto

Ve a Texto > Adaptar a Trayecto. El texto se pegará y fluirá a lo largo del trayecto. El texto sigue siendo editable.

2. Manipulación y Control

Una vez que el texto está en el trayecto, puedes ajustarlo de varias maneras:

Mover el Texto

Usa la herramienta **Selector (F1)** para mover el texto o el trayecto. El texto se moverá con el trayecto.

Invertir el Flujo

Si el texto aparece de cabeza en el círculo, puedes invertir la dirección del texto o el trayecto. Selecciona el trayecto guía y ve a Trayecto > Invertir (Shift + R).

Separar el Texto

Para que el texto quede fijo en su posición y el trayecto guía desaparezca, selecciona el texto y ve a Trayecto > Objeto a Trayecto. **Nota:** Esto también vectoriza las letras, haciéndolas no editables.

3. Poner el Texto Dentro de una Forma

Para que el texto fluya dentro de una forma irregular, usaremos el concepto de **Marco de Texto**:

Paso 1: Crear la Forma Guía

Dibuja la forma que quieres que contenga el texto (ej. una estrella compleja, una silueta vectorizada). Conviértela a trayecto (**Shift + Ctrl + C**).

Paso 2: Crear el Texto de Párrafo

Crea un bloque de texto de párrafo (clic y arrastrar con la herramienta Texto) que sea más grande que la forma guía.

Paso 3: Flujo de Marco

Selecciona **primero el texto** y, manteniendo **Shift**, selecciona **luego el trayecto guía**. Ve a Texto > Fluir en Marco. El texto se adaptará a la forma del trayecto guía.

Ejercicio Sugerido: Logo Circular de Sello

Objetivo: Crear un texto que circule en un diseño de sello.

  1. Dibuja un círculo grande para el borde exterior del sello.
  2. Dibuja un segundo círculo ligeramente más pequeño y céntralo.
  3. Escribe un texto (ej. "CURSO INKSCAPE") y adáptalo al círculo exterior (**Texto > Adaptar a Trayecto**).
  4. Escribe un segundo texto (ej. "AVANZADO") y adáptalo al círculo interior (necesitarás invertir el trayecto del círculo interior para que el texto se lea correctamente en la parte inferior).
