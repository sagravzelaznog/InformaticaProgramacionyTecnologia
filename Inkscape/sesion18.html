Sesión 18: Simplificación y Trazado Dinámico

1. Simplificación de Trayectos (Path Simplification)

La **Simplificación (Ctrl + L)** es vital para optimizar tus archivos y limpiar trayectos dibujados a mano (con el Lápiz o vectorizados) que tienen demasiados nodos innecesarios. Menos nodos significa archivos más ligeros y fáciles de editar.

Paso 1: Aplicación Rápida

Selecciona un objeto con muchos nodos (puedes verlo con la herramienta Nodo). Presiona **Ctrl + L**. Repite el atajo para simplificar aún más, pero ten cuidado de no perder el detalle deseado.

Paso 2: Ajuste Manual de Parámetros

Para un control más fino, ve a Trayecto > Simplificar.... Esto abre una ventana donde puedes ajustar el **Factor de umbral** manualmente. Un umbral más alto resulta en una mayor simplificación (menos nodos).

2. Trazado Dinámico (Offset)

El **Trazado Dinámico (Dynamic Offset, Ctrl + J)** es una técnica increíblemente útil para crear contornos perfectos o formas internas a partir de un trayecto existente.

Paso 1: Aplicar el Trazado Dinámico

Selecciona un objeto y ve a Trayecto > Trazado Dinámico (Ctrl + J). El objeto se convertirá en un trazado dinámico con un solo **manejador en forma de diamante**.

Paso 2: Editar el Contorno

Usa la herramienta **Selector (F1)** o **Nodo (F2)**. Arrastra el **manejador de diamante** hacia afuera para crear un contorno (offset positivo) o hacia adentro para reducir el tamaño (offset negativo). ¡La forma siempre conserva la suavidad y el estilo del original!

3. Trazado Enlazado (Linked Offset)

Similar al Trazado Dinámico, pero crea un nuevo objeto que es un clon enlazado al trazado original. Si editas el trayecto original, el offset enlazado se actualiza.

Paso 1: Crear el Trazado Enlazado

Selecciona el objeto original. Ve a Trayecto > Trazado Enlazado (Shift + Ctrl + J). Aparecerá un nuevo objeto con un manejador de diamante.

Paso 2: Ventaja del Enlazado

Puedes cambiar el color y el estilo del offset enlazado de forma independiente, pero si usas la herramienta **Nodo (F2)** para editar el objeto *original*, la forma del *clon* enlazado se actualizará, manteniendo su offset.

Ejercicio Sugerido: Sombra y Borde Perfecto

Objetivo: Crear un borde limpio y simplificar un trazado.

  1. Dibuja una forma orgánica compleja con la herramienta **Lápiz (P)** con poco suavizado.
  2. Presiona **Ctrl + L** varias veces para simplificar drásticamente los nodos.
  3. Con la forma simplificada seleccionada, aplica **Trazado Dinámico (Ctrl + J)**.
  4. Arrastra el manejador de diamante hacia afuera para crear un borde grueso de color diferente.
  5. Duplica la forma original (**Ctrl + D**). Aplica **Trazado Enlazado (Shift + Ctrl + J)** a este duplicado y úsalo para crear una sombra interior.
