Sesión 16: Proyecto Básico: Diseño de un Logotipo

1. Concepto y Brief del Proyecto

El objetivo de este proyecto es consolidar los conocimientos del Bloque I creando un logotipo funcional. Inventa una marca (ej. una cafetería, un estudio de diseño, una aplicación de jardinería) y define su concepto.

  • **Tema:** (Ej. "Cafetería Rústica", "App de Fitness").
  • **Estilo:** Geométrico y simple (usando las técnicas aprendidas).
  • **Paleta:** 2 o 3 colores principales.

2. Desarrollo del Símbolo Gráfico (Isotipo)

Crea la parte gráfica del logo usando la fuerza de las operaciones booleanas y la edición de nodos.

Paso 1: Construcción Base

Utiliza formas básicas (Círculos, Rectángulos, Polígonos) como base de tu diseño. Dales los colores de tu paleta.

Paso 2: Operaciones Booleanas

Usa **Unión (Ctrl + +)** para ensamblar las piezas y **Diferencia (Ctrl + -)** para crear cortes o agujeros definidos. El objetivo es que el símbolo sea un solo trayecto compuesto.

Paso 3: Refinamiento de Nodos

Usa la herramienta **Nodo (F2)** para suavizar o afilar cualquier curva o esquina del símbolo resultante, garantizando un aspecto limpio.

3. Tipografía y Composición (Logotipo)

Añade el nombre de la marca y combínalo con el símbolo.

Paso 1: Selección y Edición de Texto

Escribe el nombre de la marca (Texto Artístico). Experimenta con diferentes fuentes para encontrar el tono adecuado para tu marca.

Paso 2: Vectorización (Opcional, pero Recomendado)

Convierte el texto a trayecto (**Shift + Ctrl + C**) para asegurarte de que se verá igual en cualquier software y para poder aplicar cualquier manipulación de color o booleana.

Paso 3: Alineación Final

Selecciona el símbolo gráfico y el texto. Usa el diálogo **Alinear y Distribuir** para centrar perfectamente el texto debajo (o junto a) el símbolo.

4. Entrega y Exportación

Revisión

Verifica que todo esté agrupado y que no queden objetos guía o la imagen de mapa de bits original.

Exportación a PNG (Web)

Ve a Archivo > Exportar... (Shift + Ctrl + E). Selecciona la opción **Dibujo** para exportar todo el lienzo o **Selección** para exportar solo el logotipo. Exporta a una resolución de 500px o 1000px de ancho.

Guardar el Fuente

Guarda el archivo final como **Logotipo_Final.svg**.

Proyecto a Entregar: Logotipo Completo

Requerimientos:

  1. Un símbolo gráfico creado con al menos 2 operaciones booleanas.
  2. Un nombre de marca usando texto.
  3. Uso de al menos un **Degradado** para dar un efecto de sombra o volumen.
  4. El archivo debe estar perfectamente alineado.
