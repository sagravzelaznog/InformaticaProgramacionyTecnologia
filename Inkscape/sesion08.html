Sesión 8: Práctica: Creación de un Set de Iconos Básicos

1. Estilo Básico de Icono: Flat Design

Hoy aplicaremos todo lo aprendido para crear un set de 3 iconos simples en estilo **Flat Design** (diseño plano), que usa formas geométricas, colores sólidos y carece de sombras o gradientes complejos.

Elegiremos tres temas comunes: Casa 🏠, Engranaje ⚙️, y Sobre ✉️.

2. Icono 1: Casa (Home)

Paso 1: Paredes (Rectángulo)

Dibuja un cuadrado perfecto (**Ctrl** + arrastrar con la herramienta Rectángulo). Asigna un relleno gris o azul. **Elimina el trazo** (Shift + clic en 'X' en la paleta o en el diálogo Relleno y Borde).

Paso 2: Techo (Polígono)

Usa la herramienta Estrella/Polígono (Shift + F9), configura **3 esquinas** (triángulo). Dibuja un triángulo que cubra el ancho del cuadrado. Asigna un relleno de color más oscuro.

Paso 3: Ensamblaje y Alineación

Coloca el triángulo sobre el cuadrado. Selecciona ambos y usa el diálogo **Alinear (Shift + Ctrl + A)** para **Centrar en el eje vertical**.

Paso 4: La Puerta (Rectángulo de Diferencia)

Dibuja un rectángulo pequeño (la puerta) en un color de contraste, céntralo en la base. ¡Esto es opcional! La sencillez es clave en iconos flat.

3. Icono 2: Engranaje (Settings)

Paso 1: Círculo Base

Dibuja un círculo grande (Ctrl + F5). Duplícalo (**Ctrl + D**). Escala el duplicado más pequeño (**Ctrl** + arrastrar) y asígnale el mismo color del fondo o un color blanco. Céntralos (**Shift + Ctrl + A**) para crear el "agujero".

Paso 2: Dientes (Rectángulos Rotados)

Dibuja un rectángulo pequeño (un diente). Duplícalo (**Ctrl + D**). Usa el diálogo **Transformar (Shift + Ctrl + M)**, Rotar, con un ángulo de **30 grados**.

Paso 3: Corona de Dientes

Duplica el rectángulo rotado (**Ctrl + D**) y vuelve a aplicar la rotación (30 grados). Repite este paso hasta completar la corona (12 dientes en total). Agrupa todos los dientes (**Ctrl + G**).

Paso 4: Finalizar

Selecciona el grupo de dientes y el círculo base. Centra todo horizontal y verticalmente.

Ejercicio Final: Set Completo de Iconos

Objetivo: Crear un tercer icono (Sobre) y organizar el set completo.

  1. **Icono 3 (Sobre):** Usa la herramienta **Rectángulo** para el cuerpo del sobre y la herramienta **Pluma Bézier** (solo clics) para el solapa triangular superior. Usa la alineación.
  2. **Organización:** Coloca los tres iconos (**Casa, Engranaje, Sobre**) en línea horizontal.
  3. **Distribución:** Usa la herramienta **Alinear y Distribuir** para asegurar que el espaciado entre los tres iconos sea exactamente el mismo.
  4. **Guardar:** Guarda el archivo como **Semana2_Iconos.svg**.
