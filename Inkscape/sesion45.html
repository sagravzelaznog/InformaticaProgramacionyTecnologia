Sesión 45: Exportación para Web y Apps (Formatos y DPI)

1. El Diálogo de Exportación (Shift + Ctrl + E)

El diálogo **Exportar (Shift + Ctrl + E)** es crucial. Permite exportar tu trabajo en varios formatos de mapa de bits (PNG, JPG) a la resolución adecuada para diferentes dispositivos.

Áreas de Exportación
  • **Selección:** Exporta solo los objetos que tienes seleccionados (ideal para iconos).
  • **Dibujo:** Exporta todos los objetos que existan en el lienzo.
  • **Página:** Exporta solo el área definida por la página del documento.

2. Gestión de Resoluciones para DPI/PPI

En el diseño web y móvil, es común exportar activos en múltiples resoluciones (ej. 1x, 2x, 3x) para dispositivos con diferentes densidades de píxeles (DPI/PPI).

Resolución Base (1x)

Define la resolución base (1x) en el tamaño requerido (ej. un icono de 64x64px). La resolución estándar para la web es **96 DPI**. Asegúrate de que este valor esté configurado en el diálogo de exportación.

Exportación 2x (Retina)

Para la resolución 2x (Retina o pantallas de alta densidad), debes exportar el doble de grande. Si tu base es 64x64px, exporta a 128x128px. En Inkscape, puedes introducir el tamaño en el campo **Ancho/Alto** o simplemente ajustar el **Factor de escala** a **2.0** en el diálogo de exportación. El archivo resultante debe ser nombrado con el sufijo **@2x** (ej. icono_home@2x.png).

3. Optimización para SVG (Vectorial)

El formato ideal para la web es el SVG. Necesita estar lo más limpio posible.

SVG Plano (Plain SVG)

Guarda siempre los archivos finales para la web como **SVG plano de Inkscape (\*.svg)**. Esto elimina metadatos, historial de edición y otras etiquetas innecesarias, reduciendo drásticamente el tamaño del archivo y facilitando la animación o manipulación con código.

Convertir Trazo a Trayecto

Si tu diseño usa muchos trazos (líneas con grosor), selecciona los trazos y ve a Trayecto > Contorno a Trayecto (Ctrl + Alt + C). Esto convierte la línea con grosor en una forma rellena. Esto asegura que el grosor se mantenga consistente en todos los navegadores, especialmente si el SVG se manipula con código.

Ejercicio Sugerido: Icono Multi-Resolución

Objetivo: Exportar un icono para diferentes densidades de píxeles.

  1. Dibuja un icono simple de 32x32px.
  2. Abre el diálogo de **Exportar (Shift + Ctrl + E)** y selecciona tu icono.
  3. Exporta la versión **1x (96 DPI)**, nombrándola icono_menu.png.
  4. Ajusta el **Factor de Escala** a **2.0** y exporta la versión **2x (192 DPI)**, nombrándola icono_menu@2x.png.
  5. Ajusta el **Factor de Escala** a **3.0** y exporta la versión **3x (288 DPI)**, nombrándola icono_menu@3x.png.
