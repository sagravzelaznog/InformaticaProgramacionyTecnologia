## SEMANA 9: FILTROS Y EFECTOS VISUALES

### SESIÓN 33: Filtros de Inkscape (Introducción)

**Objetivo:** Introducir el sistema profesional de filtros SVG para efectos visuales avanzados.

**Contenido Teórico (45 min):**

- Sistema de filtros SVG: arquitectura y filosofía profesional
- Aplicación de filtros preestablecidos: categorías y usos
- Categorías principales: sombras, texturas, distorsión, luces
- Parámetros básicos de filtros: intensidad, configuración
- Aplicaciones creativas en diseño gráfico profesional

**Práctica Dirigida (1:30 horas):**

- Aplicar filtros básicos profesionales a objetos vectoriales
- Experimentar sistemáticamente con diferentes categorías de filtros
- Crear efectos visuales profesionales simples pero impactantes
- Combinar múltiples filtros para efectos personalizados

**Tarea Individual:** Crear serie de 5 composiciones visuales aplicando diferentes categorías de filtros para transmitir conceptos específicos.
