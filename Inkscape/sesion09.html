Sesión 9: Trayectos y Operaciones Booleanas (Parte I)

1. ¿Qué son las Operaciones Booleanas?

Las **Operaciones Booleanas** (ubicadas en el menú **Trayecto**) permiten combinar dos o más objetos para crear una nueva forma compleja. Son el método principal para construir geometrías complejas a partir de formas simples.

Recordatorio: Estas operaciones solo funcionan con **Trayectos**. Si estás usando formas básicas (Rectángulo, Círculo), primero conviértelas a trayecto con Trayecto > Objeto a Trayecto (Shift + Ctrl + C).

2. Unión (Union) - Combinar

La **Unión (Ctrl + +)** combina todos los objetos seleccionados en un único trayecto. El nuevo trayecto adopta el estilo (relleno y borde) del objeto que estaba más abajo en el orden Z (el más viejo o el que fue enviado al fondo).

Ejemplo de Uso: Una Pera Simple

Dibuja dos círculos superpuestos, uno más grande (cuerpo) y uno más pequeño (parte superior). Selecciona ambos y aplica **Unión**. La forma resultante es un solo objeto continuo.

3. Diferencia (Difference) - Restar

La **Diferencia (Ctrl + -)** utiliza el objeto superior para "cortar" o "restar" al objeto que se encuentra debajo. El objeto superior desaparece, dejando un agujero en el objeto inferior.

Ejemplo de Uso: Un Agujero o Media Luna

Dibuja un círculo (fondo). Dibuja un segundo círculo más pequeño o movido (corte) por encima del primero. Selecciona ambos y aplica **Diferencia**. Esto crea un agujero o la forma de una media luna.

4. Intersección (Intersection) - Encontrar el Común

La **Intersección (Ctrl + *)** mantiene solo el área donde todos los objetos seleccionados se superponen. Todo lo que esté fuera de esa área se elimina. El resultado adopta el estilo del objeto superior.

Ejemplo de Uso: Una Gotita o Pestaña

Dibuja dos óvalos superpuestos de forma cruzada. Selecciona ambos y aplica **Intersección**. La forma resultante es la intersección entre los dos, perfecta para crear formas de gota o de ojo estilizado.

Ejercicio Sugerido: La Nube y el Sol

Objetivo: Usar Unión y Diferencia.

  1. **Nube:** Dibuja varios círculos de diferente tamaño superpuestos. Selecciona todos y aplica **Unión**.
  2. **Sol Creciente:** Dibuja un círculo grande (Sol). Dibuja un círculo idéntico y muévelo ligeramente para crear la forma de creciente sobre el sol. Selecciona ambos y aplica **Diferencia** para cortar el sol y dejar solo la media luna.
