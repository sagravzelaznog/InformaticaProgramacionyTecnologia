Sesión 61: Preparación del Proyecto Final: Maquetación y Exportación

1. Organización Maestra del Archivo

Un archivo final de proyecto debe ser un ejemplo de organización y profesionalismo. Un desarrollador o un colega debe poder navegarlo sin esfuerzo.

Jerarquía de Capas Definitiva

Revisa y renombra todas tus capas para que sean claras (ej. `Logo_Principal`, `Iconos_Exportables`, `Arte_Fondo`, `Textos_Finales`). Oculta cualquier capa de boceto o referencia que ya no uses.

Nomenclatura de Objetos

Asigna IDs claros a todos los elementos que serán exportados o manipulados por código (ej. **Boton_CTA**, **Ilustracion_Hero**). Usa el panel **Objetos (Shift + Ctrl + O)**.

2. Exportación de Activos Múltiples (Batch Export)

Genera todos los archivos de salida necesarios para el proyecto (web, móvil, impresión).

Exportación de PNG Múltiple

Selecciona todos los iconos y elementos de interfaz. Abre el diálogo de **Exportar (Shift + Ctrl + E)**. Asegúrate de que están nombrados correctamente (ej. **Icono_Menu@2x.png**). Usa la opción **Exportar lote** para generar todos los PNG a 1x, 2x y 3x de resolución de una sola vez.

Archivos de Salida SVG (Optimizados)

Guarda el logo y los iconos complejos como archivos **SVG Plano**. Aplica la extensión **SVG Optimizer (Scour)** antes de guardar para reducir el tamaño del archivo y limpiarlo de metadatos de Inkscape.

3. Estructura de Carpetas de Entrega

Organiza todos los archivos finales en una estructura lógica.

Estructura Estándar
  • `/Proyecto_Final/`
  • `L /01_Fuentes/` (Archivos SVG fuente del proyecto)
  • `L /02_Exportados/`
  • `L / L /web/` (PNG @2x, SVG optimizados, Favicon)
  • `L / L /impresion/` (PDF/X, Trazado de Corte)
  • `L /03_Documentacion/` (Guía de Estilo, Notas)
Archivos Readme

Incluye un archivo de texto simple (`README.txt`) con notas clave: licencia de la fuente, breve descripción del proyecto, y contacto.

Ejercicio Sugerido: Creación de Carpeta de Entrega

Objetivo: Simular el proceso de entrega final.

  1. Crea la estructura de carpetas de entrega en tu sistema.
  2. Guarda tu proyecto final como **SVG Plano** en la carpeta `01_Fuentes`.
  3. Exporta 3 iconos a `@2x` de resolución y colócalos en `02_Exportados/web`.
  4. Crea un `README.txt` con la nota "Todos los archivos de texto han sido convertidos a trayecto para impresión".
