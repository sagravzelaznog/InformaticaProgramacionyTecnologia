Sesión 11: Agrupación, Clonación y Capas (Introducción)

1. Agrupar y Desagrupar (Grouping)

La **Agrupación (Ctrl + G)** es la forma más básica de organización. Permite tratar múltiples objetos como si fueran una sola entidad para moverlos o transformarlos.

Paso 1: Agrupar

Selecciona todos los objetos que quieres agrupar y presiona **Ctrl + G**. Ahora puedes mover y escalar el grupo como un todo.

Paso 2: Editar un Objeto del Grupo

Puedes editar un objeto dentro de un grupo sin desagruparlo haciendo **doble clic** sobre él. El resto del grupo aparecerá atenuado.

Paso 3: Desagrupar

Selecciona el grupo y usa **Shift + Ctrl + G** para separarlos de nuevo en objetos individuales.

2. Clonación (Cloning)

A diferencia de la duplicación (**Ctrl + D**), un **Clon (Alt + D)** mantiene un vínculo dinámico con su original. Si modificas el original (ej. cambias el color), todos sus clones se actualizan automáticamente.

Paso 1: Crear y Usar un Clon

Selecciona un objeto. Usa **Alt + D** para crear un clon. Mueve el clon a otra parte del lienzo.

Paso 2: Desconectar Clon

Si quieres que un clon vuelva a ser un objeto independiente, usa **Shift + Alt + D** (Desconectar clon). Ya no se actualizará con el original.

3. Capas (Layers) - Organización Introductoria

El panel **Capas (Shift + Ctrl + L)** te permite organizar el dibujo en niveles. Esto es vital para ilustraciones complejas o trabajos colaborativos.

Paso 1: Añadir y Renombrar

Abre el panel. Haz clic en el signo **+** para añadir una capa. Haz doble clic en el nombre para renombrarla (ej. Fondo, Líneas, Color, Texto).

Paso 2: Visibilidad y Bloqueo

Utiliza el **ícono del ojo** para ocultar o mostrar una capa. Utiliza el **ícono del candado** para bloquear una capa, evitando que selecciones o modifiques los objetos que contiene (útil para proteger un fondo).

Paso 3: Mover Objetos entre Capas

Selecciona un objeto. Haz clic derecho y selecciona **Mover a la capa...** para reubicarlo. Esto mantiene tu proyecto ordenado.

Ejercicio Sugerido: Flores Clónicas

Objetivo: Practicar la clonación y la organización en capas.

  1. **Capas:** Crea tres capas: **Fondo**, **Flor** y **Texto**. Bloquea la capa Fondo.
  2. **Original:** Dibuja un pétalo simple con la herramienta Pluma o una elipse. Asígnale un relleno rojo.
  3. **Clones:** Crea 5 clones (**Alt + D**) del pétalo. Usa la herramienta Selector para rotar y posicionar los clones formando una flor.
  4. **Prueba Dinámica:** Regresa al pétalo original. Cambia su relleno a azul. Observa cómo todos los clones se actualizan.
  5. **Organización:** Selecciona la flor completa y asegúrate de que esté en la capa **Flor**. En la capa **Texto**, añade tu nombre.
