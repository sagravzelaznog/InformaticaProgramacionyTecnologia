Sesión 41: Diseño de Wireframes (Esqueletos Funcionales)

1. Introducción al Wireframe en Vectorial

Un **Wireframe** es el esqueleto funcional de una interfaz (web o móvil). Se centra en la estructura, el contenido y la interacción, **no en el diseño visual** (colores, tipografía fina). Inkscape es excelente para esto por su precisión vectorial.

Estilo "Low Fidelity"

Trabajaremos en blanco, negro y gris. Usa rectángulos para botones y áreas de contenido. Las líneas onduladas o cruces en una caja representan imágenes. Los trazos representan texto simple.

2. Configuración del Lienzo y Guías

Necesitas un lienzo con dimensiones estándar para tu Wireframe.

Paso 1: Definir la Mesa de Trabajo

Ve a Archivo > Propiedades del Documento (Shift + Ctrl + D). Si es para móvil, usa una medida estándar (ej. 375px x 812px para iPhone X). Si es web, usa un ancho estándar (ej. 1440px).

Paso 2: Maquetación con Guías y Rejillas

Activa la **Rejilla Rectangular** con un espaciado grande (ej. 20px). Utiliza las **Guías** para definir los márgenes exteriores (padding) (ej. 16px a cada lado). Esto asegura que todos los elementos estén alineados con el mismo sistema.

3. Construcción de Elementos de Interfaz

Usa las herramientas de forma para simular los elementos comunes de la interfaz.

Botones y Tarjetas (Cards)

Usa la herramienta **Rectángulo (F4)** con un ligero **Radio de Esquina** para crear botones y tarjetas. Rellena los botones de gris oscuro y los fondos de tarjeta de gris claro. Usa la herramienta **Duplicar (Ctrl + D)** y el panel **Alinear y Distribuir** para mantener el espaciado constante.

Espacio de Texto y Encabezados

Los textos se representan con líneas horizontales simples (una línea más gruesa para el título, líneas más finas para el cuerpo). Dibuja líneas con la herramienta **Pluma (B)** y ajústalas a la rejilla.

Barra de Navegación

Dibuja un rectángulo que ocupe todo el ancho. Utiliza la herramienta **Círculo (F5)** o **Polígono (Estrella/Polígono)** para dibujar iconos simples (ej. una estrella para "Favoritos") dentro de la barra.

Ejercicio Sugerido: Wireframe de Home de App

Objetivo: Diseñar la estructura de una pantalla móvil.

  1. Configura un lienzo de 375x812px.
  2. Dibuja una barra de navegación superior (encabezado).
  3. Crea un área de contenido principal que contenga 3 **tarjetas (cards)** apiladas verticalmente.
  4. Añade una barra de navegación inferior (footer) con 4 iconos simples.
  5. Asegúrate de que todos los espacios y márgenes sean consistentes (ej. 16px).
