Sesión 53: Gráficos de Datos: Gráficos de Barra y Anillo

1. Creación de Gráficos de Barra Vectoriales

La precisión de Inkscape lo hace ideal para crear gráficos de barra limpios, escalables y estéticos. Usaremos la herramienta **Rectángulo (F4)**, el panel **Alinear y Distribuir** y la **Rejilla**.

Paso 1: Configuración de la Base

Dibuja el eje X (horizontal) y el eje Y (vertical) con líneas simples (Pluma B). Asegúrate de que el **Ajuste a rejilla** esté activo para la precisión.

Paso 2: Dibujar Barras y Distribución

Dibuja el primer rectángulo (la primera barra). Ajusta su altura al valor deseado. Duplícalo (**Ctrl + D**) tantas veces como necesites. Con todas las barras seleccionadas, usa el panel **Alinear y Distribuir** para espaciarlas de manera uniforme (ej. entre los bordes derechos o izquierdos).

Paso 3: Estilo de Barra

Aplica diferentes colores a las barras. Usa **Degradados Lineales** sutiles para dar un efecto de luz y volumen, o añade una sombra simple (Desenfoque Gaussiano) para un estilo **Neumórfico**.

2. Creación de Gráficos de Anillo (Doughnut Charts)

El gráfico de anillo (similar al gráfico de pastel, pero con un agujero central) es más fácil de crear que el gráfico de pastel tradicional en Inkscape.

Paso 1: El Objeto Anillo

Usa la herramienta **Círculo/Elipse (F5)**. Dibuja un círculo. Con la herramienta activa, verás un pequeño **manejador en forma de Arco**. Arrástralo para convertir el círculo en un **Arco o Segmento**. Esto crea el efecto de "porción" o "rebanada".

Paso 2: Crear el Agujero Central

Dibuja un círculo más pequeño en el centro. Selecciona el círculo grande (la rebanada) y el círculo pequeño. Aplica **Diferencia (Ctrl + -)**. Esto corta el círculo pequeño del grande, dejando un anillo con la forma de la porción.

Paso 3: Ensamblaje de Anillos

Duplica el anillo base. Rota y ajusta el manejador de arco para crear la siguiente porción. Repite hasta que todos los valores estén representados. Usa un **Círculo Central** para ocultar las uniones imperfectas de los arcos.

3. Anotaciones y Leyendas

Etiquetas de Datos

Usa la herramienta **Texto (F8)** para añadir los porcentajes y los nombres de las categorías. Asegúrate de que el texto está alineado con precisión con el centro de las barras o las porciones de anillo.

Leyendas (Swatches)

Crea un pequeño cuadro de color para cada categoría. Agrupa el cuadro de color con su nombre de texto. Usa el panel **Alinear y Distribuir** para alinear todas las leyendas de forma consistente.

Ejercicio Sugerido: Gráfico de Barra 3D Estilizado

Objetivo: Crear un gráfico estético y legible.

  1. Crea un gráfico de barra de 4 valores.
  2. Aplica un **Degradado Lineal** de un color a un tono ligeramente más oscuro del mismo color para dar profundidad a cada barra.
  3. Dibuja un rectángulo delgado que simule el plano del suelo y aplícale un **Desenfoque Gaussiano** para simular una sombra proyectada por las barras.
  4. Añade el texto de la leyenda y los valores de forma limpia.
