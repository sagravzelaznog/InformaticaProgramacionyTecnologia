Conceptos Clave

1. Operadores Aritméticos Básicos

Python incluye los operadores aritméticos estándar:

Operador Operación Ejemplo Resultado
+ Suma 5 + 3 8
- Resta 10 - 4 6
* Multiplicación 6 * 7 42
/ División 15 / 3 5.0
// División entera 15 // 2 7
% Módulo (resto) 15 % 4 3
** Exponenciación 2 ** 3 8

💡 Nota sobre división

En Python 3, el operador / siempre devuelve un número de punto flotante, incluso si el resultado es un número entero. Usa // para la división entera.

2. Precedencia de Operadores

El orden en que se evalúan las operaciones sigue las reglas matemáticas estándar:

  1. Paréntesis: () (siempre tienen la mayor precedencia)
  2. Exponenciación: ** (de derecha a izquierda)
  3. Multiplicación, División, Módulo: *, /, //, % (de izquierda a derecha)
  4. Suma y Resta: +, - (de izquierda a derecha)

Ejemplo de precedencia:

resultado = 5 + 3 * 2 ** 2  # ¿Cuál es el resultado?
# 1. 2 ** 2 = 4
# 2. 3 * 4 = 12
# 3. 5 + 12 = 17
print(resultado)  # 17

💡 Mejores prácticas

Usa paréntesis para hacer el código más legible, incluso cuando no sean estrictamente necesarios.

# Menos claro
volumen = largo * ancho * altura / 3

# Más claro
volumen = (largo * ancho * altura) / 3

3. El Módulo math

Python incluye el módulo math que proporciona funciones matemáticas avanzadas.

import math

# Constantes comunes
print(math.pi)       # 3.141592653589793
print(math.e)        # 2.718281828459045
print(math.tau)      # 6.283185307179586 (2π)
print(math.inf)      # inf (infinito)
print(math.nan)      # nan (no es un número)

# Funciones de redondeo
print(math.ceil(4.2))    # 5 (redondeo hacia arriba)
print(math.floor(4.9))   # 4 (redondeo hacia abajo)
print(round(3.5))        # 4 (redondeo al entero más cercano)
print(round(3.14159, 2)) # 3.14 (redondeo a 2 decimales)

# Potencias y raíces
print(math.pow(2, 3))    # 8.0 (2 elevado a 3)
print(math.sqrt(16))     # 4.0 (raíz cuadrada)
print(math.cbrt(27))     # 3.0 (raíz cúbica, Python 3.11+)

# Funciones trigonométricas (ángulos en radianes)
print(math.sin(math.pi/2))   # 1.0
print(math.cos(math.pi))     # -1.0
print(math.degrees(math.pi)) # 180.0 (conversión a grados)
print(math.radians(180))     # 3.1415... (conversión a radianes)

# Logaritmos
print(math.log(100, 10))  # 2.0 (log base 10 de 100)
print(math.log10(100))    # 2.0 (log base 10)
print(math.log2(8))       # 3.0 (log base 2)
print(math.log(10))       # 2.302585... (log natural, base e)

💡 Importando el módulo math

Puedes importar solo las funciones que necesites para hacer tu código más limpio:

from math import pi, sin, cos

# Ahora podemos usar las funciones directamente
volumen_circulo = pi * radio ** 2

4. Aplicaciones Prácticas

Conversión de unidades

Convierte entre diferentes unidades de medida:

def celsius_a_fahrenheit(celsius):
    """Convierte grados Celsius a Fahrenheit"""
    return (celsius * 9/5) + 32

def kilometros_a_millas(kilometros):
    """Convierte kilómetros a millas"""
    return kilometros * 0.621371

# Uso
print(f"20°C = {celsius_a_fahrenheit(20):.1f}°F")
print(f"5 km = {kilometros_a_millas(5):.2f} millas")

Cálculo de áreas y volúmenes

Fórmulas comunes para figuras geométricas:

import math

def volumen_circulo(radio):
    return math.pi * radio ** 2

def volumen_rectangulo(ancho, alto):
    return ancho * alto

def volumen_esfera(radio):
    return (4/3) * math.pi * radio ** 3

# Uso
print(f"Área del círculo: {volumen_circulo(5):.2f}")
print(f"Área del rectángulo: {volumen_rectangulo(4, 7)}")
print(f"Volumen de la esfera: {volumen_esfera(3):.2f}")

Ecuación de segundo grado

Resuelve ecuaciones de la forma ax² + bx + c = 0

import math

def resolver_ecuacion(a, b, c):
    """Resuelve una ecuación de segundo grado y devuelve las raíces"""
    discriminante = b**2 - 4*a*c
    
    if discriminante > 0:
        x1 = (-b + math.sqrt(discriminante)) / (2*a)
        x2 = (-b - math.sqrt(discriminante)) / (2*a)
        return x1, x2
    elif discriminante == 0:
        x = -b / (2*a)
        return x,
    else:
        return "No hay soluciones reales"

# Uso: 2x² -5x + 2 = 0
soluciones = resolver_ecuacion(2, -5, 2)
print(f"Soluciones: {soluciones}")  # (2.0, 0.5)

Actividad 4: Calculadora de Propinas

Crea un programa que calcule el monto de la propina basado en el total de la cuenta y el porcentaje de propina que el usuario desea dejar.

Recuerda que para calcular un porcentaje, multiplicas el monto por el porcentaje y divides entre 100.

propina = total * porcentaje / 100
