# Curso Básico de Python 🐍

## 📋 Información General del Curso

### 🎯 Objetivos del Curso

Este curso completo de Python está diseñado para llevarte desde cero hasta tener la capacidad de crear tus propios programas. Al finalizar, serás capaz de:

- Comprender los fundamentos de la programación
- Desarrollar aplicaciones básicas en Python
- Resolver problemas mediante código estructurado
- Aplicar las mejores prácticas de desarrollo

### 📚 Prerequisitos

- Ningún conocimiento previo de programación requerido
- Una computadora con acceso a internet
- Motivación y dedicación para aprender

### 🛠️ Materiales Necesarios

- Python 3.8 o superior instalado
- Un editor de código (recomendamos Visual Studio Code)
- Acceso a terminal/consola de comandos

### ⏱️ Duración y Estructura

- **32 sesiones** organizadas en **4 módulos**
- Cada sesión: aproximadamente 1-2 horas
- Ritmo sugerido: 2-3 sesiones por semana

---

## 📖 Metodología de Enseñanza

### 🎓 Enfoque Pedagógico

Nuestro método se basa en el aprendizaje activo mediante:

- **Explicación teórica clara y concisa**
- **Ejemplos prácticos inmediatos**
- **Ejercicios progresivos de dificultad**
- **Proyectos aplicados para reforzar conceptos**

### 📝 Estrategia de Aprendizaje

1. **Ver → Entender** los conceptos básicos
2. **Hacer → Practicar** con ejercicios guiados
3. **Aplicar → Crear** proyectos personales
4. **Compartir → Enseñar** lo aprendido

## 🎯 Módulo 1: Fundamentos de Python (Sesiones 1-8)

### 📋 Objetivos del Módulo

Al completar este módulo podrás:

- Comprender qué es la programación y Python
- Manejar variables y tipos de datos básicos
- Crear programas interactivos simples
- Aplicar lógica condicional básica

### 📚 Contenido del Módulo

#### **Sesión 1: ¡Hola, Mundo! - Introducción a la Programación**

🎯 **Objetivo:** Comprender el ecosistema de la programación y dar los primeros pasos con Python

📖 **Conceptos clave:**

- ¿Qué es la programación? ¿Qué es un algoritmo?
- Diferencia entre código fuente y programa ejecutable
- Instalación de Python y configuración del entorno
- Introducción a editores de código

🔧 **Actividades prácticas:**

1. Instalar Python en tu sistema
2. Configurar un editor de código
3. Escribir el clásico `print("¡Hola, Mundo!")`
4. Ejecutar el programa desde terminal

#### **Sesión 2: Variables y Tipos de Datos Primitivos**

🎯 **Objetivo:** Aprender a almacenar y manipular información básica

📖 **Conceptos clave:**

- ¿Qué es una variable? ¿Para qué sirve?
- Tipos de datos: `int`, `float`, `str`, `bool`
- Reglas para nombrar variables
- Función `type()` para identificar tipos

🔧 **Actividades prácticas:**

1. Crear variables con diferentes tipos de datos
2. Experimentar con la función `type()`
3. Realizar conversiones entre tipos básicos
4. Crear un programa que muestre información personal

#### **Sesión 3: El Poder de las Cadenas de Texto**

🎯 **Objetivo:** Dominar la manipulación de texto en Python

📖 **Conceptos clave:**

- Operaciones básicas con cadenas
- F-strings para formateo avanzado
- Métodos útiles: `.upper()`, `.lower()`, `.strip()`, `.replace()`
- Índices y slicing en cadenas

🔧 **Actividades prácticas:**

1. Crear mensajes personalizados con f-strings
2. Limpiar y formatear texto de usuario
3. Construir oraciones dinámicas
4. Crear un generador de iniciales artísticas

#### **Sesión 4: Operaciones Matemáticas**

🎯 **Objetivo:** Usar Python como calculadora avanzada

📖 **Conceptos clave:**

- Operadores aritméticos básicos y avanzados
- Precedencia de operaciones
- Funciones matemáticas básicas
- Aplicaciones prácticas de cálculos

🔧 **Actividades prácticas:**

1. Crear una calculadora básica por terminal
2. Calcular áreas y perímetros de figuras
3. Convertir entre diferentes unidades
4. Crear un programa de cálculo de propinas

#### **Sesión 5: Entrada del Usuario y Conversión de Tipos**

🎯 **Objetivo:** Crear programas interactivos que respondan al usuario

📖 **Conceptos clave:**

- Función `input()` para entrada de datos
- Conversión entre tipos de datos
- Validación básica de entrada
- Manejo de errores comunes

🔧 **Actividades prácticas:**

1. Crear un programa de saludo personalizado
2. Construir una calculadora interactiva
3. Crear un conversor de monedas básico
4. Desarrollar un cuestionario simple

#### **Sesión 6: Introducción a los Booleanos y Operadores de Comparación**

🎯 **Objetivo:** Entender la lógica verdadera/falsa en programación

📖 **Conceptos clave:**

- Valores booleanos: `True` y `False`
- Operadores de comparación
- Expresiones lógicas
- Aplicaciones prácticas de condiciones

🔧 **Actividades prácticas:**

1. Crear un verificador de edad para diferentes actividades
2. Desarrollar un comparador de números
3. Construir un validador de contraseñas básico
4. Crear un programa de clasificación de números

#### **Sesión 7: Lógica Condicional con `if` y `else`**

🎯 **Objetivo:** Aprender a tomar decisiones en el código

📖 **Conceptos clave:**

- Estructura `if-else`
- Condiciones múltiples con `elif`
- Anidación de condiciones
- Aplicaciones prácticas

🔧 **Actividades prácticas:**

1. Crear un programa que determine si un número es par o impar
2. Desarrollar un adivina-el-número básico
3. Construir un verificador de calificaciones
4. Crear un selector de menú simple

#### **Sesión 8: Mini-Proyecto 1: Calculadora Básica**

🎯 **Objetivo:** Aplicar todo lo aprendido en un proyecto completo

📋 **Descripción del proyecto:**
Desarrollarás una calculadora interactiva que:

- Pida al usuario dos números
- Ofrezca un menú de operaciones
- Realice el cálculo solicitado
- Maneje errores de entrada

🔧 **Características técnicas:**

- Validación de entrada numérica
