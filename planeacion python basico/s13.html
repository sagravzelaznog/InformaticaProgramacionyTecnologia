Objetivo de la Sesión

En esta sesión, aprenderás a trabajar con diccionarios en Python, una estructura de datos poderosa que te permite almacenar y organizar información en pares clave-valor. Los diccionarios son fundamentales para manejar datos estructurados de manera eficiente.

Al finalizar esta sesión, podrás:

  • Crear y manipular diccionarios usando la sintaxis adecuada
  • Comprender el concepto de pares clave-valor y su importancia
  • Realizar operaciones básicas como agregar, modificar y eliminar elementos
  • Aplicar diccionarios en situaciones prácticas del mundo real

Conceptos Clave

1. Sintaxis Básica de los Diccionarios

Un diccionario en Python es una colección desordenada, modificable e indexada de pares clave-valor. Las claves deben ser únicas e inmutables (números, cadenas o tuplas).

# Crear un diccionario vacío
mi_diccionario = {}
otro_diccionario = dict()

# Diccionario con datos
estudiante = {
    "nombre": "Ana García",
    "edad": 22,
    "carrera": "Ingeniería",
    "promedio": 9.2,
    "activo": True
}

# Acceder a valores
print(estudiante["nombre"])  # Ana García
print(estudiante.get("edad"))  # 22 (método get es más seguro)

# Longitud del diccionario
print(f"El diccionario tiene {len(estudiante)} elementos")  # 5

# Verificar si una clave existe
if "carrera" in estudiante:
    print(f"Carrera: {estudiante['carrera']}")

# Métodos útiles
claves = estudiante.keys()    # Obtener todas las claves
valores = estudiante.values() # Obtener todos los valores
items = estudiante.items()    # Obtener pares clave-valor como tuplas

# Iterar sobre un diccionario
for clave in estudiante:
    print(f"{clave}: {estudiante[clave]}")

# Iterar sobre claves y valores simultáneamente
for clave, valor in estudiante.items():
    print(f"{clave}: {valor}")

💡 Claves en diccionarios

Las claves de un diccionario deben ser inmutables. Puedes usar números, cadenas o tuplas como claves, pero no listas u otros diccionarios. Los valores pueden ser de cualquier tipo de dato.

2. Operaciones Básicas con Diccionarios

Python proporciona varios métodos para manipular diccionarios de manera eficiente.

# Crear un diccionario de ejemplo
inventario = {
    "manzanas": 30,
    "plátanos": 45,
    "naranjas": 25
}

# Agregar o actualizar elementos
inventario["peras"] = 20      # Agregar nuevo par clave-valor
inventario["manzanas"] = 35   # Actualizar valor existente

# Eliminar elementos
del inventario["naranjas"]     # Elimina la clave y su valor
perdido = inventario.pop("plátanos")  # Elimina y devuelve el valor
print(f"Se eliminaron {perdido} plátanos")

# Método update() para combinar diccionarios
extras = {"uvas": 15, "fresas": 30}
inventario.update(extras)  # Añade o actualiza elementos

# Copiar un diccionario
copia_inventario = inventario.copy()  # Copia superficial

# Limpiar el diccionario
inventario.clear()  # Elimina todos los elementos

# Diccionarios anidados
colegio = {
    "estudiante1": {"nombre": "Ana", "edad": 15, "grado": 10},
    "estudiante2": {"nombre": "Luis", "edad": 16, "grado": 11},
    "estudiante3": {"nombre": "Marta", "edad": 14, "grado": 9}
}

# Acceder a valores en diccionarios anidados
print(colegio["estudiante1"]["nombre"])  # Ana

# Comprehesions de diccionarios
cuadrados = {x: x**2 for x in range(1, 6)}  # {1: 1, 2: 4, 3: 9, 4: 16, 5: 25}

💡 Método get() vs acceso directo

Usa diccionario.get(clave, valor_por_defecto) en lugar de diccionario[clave] cuando no estés seguro de si la clave existe. El método get() devuelve None (o el valor por defecto que especifiques) si la clave no existe, mientras que el acceso directo genera un KeyError.

3. Casos de Uso Comunes de los Diccionarios

Los diccionarios son increíblemente versátiles y se utilizan en una amplia variedad de escenarios de programación.

# 1. Contar ocurrencias de elementos
frutas = ["manzana", "banana", "cereza", "manzana", "banana", "manzana"]
contador = {}

for fruta in frutas:
    if fruta in contador:
        contador[fruta] += 1
    else:
        contador[fruta] = 1

# Versión más eficiente usando get()
contador = {}
for fruta in frutas:
    contador[fruta] = contador.get(fruta, 0) + 1

print(contador)  # {'manzana': 3, 'banana': 2, 'cereza': 1}

# 2. Agrupar elementos por categoría
estudiantes = [
    {"nombre": "Ana", "edad": 15, "grado": 10},
    {"nombre": "Luis", "edad": 16, "grado": 11},
    {"nombre": "Marta", "edad": 15, "grado": 10},
    {"nombre": "Carlos", "edad": 16, "grado": 11}
]

# Agrupar por grado
grados = {}
for estudiante in estudiantes:
    grado = estudiante["grado"]
    if grado not in grados:
        grados[grado] = []
    grados[grado].append(estudiante["nombre"])

print(grados)  # {10: ['Ana', 'Marta'], 11: ['Luis', 'Carlos']}

# 3. Configuración de aplicaciones
configuracion = {
    "tema": "oscuro",
    "notificaciones": True,
    "idioma": "es",
    "tamaño_fuente": 14,
    "atajos_teclado": {
        "guardar": "Ctrl+S",
        "copiar": "Ctrl+C",
        "pegar": "Ctrl+V"
    }
}

# 4. Traducción simple
traductor = {
    "hola": "hello",
    "adiós": "goodbye",
    "gracias": "thank you",
    "por favor": "please",
    "sí": "yes",
    "no": "no"
}

frase = "hola, ¿cómo estás?"
palabras = frase.lower().split()
traducido = [traductor.get(palabra, palabra) for palabra in palabras]
print(" ".join(traducido))  # hello, ¿cómo estás?

💡 Diccionarios vs Listas

Usa listas cuando el orden de los elementos es importante y necesitas acceder a ellos por su posición. Usa diccionarios cuando necesites buscar valores por claves descriptivas y el orden no sea relevante (aunque desde Python 3.7, los diccionarios mantienen el orden de inserción).

4. Métodos Avanzados de los Diccionarios

Python ofrece varios métodos útiles para trabajar con diccionarios de manera más eficiente.

# Crear un diccionario de ejemplo
productos = {
    "manzana": 15.5,
    "banana": 12.0,
    "naranja": 10.8,
    "uva": 25.3
}

# setdefault(): obtiene el valor de una clave o lo establece si no existe
precio = productos.setdefault("pera", 18.0)  # Agrega "pera" con valor 18.0

# fromkeys(): crea un nuevo diccionario con claves de una secuencia y un valor por defecto
nuevas_claves = ["fresa", "mango", "sandía"]
nuevos_productos = dict.fromkeys(nuevas_claves, 0.0)  # {'fresa': 0.0, 'mango': 0.0, 'sandía': 0.0}

# popitem(): elimina y devuelve el último par clave-valor insertado
# Útil para procesar elementos en orden LIFO (último en entrar, primero en salir)
ultimo_producto = productos.popitem()  # Devuelve ('uva', 25.3)

# update() con otro diccionario o iterable de pares clave-valor
ofertas = {"manzana": 12.5, "banana": 10.0, "kiwi": 20.0}
productos.update(ofertas)  # Actualiza precios existentes y agrega kiwi

# Diccionarios con valores por defecto
from collections import defaultdict

# Crear un diccionario con valores por defecto de tipo int (0)
contador = defaultdict(int)
palabras = ["manzana", "banana", "manzana", "cereza", "banana", "manzana"]
for palabra in palabras:
    contador[palabra] += 1  # No necesita verificar si la clave existe

print(contador)  # defaultdict(, {'manzana': 3, 'banana': 2, 'cereza': 1})

# Diccionario ordenado (aunque desde Python 3.7 los diccionarios mantienen el orden)
from collections import OrderedDict

# Útil para versiones anteriores a Python 3.7 o para operaciones específicas
ordenado = OrderedDict()
ordenado["primero"] = 1
ordenado["segundo"] = 2
ordenado["tercero"] = 3

# Unión de diccionarios (Python 3.9+)
# dic1 = {"a": 1, "b": 2}
# dic2 = {"b": 3, "c": 4}
# dic1 | dic2  # {'a': 1, 'b': 3, 'c': 4}

💡 Diccionarios y JSON

Los diccionarios de Python son muy similares a los objetos JSON, lo que los hace ideales para trabajar con datos web. Puedes usar los módulos json para convertir entre diccionarios y cadenas JSON:

import json

# Convertir diccionario a JSON
datos = {"nombre": "Ana", "edad": 25, "ciudad": "Madrid"}
json_str = json.dumps(datos, indent=2)  # Convierte a cadena JSON formateada

# Convertir JSON a diccionario
diccionario = json.loads('{"nombre": "Ana", "edad": 25, "ciudad": "Madrid"}')
