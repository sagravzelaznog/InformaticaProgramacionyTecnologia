Bucles while - Repetición Condicional

Objetivo de la Sesión

En esta sesión, aprenderás a utilizar los bucles while en Python para crear estructuras de repetición controladas por condiciones. A diferencia de los bucles for, los bucles while son ideales cuando no sabes de antemano cuántas veces necesitas repetir un bloque de código.

Al finalizar esta sesión, podrás:

  • Comprender la diferencia entre los bucles for y while
  • Implementar correctamente condiciones de parada para evitar bucles infinitos
  • Crear menús interactivos y programas que requieren entrada del usuario
  • Resolver problemas donde el número de iteraciones no es conocido de antemano

Conceptos Clave

1. Sintaxis Básica del Bucle while

El bucle while ejecuta un bloque de código mientras una condición sea verdadera. Es fundamental asegurar que la condición eventualmente se convierta en falsa para evitar bucles infinitos.

# Sintaxis básica
contador = 0
while contador < 5:  # Mientras la condición sea True
    print(f"Contador: {contador}")
    contador += 1  # Importante: modificar la variable de control

# Bucle con entrada del usuario
respuesta = ""
while respuesta.lower() != "salir":
    respuesta = input("Escribe 'salir' para terminar: ")
    print(f"Escribiste: {respuesta}")

# Bucle con break
while True:  # Bucle infinito controlado
    opcion = input("Selecciona una opción (1-3) o 'q' para salir: ")
    if opcion == 'q':
        print("¡Hasta luego!")
        break  # Sale del bucle
    elif opcion in ['1', '2', '3']:
        print(f"Ejecutando opción {opcion}")
    else:
        print("Opción no válida. Intenta de nuevo.")

# Bucle con continue
numero = 0
while numero < 10:
    numero += 1
    if numero % 2 == 0:  # Si el número es par
        continue  # Salta a la siguiente iteración
    print(f"Número impar: {numero}")

💡 Diferencia clave: for vs while

Usa for cuando sepas de antemano cuántas veces necesitas iterar (ej: recorrer una lista). Usa while cuando necesites repetir un bloque de código hasta que se cumpla una condición que puede depender de factores externos o de la entrada del usuario.

2. Condiciones de Parada y Bucles Infinitos

Un bucle infinito ocurre cuando la condición del while nunca se vuelve falsa. Es un error común que puede hacer que el programa se cuelgue.

# Ejemplo de bucle infinito (¡No ejecutar tal cual!)
# contador = 0
# while contador < 5:
#     print("Este bucle nunca terminará")
#     # Falta incrementar el contador

# Cómo evitar bucles infinitos
contador = 0
while contador < 5:
    print(f"Iteración {contador + 1}")
    contador += 1  # Variable de control que asegura la terminación

# Usando un booleano como bandera
activo = True
while activo:
    respuesta = input("¿Deseas continuar? (s/n): ")
    if respuesta.lower() == 'n':
        activo = False  # Cambia la condición para salir del bucle
    print("Continuando...")

# Uso de break para salir de bucles while
while True:  # Bucle aparentemente infinito
    numero = int(input("Ingresa un número (0 para salir): "))
    if numero == 0:
        print("Saliendo...")
        break  # Sale del bucle
    print(f"El cuadrado es: {numero ** 2}")

# Contador con límite de intentos
intentos = 3
while intentos > 0:
    contraseña = input("Ingresa la contraseña: ")
    if contraseña == "secreto":
        print("¡Acceso concedido!")
        break
    else:
        intentos -= 1
        print(f"Contraseña incorrecta. Te quedan {intentos} intentos.")
else:
    print("Has agotado tus intentos. Cuenta bloqueada.")

⚠️ Prevención de bucles infinitos

Siempre asegúrate de que exista una condición de salida clara en tus bucles while. Si estás probando código con bucles, considera agregar un contador de seguridad que fuerce la salida después de un número máximo de iteraciones.

3. Aplicaciones Prácticas de los Bucles while

Los bucles while son ideales para situaciones donde necesitas repetir una acción hasta que se cumpla una condición que no depende de un contador o secuencia predefinida.

# Menú interactivo
def mostrar_menu():
    print("\n=== MENÚ PRINCIPAL ===")
    print("1. Ver perfil")
    print("2. Configuración")
    print("3. Ayuda")
    print("4. Salir")

while True:
    mostrar_menu()
    opcion = input("Selecciona una opción (1-4): ")
    
    if opcion == '1':
        print("\nMostrando perfil del usuario...")
    elif opcion == '2':
        print("\nAbriendo configuración...")
    elif opcion == '3':
        print("\nMostrando ayuda...")
    elif opcion == '4':
        print("\n¡Hasta luego!")
        break
    else:
        print("\nOpción no válida. Intenta de nuevo.")

# Juego de adivinanza
import random

numero_secreto = random.randint(1, 100)
intentos = 0
max_intentos = 5
adivinado = False

print("\n=== JUEGO DE ADIVINANZA ===")
print(f"Tienes {max_intentos} intentos para adivinar el número (1-100).")

while intentos < max_intentos and not adivinado:
    try:
        intento = int(input("\nIngresa tu suposición: "))
        intentos += 1
        
        if intento < numero_secreto:
            print("El número es mayor. Intenta de nuevo.")
        elif intento > numero_secreto:
            print("El número es menor. Intenta de nuevo.")
        else:
            print(f"¡Felicidades! Adivinaste el número en {intentos} intentos.")
            adivinado = True
            
        if not adivinado and intentos < max_intentos:
            print(f"Te quedan {max_intentos - intentos} intentos.")
            
    except ValueError:
        print("Por favor, ingresa un número válido.")

if not adivinado:
    print(f"\n¡Se acabaron los intentos! El número era {numero_secreto}.")

# Validación de entrada
while True:
    try:
        edad = int(input("Ingresa tu edad: "))
        if 0 < edad <= 120:  # Rango de edades razonable
            break
        else:
            print("Por favor, ingresa una edad entre 1 y 120 años.")
    except ValueError:
        print("Error: Debes ingresar un número entero.")

print(f"Tienes {edad} años.")

💡 Mejores prácticas con bucles while

1. Siempre inicializa las variables de control antes del bucle.
2. Asegúrate de que la condición del bucle eventualmente se vuelva falsa.
3. Usa break para salir del bucle cuando sea necesario.
4. Considera usar un contador de seguridad para evitar bucles infinitos accidentales.

4. Bucles Anidados y Patrones con while

Los bucles while pueden anidarse para crear patrones o manejar estructuras de datos multidimensionales.

# Patrón de triángulo con while
fila = 1
max_filas = 5

while fila <= max_filas:
    columna = 1
    while columna <= fila:
        print("*", end=" ")
        columna += 1
    print()  # Nueva línea al final de cada fila
    fila += 1

# Tabla de multiplicar con while
numero = 1
while numero <= 10:
    multiplicador = 1
    print(f"\nTabla del {numero}:")
    print("-" * 15)
    
    while multiplicador <= 10:
        resultado = numero * multiplicador
        print(f"{numero} x {multiplicador:2} = {resultado:2}")
        multiplicador += 1
    
    numero += 1
    if numero <= 10:
        input("\nPresiona Enter para ver la siguiente tabla...")

# Búsqueda en una matriz
matriz = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]

fila = 0
encontrado = False
buscar = 5  # Número a buscar

while fila < len(matriz) and not encontrado:
    columna = 0
    while columna < len(matriz[fila]):
        if matriz[fila][columna] == buscar:
            print(f"Encontrado {buscar} en la posición [{fila}][{columna}]")
            encontrado = True
            break  # Sale del bucle interno
        columna += 1
    fila += 1

if not encontrado:
    print(f"El número {buscar} no se encuentra en la matriz")

💡 Optimización de bucles anidados

Cuando trabajes con bucles anidados, recuerda que el bucle más interno se ejecutará el mayor número de veces. Si el rendimiento es crítico, intenta colocar las condiciones que terminan el bucle lo antes posible para evitar iteraciones innecesarias.
