Introducción al Proyecto

¡Bienvenido al segundo mini-proyecto del curso! En esta sesión, pondrás en práctica todo lo que has aprendido hasta ahora para crear un juego de "Adivina el Número" mejorado. Este proyecto te permitirá aplicar conceptos de estructuras de control, manejo de entrada/salida, generación de números aleatorios y más, todo mientras creas un juego interactivo y divertido.

Objetivos de Aprendizaje

  • Reforzar el uso de estructuras de control (condicionales y bucles)
  • Practicar la generación de números aleatorios con el módulo random
  • Mejorar el manejo de entrada/salida del usuario
  • Implementar niveles de dificultad
  • Crear una interfaz de usuario más amigable

Vista General del Proyecto

El juego "Adivina el Número Mejorado" desafiará a los jugadores a adivinar un número generado aleatoriamente dentro de un rango específico. A diferencia de la versión básica, este proyecto incluirá características avanzadas como múltiples niveles de dificultad, un sistema de puntuación, y retroalimentación detallada para el jugador.

Generación Aleatoria

El programa generará un número aleatorio dentro de un rango específico según el nivel de dificultad seleccionado.

Múltiples Niveles

Los jugadores podrán elegir entre diferentes niveles de dificultad, cada uno con su propio rango de números y cantidad de intentos.

Pistas Inteligentes

El juego proporcionará pistas útiles (mayor/menor) después de cada intento para ayudar al jugador.

Sistema de Puntuación

Los jugadores recibirán una puntuación basada en la cantidad de intentos utilizados y el nivel de dificultad.

Requisitos del Proyecto

Requisitos Mínimos

Para completar este proyecto, tu programa debe cumplir con los siguientes requisitos:

  1. Generación de Número Aleatorio: El programa debe generar un número aleatorio dentro de un rango específico.
  2. Niveles de Dificultad: Al menos tres niveles de dificultad con diferentes rangos de números y cantidad de intentos.
  3. Entrada del Usuario: Validar la entrada del usuario para asegurar que sea un número dentro del rango permitido.
  4. Retroalimentación: Proporcionar pistas después de cada intento (mayor/menor).
  5. Conteo de Intentos: Llevar un registro del número de intentos realizados.
  6. Mensajes de Ayuda: Mostrar mensajes claros para guiar al jugador.
  7. Reinicio del Juego: Preguntar al jugador si desea jugar nuevamente al finalizar.

Historias de Usuario

Como jugador, quiero seleccionar un nivel de dificultad

Para poder ajustar el desafío a mi nivel de habilidad.

Criterios de aceptación: El menú debe mostrar al menos tres niveles de dificultad con rangos de números y cantidad de intentos claramente definidos.

Como jugador, quiero recibir pistas después de cada intento

Para poder ajustar mi siguiente suposición de manera informada.

Criterios de aceptación: Después de cada intento, el juego debe indicar si el número objetivo es mayor o menor que el número ingresado.

Como jugador, quiero ver mi puntuación al final del juego

Para poder medir mi rendimiento y mejorar en partidas futuras.

Criterios de aceptación: Al adivinar el número, se debe mostrar una puntuación basada en la dificultad y los intentos utilizados.

Niveles de Dificultad Sugeridos

Fácil

  • Rango: 1-50
  • Intentos: 10
  • Puntuación máxima: 100 puntos

Intermedio

  • Rango: 1-100
  • Intentos: 7
  • Puntuación máxima: 200 puntos

Difícil

  • Rango: 1-200
  • Intentos: 5
  • Puntuación máxima: 300 puntos

Experto (Opcional)

  • Rango: 1-500
  • Intentos: 3
  • Puntuación máxima: 500 puntos

Sistema de Puntuación

La puntuación se calcula de la siguiente manera:

  • Puntos base: 100, 200, 300 o 500 puntos según el nivel de dificultad.
  • Descuento por intentos: Se resta 10 puntos por cada intento utilizado.
  • Puntuación mínima: 10 puntos (incluso si se usan todos los intentos).

Fórmula: puntuación = max(10, puntos_base - (intentos_utilizados * 10))

Desarrollo del Proyecto

Paso 1: Configuración Inicial

Comienza importando los módulos necesarios y configurando las constantes del juego.

Estructura Básica

import random
import time

def limpiar_pantalla():
    """Limpia la pantalla de la consola."""
    import os
    os.system('cls' if os.name == 'nt' else 'clear')

def mostrar_titulo():
    """Muestra el título del juego."""
    print("=== ADIVINA EL NÚMERO MEJORADO ===\n")

# Niveles de dificultad
NIVELES = {
    1: {"nombre": "Fácil", "rango": 50, "intentos": 10, "puntos": 100},
    2: {"nombre": "Intermedio", "rango": 100, "intentos": 7, "puntos": 200},
    3: {"nombre": "Difícil", "rango": 200, "intentos": 5, "puntos": 300},
    4: {"nombre": "Experto", "rango": 500, "intentos": 3, "puntos": 500}
}

def main():
    """Función principal del juego."""
    limpiar_pantalla()
    mostrar_titulo()
    print("¡Bienvenido al juego Adivina el Número Mejorado!")
    print("Tendrás que adivinar un número en la menor cantidad de intentos posibles.\n")

if __name__ == "__main__":
    main()

Consejo

El diccionario NIVELES almacena toda la configuración de cada nivel. Esto hace que sea fácil agregar o modificar niveles sin tener que cambiar la lógica principal del juego.

Paso 2: Menú de Niveles

Implementa una función que permita al jugador seleccionar un nivel de dificultad.

Selección de Nivel

def seleccionar_nivel():
    """Permite al jugador seleccionar un nivel de dificultad."""
    while True:
        print("\nSelecciona un nivel de dificultad:")
        for num, nivel in NIVELES.items():
            print(f"{num}. {nivel['nombre']} (1-{nivel['rango']}, {nivel['intentos']} intentos)")
        
        try:
            opcion = int(input("\nIngresa el número del nivel (1-4): "))
            if opcion in NIVELES:
                return opcion
            else:
                print("\n❌ Por favor, selecciona un número del 1 al 4.")
        except ValueError:
            print("\n❌ Entrada inválida. Por favor, ingresa un número.")

def main():
    limpiar_pantalla()
    mostrar_titulo()
    print("¡Bienvenido al juego Adivina el Número Mejorado!")
    print("Tendrás que adivinar un número en la menor cantidad de intentos posibles.\n")
    
    nivel = seleccionar_nivel()
    config = NIVELES[nivel]
    
    print(f"\n¡Perfecto! Has seleccionado el nivel {config['nombre']}.")
    print(f"He elegido un número entre 1 y {config['rango']}.")
    print(f"Tienes {config['intentos']} intentos. ¡Buena suerte!\n")

Manejo de Errores

Paso 3: Lógica Principal del Juego

Implementa la lógica principal del juego, incluyendo la generación del número aleatorio y el bucle de adivinanzas.

Lógica del Juego

def jugar_partida(nivel):
    """Ejecuta una partida del juego con el nivel seleccionado."""
    config = NIVELES[nivel]
    numero_secreto = random.randint(1, config['rango'])
    intentos_restantes = config['intentos']
    intentos_realizados = 0
    
    while intentos_restantes > 0:
        print(f"\nIntentos restantes: {intentos_restantes}")
        
        try:
            # Obtener y validar la suposición del jugador
            intento = int(input(f"Intento #{intentos_realizados + 1}: Ingresa un número (1-{config['rango']}): "))
            
            if intento < 1 or intento > config['rango']:
                print(f"❌ Por favor, ingresa un número entre 1 y {config['rango']}.")
                continue
                
        except ValueError:
            print("❌ Entrada inválida. Por favor, ingresa un número.")
            continue
            
        # Incrementar el contador de intentos
        intentos_realizados += 1
        intentos_restantes -= 1
        
        # Verificar la suposición
        if intento < numero_secreto:
            print("🔍 Demasiado bajo. Intenta con un número más alto.")
        elif intento > numero_secreto:
            print("🔍 Demasiado alto. Intenta con un número más bajo.")
        else:
            # ¡Adivinó el número!
            puntuacion = max(10, config['puntos'] - (intentos_realizados * 10))
            print(f"\n🎉 ¡Felicidades! ¡Has adivinado el número en {intentos_realizados} intentos!")
            print(f"🏆 Puntuación: {puntuacion}/{config['puntos']}")
            return True  # El jugador ganó
    
    # Si se agotaron los intentos
    print(f"\n😢 ¡Se acabaron los intentos! El número era {numero_secreto}.")
    return False  # El jugador perdió

def main():
    limpiar_pantalla()
    mostrar_titulo()
    print("¡Bienvenido al juego Adivina el Número Mejorado!")
    print("Tendrás que adivinar un número en la menor cantidad de intentos posibles.\n")
    
    nivel = seleccionar_nivel()
    config = NIVELES[nivel]
    
    print(f"\n¡Perfecto! Has seleccionado el nivel {config['nombre']}.")
    print(f"He elegido un número entre 1 y {config['rango']}.")
    print(f"Tienes {config['intentos']} intentos. ¡Buena suerte!\n")
    
    jugar_partida(nivel)

Paso 4: Sistema de Repetición y Mejoras

Agrega la funcionalidad para jugar múltiples partidas y mejorar la experiencia del usuario.

Juego Completo

def jugar_de_nuevo():
    """Pregunta al jugador si desea jugar otra partida."""
    while True:
        respuesta = input("\n¿Quieres jugar de nuevo? (s/n): ").strip().lower()
        if respuesta in ['s', 'si', 'sí']:
            return True
        elif respuesta in ['n', 'no']:
            return False
        else:
            print("Por favor, responde 's' para sí o 'n' para no.")

def mostrar_estadisticas(partidas_jugadas, partidas_ganadas, puntuacion_total):
    """Muestra las estadísticas del jugador."""
    print("\n=== ESTADÍSTICAS ===")
    print(f"Partidas jugadas: {partidas_jugadas}")
    print(f"Partidas ganadas: {partidas_ganadas}")
    if partidas_jugadas > 0:
        porcentaje_victorias = (partidas_ganadas / partidas_jugadas) * 100
        print(f"Porcentaje de victorias: {porcentaje_victorias:.1f}%")
    print(f"Puntuación total: {puntuacion_total}")

def main():
    limpiar_pantalla()
    mostrar_titulo()
    print("¡Bienvenido al juego Adivina el Número Mejorado!")
    print("Tendrás que adivinar un número en la menor cantidad de intentos posibles.\n")
    
    # Estadísticas
    partidas_jugadas = 0
    partidas_ganadas = 0
    puntuacion_total = 0
    
    while True:
        nivel = seleccionar_nivel()
        config = NIVELES[nivel]
        
        print(f"\n¡Perfecto! Has seleccionado el nivel {config['nombre']}.")
        print(f"He elegido un número entre 1 y {config['rango']}.")
        print(f"Tienes {config['intentos']} intentos. ¡Buena suerte!\n")
        
        # Jugar una partida
        partidas_jugadas += 1
        if jugar_partida(nivel):
            partidas_ganadas += 1
            puntuacion_actual = max(10, config['puntos'] - (config['intentos'] - 1) * 10)
            puntuacion_total += puntuacion_actual
        
        # Mostrar estadísticas
        mostrar_estadisticas(partidas_jugadas, partidas_ganadas, puntuacion_total)
        
        # Preguntar si quiere jugar de nuevo
        if not jugar_de_nuevo():
            break
            
        limpiar_pantalla()
        mostrar_titulo()
    
    print("\n¡Gracias por jugar! Hasta la próxima. 👋")

if __name__ == "__main__":
    main()

def ofrecer_pista(numero_secreto, rango, pistas_disponibles):
    """Ofrece una pista al jugador si tiene pistas disponibles."""
    if pistas_disponibles <= 0:
        print("❌ No te quedan más pistas.")
        return pistas_disponibles
        
    print("\n💡 Pistas disponibles:")
    print("1. Mostrar si el número es par o impar")
    print("2. Mostrar el primer dígito del número")
    print("3. Mostrar un número cercano (dentro de un rango de ±10%)")
    
    try:
        opcion = int(input("Selecciona una pista (1-3) o 0 para cancelar: "))
        
        if opcion == 0:
            return pistas_disponibles
            
        if opcion == 1:
            print(f"El número es {'par' if numero_secreto % 2 == 0 else 'impar'}.")
        elif opcion == 2:
            primer_digito = int(str(numero_secreto)[0])
            print(f"El número comienza con {primer_digito}.")
        elif opcion == 3:
            margen = max(1, int(rango * 0.1))  # 10% del rango como margen
            minimo = max(1, numero_secreto - margen)
            maximo = min(rango, numero_secreto + margen)
            print(f"El número está entre {minimo} y {maximo}.")
        else:
            print("Opción no válida.")
            return pistas_disponibles
            
        return pistas_disponibles - 1
        
    except ValueError:
        print("Por favor, ingresa un número.")
        return pistas_disponibles
