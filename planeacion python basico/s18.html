Objetivo de la Sesión

En esta sesión, profundizarás en el manejo avanzado de parámetros y argumentos en funciones Python. Aprenderás a crear funciones más flexibles y versátiles que puedan adaptarse a diferentes situaciones de uso, utilizando técnicas como argumentos por nombre, valores por defecto y argumentos variables.

Al finalizar esta sesión, podrás:

  • Diferenciar entre parámetros obligatorios y opcionales
  • Usar argumentos por posición y por nombre correctamente
  • Definir valores por defecto para parámetros opcionales
  • Manejar número variable de argumentos usando *args y **kwargs
  • Crear funciones altamente configurables y reutilizables
  • Mejorar la legibilidad y mantenibilidad de tu código mediante buenas prácticas

Parámetros Obligatorios

Son parámetros que siempre deben ser proporcionados cuando se llama a la función.

def dividir(a, b):  # Ambos parámetros son obligatorios
    return a / b

Parámetros Opcionales

Son parámetros que tienen valores por defecto y pueden ser omitidos en la llamada.

def saludar(nombre, saludo="Hola"):  # saludo es opcional
    return f"{saludo}, {nombre}"

Argumentos Variables

Permiten pasar un número variable de argumentos a la función.

def sumar_todos(*numeros):  # Puede recibir cualquier cantidad
    return sum(numeros)

Conceptos Clave

1. Parámetros Obligatorios vs Opcionales

Los parámetros pueden ser obligatorios (sin valor por defecto) u opcionales (con valor por defecto). Los parámetros opcionales siempre deben ir después de los obligatorios.

# Parámetros obligatorios (sin valores por defecto)
def calcular_area_rectangulo(ancho, largo):
    """Calcula el área de un rectángulo."""
    return ancho * largo

# Parámetros opcionales (con valores por defecto)
def crear_usuario(nombre, edad, ciudad="Ciudad no especificada", activo=True):
    """
    Crea un perfil de usuario con información básica.
    
    Args:
        nombre (str): Nombre del usuario (obligatorio)
        edad (int): Edad del usuario (obligatorio)
        ciudad (str): Ciudad del usuario (opcional, por defecto "Ciudad no especificada")
        activo (bool): Estado activo del usuario (opcional, por defecto True)
        
    Returns:
        dict: Diccionario con la información del usuario
    """
    return {
        "nombre": nombre,
        "edad": edad,
        "ciudad": ciudad,
        "activo": activo
    }

# Función con parámetros mixtos
def generar_informe(titulo, datos, formato="texto", incluir_fecha=True, separador="="):
    """
    Genera un informe formateado.
    
    Args:
        titulo (str): Título del informe (obligatorio)
        datos (dict): Datos a incluir en el informe (obligatorio)
        formato (str): Formato del informe (opcional, por defecto "texto")
        incluir_fecha (bool): Incluir fecha en el informe (opcional, por defecto True)
        separador (str): Carácter separador para el título (opcional, por defecto "=")
        
    Returns:
        str: Informe formateado
    """
    # Construir el encabezado
    linea_separadora = separador * len(titulo)
    informe = [linea_separadora, titulo, linea_separadora, ""]
    
    # Agregar fecha si está habilitado
    if incluir_fecha:
        from datetime import datetime
        fecha_actual = datetime.now().strftime("%d/%m/%Y %H:%M:%S")
        informe.append(f"Fecha: {fecha_actual}")
        informe.append("")
    
    # Agregar los datos
    for clave, valor in datos.items():
        informe.append(f"{clave}: {valor}")
    
    return "\n".join(informe)

# Uso de las funciones
area = calcular_area_rectangulo(10, 5)  # Ambos parámetros obligatorios
print(f"Área: {area}")

usuario1 = crear_usuario("Ana", 25)  # Solo parámetros obligatorios
usuario2 = crear_usuario("Luis", 30, "Madrid")  # Ciudad opcional especificada
usuario3 = crear_usuario("María", 28, "Barcelona", False)  # Todos los parámetros

print("\nUsuarios creados:")
for usuario in [usuario1, usuario2, usuario3]:
    print(usuario)

# Ejemplo de informe
datos_informe = {
    "Proyecto": "Sistema de Gestión",
    "Versión": "1.0",
    "Desarrollador": "Equipo Python",
    "Estado": "En desarrollo"

informe_texto = generar_informe("INFORME DE PROYECTO", datos_informe)
print(f"\n{informe_texto}")

informe_html = generar_informe("INFORME DE PROYECTO", datos_informe, formato="html", incluir_fecha=True)

Regla Importante

Los parámetros opcionales (con valores por defecto) siempre deben ir después de los parámetros obligatorios en la definición de la función. Si colocas un parámetro obligatorio después de uno opcional, Python generará un error de sintaxis.

2. Argumentos por Posición y por Nombre

Python permite pasar argumentos de dos maneras: por posición (el orden importa) o por nombre (usando el nombre del parámetro). Puedes combinar ambos métodos, pero los argumentos por posición deben ir primero.

# Función de ejemplo
def configurar_servidor(host, puerto, protocolo="http", seguridad=True, tiempo_espera=30):
    """
    Configura un servidor con parámetros específicos.
    
    Args:
        host (str): Dirección del servidor
        puerto (int): Puerto del servidor
        protocolo (str): Protocolo de comunicación
        seguridad (bool): Habilitar seguridad
        tiempo_espera (int): Tiempo de espera en segundos
        
    Returns:
        dict: Configuración del servidor
    """
    return {
        "host": host,
        "puerto": puerto,
        "protocolo": protocolo,
        "seguridad": seguridad,
        "tiempo_espera": tiempo_espera
    }

# 1. Solo argumentos por posición (orden importa)
config1 = configurar_servidor("localhost", 8080)
print("Configuración 1:", config1)
# Equivalente a: host="localhost", puerto=8080, protocolo="http", seguridad=True, tiempo_espera=30

# 2. Solo argumentos por nombre (orden no importa)
config2 = configurar_servidor(
    puerto=443,
    host="example.com",
    protocolo="https"
)
print("Configuración 2:", config2)
# Equivalente a: host="example.com", puerto=443, protocolo="https", seguridad=True, tiempo_espera=30

# 3. Mezcla de argumentos por posición y nombre
config3 = configurar_servidor("api.example.com", 8080, protocolo="https", tiempo_espera=60)
print("Configuración 3:", config3)
# Equivalente a: host="api.example.com", puerto=8080, protocolo="https", seguridad=True, tiempo_espera=60

# 4. Ejemplo más complejo con argumentos mixtos

def procesar_archivo(archivo, operacion="leer", formato="texto", codificacion="utf-8", validar=True):
    """Procesa un archivo con diferentes operaciones."""
    print(f"Procesando {archivo}")

procesar_archivo(
    archivo="datos.txt",
    operacion="escribir",
    formato="json",
    validar=True
)
Argumentos por Posición
  • Se asignan según el orden en que aparecen
  • No necesitas especificar el nombre del parámetro
  • Más concisos para funciones simples
  • El orden sí importa
funcion(valor1, valor2, valor3)
Argumentos por Nombre
  • Se asignan usando el nombre del parámetro
  • Especificas explícitamente qué valor va a qué parámetro
  • Más legibles para funciones complejas
  • El orden no importa
funcion(param1=valor1, param2=valor2)

Recomendación

Usa argumentos por nombre cuando:

  • La función tiene muchos parámetros
  • Algunos parámetros tienen valores por defecto
  • Quieres mejorar la legibilidad del código
  • Estás trabajando en equipo y quieres que el código sea auto-documentado

3. Número Variable de Argumentos (*args, **kwargs)

Python permite crear funciones que acepten un número variable de argumentos usando *args (para argumentos posicionales) y **kwargs (para argumentos por nombre).

# *args: Número variable de argumentos posicionales
def sumar_todos(*numeros):
    """
    Suma todos los números pasados como argumentos.
    
    Args:
        *numeros: Números a sumar (cualquier cantidad)
        
    Returns:
        float: Suma de todos los números
    """
    return sum(numeros)

# Uso de *args
suma1 = sumar_todos(1, 2, 3)           # 6
suma2 = sumar_todos(10, 20, 30, 40)    # 100
suma3 = sumar_todos()                  # 0 (sin argumentos)

print(f"Suma 1: {suma1}, Suma 2: {suma2}, Suma 3: {suma3}")

# **kwargs: Número variable de argumentos por nombre
def configurar_base_datos(**configuracion):
    """
    Configura una base de datos con parámetros variables.
    
    Args:
        **configuracion: Parámetros de configuración (nombre=valor)
        
    Returns:
        dict: Configuración aplicada
    """
    print("Configuración de base de datos:")
    for clave, valor in configuracion.items():
        print(f"  {clave}: {valor}")
    return configuracion

# Uso de **kwargs
config1 = configurar_base_datos(host="localhost", puerto=5432, usuario="admin")
config2 = configurar_base_datos(
    host="db.example.com",
    puerto=3306,
    usuario="root",
    contrasena="secreta",
    base_datos="produccion"
)

# Combinación de parámetros normales con *args y **kwargs
def generar_reporte(titulo, *datos, **opciones):
    """
    Genera un reporte con datos variables y opciones de formato.
    
    Args:
        titulo (str): Título del reporte
        *datos: Datos a incluir en el reporte
        **opciones: Opciones de formato
        
    Returns:
        str: Reporte formateado
    """
    # Procesar opciones con valores por defecto
    formato = opciones.get("formato", "texto")
    incluir_total = opciones.get("incluir_total", True)
    separador = opciones.get("separador", "-")
    
    if formato == "html":
        # Construir reporte en formato HTML desde el principio
        reporte = [f"
{titulo}
"]
        
        # Filtrar elementos válidos (no None, no vacío)
        elementos_validos = []
        if datos:
            elementos_validos = [dato for dato in datos if dato and str(dato).strip()]
        
        # Solo crear 
     si hay elementos válidos
        if elementos_validos:
            reporte.append("
      ")
            for dato in elementos_validos:
                reporte.append(f"
    • {dato}
      • ")
            reporte.append("
    ")
        
        if incluir_total:
            total = len(elementos_validos)
            reporte.append(f"
    Total: {total}
    ")
        
        return "\n".join(reporte)
    else:
        # Construir reporte en formato texto
        reporte = [f"=== {titulo} ==="]
        
        for i, dato in enumerate(datos, 1):
            reporte.append(f"{i}. {dato}")
        
        if incluir_total:
            total = len(datos)
            reporte.append(f"\nTotal de elementos: {total}")
        
        return f"\n{separador * 20}\n".join(reporte)

# Uso de la función combinada
reporte1 = generar_reporte("Productos", "Manzanas", "Peras", "Plátanos")
print(reporte1)

reporte2 = generar_reporte(
    "Ventas del Mes",
    "Producto A", "Producto B", "Producto C", "Producto D",
    formato="html",
    incluir_total=True,
    separador="="
)
print(f"\n{reporte2}")

# Función avanzada: calculadora flexible
def calculadora_flexible(operacion, *numeros, **opciones):
    """
    Calculadora que acepta operaciones y números variables.
    
    Args:
        operacion (str): Operación a realizar (+, -, *, /)
        *numeros: Números para la operación
        **opciones: Opciones adicionales
        
    Returns:
        float or str: Resultado de la operación
    """
    if not numeros:
        return "Error: No se proporcionaron números"
    
    # Obtener opciones
    precision = opciones.get("precision", 2)
    
    try:
        if operacion == "+":
            resultado = sum(numeros)
        elif operacion == "-":
            resultado = numeros[0]
            for num in numeros[1:]:
                resultado -= num
        elif operacion == "*":
            resultado = 1
            for num in numeros:
                resultado *= num
        elif operacion == "/":
            resultado = numeros[0]
            for num in numeros[1:]:
                if num == 0:
                    return "Error: División por cero"
                resultado /= num
        else:
            return f"Error: Operación '{operacion}' no soportada"
        
        if opciones.get("redondear", False):
            resultado = round(resultado, precision)
            
        return resultado
        
    except Exception as e:
        return f"Error: {str(e)}"

# Uso de la calculadora flexible
print("\nCalculadora flexible:")
print(f"Suma: {calculadora_flexible('+', 10, 20, 30)}")
print(f"Resta: {calculadora_flexible('-', 100, 25, 15)}")
print(f"Multiplicación: {calculadora_flexible('*', 2, 3, 4, 5)}")
print(f"División: {calculadora_flexible('/', 100, 2, 5)}")
print(f"Con redondeo: {calculadora_flexible('+', 1.1, 2.2, 3.3, redondear=True)}")

Cuidado con Listas Mutables

Cuando uses listas o diccionarios como valores por defecto para parámetros opcionales, todos los llamados compartirán la misma instancia. Esto puede causar efectos inesperados:

# ¡Problema potencial!
def agregar_elemento(elemento, lista=[]):
    lista.append(elemento)
    return lista

resultado1 = agregar_elemento(1)  # [1]
resultado2 = agregar_elemento(2)  # [1, 2] ¡Incluye el 1 también!

# Solución correcta:
def agregar_elemento(elemento, lista=None):
    if lista is None:
        lista = []
    lista.append(elemento)
    return lista

¿Cuándo usar *args y **kwargs?

  • *args: Cuando necesitas aceptar un número variable de argumentos posicionales
  • **kwargs: Cuando necesitas aceptar un número variable de argumentos por nombre
  • Ambos: Para crear funciones altamente flexibles y reutilizables
  • Úsalos con moderación: Pueden hacer que las funciones sean más difíciles de entender y mantener

Ejemplo 1: Función de Cálculo de Estadísticas

Crearemos una función flexible que calcule diferentes estadísticas de una lista de números.

Función de Estadísticas Flexible

Implementación Completa
def calcular_estadisticas(
    numeros,                    # Lista de números (obligatorio)
    incluir_media=True,        # Calcular media (opcional)
    incluir_mediana=True,      # Calcular mediana (opcional)
    incluir_moda=True,         # Calcular moda (opcional)
    incluir_desviacion=True,   # Calcular desviación estándar (opcional)
    precision=2,               # Precisión decimal (opcional)
    ordenar_resultados=False   # Ordenar resultados alfabéticamente (opcional)
):
    """
    Calcula estadísticas básicas de una lista de números.
    
    Args:
        numeros (list): Lista de números para analizar
        incluir_media (bool): Incluir cálculo de media
        incluir_mediana (bool): Incluir cálculo de mediana
        incluir_moda (bool): Incluir cálculo de moda
        incluir_desviacion (bool): Incluir desviación estándar
        precision (int): Número de decimales para resultados
        ordenar_resultados (bool): Ordenar resultados alfabéticamente
        
    Returns:
        dict: Diccionario con las estadísticas calculadas
    """
    if not numeros:
        return {"error": "La lista de números está vacía"}
    
    resultados = {}
    
    # Estadísticas básicas siempre incluidas
    resultados["cantidad"] = len(numeros)
    resultados["minimo"] = min(numeros)
    resultados["maximo"] = max(numeros)
    resultados["suma"] = sum(numeros)
    
    # Media (promedio)
    if incluir_media:
        resultados["media"] = round(sum(numeros) / len(numeros), precision)
    
    # Mediana
    if incluir_mediana:
        numeros_ordenados = sorted(numeros)
        n = len(numeros_ordenados)
        if n % 2 == 0:
            mediana = (numeros_ordenados[n//2 - 1] + numeros_ordenados[n//2]) / 2
        else:
            mediana = numeros_ordenados[n//2]
        resultados["mediana"] = round(mediana, precision)
    
    # Moda (número que más se repite)
    if incluir_moda:
        from collections import Counter
        conteo = Counter(numeros)
        max_frecuencia = max(conteo.values())
        modas = [num for num, freq in conteo.items() if freq == max_frecuencia]
        resultados["moda"] = modas if len(modas) > 1 else modas[0] if modas else None
    
    # Desviación estándar
    if incluir_desviacion:
        import math
        media = sum(numeros) / len(numeros)
        varianza = sum((x - media) ** 2 for x in numeros) / len(numeros)
        desviacion = math.sqrt(varianza)
        resultados["desviacion_estandar"] = round(desviacion, precision)
    
    # Ordenar resultados si se solicita
    if ordenar_resultados:
        resultados = dict(sorted(resultados.items()))
    
    return resultados

# Uso de la función con diferentes configuraciones
datos = [85, 92, 78, 85, 88, 92, 85, 76, 92, 88]

# Todas las estadísticas
estadisticas_completas = calcular_estadisticas(datos)
print("Estadísticas completas:")
for clave, valor in estadisticas_completas.items():
    print(f"  {clave}: {valor}")

# Solo estadísticas básicas
estadisticas_basicas = calcular_estadisticas(
    datos,
    incluir_media=False,
    incluir_mediana=False,
    incluir_moda=False,
    incluir_desviacion=False
)
print(f"\nEstadísticas básicas: {estadisticas_basicas}")

# Estadísticas ordenadas con precisión específica
estadisticas_ordenadas = calcular_estadisticas(
    datos,
    precision=3,
    ordenar_resultados=True
)
print(f"\nEstadísticas ordenadas (3 decimales): {estadisticas_ordenadas}")

# Solo media y desviación estándar
estadisticas_parciales = calcular_estadisticas(
    datos,
    incluir_mediana=False,
    incluir_moda=False,
    precision=4
)
print(f"\nEstadísticas parciales: {estadisticas_parciales}")

def formatear_mensaje(
    mensaje,                    # Mensaje principal (obligatorio)
    tipo="info",               # Tipo de mensaje (opcional)
    *args,                     # Información adicional (variable)
    estilo="normal",           # Estilo de formato (opcional)
    mayusculas=False,          # Convertir a mayúsculas (opcional)
    incluir_timestamp=True,    # Incluir marca de tiempo (opcional)
    separador=" | ",           # Separador entre elementos (opcional)
    **kwargs                   # Opciones adicionales (variable)
):
    """
    Formatea un mensaje con múltiples opciones de estilo y formato.
    
    Args:
        mensaje (str): Mensaje principal a formatear
        tipo (str): Tipo de mensaje ("info", "warning", "error", "success")
        *args: Información adicional a incluir
        estilo (str): Estilo de formato ("normal", "titulo", "lista")
        mayusculas (bool): Convertir mensaje a mayúsculas
        incluir_timestamp (bool): Incluir marca de tiempo
        separador (str): Separador entre elementos
        **kwargs: Opciones adicionales para formateo
        
    Returns:
        str: Mensaje formateado
    """
    # Diccionario de prefijos por tipo
    prefijos = {
        "info": "ℹ️",
        "warning": "⚠️",
        "error": "❌",
        "success": "✅",
        "debug": "🔍"
    }
    
    # Diccionario de colores por tipo (para futuras mejoras)
    colores = {
        "info": "azul",
        "warning": "amarillo",
        "error": "rojo",
        "success": "verde",
        "debug": "gris"
    }
    
    # Construir el mensaje formateado
    elementos = []
    
    # Agregar prefijo según el tipo
    prefijo = prefijos.get(tipo.lower(), prefijos["info"])
    elementos.append(prefijo)
    
    # Procesar el mensaje principal
    texto = mensaje
    if mayusculas:
        texto = texto.upper()
    
    elementos.append(texto)
    
    # Agregar información adicional si existe
    if args:
        info_adicional = separador.join(str(arg) for arg in args)
        elementos.append(f"({info_adicional})")
    
    # Agregar marca de tiempo si está habilitada
    if incluir_timestamp:
        from datetime import datetime
        timestamp = datetime.now().strftime("%H:%M:%S")
        elementos.append(f"[{timestamp}]")
    
    # Aplicar estilo específico
    resultado = separador.join(elementos)
    
    if estilo == "titulo":
        resultado = f"=== {resultado} ==="
    elif estilo == "lista":
        resultado = f"• {resultado}"
    elif estilo == "caja":
        resultado = f"┌─ {resultado} ─┐"
    
    # Aplicar opciones adicionales
    if kwargs.get("centrado", False):
        ancho = kwargs.get("ancho", 50)
        resultado = resultado.center(ancho)
    
    if kwargs.get("negrita", False):
        resultado = f"**{resultado}**"
    
    return resultado

# Uso del formateador flexible
print("=== EJEMPLOS DE FORMATEO ===\n")

# Mensaje básico
print(formatear_mensaje("Sistema iniciado correctamente"))

Opciones de Configuración
def generar_informe_personalizado(
    titulo,                          # Título del informe (obligatorio)
    datos,                          # Datos a incluir (obligatorio)
    formato="texto",                # Formato de salida (opcional)
    *secciones,                     # Secciones adicionales (variable)
    estilo_encabezado="normal",     # Estilo del encabezado (opcional)
    incluir_resumen=True,           # Incluir sección de resumen (opcional)
    incluir_conclusiones=True,      # Incluir conclusiones (opcional)
    ordenar_claves=False,           # Ordenar claves alfabéticamente (opcional)
    limite_decimales=2,             # Límite de decimales (opcional)
    unidad_moneda="$",              # Unidad de moneda (opcional)
    **opciones_formato               # Opciones adicionales de formato (variable)
):
    """
    Genera un informe altamente personalizable con múltiples opciones.
    
    Args:
        titulo (str): Título del informe
        datos (dict): Datos principales del informe
        formato (str): Formato de salida ("texto", "html", "json")
        *secciones: Secciones adicionales a incluir
        estilo_encabezado (str): Estilo del encabezado
        incluir_resumen (bool): Incluir sección de resumen
        incluir_conclusiones (bool): Incluir sección de conclusiones
        ordenar_claves (bool): Ordenar claves alfabéticamente
        limite_decimales (int): Número máximo de decimales
        unidad_moneda (str): Símbolo de moneda
        **opciones_formato: Opciones adicionales de formato
        
    Returns:
        str: Informe formateado según las especificaciones
    """
    # Procesar claves de datos
    claves_datos = list(datos.keys())
    if ordenar_claves:
        claves_datos.sort()
    
    # Construir encabezado según el estilo
    if estilo_encabezado == "titulo":
        encabezado = f"=== {titulo} ==="
    elif estilo_encabezado == "subrayado":
        encabezado = f"{titulo}\n{'=' * len(titulo)}"
    elif estilo_encabezado == "caja":
        encabezado = f"┌{'─' * (len(titulo) + 2)}┐\n│ {titulo} │\n└{'─' * (len(titulo) + 2)}┘"
    else:
        encabezado = titulo
    
    lineas = [encabezado, ""]
    
    # Agregar datos principales
    lineas.append("DATOS PRINCIPALES:")
    lineas.append("-" * 20)
    
    for clave in claves_datos:
        valor = datos[clave]
        
        # Formatear valores numéricos
        if isinstance(valor, (int, float)):
            if "." in str(valor):
                valor = round(valor, limite_decimales)
            if "precio" in clave.lower() or "costo" in clave.lower():
                valor = f"{unidad_moneda}{valor:,.{limite_decimales}f}"
        
        lineas.append(f"{clave.replace('_', ' ').title()}: {valor}")
    
    # Agregar secciones adicionales
    for seccion in secciones:
        lineas.extend(["", seccion.upper() + ":", "-" * 20])
        # Aquí podrías agregar lógica específica para cada sección
    
    # Agregar resumen si está habilitado
    if incluir_resumen:
        lineas.extend([
            "",
            "RESUMEN:",
            "-" * 10,
            generar_resumen(datos)
        ])
    
    # Agregar conclusiones si están habilitadas
    if incluir_conclusiones:
        lineas.extend([
            "",
            "CONCLUSIONES:",
            "-" * 15,
            generar_conclusiones(datos, opciones_formato)
        ])
    
    # Agregar metadatos si están habilitados
    if opciones_formato.get("incluir_metadata", False):
        from datetime import datetime
        lineas.extend([
            "",
            "METADATOS:",
            "-" * 11,
            f"Generado: {datetime.now().strftime('%d/%m/%Y %H:%M:%S')}",
            f"Formato: {formato}",
            f"Opciones: {opciones_formato}"
        ])
    
    resultado = "\n".join(lineas)
    
    # Aplicar formato específico si se solicita
    if formato == "html":
        resultado = convertir_a_html(resultado)
    elif formato == "json":
        resultado = convertir_a_json(titulo, datos, secciones, opciones_formato)
    
    return resultado

def generar_resumen(datos):
    """Genera un resumen básico de los datos."""
    resumen = []
    if "total" in datos:
        resumen.append(f"Total general: {datos['total']}")
    if "promedio" in datos:
        resumen.append(f"Valor promedio: {datos['promedio']}")
    if "cantidad" in datos:
        resumen.append(f"Elementos procesados: {datos['cantidad']}")
    
    return "\n".join(resumen) if resumen else "Resumen no disponible"

def generar_conclusiones(datos, opciones):
    """Genera conclusiones basadas en los datos."""
    conclusiones = []
    
    # Ejemplo de lógica de conclusiones
    if "eficiencia" in datos and datos["eficiencia"] > 90:
        conclusiones.append("✅ Excelente rendimiento alcanzado")
    elif "eficiencia" in datos and datos["eficiencia"] > 70:
        conclusiones.append("⚠️ Rendimiento aceptable, hay margen de mejora")
    else:
        conclusiones.append("❌ Rendimiento por debajo del estándar")
    
    if opciones.get("recomendaciones", True):
        conclusiones.append("💡 Revisar procesos para optimización continua")
    
    return "\n".join(conclusiones) if conclusiones else "Conclusiones no disponibles"

def convertir_a_html(texto_plano):
    """Convierte texto plano a formato HTML básico."""
    lineas = texto_plano.split('\n')
    html_lineas = ["
"]
    
    for linea in lineas:
        if linea.startswith("===") and linea.endswith("==="):
            html_lineas.append(f"
{linea.strip('=')}
")
        elif linea.startswith("---"):
            html_lineas.append("
")
        elif ": " in linea:
            clave, valor = linea.split(": ", 1)
            html_lineas.append(f"
{clave}: {valor}
")
        elif linea.strip():
            html_lineas.append(f"
{linea}
")
    
    html_lineas.append("
")
    return "\n".join(html_lineas)

def convertir_a_json(titulo, datos, secciones, opciones):
    """Convierte datos a formato JSON."""
    import json
    
    estructura = {
        "titulo": titulo,
        "datos": datos,
        "secciones": list(secciones),
        "opciones": opciones,
        "timestamp": datetime.now().isoformat()
    }
    
    return json.dumps(estructura, indent=2, ensure_ascii=False)
