Objetivo de la Sesión

En esta sesión, aprenderás a trabajar con listas en Python, una de las estructuras de datos más versátiles y utilizadas. Las listas te permiten almacenar colecciones ordenadas de elementos de diferentes tipos de datos.

Al finalizar esta sesión, podrás:

  • Crear y manipular listas en Python
  • Acceder y modificar elementos de una lista
  • Utilizar los métodos básicos de las listas
  • Aplicar listas en situaciones prácticas

Conceptos Clave

1. Creación de Listas

Las listas en Python son colecciones ordenadas y mutables de elementos. Pueden contener elementos de diferentes tipos de datos.

# Crear una lista vacía
lista_vacia = []
lista_vacia2 = list()

# Crear una lista con elementos
numeros = [1, 2, 3, 4, 5]
frutas = ["manzana", "banana", "cereza"]
mezclada = [1, "hola", 3.14, True]

# Listas anidadas
matriz = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]

# Usando el constructor list()
olimpicos = list(("Río 2016", "Tokio 2020", "París 2024"))

💡 Dato curioso

En Python, las listas son dinámicas, lo que significa que pueden crecer o reducirse según sea necesario, a diferencia de los arreglos en otros lenguajes de programación que tienen un tamaño fijo.

2. Acceso a Elementos

Puedes acceder a los elementos de una lista utilizando índices. En Python, los índices comienzan en 0.

frutas = ["manzana", "banana", "cereza", "dátil", "fresa"]

# Acceso por índice (comienza en 0)
primera_fruta = frutas[0]     # "manzana"
tercera_fruta = frutas[2]     # "cereza"

# Índices negativos (cuentan desde el final)
ultima_fruta = frutas[-1]     # "fresa"
penultima = frutas[-2]        # "dátil"

# Rebanado (slicing)
primeras_tres = frutas[0:3]   # ["manzana", "banana", "cereza"]
desde_segunda = frutas[1:]    # ["banana", "cereza", "dátil", "fresa"]
hasta_tercera = frutas[:3]    # ["manzana", "banana", "cereza"]
todas = frutas[:]            # Copia de la lista original

# Paso en el rebanado
pares = frutas[::2]          # ["manzana", "cereza", "fresa"]
invertida = frutas[::-1]     # Lista invertida

⚠️ Índices fuera de rango

Si intentas acceder a un índice que no existe, Python generará un error IndexError. Siempre verifica la longitud de la lista con len(lista) antes de acceder a un índice desconocido.

3. Métodos Básicos de Listas

Las listas en Python tienen varios métodos incorporados para manipular sus elementos.

# Crear una lista de ejemplo
numeros = [1, 2, 3]

# Añadir elementos
numeros.append(4)           # Añade al final: [1, 2, 3, 4]
numeros.insert(1, 1.5)      # Inserta en posición: [1, 1.5, 2, 3, 4]
numeros.extend([5, 6])      # Extiende con otra lista: [1, 1.5, 2, 3, 4, 5, 6]

# Eliminar elementos
ultimo = numeros.pop()      # Elimina y devuelve el último: 6
segundo = numeros.pop(1)    # Elimina y devuelve el índice 1: 1.5
numeros.remove(3)           # Elimina el primer 3 encontrado
# numeros.clear()           # Vacía la lista

# Obtener información
indice = numeros.index(2)   # Devuelve el índice del valor 2
conteo = numeros.count(1)   # Cuenta cuántas veces aparece 1
existe = 4 in numeros       # Verifica si 4 está en la lista

# Ordenar y revertir
numeros.sort()              # Ordena la lista
numeros.reverse()           # Invierte el orden actual

# Obtener longitud
tamano = len(numeros)       # Número de elementos

💡 Inmutabilidad de los métodos

Algunos métodos como sort() y reverse() modifican la lista original. Si necesitas mantener la lista original, usa sorted(lista) o lista[::-1] que devuelven una nueva lista.

4. Operaciones con Listas

Puedes realizar varias operaciones con listas, como concatenación, repetición y más.

# Concatenación
lista1 = [1, 2, 3]
lista2 = [4, 5, 6]
combinada = lista1 + lista2  # [1, 2, 3, 4, 5, 6]

# Repetición
repetida = [0] * 5          # [0, 0, 0, 0, 0]

# Verificación de pertenencia
print(2 in [1, 2, 3])       # True
print(5 not in [1, 2, 3])   # True

# Iteración
for numero in [1, 2, 3]:
    print(numero * 2)       # 2, 4, 6

# Comprensión de listas (más en sesiones futuras)
cuadrados = [x**2 for x in range(5)]  # [0, 1, 4, 9, 16]

💡 Copiar listas correctamente

Ten cuidado al copiar listas. Usar nueva = vieja solo crea una referencia, no una copia. Para copiar una lista, usa nueva = vieja.copy() o nueva = list(vieja) o nueva = vieja[:].

Actividades Prácticas

Actividad 1: Creación y Manipulación de Listas

Crea un programa que permita al usuario crear y manipular una lista de compras.

Ejemplo de salida:

=== Lista de Compras ===
1. Ver lista
2. Añadir artículo
3. Eliminar artículo
4. Ver cantidad de artículos
5. Salir

Opción: 2
Ingrese el artículo a añadir: Manzanas
'Manzanas' ha sido añadido a la lista.

Opción: 1
Tu lista de compras:
1. Manzanas

Usa un bucle while para mantener el menú activo hasta que el usuario elija salir. Para cada opción, utiliza los métodos de lista correspondientes (append(), remove(), len(), etc.).

Actividad 2: Estadísticas de Números

Desarrolla un programa que pida al usuario una serie de números y muestre estadísticas básicas.

Ejemplo de ejecución:

=== Estadísticas de Números ===
Ingrese números (escriba 'fin' para terminar):
Número: 10
Número: 15
Número: 20
Número: 10
Número: fin

Resultados:
Números ingresados: [10, 15, 20, 10]
Suma: 55
Promedio: 13.75
Máximo: 20
Mínimo: 10

Usa un bucle while para solicitar números hasta que el usuario ingrese 'fin'. Convierte cada entrada a número y guárdala en una lista. Luego, usa las funciones sum(), max(), min() y len() para calcular las estadísticas.

Actividad 3: Lista de Tareas Pendientes

Crea un gestor de tareas que permita marcar tareas como completadas.

Ejemplo:

=== Gestor de Tareas ===
1. Ver tareas
2. Agregar tarea
3. Marcar como completada
4. Salir

Opción: 2
Ingrese la nueva tarea: Hacer la compra
Tarea agregada: Hacer la compra

Opción: 1
Tareas pendientes:
[ ] 1. Hacer la compra
[ ] 2. Estudiar Python

Opción: 3
Ingrese el número de tarea completada: 1
¡Tarea marcada como completada!

Opción: 1
Tareas pendientes:
[X] 1. Hacer la compra
[ ] 2. Estudiar Python

Considera usar una lista de diccionarios para almacenar las tareas, donde cada diccionario tenga las propiedades 'descripcion' y 'completada'. Para marcar una tarea como completada, actualiza el valor de 'completada' a True.

Actividad 4: Búsqueda en Listas

Desarrolla un programa que permita buscar elementos en una lista de contactos.

Ejemplo de ejecución:

=== Buscador de Contactos ===
1. Agregar contacto
2. Buscar contacto
3. Ver todos los contactos
4. Salir

Opción: 1
Nombre: Ana Pérez
Teléfono: 555-1234
Contacto agregado correctamente.

Opción: 2
Término de búsqueda: ana
Resultados de búsqueda:
- Ana Pérez: 555-1234

Almacena cada contacto como un diccionario dentro de una lista. Para la búsqueda, itera sobre la lista de contactos y verifica si el término de búsqueda está contenido en el nombre o el teléfono (usando in). Convierte ambos a minúsculas para hacer la búsqueda insensible a mayúsculas/minúsculas.
