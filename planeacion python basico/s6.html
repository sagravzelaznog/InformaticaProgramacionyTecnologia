Objetivo de la Sesión

Comprender los conceptos fundamentales de la lógica booleana y cómo se aplican en la programación a través de operadores de comparación y expresiones lógicas.

Al finalizar esta sesión, podrás:

  • Entender los valores booleanos True y False
  • Utilizar operadores de comparación para crear expresiones booleanas
  • Combinar expresiones booleanas con operadores lógicos
  • Aplicar la lógica booleana en situaciones prácticas

Conceptos Clave

1. Valores Booleanos: True y False

En Python, los valores booleanos son un tipo de dato que solo puede ser True (Verdadero) o False (Falso). Son fundamentales para el control de flujo en los programas.

# Valores booleanos básicos
verdadero = True
falso = False

# Los valores booleanos son sensibles a mayúsculas/minúsculas
print(type(True))    # 
print(type(False))   # 
print(type(true))    # Error: NameError: name 'true' is not defined

💡 Dato curioso

En Python, los valores booleanos son en realidad una subclase de enteros, donde True es igual a 1 y False es igual a 0.

2. Operadores de Comparación

Los operadores de comparación se utilizan para comparar dos valores y devuelven un valor booleano como resultado.

# Igualdad (==)
print(5 == 5)    # True
print(5 == 3)    # False

# Desigualdad (!=)
print(5 != 3)    # True
print(5 != 5)    # False

# Mayor que (>)
print(5 > 3)     # True
print(3 > 5)     # False

# Menor que (<)
print(3 < 5)     # True
print(5 < 3)     # False

# Mayor o igual que (>=)
print(5 >= 5)    # True
print(4 >= 5)    # False

# Menor o igual que (<=)
print(5 <= 5)    # True
print(6 <= 5)    # False

⚠️ Presta atención

No confundas el operador de asignación = con el operador de igualdad ==. El primero asigna un valor a una variable, mientras que el segundo compara dos valores.

3. Operadores Lógicos

Los operadores lógicos te permiten combinar múltiples condiciones en una sola expresión.

# AND (y lógico) - Todas las condiciones deben ser verdaderas
print(True and True)     # True
print(True and False)    # False

# OR (o lógico) - Al menos una condición debe ser verdadera
print(True or False)     # True
print(False or False)    # False

# NOT (negación) - Invierte el valor booleano
print(not True)          # False
print(not False)         # True

# Combinando operadores
edad = 20
tiene_licencia = True
print(edad >= 18 and tiene_licencia)  # True

# Precedencia de operadores: not > and > or
print(True or False and False)  # True (el and se evalúa primero)
print((True or False) and False)  # False (los paréntesis cambian el orden)

💡 Regla mnemotécnica

Recuerda que and es como la multiplicación (todos deben ser 1/True) y or es como la suma (basta con que uno sea 1/True).

4. Valores que se evalúan como False

En Python, ciertos valores se consideran "falsos" en un contexto booleano. Todos los demás valores se consideran verdaderos.

# Valores que se evalúan como False
valores_falsos = [False, None, 0, 0.0, "", [], (), {}, set()]

# Verificación
for valor in valores_falsos:
    if not valor:
        print(f"{repr(valor)} se evalúa como False")

# Ejemplo práctico
nombre = ""
if nombre:
    print(f"Hola, {nombre}")
else:
    print("No se proporcionó ningún nombre")  # Se ejecuta esta línea

💡 Buenas prácticas

Puedes aprovechar esta característica para escribir código más conciso. Por ejemplo, en lugar de if len(lista) > 0: puedes simplemente escribir if lista:.

Actividades Prácticas

Actividad 1: Verificador de Edad

Crea un programa que pida la edad del usuario y determine si puede realizar ciertas actividades.

Ejemplo de salida:

=== Verificador de Edad ===
Ingrese su edad: 16

Puedes:
- Conducir un auto: No (requiere 18 años)
- Votar: No (requiere 18 años)
- Tomar bebidas alcohólicas: No (requiere 21 años)
- Entrar a la montaña rusa: Sí (requiere 12 años)

Usa múltiples declaraciones condicionales if para verificar cada condición. Recuerda que puedes anidar condiciones cuando sea necesario.

Actividad 2: Comparador de Números

Desarrolla un programa que pida dos números al usuario y muestre la relación entre ellos.

Ejemplo de ejecución:

=== Comparador de Números ===
Ingrese el primer número: 10
Ingrese el segundo número: 20

Resultados:
10 es menor que 20
10 no es igual a 20
10 es menor o igual que 20

Usa los operadores de comparación (>, <, ==, >=, <=, !=) para comparar los dos números. Recuerda convertir las entradas a números con int() o float().

Actividad 3: Validador de Contraseñas

Crea un programa que valide si una contraseña cumple con ciertos requisitos de seguridad.

Requisitos:

  • Al menos 8 caracteres de longitud
  • Al menos una letra mayúscula
  • Al menos una letra minúscula
  • Al menos un número

Ejemplo:

=== Validador de Contraseñas ===
Ingrese su contraseña: Segura123

Análisis de seguridad:
- Longitud suficiente: ✓
- Tiene mayúsculas: ✓
- Tiene minúsculas: ✓
- Tiene números: ✓

¡Contraseña válida!

Puedes usar los métodos de cadenas isupper(), islower() e isdigit() para verificar los caracteres. También puedes usar una variable booleana para cada requisito y combinarlas con operadores lógicos.

Actividad 4: Clasificador de Números

Desarrolla un programa que pida al usuario un número y lo clasifique según diferentes criterios.

Ejemplo de ejecución:

=== Clasificador de Números ===
Ingrese un número: 42

Análisis del número 42:
- Es par: Sí
- Es positivo: Sí
- Es múltiplo de 3: Sí
- Es mayor que 100: No
- Está entre 1 y 100: Sí

Para verificar si un número es par, usa el operador módulo % (el residuo de la división entre 2 debe ser 0). Para verificar si es múltiplo de 3, verifica si el residuo de la división entre 3 es 0.
