Objetivo de la Sesión

Aprender a crear programas interactivos que puedan recibir información del usuario, procesarla y mostrar resultados significativos, manejando adecuadamente los diferentes tipos de datos.

Al finalizar esta sesión, podrás:

  • Utilizar la función input() para recibir datos del usuario
  • Convertir entre diferentes tipos de datos en Python
  • Validar la entrada del usuario para evitar errores
  • Manejar excepciones básicas en la entrada de datos

Conceptos Clave

1. La Función input()

La función input() permite que el usuario ingrese datos a través del teclado. Por defecto, siempre devuelve los datos como una cadena de texto (str).

# Ejemplo básico de input()
nombre = input("¿Cuál es tu nombre? ")
print(f"¡Hola, {nombre}!")

💡 Buenas prácticas con input()

  • Siempre incluye un mensaje claro que indique qué tipo de entrada esperas
  • Considera agregar un espacio al final del mensaje para mejor legibilidad
  • Recuerda que el valor devuelto siempre es una cadena de texto

2. Conversión de Tipos de Datos

Como input() siempre devuelve una cadena, a menudo necesitarás convertir el valor al tipo de dato adecuado.

# Convertir a entero (int)
edad = int(input("¿Cuántos años tienes? "))

# Convertir a número decimal (float)
precio = float(input("Ingrese el precio: "))

# Convertir a booleano (bool)
es_estudiante = input("¿Eres estudiante? (sí/no): ").lower() == 'sí'

# Mostrar los tipos de datos
print(f"Tipo de edad: {type(edad)}")
print(f"Tipo de precio: {type(precio)}")
print(f"Tipo de es_estudiante: {type(es_estudiante)}")

⚠️ Cuidado con las conversiones

Si el usuario ingresa un valor que no puede convertirse al tipo solicitado, se producirá un error. Por ejemplo, intentar convertir "abc" a un entero generará un ValueError.

3. Validación de Entrada

Es importante validar la entrada del usuario para evitar errores en tiempo de ejecución.

# Validar entrada numérica
def obtener_numero(mensaje):
    while True:
        entrada = input(mensaje)
        if entrada.isdigit():
            return int(entrada)
        print("Error: Por favor ingrese un número válido.")

# Uso
edad = obtener_numero("¿Cuántos años tienes? ")
print(f"Tienes {edad} años.")

Métodos útiles para validación:

# Verificar si una cadena es un número entero
"123".isdigit()  # True
"12.3".isdigit()  # False
"abc".isdigit()   # False

# Verificar si una cadena es un número (incluyendo decimales)
def es_numero(valor):
    try:
        float(valor)
        return True
    except ValueError:
        return False

# Verificar si una cadena está vacía o solo contiene espacios
"".strip() == ""  # True
"   ".strip() == ""  # True
"hola".strip() == ""  # False

4. Manejo de Excepciones con try-except

El manejo de excepciones nos permite controlar errores que pueden ocurrir durante la ejecución del programa.

# Manejo básico de excepciones
try:
    numero = int(input("Ingrese un número: "))
    print(f"El doble es: {numero * 2}")
except ValueError:
    print("Error: Debe ingresar un número entero válido.")

Manejo de múltiples excepciones:

try:
    # Código que podría generar errores
    numerador = int(input("Ingrese el numerador: "))
    denominador = int(input("Ingrese el denominador: "))
    resultado = numerador / denominador
    print(f"El resultado es: {resultado}")
    
except ValueError:
    print("Error: Debe ingresar números enteros.")
except ZeroDivisionError:
    print("Error: No se puede dividir entre cero.")
except Exception as e:
    print(f"Ocurrió un error inesperado: {e}")
else:
    print("Operación completada exitosamente.")
finally:
    print("Fin del programa.")

💡 Buenas prácticas con excepciones

  • Sé específico con los tipos de excepciones que capturas
  • Evita usar except sin especificar el tipo de excepción
  • Proporciona mensajes de error claros y útiles
  • Usa else para código que debe ejecutarse solo si no hay excepciones
  • Usa finally para código de limpieza que debe ejecutarse siempre

Actividades Prácticas

Actividad 1: Saludo Personalizado

Crea un programa que pida al usuario su nombre, edad y ciudad de residencia, y muestre un mensaje personalizado que incluya esta información.

Ejemplo de salida:

Bienvenido al sistema, Ana.
Veo que tienes 28 años y vives en la ciudad de Madrid.
¡Esperamos que tengas un excelente día!

Recuerda que la función input() siempre devuelve una cadena. Si necesitas la edad como número, debes convertirla a entero con int().

Actividad 2: Calculadora Interactiva

Crea una calculadora que permita al usuario realizar operaciones básicas (suma, resta, multiplicación, división) con dos números.

Ejemplo de ejecución:

=== Calculadora Básica ===
Ingrese el primer número: 10
Ingrese la operación (+, -, *, /): *
Ingrese el segundo número: 5
El resultado de 10 * 5 es: 50.0

Usa una estructura condicional (if-elif-else) para determinar qué operación realizar según lo que ingrese el usuario.

Actividad 3: Conversor de Monedas

Crea un programa que convierta entre diferentes monedas. El usuario debe poder elegir la moneda de origen, la moneda de destino y el monto a convertir.

Ejemplo de menú:

=== Conversor de Monedas ===
Monedas disponibles:
1. Dólares (USD)
2. Euros (EUR)
3. Pesos Mexicanos (MXN)
4. Yenes (JPY)

Seleccione la moneda de origen (1-4): 1
Seleccione la moneda de destino (1-4): 3
Ingrese el monto a convertir: 100
100.00 USD = 1,700.00 MXN (tasa de cambio: 17.00)

Puedes usar un diccionario para almacenar las tasas de cambio con respecto a una moneda base, por ejemplo, el dólar.

tasas = {
    'USD': 1.0,
    'EUR': 0.85,
    'MXN': 17.0,
    'JPY': 110.0
}

Actividad 4: Cuestionario Interactivo

Crea un cuestionario de 5 preguntas con opciones múltiples. El programa debe llevar la cuenta de las respuestas correctas y mostrar el puntaje final.

Ejemplo de ejecución:

=== Cuestionario de Cultura General ===

1. ¿Cuál es la capital de Francia?
   a) Londres
   b) París
   c) Madrid
   d) Roma

Tu respuesta: b
¡Correcto!

[Preguntas restantes...]

=== Resultados ===
Respondiste 4 de 5 preguntas correctamente.
Puntaje: 80%

Puedes usar una lista de diccionarios para almacenar las preguntas, opciones y respuestas correctas:

preguntas = [
    {
        'pregunta': '¿Cuál es la capital de Francia?',
        'opciones': ['Londres', 'París', 'Madrid', 'Roma'],
        'respuesta': 'b'
    },
    # Más preguntas...
]
