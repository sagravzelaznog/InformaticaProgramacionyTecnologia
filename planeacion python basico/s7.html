Lógica Condicional con if-else

Objetivo de la Sesión

Aprender a implementar la toma de decisiones en Python utilizando las estructuras condicionales if, elif y else para crear programas más dinámicos y flexibles.

Al finalizar esta sesión, podrás:

  • Utilizar la estructura if-else para controlar el flujo de ejecución
  • Implementar múltiples condiciones con elif
  • Anidar estructuras condicionales para casos complejos
  • Aplicar la lógica condicional en escenarios prácticos

Conceptos Clave

1. Estructura Básica if-else

La estructura if-else permite que el programa tome decisiones ejecutando diferentes bloques de código según se cumplan o no ciertas condiciones.

# Sintaxis básica de if-else
edad = 18

if edad >= 18:
    print("Eres mayor de edad")
else:
    print("Eres menor de edad")

# También se puede usar sin else
if edad > 0:
    print("La edad es positiva")

# Ejemplo con entrada de usuario
puntuacion = int(input("Ingresa tu puntuación: "))
if puntuacion >= 60:
    print("¡Aprobado!")
else:
    print("Reprobado")

💡 Buenas prácticas

  • Usa sangría consistente (4 espacios o 1 tabulador)
  • Los dos puntos (:) al final de la condición son obligatorios
  • El bloque de código que pertenece a cada condición debe estar indentado

2. Condiciones Múltiples con elif

Cuando necesitas verificar múltiples condiciones, puedes usar elif (abreviatura de "else if").

# Ejemplo de condiciones múltiples
puntuacion = 85

if puntuacion >= 90:
    print("Calificación: A")
elif puntuacion >= 80:
    print("Calificación: B")  # Se ejecutará esto
elif puntuacion >= 70:
    print("Calificación: C")
elif puntuacion >= 60:
    print("Calificación: D")
else:
    print("Calificación: F")

# El orden de las condiciones es importante
# Las condiciones se evalúan de arriba hacia abajo
# Solo se ejecutará el primer bloque cuya condición sea verdadera

⚠️ Importante

Python evalúa las condiciones en orden y ejecuta solo el primer bloque cuya condición sea verdadera. Una vez que encuentra una condición verdadera, ignora el resto de los bloques elif y else.

3. Anidación de Condiciones

Puedes anidar estructuras condicionales dentro de otras para manejar casos más complejos.

# Ejemplo de anidación de condiciones
edad = 20
tiene_licencia = True

if edad >= 18:
    print("Eres mayor de edad")
    if tiene_licencia:
        print("Puedes conducir un automóvil")
    else:
        print("Necesitas obtener una licencia para conducir")
else:
    print("Eres menor de edad")
    if edad >= 16:
        print("Puedes obtener un permiso de aprendiz")
    else:
        print("Aún eres demasiado joven para conducir")

💡 Consejo de legibilidad

Si tienes muchas condiciones anidadas, considera refactorizar tu código usando funciones o estructuras de datos como diccionarios para mejorar la legibilidad.

4. Operador Ternario

Python ofrece una forma concisa de escribir declaraciones if-else en una sola línea.

# Sintaxis: valor_si_verdadero if condicion else valor_si_falso

# Forma tradicional
edad = 20
if edad >= 18:
    estatus = "Mayor"
else:
    estatus = "Menor"

# Equivalente con operador ternario
estatus = "Mayor" if edad >= 18 else "Menor"

# Ejemplos adicionales
precio = 100
descuento = precio * 0.2 if precio > 50 else precio * 0.1

numero = 7
resultado = "Par" if numero % 2 == 0 else "Impar"

⚠️ Uso adecuado

El operador ternario es útil para asignaciones simples, pero puede hacer que el código sea menos legible si se usa en exceso o con lógica compleja. Úsalo con moderación.

Actividades Prácticas

Actividad 1: Número Par o Impar

Crea un programa que determine si un número ingresado por el usuario es par o impar.

Ejemplo de salida:

=== Verificador de Números Pares e Impares ===
Ingresa un número entero: 7
El número 7 es impar

Ingresa un número entero: 12
El número 12 es par

Recuerda que un número es par si el residuo de su división entre 2 es 0. Puedes usar el operador módulo % para obtener el residuo.

Actividad 2: Adivina el Número

Desarrolla un juego donde el programa elija un número aleatorio y el usuario intente adivinarlo.

Ejemplo de ejecución:

=== Adivina el Número (1-100) ===
Intento #1: 50
Demasiado bajo
Intento #2: 75
Demasiado alto
Intento #3: 63
¡Correcto! Adivinaste en 3 intentos

Usa el módulo random para generar un número aleatorio. Necesitarás un bucle (que aprenderás en la siguiente sesión) o múltiples condiciones para manejar los intentos del usuario.

Actividad 3: Verificador de Calificaciones

Crea un programa que asigne una calificación en letra basada en una puntuación numérica.

Escala de calificaciones:

  • 90-100: A
  • 80-89: B
  • 70-79: C
  • 60-69: D
  • 0-59: F

Ejemplo:

=== Verificador de Calificaciones ===
Ingresa tu puntuación (0-100): 85
Tu calificación es: B

Usa una serie de condiciones if-elif-else para verificar en qué rango cae la puntuación. Asegúrate de validar que la entrada esté dentro del rango 0-100.

Actividad 4: Menú de Opciones

Desarrolla un programa que muestre un menú de opciones y realice diferentes acciones según la selección del usuario.

Ejemplo de menú:

=== Menú Principal ===
1. Saludar
2. Calcular el doble de un número
3. Verificar si un número es positivo
4. Salir

Selecciona una opción (1-4): 2
Ingresa un número: 7
El doble de 7 es 14

Selecciona una opción (1-4): 4
¡Hasta luego!

Usa una estructura if-elif-else para manejar cada opción del menú. Para hacer que el menú se repita hasta que el usuario elija salir, necesitarás un bucle (que aprenderás en la siguiente sesión). Por ahora, puedes hacer que el programa se ejecute una sola vez.
