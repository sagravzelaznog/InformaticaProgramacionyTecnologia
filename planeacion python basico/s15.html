Objetivo de la Sesión

En esta sesión, explorarás dos estructuras de datos fundamentales en Python: las tuplas y los conjuntos. Aprenderás sus características únicas, cuándo utilizarlas y cómo aprovechar sus ventajas en diferentes escenarios de programación.

Al finalizar esta sesión, podrás:

  • Comprender las características y usos de las tuplas en Python
  • Manipular conjuntos para manejar colecciones de elementos únicos
  • Identificar cuándo es más apropiado usar tuplas o conjuntos en lugar de listas o diccionarios
  • Realizar operaciones de conjuntos como unión, intersección y diferencia
  • Convertir entre diferentes estructuras de datos según sea necesario

Conceptos Clave

1. Tuplas: Datos Inmutables

Las tuplas son estructuras de datos inmutables en Python, ideales para agrupar datos relacionados que no deben modificarse.

# Creación de tuplas
coordenadas = (40.7128, -74.0060)  # Latitud y longitud de Nueva York
colores_rgb = (255, 128, 0)        # Color naranja en formato RGB
usuario = ('Juan', 'Pérez', 28)    # Datos de un usuario

# Las tuplas pueden contener diferentes tipos de datos
tupla_mixta = ('texto', 42, 3.14, True)

# Tupla vacía
tupla_vacia = ()

# Tupla con un solo elemento (¡necesita una coma!)
tupla_un_elemento = (42,)

# Acceso a elementos
print(coordenadas[0])  # 40.7128
print(usuario[1])      # 'Pérez'

# Desempaquetado de tuplas
nombre, apellido, edad = usuario
print(f"{nombre} {apellido} tiene {edad} años")  # Juan Pérez tiene 28 años

# Las tuplas son inmutables
# coordenadas[0] = 42.3601  # Error: 'tuple' object does not support item assignment

# Métodos de tuplas
numeros = (5, 2, 8, 2, 9, 2, 5)
print(numeros.count(2))  # 3 (cuenta ocurrencias del valor 2)
print(numeros.index(8))  # 2 (índice de la primera ocurrencia de 8)

# Comparación de tuplas
print((1, 2, 3) < (1, 2, 4))  # True
print((1, 2, 3) == (1, 3, 2))  # False

# Uso común: retornar múltiples valores desde una función
def dividir_y_sobrante(dividendo, divisor):
    cociente = dividendo // divisor
    resto = dividendo % divisor
    return cociente, resto  # Esto es una tupla

resultado = dividir_y_sobrante(17, 5)  # (3, 2)
coc, res = dividir_y_sobrante(17, 5)   # Desempaquetado: coc=3, res=2

💡 ¿Cuándo usar tuplas?

Usa tuplas cuando:

  • Los datos no deben cambiar después de su creación
  • Necesitas usar la colección como clave en un diccionario (las listas no son hasheables)
  • Quieres asegurar que los datos permanezcan constantes
  • Necesitas retornar múltiples valores desde una función

2. Conjuntos: Elementos Únicos

Los conjuntos son colecciones desordenadas de elementos únicos, ideales para operaciones de pertenencia y eliminación de duplicados.

# Creación de conjuntos
frutas = {'manzana', 'banana', 'cereza', 'manzana'}  # Los duplicados se eliminan
print(frutas)  # {'banana', 'manzana', 'cereza'}

# Crear un conjunto a partir de una lista
numeros = set([1, 2, 3, 4, 4, 3, 2, 1])
print(numeros)  # {1, 2, 3, 4}

# Conjunto vacío (¡usar set(), no {} que es un diccionario!)
conjunto_vacio = set()

# Operaciones básicas
frutas.add('naranja')     # Añadir un elemento
frutas.add('banana')      # No hace nada, ya existe
frutas.remove('manzana')  # Eliminar un elemento (lanza error si no existe)
frutas.discard('kiwi')    # Elimina si existe, no hace nada si no

# Operaciones de conjuntos
A = {1, 2, 3, 4, 5}
B = {4, 5, 6, 7, 8}

# Unión: elementos en A o en B
print(A | B)   # {1, 2, 3, 4, 5, 6, 7, 8}
print(A.union(B))  # Equivalente

# Intersección: elementos en A y en B
print(A & B)   # {4, 5}
print(A.intersection(B))  # Equivalente

# Diferencia: elementos en A pero no en B
print(A - B)   # {1, 2, 3}
print(A.difference(B))  # Equivalente

# Diferencia simétrica: elementos en A o en B pero no en ambos
print(A ^ B)   # {1, 2, 3, 6, 7, 8}
print(A.symmetric_difference(B))  # Equivalente

# Subconjunto y superconjunto
C = {2, 3}
print(C.issubset(A))     # True
print(A.issuperset(C))   # True
print(A.isdisjoint(B))   # False (hay intersección)

# Métodos útiles
print(len(frutas))       # Número de elementos
print('banana' in frutas) # Verificar pertenencia

# Eliminar y devolver un elemento aleatorio
fruta = frutas.pop()
print(f"Fruta eliminada: {fruta}")

# Limpiar el conjunto
frutas.clear()
print(frutas)  # set()

💡 ¿Cuándo usar conjuntos?

Usa conjuntos cuando:

  • Necesitas eliminar duplicados de una secuencia
  • Quieres realizar operaciones de conjuntos (unión, intersección, diferencia)
  • Necesitas verificar rápidamente la pertenencia de un elemento
  • El orden de los elementos no es importante
  • Necesitas colecciones de elementos únicos

3. Comparación y Conversión entre Estructuras

Python permite convertir fácilmente entre listas, tuplas y conjuntos según las necesidades del programa.

# Conversiones entre estructuras de datos

# De lista a conjunto (elimina duplicados)
numeros_con_duplicados = [1, 2, 2, 3, 4, 4, 5]
numeros_unicos = set(numeros_con_duplicados)  # {1, 2, 3, 4, 5}

# De conjunto a lista (sin duplicados)
lista_sin_duplicados = list(numeros_unicos)  # [1, 2, 3, 4, 5]

# De tupla a conjunto
puntos = ((1, 2), (3, 4), (1, 2))
puntos_unicos = set(puntos)  # {(1, 2), (3, 4)}

# De cadena a conjunto (caracteres únicos)
letras = set("programación")  # {'a', 'c', 'd', 'g', 'i', 'm', 'n', 'o', 'p', 'r', 'ó'}

# De diccionario a conjunto (solo claves)
diccionario = {'a': 1, 'b': 2, 'c': 3}
claves = set(diccionario)  # {'a', 'b', 'c'}

# Ordenar un conjunto (convertir a lista ordenada)
numeros = {5, 2, 8, 1, 9}
numeros_ordenados = sorted(numeros)  # [1, 2, 5, 8, 9]

# Conjuntos inmutables (frozenset)
numeros_inmutables = frozenset([1, 2, 3, 4])
# numeros_inmutables.add(5)  # Error: 'frozenset' object has no attribute 'add'

# Uso de frozenset como clave de diccionario
puntajes = {frozenset([1, 2]): "Par bajo", frozenset([5, 6]): "Par alto"}
print(puntajes[frozenset([1, 2])])  # "Par bajo"

# Comparación de rendimiento: listas vs conjuntos (búsqueda)
import time

def tiempo_busqueda(estructura, elemento, repeticiones=1000000):
    inicio = time.time()
    for _ in range(repeticiones):
        elemento in estructura
    return time.time() - inicio

# Lista grande
lista_grande = list(range(1000000))
conjunto_grande = set(lista_grande)

# Búsqueda del último elemento
tiempo_lista = tiempo_busqueda(lista_grande, 999999)
tiempo_conjunto = tiempo_busqueda(conjunto_grande, 999999)

print(f"Tiempo de búsqueda en lista: {tiempo_lista:.6f} segundos")
print(f"Tiempo de búsqueda en conjunto: {tiempo_conjunto:.6f} segundos")
# Ejemplo de salida (puede variar según el sistema):
# Tiempo de búsqueda en lista: 0.045234 segundos
# Tiempo de búsqueda en conjunto: 0.000035 segundos

⚡ Consejos de rendimiento

  • Usa conjuntos para verificar pertenencia en grandes colecciones (O(1) vs O(n) en listas)
  • Las tuplas son más ligeras en memoria que las listas para datos inmutables
  • Los conjuntos consumen más memoria que las listas debido a su implementación de tabla hash
  • Usa frozenset cuando necesites un conjunto inmutable (por ejemplo, como clave de diccionario)

Para calcular la distancia entre dos puntos en la Tierra (fórmula del haversine):

from math import radians, sin, cos, sqrt, atan2

def calcular_distancia(punto1, punto2):
    # Radio de la Tierra en kilómetros
    R = 6371.0
    
    # Convertir grados a radianes
    lat1, lon1 = map(radians, punto1)
    lat2, lon2 = map(radians, punto2)
    
    # Diferencia de coordenadas
    dlat = lat2 - lat1
    dlon = lon2 - lon1
    
    # Fórmula del haversine
    a = sin(dlat / 2)**2 + cos(lat1) * cos(lat2) * sin(dlon / 2)**2
    c = 2 * atan2(sqrt(a), sqrt(1 - a))
    distancia = R * c
    
    return distancia

Para mantener el orden de inserción al eliminar duplicados, puedes usar un conjunto para rastrear las líneas ya vistas:

def eliminar_duplicados(archivo_entrada, archivo_salida=None):
    lineas_vistas = set()
    lineas_unicas = []
    
    with open(archivo_entrada, 'r', encoding='utf-8') as f:
        for linea in f:
            linea = linea.strip()
            if linea not in lineas_vistas:
                lineas_vistas.add(linea)
                lineas_unicas.append(linea)
    
    if archivo_salida:
        with open(archivo_salida, 'w', encoding='utf-8') as f:
            f.write('\n'.join(lineas_unicas))
    
    return lineas_unicas

Actividad 3: Sistema de Etiquetas para Archivos

Desarrolla un programa que permita etiquetar archivos con múltiples etiquetas y luego buscar archivos por una o más etiquetas.

Ejemplo de ejecución:

=== GESTOR DE ETIQUETAS ===
1. Agregar archivo con etiquetas
2. Buscar archivos por etiqueta
3. Mostrar todos los archivos y etiquetas
4. Salir

Selecciona una opción (1-4): 1

Ruta del archivo: C:/fotos/vacaciones.jpg
Ingresa las etiquetas (separadas por comas): vacaciones, playa, verano2023
Archivo agregado correctamente con 3 etiquetas.

Selecciona una opción (1-4): 2

Ingresa las etiquetas a buscar (separadas por comas): playa, sol

Archivos encontrados:
- C:/fotos/vacaciones.jpg (3 etiquetas)
- C:/fotos/playa_sol.jpg (4 etiquetas)

Selecciona una opción (1-4): 4
¡Hasta luego!

Usa un diccionario donde las claves sean las rutas de los archivos y los valores sean conjuntos de etiquetas. Para la búsqueda, puedes usar operaciones de conjuntos:

class GestorEtiquetas:
    def __init__(self):
        self.archivos = {}  # {ruta: set(etiquetas)}
        self.etiquetas = {}  # {etiqueta: set(rutas)}
    
    def agregar_archivo(self, ruta, etiquetas):
        # Limpiar etiquetas (minúsculas, sin espacios)
        etiquetas = {e.strip().lower() for e in etiquetas.split(',') if e.strip()}
        
        # Si el archivo ya existe, actualizar etiquetas
        if ruta in self.archivos:
            etiquetas_antiguas = self.archivos[ruta]
            # Eliminar referencias a etiquetas que ya no están
            for etiqueta in etiquetas_antiguas - etiquetas:
                self.etiquetas[etiqueta].discard(ruta)
        
        # Actualizar el archivo con las nuevas etiquetas
        self.archivos[ruta] = etiquetas
        
        # Actualizar el índice de etiquetas
        for etiqueta in etiquetas:
            if etiqueta not in self.etiquetas:
                self.etiquetas[etiqueta] = set()
            self.etiquetas[etiqueta].add(ruta)
    
    def buscar_por_etiquetas(self, etiquetas_busqueda, operador='AND'):
        etiquetas_busqueda = {e.strip().lower() for e in etiquetas_busqueda.split(',') if e.strip()}
        
        if not etiquetas_busqueda:
            return set()
        
        if operador.upper() == 'AND':
            # Intersección de conjuntos
            rutas_encontradas = None
            for etiqueta in etiquetas_busqueda:
                if etiqueta in self.etiquetas:
                    if rutas_encontradas is None:
                        rutas_encontradas = set(self.etiquetas[etiqueta])
                    else:
                        rutas_encontradas.intersection_update(self.etiquetas[etiqueta])
                else:
                    return set()
            return rutas_encontradas or set()
        else:
            # Unión de conjuntos
            rutas_encontradas = set()
            for etiqueta in etiquetas_busqueda:
                if etiqueta in self.etiquetas:
                    rutas_encontradas.update(self.etiquetas[etiqueta])
            return rutas_encontradas

Actividad 4: Analizador de Texto con Conjuntos

Crea un programa que compare dos textos y muestre estadísticas como palabras únicas, palabras en común y palabras exclusivas de cada texto.

Ejemplo de ejecución:

=== ANALIZADOR DE TEXTO ===
Ingresa el primer texto (o 'cargar archivo.txt' para cargar desde archivo):
El rápido zorro marrón salta sobre el perro perezoso.

Ingresa el segundo texto (o 'cargar archivo.txt' para cargar desde archivo):
El perro perezoso duerme bajo el sol del verano.

=== RESULTADOS ===
Total de palabras únicas en el texto 1: 7
Total de palabras únicas en el texto 2: 7

Palabras en común (5):
- el
- perro
- perezoso
- sobre
- zorro

Palabras exclusivas del texto 1 (2):
- marrón
- rápido

Palabras exclusivas del texto 2 (2):
- bajo
- duerme
- sol
- verano

Para procesar el texto y extraer palabras únicas, puedes usar expresiones regulares y conjuntos:

import re

def procesar_texto(texto):
    # Convertir a minúsculas y extraer palabras
    palabras = re.findall(r'\b\w+\b', texto.lower())
    return set(palabras)

def comparar_textos(texto1, texto2):
    palabras1 = procesar_texto(texto1)
    palabras2 = procesar_texto(texto2)
    
    # Calcular estadísticas
    total_unicas1 = len(palabras1)
    total_unicas2 = len(palabras2)
    palabras_comunes = palabras1 & palabras2
    exclusivas1 = palabras1 - palabras2
    exclusivas2 = palabras2 - palabras1
    
    return {
        'total_unicas1': total_unicas1,
        'total_unicas2': total_unicas2,
        'palabras_comunes': sorted(palabras_comunes),
        'exclusivas1': sorted(exclusivas1),
        'exclusivas2': sorted(exclusivas2)
    }
