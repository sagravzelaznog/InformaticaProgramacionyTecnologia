Objetivo de la Sesión

En esta sesión, profundizarás en el uso avanzado de diccionarios en Python, explorando técnicas y métodos que te permitirán manipular datos de manera más eficiente y efectiva. Aprenderás a trabajar con diccionarios anidados, métodos avanzados y estrategias para resolver problemas complejos.

Al finalizar esta sesión, podrás:

  • Utilizar métodos avanzados como .keys(), .values() y .items() para manipular diccionarios
  • Iterar eficientemente sobre diccionarios utilizando diferentes técnicas
  • Trabajar con estructuras de datos anidadas que incluyan diccionarios
  • Aplicar técnicas avanzadas de manipulación de diccionarios en situaciones prácticas

Conceptos Clave

1. Métodos Esenciales de los Diccionarios

Python proporciona varios métodos útiles para trabajar con diccionarios de manera más efectiva.

# Crear un diccionario de ejemplo
estudiante = {
    "nombre": "Ana García",
    "edad": 22,
    "carrera": "Ingeniería",
    "promedio": 9.2,
    "materias": ["Cálculo", "Programación", "Física"]
}

# keys() - devuelve una vista de las claves
claves = estudiante.keys()
print("Claves:", list(clves))  # ['nombre', 'edad', 'carrera', 'promedio', 'materias']

# values() - devuelve una vista de los valores
valores = estudiante.values()
print("Valores:", list(valores))  # ['Ana García', 22, 'Ingeniería', 9.2, [...]]

# items() - devuelve una vista de pares clave-valor
pares = estudiante.items()
print("Pares:", list(pares))  # [('nombre', 'Ana García'), ('edad', 22), ...]

# get() - obtiene el valor de una clave o un valor por defecto
edad = estudiante.get("edad", "No especificada")  # 22
email = estudiante.get("email", "No proporcionado")  # "No proporcionado"

# update() - actualiza el diccionario con pares clave-valor de otro diccionario
estudiante.update({"email": "ana@ejemplo.com", "semestre": 5})

# pop() - elimina y devuelve el valor de la clave especificada
promedio = estudiante.pop("promedio")  # Elimina 'promedio' y devuelve 9.2

# setdefault() - obtiene el valor de una clave o lo establece si no existe
ciudad = estudiante.setdefault("ciudad", "Ciudad de México")  # Como 'ciudad' no existe, la crea

# fromkeys() - crea un nuevo diccionario con claves de una secuencia y un valor por defecto
nuevas_claves = ["matricula", "telefono"]
nuevo_estudiante = dict.fromkeys(nuevas_claves, None)  # {'matricula': None, 'telefono': None}

# clear() - elimina todos los elementos del diccionario
estudiante.clear()  # {}

💡 Vistas de diccionario

Los métodos keys(), values() e items() devuelven objetos de vista que reflejan los cambios en el diccionario subyacente. Son eficientes en memoria y actualizan automáticamente cuando cambia el diccionario.

2. Iteración Eficiente sobre Diccionarios

Python ofrece varias formas de iterar sobre diccionarios, cada una útil en diferentes situaciones.

# Diccionario de ejemplo
inventario = {
    "manzanas": 30,
    "plátanos": 45,
    "naranjas": 25,
    "peras": 20,
    "uvas": 15
}

# 1. Iterar sobre claves (forma implícita)
for fruta in inventario:
    print(f"Fruta: {fruta}")

# 2. Iterar sobre claves (forma explícita)
for fruta in inventario.keys():
    print(f"Fruta: {fruta}")

# 3. Iterar sobre valores
for cantidad in inventario.values():
    print(f"Cantidad: {cantidad}")

# 4. Iterar sobre pares clave-valor
for fruta, cantidad in inventario.items():
    print(f"Hay {cantidad} unidades de {fruta}")

# 5. Ordenar claves antes de iterar
for fruta in sorted(inventario.keys()):
    print(f"{fruta}: {inventario[fruta]}")

# 6. Ordenar por valor (de menor a mayor)
for fruta, cantidad in sorted(inventario.items(), key=lambda item: item[1]):
    print(f"{fruta}: {cantidad}")

# 7. Ordenar por valor (de mayor a menor)
for fruta, cantidad in sorted(inventario.items(), key=lambda item: item[1], reverse=True):
    print(f"{fruta}: {cantidad}")

# 8. Usar enumerate() para obtener el índice
for i, (fruta, cantidad) in enumerate(inventario.items(), 1):
    print(f"{i}. {fruta}: {cantidad}")

# 9. Filtrar elementos durante la iteración
for fruta, cantidad in inventario.items():
    if cantidad > 25:
        print(f"¡Alerta! Stock alto de {fruta} ({cantidad} unidades)")

# 10. Usar zip() para combinar con otra secuencia
precios = [15.5, 12.0, 10.8, 18.2, 25.0]
for (fruta, cantidad), precio in zip(inventario.items(), precios):
    valor_total = cantidad * precio
    print(f"{fruta}: {cantidad} x ${precio:.2f} = ${valor_total:.2f}")

💡 Orden en diccionarios

A partir de Python 3.7, los diccionarios mantienen el orden de inserción. Sin embargo, si necesitas un orden específico al iterar, es buena práctica ordenar explícitamente las claves o valores como se muestra en los ejemplos.

3. Trabajando con Diccionarios Anidados

Los diccionarios pueden contener otros diccionarios, lo que permite crear estructuras de datos complejas y jerárquicas.

# Ejemplo de diccionario anidado
colegio = {
    "estudiantes": {
        "A001": {
            "nombre": "Ana García",
            "edad": 15,
            "grado": 10,
            "calificaciones": {
                "Matemáticas": 9.5,
                "Ciencias": 8.8,
                "Historia": 9.0
            }
        },
        "A002": {
            "nombre": "Luis Martínez",
            "edad": 16,
            "grado": 11,
            "calificaciones": {
                "Matemáticas": 8.5,
                "Ciencias": 9.2,
                "Historia": 8.0
            }
        }
    },
    "profesores": {
        "P001": {"nombre": "Dra. Pérez", "asignatura": "Matemáticas"},
        "P002": {"nombre": "Dr. López", "asignatura": "Ciencias"}
    },
    "aulas": ["A101", "A102", "B201", "B202"]
}

# Acceso a elementos anidados
nombre_estudiante = colegio["estudiantes"]["A001"]["nombre"]  # "Ana García"
calificacion_mate = colegio["estudiantes"]["A001"]["calificaciones"]["Matemáticas"]  # 9.5

# Añadir un nuevo estudiante
nuevo_estudiante = {
    "nombre": "María López",
    "edad": 14,
    "grado": 9,
    "calificaciones": {"Matemáticas": 9.0, "Ciencias": 9.5, "Historia": 8.5}
}
colegio["estudiantes"]["A003"] = nuevo_estudiante

# Función para calcular el promedio de un estudiante
def calcular_promedio(estudiante_id):
    calificaciones = colegio["estudiantes"][estudiante_id]["calificaciones"].values()
    return sum(calificaciones) / len(calificaciones)

# Actualizar información
colegio["estudiantes"]["A001"]["edad"] = 16
colegio["estudiantes"]["A001"]["calificaciones"]["Matemáticas"] = 9.8

# Eliminar información
del colegio["estudiantes"]["A002"]["calificaciones"]["Historia"]

# Iterar sobre estudiantes y sus calificaciones
for estudiante_id, info in colegio["estudiantes"].items():
    print(f"\nEstudiante: {info['nombre']}")
    print("Calificaciones:")
    for asignatura, calificacion in info["calificaciones"].items():
        print(f"  - {asignatura}: {calificacion}")
    print(f"Promedio: {calcular_promedio(estudiante_id):.2f}")

# Diccionarios anidados con listas
cursos = {
    "Matemáticas": {
        "profesor": "Dr. Pérez",
        "estudiantes": ["A001", "A003"],
        "horario": "Lunes y Miércoles 10:00-11:30"
    },
    "Ciencias": {
        "profesor": "Dr. López",
        "estudiantes": ["A001", "A002", "A003"],
        "horario": "Martes y Jueves 14:00-15:30"
    }
}

# Añadir un estudiante a un curso
def inscribir_estudiante(curso, estudiante_id):
    if estudiante_id not in cursos[curso]["estudiantes"]:
        cursos[curso]["estudiantes"].append(estudiante_id)
        return True
    return False

inscribir_estudiante("Matemáticas", "A002")  # Añade al estudiante A002 a Matemáticas

⚠️ Cuidado con las copias de diccionarios anidados

Al copiar diccionarios anidados con copy() o dict(), solo se crea una copia superficial. Para una copia profunda que incluya todos los objetos anidados, usa el módulo copy con copy.deepcopy().

4. Técnicas Avanzadas de Manipulación

Exploraremos técnicas avanzadas para trabajar con diccionarios en Python.

# 1. Comprensión de diccionarios
cuadrados = {x: x**2 for x in range(1, 6)}  # {1: 1, 2: 4, 3: 9, 4: 16, 5: 25}

# 2. Filtrar un diccionario
precios = {"manzana": 15.5, "banana": 12.0, "naranja": 10.8, "pera": 18.2}
caros = {k: v for k, v in precios.items() if v > 15}  # {'manzana': 15.5, 'pera': 18.2}

# 3. Invertir claves y valores (si los valores son únicos)
inventario = {"manzanas": 30, "plátanos": 45, "naranjas": 25}
inventario_invertido = {v: k for k, v in inventario.items()}

# 4. Combinar dos diccionarios (Python 3.5+)
dic1 = {"a": 1, "b": 2}
dic2 = {"c": 3, "d": 4}
combinado = {**dic1, **dic2}  # {'a': 1, 'b': 2, 'c': 3, 'd': 4}

# 5. Contar ocurrencias de elementos
from collections import defaultdict, Counter

# Usando defaultdict
conteo = defaultdict(int)
palabras = ["manzana", "banana", "manzana", "cereza", "banana", "manzana"]
for palabra in palabras:
    conteo[palabra] += 1

# Usando Counter (más simple)
conteo = Counter(palabras)  # Counter({'manzana': 3, 'banana': 2, 'cereza': 1})

# 6. Agrupar elementos por una clave
datos = [
    {"nombre": "Ana", "edad": 15, "grado": 10},
    {"nombre": "Luis", "edad": 16, "grado": 11},
    {"nombre": "Marta", "edad": 15, "grado": 10},
    {"nombre": "Carlos", "edad": 16, "grado": 11}
]

# Agrupar por grado
grados = {}
for estudiante in datos:
    grado = estudiante["grado"]
    if grado not in grados:
        grados[grado] = []
    grados[grado].append(estudiante["nombre"])

# Versión más concisa con defaultdict
grados = defaultdict(list)
for estudiante in datos:
    grados[estudiante["grado"]].append(estudiante["nombre"])

# 7. Diccionarios ordenados (aunque desde Python 3.7 los diccionarios mantienen el orden)
from collections import OrderedDict

# Útil para versiones anteriores a Python 3.7 o para operaciones específicas
d = OrderedDict()
d["primero"] = 1
d["segundo"] = 2
d.move_to_end("primero")  # Mueve 'primero' al final

# 8. Diccionarios inmutables con MappingProxyType
from types import MappingProxyType

d = {"a": 1, "b": 2}
proxy = MappingProxyType(d)  # Vista de solo lectura de d
# proxy["c"] = 3  # Error: no se puede modificar

# 9. Diccionarios con valores por defecto
from collections import defaultdict

# Contar letras en palabras
contador = defaultdict(int)
palabra = "abracadabra"
for letra in palabra:
    contador[letra] += 1

# 10. Fusionar diccionarios (Python 3.9+)
dic1 = {"a": 1, "b": 2}
dic2 = {"b": 3, "c": 4}
combinado = dic1 | dic2  # {'a': 1, 'b': 3, 'c': 4}

# 11. Ordenar diccionario por valor
precios = {"manzana": 15.5, "banana": 12.0, "naranja": 10.8, "pera": 18.2}
ordenado_por_valor = dict(sorted(precios.items(), key=lambda item: item[1]))

# 12. Encontrar claves con valores máximos/mínimos
precio_max = max(precios, key=precios.get)  # 'pera'
precio_min = min(precios, key=precios.get)  # 'naranja'

💡 El operador de morsa (:=) en comprensiones de diccionario

En Python 3.8+, puedes usar el operador de asignación de expresión (:=) dentro de comprensiones de diccionario para evitar cálculos repetidos:

# Sin operador morsa
resultado = {x: x**2 for x in range(10) if x**2 > 20}

# Con operador morsa (más eficiente)
resultado = {x: cuadrado for x in range(10) if (cuadrado := x**2) > 20}

Actividades Prácticas

Actividad 1: Sistema de Inventario con Categorías

Crea un programa que gestione un inventario de productos organizados por categorías, permitiendo agregar, actualizar, eliminar y buscar productos.

Ejemplo de salida:

=== SISTEMA DE INVENTARIO ===
1. Ver categorías
2. Agregar categoría
3. Agregar producto
4. Actualizar stock
5. Buscar producto
6. Salir

Selecciona una opción (1-6): 1

=== CATEGORÍAS DISPONIBLES ===
1. Frutas (3 productos)
2. Lácteos (2 productos)
3. Bebidas (4 productos)

Selecciona una categoría (1-3) o 0 para volver: 1

=== FRUTAS ===
1. Manzana - Stock: 30 - Precio: $15.50
2. Plátano - Stock: 45 - Precio: $12.00
3. Naranja - Stock: 25 - Precio: $10.80

Usa un diccionario anidado donde las claves principales sean las categorías y los valores sean listas de productos. Cada producto puede ser un diccionario con claves como "nombre", "stock", "precio", etc. Implementa funciones para cada operación (agregar, actualizar, buscar) y un menú interactivo para que el usuario pueda interactuar con el sistema.

Actividad 2: Análisis de Texto Avanzado

Desarrolla un programa que analice un texto y proporcione estadísticas detalladas como frecuencia de palabras, palabras más comunes, longitud media de las palabras, etc.

Ejemplo de ejecución:

=== ANALIZADOR DE TEXTO ===
Ingresa un texto (o 'salir' para terminar):
El rápido zorro marrón salta sobre el perro perezoso.

=== ESTADÍSTICAS ===
Total de palabras: 8
Palabras únicas: 7
Longitud media de palabras: 4.5

Palabras más comunes:
el: 2
rápido: 1
zorro: 1
marrón: 1
salta: 1
sobre: 1
perro: 1
perezoso: 1

Letras más comunes:
o: 7
r: 6
e: 5
p: 4

Usa el módulo collections.Counter para contar frecuencias de palabras y letras. Convierte el texto a minúsculas y elimina signos de puntuación antes de procesarlo. Para contar letras, puedes concatenar todas las palabras y usar Counter nuevamente. Implementa funciones separadas para cada estadística y muestra los resultados de manera ordenada.

Actividad 3: Gestor de Contactos Avanzado

Crea un programa que gestione una agenda de contactos con información detallada y capacidades de búsqueda avanzada.

Ejemplo de ejecución:

=== GESTOR DE CONTACTOS ===
1. Ver todos los contactos
2. Buscar contacto
3. Agregar contacto
4. Actualizar contacto
5. Eliminar contacto
6. Exportar contactos a CSV
7. Importar contactos desde CSV
8. Salir

Selecciona una opción (1-8): 2

=== BUSCAR CONTACTO ===
1. Por nombre
2. Por apellido
3. Por empresa
4. Por etiqueta
5. Volver

Selecciona un criterio de búsqueda (1-5): 4

Ingresa la etiqueta: familia

=== RESULTADOS DE BÚSQUEDA ===
1. Ana García - ana@ejemplo.com - Tel: 555-1234 (Familia, Cumpleaños)
2. Juan Pérez - juan@ejemplo.com - Tel: 555-5678 (Trabajo, Familia)

Usa un diccionario donde cada contacto tenga un ID único como clave. Cada contacto puede ser un diccionario con claves como "nombre", "apellido", "email", "telefono", "empresa", "etiquetas" (lista), etc. Implementa funciones para cada operación (agregar, buscar, actualizar, eliminar) y utiliza el módulo csv para importar/exportar contactos. Para la búsqueda avanzada, itera sobre los contactos y filtra según los criterios especificados.
