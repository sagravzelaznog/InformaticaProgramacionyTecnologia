Objetivo de la Sesión

Aprender a almacenar y manipular información básica en Python utilizando variables y tipos de datos primitivos.

Al finalizar esta sesión, podrás:

  • Entender qué son las variables y cómo se utilizan en Python
  • Identificar y utilizar los tipos de datos primitivos principales
  • Nombrar variables siguiendo las convenciones de Python
  • Usar la función type() para verificar tipos de datos

Conceptos Clave

1. Variables en Python

Una variable es un nombre que hace referencia a un valor almacenado en la memoria de la computadora. En Python, las variables se crean cuando se les asigna un valor por primera vez.

# Ejemplo de variables
nombre = "Ana"
edad = 25
estatura = 1.68
estudiante = True

📌 Nota Importante

En Python, no necesitas declarar explícitamente el tipo de variable. Python infiere el tipo basado en el valor asignado.

2. Tipos de Datos Primitivos

Enteros (int)

Números enteros, positivos o negativos, sin decimales.

edad = 25
año = 2023
puntaje = -10

Números de punto flotante (float)

Números reales con punto decimal.

pi = 3.1416
precio = 19.99
temperatura = -5.5

Cadenas de texto (str)

Secuencias de caracteres entre comillas simples o dobles.

nombre = "Carlos"
mensaje = 'Hola, ¿cómo estás?'
direccion = "Calle Falsa 123"

Valores booleanos (bool)

Representan valores de verdad: True o False (Verdadero o Falso).

es_estudiante = True
tiene_descuento = False
mayor_de_edad = True

3. Reglas para Nombrar Variables

  • Pueden contener letras (a-z, A-Z), números (0-9) y guiones bajos (_)
  • No pueden comenzar con un número
  • Son sensibles a mayúsculas y minúsculas (edad, Edad y EDAD son variables diferentes)
  • No pueden ser palabras reservadas de Python (como if, else, for, while, etc.)

Ejemplos de nombres válidos:

nombre_usuario = "Ana"
contador1 = 10
precio_total = 99.99
es_activo = True

Ejemplos de nombres no válidos:

1nombre = "Ana"       # No puede comenzar con número
precio-total = 99.99  # No puede contener guiones
if = 10               # No puede ser palabra reservada

4. La Función type()

Esta función nos permite determinar el tipo de dato de una variable o valor.

# Ejemplos de uso de type()
elemento1 = 42
elemento2 = 3.14
elemento3 = "Hola"
elemento4 = True

print(type(elemento1))  # 
print(type(elemento2))  # 
print(type(elemento3))  # 
print(type(elemento4))  #

💡 Consejo

Usa type() cuando necesites verificar el tipo de una variable, especialmente cuando trabajas con entradas de usuario o datos externos.

Actividades Prácticas

Actividad 1: Creación de Variables

Crea un archivo llamado variables.py y declara las siguientes variables con valores apropiados:

  • Una variable para tu nombre
  • Una variable para tu edad
  • Una variable para tu estatura en metros
  • Una variable booleana que indique si eres estudiante

Luego, imprime cada variable junto con su tipo usando type().

Recuerda que en Python no necesitas declarar el tipo de variable. Simplemente asígnale un valor.

# Ejemplo:
nombre = "Ana"
print(nombre, type(nombre))

Actividad 2: Conversión de Tipos

Crea un programa que:

  1. Pida al usuario su año de nacimiento
  2. Calcule su edad restando el año actual (puedes definirlo como una variable)
  3. Muestre un mensaje como: "Tienes X años"

Recuerda que input() siempre devuelve una cadena de texto. Necesitarás convertirla a entero para hacer cálculos.

# Para convertir una cadena a entero:
numero = int("123")

Actividad 3: Calculadora de IMC

Crea un programa que calcule el Índice de Masa Corporal (IMC).

Fórmula: IMC = peso (kg) / (estatura (m) * estatura (m))

El programa debe:

  1. Pedir al usuario su peso en kilogramos
  2. Pedir al usuario su estatura en metros
  3. Calcular el IMC
  4. Mostrar el resultado con 2 decimales

Para formatear un número con 2 decimales, puedes usar f-strings:

resultado = 25.6789
print(f"{resultado:.2f}")  # Muestra: 25.68

Actividad 4: Información Personal

Crea un programa que muestre información personal formateada. El programa debe:

  1. Pedir al usuario su nombre, edad, ciudad de residencia y profesión
  2. Almacenar cada dato en una variable con un nombre descriptivo
  3. Mostrar la información en un formato amigable, como:
=== INFORMACIÓN PERSONAL ===
Nombre: [nombre]
Edad: [edad] años
Ciudad: [ciudad]
Profesión: [profesión]
=============================

Puedes usar múltiples input() para cada dato y luego imprimir todo junto con print().

Para el formato, puedes usar cadenas de varias líneas con comillas triples """...""" o múltiples llamadas a print().
