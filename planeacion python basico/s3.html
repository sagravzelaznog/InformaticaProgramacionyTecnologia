Objetivo de la Sesión

Dominar la manipulación de cadenas de texto en Python, aprendiendo a formatear, modificar y extraer información de cadenas de manera eficiente.

Al finalizar esta sesión, podrás:

  • Realizar operaciones básicas con cadenas de texto
  • Utilizar f-strings para formateo avanzado
  • Aplicar métodos de cadena como .upper(), .lower(), .strip() y .replace()
  • Manipular cadenas usando índices y slicing

Conceptos Clave

1. Operaciones Básicas con Cadenas

Las cadenas de texto en Python son secuencias inmutables de caracteres Unicode. Aquí hay algunas operaciones básicas:

# Concatenación
saludo = "Hola" + " " + "Mundo"  # Resultado: "Hola Mundo"

# Repetición
risa = "ja" * 3  # Resultado: "jajaja"

# Longitud de una cadena
longitud = len("Python")  # Resultado: 6

# Acceso a caracteres
letra = "Python"[0]  # Resultado: 'P'

# Verificación de subcadena
contiene = "hola" in "hola mundo"  # Resultado: True

2. F-strings para Formateo Avanzado

Las f-strings (formatted string literals) permiten incrustar expresiones dentro de cadenas de manera sencilla.

# Variables para los ejemplos
nombre = "Ana"
edad = 25

# Formateo básico
saludo = f"Hola, me llamo {nombre} y tengo {edad} años"

# Expresiones dentro de f-strings
precio = 19.99
cantidad = 3
total = f"Total: {precio * cantidad:.2f}€"  # Formato de 2 decimales

# Llamadas a funciones
f"En mayúsculas: {nombre.upper()}"  # Resultado: "En mayúsculas: ANA"

# Alineación de texto
f"{nombre:>10}"  # Alineado a la derecha en 10 caracteres
f"{nombre:^10}"  # Centrado en 10 caracteres
f"{nombre:<10}"  # Alineado a la izquierda en 10 caracteres

💡 Consejo

Las f-strings son la forma más moderna y legible de formatear cadenas en Python 3.6+. Son más rápidas y fáciles de leer que otros métodos de formateo.

3. Métodos Útiles de Cadenas

.upper() y .lower()

Convierten todos los caracteres de la cadena a mayúsculas o minúsculas.

texto = "Python es Genial"
texto.upper()  # "PYTHON ES GENIAL"
texto.lower()  # "python es genial"
texto.capitalize()  # "Python es genial"
texto.title()  # "Python Es Genial"

.strip(), .lstrip() y .rstrip()

Eliminan espacios en blanco (u otros caracteres) del inicio y/o final de la cadena.

texto = "   Hola   "
texto.strip()   # "Hola"
texto.lstrip()  # "Hola   "
texto.rstrip()  # "   Hola"

# Eliminar caracteres específicos
"...Python...".strip(".")  # "Python"

.replace()

Reemplaza todas las ocurrencias de una subcadena por otra.

frase = "Me gusta programar en Java"
nueva_frase = frase.replace("Java", "Python")  # "Me gusta programar en Python"

# Reemplazar múltiples valores
frase = "1, 2, 3, 4"
frase.replace(",", ";").replace(" ", "")  # "1;2;3;4"

Otros métodos útiles

# Contar ocurrencias
"banana".count("a")  # 3

# Verificar inicio/fin
"Hola mundo".startswith("Hola")  # True
"Hola mundo".endswith("mundo")    # True

# Dividir y unir cadenas
"uno,dos,tres".split(",")  # ['uno', 'dos', 'tres']
" ".join(["Hola", "mundo", "!"]))  # "Hola mundo !"

# Verificar si es numérico o alfabético
"123".isdigit()  # True
"abc".isalpha()  # True
"abc123".isalnum()  # True

4. Índices y Slicing en Cadenas

Las cadenas en Python son secuencias, lo que significa que puedes acceder a sus elementos mediante índices y slices.

texto = "Python"

# Índices (comienzan en 0)
primer_caracter = texto[0]    # 'P'
segundo_caracter = texto[1]   # 'y'
ultimo_caracter = texto[-1]   # 'n' (negativos cuentan desde el final)

# Slicing (rebanadas)
# sintaxis: [inicio:fin:paso]
primeras_tres = texto[0:3]    # 'Pyt' (índice 3 no incluido)
ultimos_tres = texto[-3:]     # 'hon'  (desde el -3 hasta el final)
cada_segundo = texto[::2]     # 'Pto'  (cada segundo carácter)
reverso = texto[::-1]         # 'nohtyP' (invierte la cadena)

# Longitud de la cadena
longitud = len(texto)         # 6

💡 Truco de slicing

Puedes omitir los valores de inicio/fin para usar los valores por defecto (inicio y final de la cadena).

texto = "Python"
texto[:3]  # 'Pyt' (igual que texto[0:3])
texto[3:]  # 'hon' (igual que texto[3:6])

Introducción a las Funciones

En las siguientes actividades, necesitarás crear funciones. Una función es un bloque de código reutilizable que realiza una tarea específica. En Python, las funciones se definen usando la palabra clave def.

Sintaxis básica de una función:

def nombre_de_la_funcion(parametro1, parametro2):
    """
    Documentación de la función (opcional pero recomendado)
    Explica qué hace la función y qué parámetros espera
    """
    # Cuerpo de la función
    resultado = parametro1 + parametro2
    return resultado  # Opcional: devuelve un valor

Ejemplo práctico:

def saludar(nombre):
    """
    Muestra un saludo personalizado
    
    Args:
        nombre (str): El nombre de la persona a saludar
        
    Returns:
        str: Un mensaje de saludo
    """
    mensaje = f"¡Hola, {nombre}! Bienvenido al curso de Python."
    return mensaje

# Llamando a la función
print(saludar("Ana"))  # Muestra: ¡Hola, Ana! Bienvenido al curso de Python.

💡 Buenas prácticas al crear funciones:

  • Usa nombres descriptivos para las funciones (verbos en minúsculas con guiones bajos)
  • Documenta siempre lo que hace tu función
  • Mantén las funciones pequeñas y con un solo propósito
  • Usa parámetros con valores por defecto cuando sea apropiado

Actividades Prácticas

Actividad 1: Mensajes Personalizados con F-strings

Crea un programa que pida al usuario su nombre, edad y ciudad de residencia. Luego, muestra un mensaje personalizado que incluya esta información de manera formateada.

Ejemplo de salida:

¡Hola Ana! Veo que tienes 28 años y vives en Madrid. ¡Bienvenida!

Recuerda usar input() para obtener los datos del usuario y f-strings para formatear el mensaje de salida.

Actividad 2: Limpiar y Formatear Texto

Crea una función llamada limpiar_texto que reciba una cadena y realice las siguientes operaciones:

  1. Convertir todo a minúsculas
  2. Eliminar espacios en blanco al inicio y final
  3. Reemplazar múltiples espacios por uno solo
  4. Capitalizar la primera letra de la cadena

Ejemplo:

texto = "   hola    MUNDO   "
print(limpiar_texto(texto))  # "Hola mundo"

Actividad 3: Constructor de Oraciones

Crea un programa que pida al usuario varias palabras (sustantivo, verbo, adjetivo, etc.) y las combine en una oración completa. Usa f-strings para crear oraciones coherentes.

Ejemplo:

Sustantivo: perro
Verbo: corre
Adjetivo: rápido
Lugar: parque

El perro corre rápido en el parque.

Actividad 4: Generador de Iniciales Artísticas

Crea un programa que pida al usuario su nombre completo y cree un diseño artístico con sus iniciales usando caracteres ASCII. El programa debe:

  1. Obtener el nombre completo del usuario
  2. Extraer las iniciales de cada palabra
  3. Crear un diseño artístico con las iniciales

Ejemplo para "Ana María López":

**********
*  A  M  L  *
*  *  *  *  *
*  *  *  *  *
**********

Puedes usar el método .split() para dividir el nombre completo en palabras, luego extraer la primera letra de cada palabra con índices, y finalmente crear el diseño con múltiples líneas de texto.
