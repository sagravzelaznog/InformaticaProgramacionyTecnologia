Mini-Proyecto: Calculadora Básica

Duración: 2-3 horas Módulo 1: Fundamentos de Python
Proyecto en progreso

  • Proyecto
  • Guía

Objetivo del Proyecto

En este mini-proyecto, aplicarás todos los conceptos aprendidos en las primeras 7 sesiones para desarrollar una calculadora interactiva desde cero. Este proyecto te permitirá consolidar tus conocimientos de programación en Python de manera práctica.

Al completar este proyecto, habrás:

  • Implementado entrada/salida de datos con el usuario
  • Aplicado operadores aritméticos y lógicos
  • Utilizado estructuras de control condicional
  • Manejado errores y validado entradas
  • Creado un programa funcional y útil

Descripción del Proyecto

📋 Características de la Calculadora

  • Solicitará al usuario dos números
  • Mostrará un menú con operaciones disponibles
  • Realizará la operación seleccionada
  • Mostrará el resultado formateado
  • Manejará errores de entrada
  • Preguntará si se desea realizar otro cálculo

📝 Ejemplo de Ejecución

Calculadora Básica

=== Calculadora Básica ===

Ingrese el primer número: 10

Ingrese el segundo número: 5

Seleccione la operación:

1. Suma

2. Resta

3. Multiplicación

4. División

Opción: 3

El resultado de 10 * 5 = 50.0

¿Desea realizar otro cálculo? (s/n): n

¡Gracias por usar la calculadora!

Guía de Implementación

Paso 1: Configuración Inicial

Crea un nuevo archivo llamado calculadora.py y comienza con un mensaje de bienvenida.

print("=== Calculadora Básica ===")
print("Bienvenido a la calculadora en Python")
print("-" * 30)

Paso 2: Obtener Entrada del Usuario

Solicita dos números al usuario y valida que sean números válidos.

while True:
    try:
        num1 = float(input("\nIngrese el primer número: "))
        num2 = float(input("Ingrese el segundo número: "))
        break
    except ValueError:
        print("Error: Por favor ingrese números válidos.")
        continue

Paso 3: Mostrar Menú de Operaciones

Muestra un menú con las operaciones disponibles.

print("\nSeleccione la operación:")
print("1. Suma (+)")
print("2. Resta (-)")
print("3. Multiplicación (*)")
print("4. División (/)")

while True:
    try:
        opcion = int(input("Opción (1-4): "))
        if 1 <= opcion <= 4:
            break
        else:
            print("Error: Opción inválida. Intente nuevamente.")
    except ValueError:
        print("Error: Por favor ingrese un número del 1 al 4.")

Paso 4: Realizar el Cálculo

Implementa la lógica para realizar la operación seleccionada.

resultado = 0
operacion = ""

if opcion == 1:
    resultado = num1 + num2
    operacion = "+"
elif opcion == 2:
    resultado = num1 - num2
    operacion = "-"
elif opcion == 3:
    resultado = num1 * num2
    operacion = "*"
elif opcion == 4:
    if num2 != 0:
        resultado = num1 / num2
        operacion = "/"
    else:
        print("Error: No se puede dividir entre cero.")
        exit()

Paso 5: Mostrar el Resultado

Muestra el resultado formateado de manera clara.

print(f"\nEl resultado de {num1} {operacion} {num2} = {resultado:.2f}")

Paso 6: Preguntar por Otro Cálculo

Pregunta al usuario si desea realizar otro cálculo.

continuar = input("\n¿Desea realizar otro cálculo? (s/n): ").lower()
if continuar != 's':
    print("\n¡Gracias por usar la calculadora!")
    break  # Salir del bucle principal si no se desea continuar

Paso 7: Mejoras Adicionales (Opcional)
