Objetivo de la Sesión

Comprender el ecosistema de la programación y dar los primeros pasos con Python, incluyendo la instalación, configuración del entorno y ejecución del primer programa.

Conceptos Clave

¿Qué es la programación?

La programación es el proceso de crear un conjunto de instrucciones que le dicen a una computadora cómo realizar una tarea. Es como escribir una receta detallada que la computadora puede seguir.

¿Qué es un algoritmo?

Un algoritmo es una secuencia lógica y finita de pasos para resolver un problema específico. Es independiente del lenguaje de programación.

Código Fuente vs. Ejecutable

Código fuente: Texto legible por humanos que contiene instrucciones en un lenguaje de programación.
Programa ejecutable: Archivo binario que la computadora puede ejecutar directamente.

Python

Un lenguaje de programación interpretado, de alto nivel y con sintaxis fácil de leer. Es versátil y se utiliza en desarrollo web, ciencia de datos, IA, automatización y más.

Instalación y Configuración

1. Instalar Python

Descarga la última versión de Python desde el sitio oficial:

Descargar Python

Nota: Durante la instalación, asegúrate de marcar la casilla "Add Python to PATH".

2. Verificar la instalación

Abre una terminal o símbolo del sistema y escribe:

python --version

Deberías ver la versión de Python instalada, por ejemplo: Python 3.9.7

3. Elegir un editor de código

Algunas opciones recomendadas:

Visual Studio Code PyCharm Sublime Text

Actividades Prácticas

Actividad 1: Instalar Python

Sigue los pasos de instalación anteriores y verifica que Python esté correctamente instalado en tu sistema.

Si usas Windows, asegúrate de abrir una nueva ventana de terminal después de la instalación para que reconozca el comando python.

Actividad 2: Configurar tu editor

Instala y configura tu editor de código preferido. Recomendamos VS Code con las siguientes extensiones:

  • Python (Microsoft)
  • Pylance
  • Jupyter

Actividad 3: ¡Hola, Mundo!

Crea tu primer programa en Python siguiendo estos pasos:

  1. Abre tu editor de código
  2. Crea un nuevo archivo llamado hola_mundo.py
  3. Escribe el siguiente código: 
    # Mi primer programa en Python
print("¡Hola, Mundo!")

# Preguntar el nombre al usuario
nombre = input("¿Cuál es tu nombre? ")
print(f"¡Bienvenido/a al curso de Python, {nombre}!")
  4. Guarda el archivo

Actividad 4: Ejecutar desde la terminal

Abre una terminal y navega hasta la carpeta donde guardaste tu archivo:

# Navegar a la carpeta (ejemplo para Windows)
cd ruta\a\tu\carpeta

# Ejecutar el programa
python hola_mundo.py

Salida esperada:

¡Hola, Mundo!
¿Cuál es tu nombre? [Tu nombre]
¡Bienvenido/a al curso de Python, [Tu nombre]!
