Objetivo de la Sesión

En esta sesión, aprenderás a crear tus propias funciones en Python, que son bloques de código reutilizables que te permiten organizar y estructurar mejor tu programa. Las funciones son uno de los conceptos más importantes en programación porque permiten dividir problemas complejos en partes más manejables.

Al finalizar esta sesión, podrás:

  • Definir funciones con la sintaxis correcta de Python
  • Comprender la diferencia entre parámetros y argumentos
  • Usar la sentencia return para devolver valores desde funciones
  • Crear funciones que realicen tareas específicas y reutilizables
  • Entender la diferencia entre funciones y procedimientos
  • Crear bibliotecas de funciones útiles para reutilizar en futuros proyectos

Funciones como Bloques Reutilizables

Las funciones son como máquinas que reciben entradas (parámetros), realizan procesos internos y producen salidas (valores de retorno).

def calcular_promedio(notas):
    suma = sum(notas)
    promedio = suma / len(notas)
    return promedio

Reutilización de Código

Una vez definida, puedes usar la misma función múltiples veces en tu programa sin repetir código.

promedio_matematicas = calcular_promedio([8, 9, 7, 10])
promedio_historia = calcular_promedio([9, 8, 9, 8])
promedio_ciencias = calcular_promedio([10, 9, 8, 9])

Organización Modular

Las funciones permiten dividir programas grandes en módulos más pequeños y manejables.

    # Lógica de procesamiento

    # Lógica de presentación

Conceptos Clave

1. Sintaxis Básica de Definición de Funciones

La sintaxis básica para definir una función en Python utiliza la palabra clave def, seguida del nombre de la función y paréntesis que contienen los parámetros.

# Sintaxis básica de una función
def nombre_de_la_funcion(parametro1, parametro2, parametro3):
    """
    Esta es la docstring de la función.
    Aquí se explica qué hace la función, qué parámetros recibe
    y qué valor devuelve.
    """
    # Cuerpo de la función
    resultado = parametro1 + parametro2 + parametro3
    return resultado

# Ejemplo de uso
suma = nombre_de_la_funcion(5, 3, 7)
print(suma)  # Imprime: 15

# Función sin parámetros
def saludar():
    """Función que muestra un saludo."""
    print("¡Hola, mundo!")

saludar()  # Imprime: ¡Hola, mundo!

# Función sin valor de retorno (procedimiento)
def mostrar_mensaje(mensaje):
    """Procedimiento que muestra un mensaje."""
    print(f"Mensaje: {mensaje}")
    # No hay return, por lo que devuelve None implícitamente

resultado = mostrar_mensaje("Hola")  # Imprime: Mensaje: Hola
print(resultado)  # Imprime: None

Importante: Docstrings

Es una buena práctica incluir una docstring (cadena de documentación) al inicio de cada función. Esta cadena entre triple comillas explica qué hace la función, qué parámetros recibe y qué devuelve. Puedes acceder a ella usando help(nombre_de_la_funcion).

Buenas Prácticas para Nombrar Funciones

  • Usa nombres descriptivos que indiquen claramente qué hace la función
  • Usa snake_case (minúsculas con guiones bajos): calcular_promedio, validar_entrada
  • Los nombres deben ser verbos o frases verbales: calcular, obtener, mostrar
  • Evita nombres genéricos como funcion1, hacer_algo

2. Parámetros y Argumentos

Los parámetros son las variables que se definen en la declaración de la función, mientras que los argumentos son los valores reales que se pasan cuando se llama a la función.

# Parámetros en la definición de la función
def calcular_area_rectangulo(ancho, largo):
    """
    Calcula el área de un rectángulo.
    
    Args:
        ancho (float): Ancho del rectángulo
        largo (float): Largo del rectángulo
        
    Returns:
        float: Área del rectángulo
    """
    area = ancho * largo
    return area

# Argumentos al llamar a la función
area_habitacion = calcular_area_rectangulo(5.5, 4.2)  # 5.5 y 4.2 son argumentos
area_jardin = calcular_area_rectangulo(10, 8)        # 10 y 8 son argumentos

print(f"El área de la habitación es: {area_habitacion} m²")
print(f"El área del jardín es: {area_jardin} m²")

# Función con múltiples tipos de parámetros
def crear_perfil_usuario(nombre, edad, ciudad="Ciudad no especificada", activo=True):
    """
    Crea un perfil de usuario con información básica.
    
    Args:
        nombre (str): Nombre del usuario
        edad (int): Edad del usuario
        ciudad (str): Ciudad del usuario (opcional)
        activo (bool): Estado activo del usuario (opcional)
        
    Returns:
        dict: Diccionario con la información del usuario
    """
    perfil = {
        "nombre": nombre,
        "edad": edad,
        "ciudad": ciudad,
        "activo": activo
    }
    return perfil

# Llamadas con diferentes números de argumentos
usuario1 = crear_perfil_usuario("Ana", 25)                    # Usa valores por defecto
usuario2 = crear_perfil_usuario("Luis", 30, "Madrid")         # Especifica ciudad
usuario3 = crear_perfil_usuario("María", 28, "Barcelona", True)  # Especifica todos

print(usuario1)  # {'nombre': 'Ana', 'edad': 25, 'ciudad': 'Ciudad no especificada', 'activo': True}
print(usuario2)  # {'nombre': 'Luis', 'edad': 30, 'ciudad': 'Madrid', 'activo': True}
print(usuario3)  # {'nombre': 'María', 'edad': 28, 'ciudad': 'Barcelona', 'activo': True}
Parámetros

Son las variables que se definen en la declaración de la función. Actúan como marcadores de posición para los valores que recibirá la función.

def funcion(param1, param2):
    # param1 y param2 son parámetros
Argumentos

Son los valores reales que se pasan a la función cuando se llama. Estos valores se asignan a los parámetros correspondientes.

funcion(valor1, valor2)
# valor1 y valor2 son argumentos

3. Valor de Retorno con return

La sentencia return permite que una función devuelva un valor al código que la llamó. Una función puede devolver cualquier tipo de dato o incluso múltiples valores usando tuplas.

# Función que devuelve un valor simple
def calcular_cuadrado(numero):
    """Calcula el cuadrado de un número."""
    resultado = numero ** 2
    return resultado

# Función que devuelve múltiples valores
def calcular_estadisticas(numeros):
    """
    Calcula estadísticas básicas de una lista de números.
    
    Args:
        numeros (list): Lista de números
        
    Returns:
        tuple: Tupla con (suma, promedio, maximo, minimo)
    """
    if not numeros:
        return 0, 0, None, None
        
    suma = sum(numeros)
    promedio = suma / len(numeros)
    maximo = max(numeros)
    minimo = min(numeros)
    
    return suma, promedio, maximo, minimo

# Función que no devuelve nada explícitamente (devuelve None)
def mostrar_informacion(datos):
    """Muestra información en pantalla (procedimiento)."""
    for clave, valor in datos.items():
        print(f"{clave}: {valor}")
    # No hay return, devuelve None implícitamente

# Función que devuelve diferentes tipos según condiciones
def procesar_texto(texto):
    """
    Procesa un texto y devuelve diferentes resultados según su contenido.
    
    Args:
        texto (str): Texto a procesar
        
    Returns:
        str or int or None: Resultado del procesamiento
    """
    if not texto:
        return None  # Texto vacío
        
    if texto.isdigit():
        return int(texto)  # Es un número
        
    if texto.isalpha():
        return texto.upper()  # Es texto, devolver en mayúsculas
        
    return texto  # Texto mixto, devolver como está

# Uso de las funciones
cuadrado = calcular_cuadrado(5)
print(f"El cuadrado de 5 es: {cuadrado}")  # Imprime: 25

suma, promedio, maximo, minimo = calcular_estadisticas([1, 5, 3, 8, 2])
print(f"Suma: {suma}, Promedio: {promedio}, Máximo: {maximo}, Mínimo: {minimo}")
# Imprime: Suma: 19, Promedio: 3.8, Máximo: 8, Mínimo: 1

resultado = mostrar_informacion({"nombre": "Ana", "edad": 25})
print(f"El procedimiento devolvió: {resultado}")  # Imprime: None

print(procesar_texto("hola"))    # Imprime: HOLA
print(procesar_texto("123"))     # Imprime: 123
print(procesar_texto(""))        # Imprime: None
print(procesar_texto("abc123"))  # Imprime: abc123

Funciones vs Procedimientos

Función: Bloque de código que devuelve un valor usando return.

Procedimiento: Bloque de código que realiza acciones pero no devuelve un valor (o devuelve None implícitamente).

En Python, técnicamente todas las funciones pueden ser procedimientos si no usan return, pero es buena práctica usar return cuando corresponda.

Ejemplo 1: Funciones Matemáticas Básicas

Crearemos un conjunto de funciones matemáticas que podemos reutilizar en diferentes programas.

import math

def calcular_area_circulo(radio):
    """Calcula el área de un círculo dado su radio."""
    return math.pi * radio ** 2

def calcular_volumen_esfera(radio):
    """Calcula el volumen de una esfera dado su radio."""
    return (4/3) * math.pi * radio ** 3

def convertir_temperatura(celsius, escala="fahrenheit"):
    """
    Convierte temperatura de Celsius a otra escala.
    
    Args:
        celsius (float): Temperatura en grados Celsius
        escala (str): Escala de destino ("fahrenheit", "kelvin")
        
    Returns:
        float: Temperatura convertida
    """
    if escala.lower() == "fahrenheit":
        return (celsius * 9/5) + 32
    elif escala.lower() == "kelvin":
        return celsius + 273.15
    else:
        raise ValueError("Escala no soportada. Use 'fahrenheit' o 'kelvin'")

def calcular_promedio_ponderado(notas, pesos):
    """
    Calcula el promedio ponderado de una lista de notas.
    
    Args:
        notas (list): Lista de calificaciones
        pesos (list): Lista de pesos correspondientes
        
    Returns:
        float: Promedio ponderado
    """
    if len(notas) != len(pesos):
        raise ValueError("Las listas de notas y pesos deben tener la misma longitud")
    
    suma_ponderada = sum(nota * peso for nota, peso in zip(notas, pesos))
    suma_pesos = sum(pesos)
    
    return suma_ponderada / suma_pesos

# Uso de las funciones matemáticas
radio = 5
area_circulo = calcular_area_circulo(radio)
volumen_esfera = calcular_volumen_esfera(radio)

print(f"Área del círculo: {area_circulo:.2f}")
print(f"Volumen de la esfera: {volumen_esfera:.2f}")

temperatura_celsius = 25
temp_fahrenheit = convertir_temperatura(temperatura_celsius, "fahrenheit")
temp_kelvin = convertir_temperatura(temperatura_celsius, "kelvin")

print(f"{temperatura_celsius}°C = {temp_fahrenheit}°F = {temp_kelvin}K")

# Promedio ponderado
notas = [8.5, 9.2, 7.8, 9.5]
pesos = [0.2, 0.3, 0.2, 0.3]  # Pesos en proporción
promedio_final = calcular_promedio_ponderado(notas, pesos)
print(f"Promedio ponderado: {promedio_final:.2f}")

Ejemplo 2: Funciones de Validación de Datos

Crearemos funciones que validen diferentes tipos de datos de entrada.

def validar_email(email):
    """
    Valida si una cadena tiene formato de email básico.
    
    Args:
        email (str): Dirección de email a validar
        
    Returns:
        bool: True si es válido, False en caso contrario
    """
    if not isinstance(email, str):
        return False
        
    if '@' not in email or '.' not in email:
        return False
        
    partes = email.split('@')
    if len(partes) != 2:
        return False
        
    usuario, dominio = partes
    if not usuario or not dominio:
        return False
        
    return True

def validar_contrasena(contrasena, longitud_minima=8):
    """
    Valida si una contraseña cumple con requisitos básicos de seguridad.
    
    Args:
        contrasena (str): Contraseña a validar
        longitud_minima (int): Longitud mínima requerida
        
    Returns:
        tuple: (bool, str) - (válido, mensaje de error)
    """
    if not isinstance(contrasena, str):
        return False, "La contraseña debe ser una cadena de texto"
        
    if len(contrasena) < longitud_minima:
        return False, f"La contraseña debe tener al menos {longitud_minima} caracteres"
        
    tiene_mayuscula = any(c.isupper() for c in contrasena)
    tiene_minuscula = any(c.islower() for c in contrasena)
    tiene_numero = any(c.isdigit() for c in contrasena)
    
    if not (tiene_mayuscula and tiene_minuscula and tiene_numero):
        return False, "La contraseña debe contener al menos una mayúscula, una minúscula y un número"
        
    return True, "Contraseña válida"

def validar_rango(numero, minimo, maximo):
    """
    Valida si un número está dentro de un rango específico.
    
    Args:
        numero: Número a validar
        minimo: Límite inferior (inclusive)
        maximo: Límite superior (inclusive)
        
    Returns:
        bool: True si está en rango, False en caso contrario
    """
    try:
        numero = float(numero)
        return minimo <= numero <= maximo
    except (ValueError, TypeError):
        return False

def validar_fecha(fecha_str, formato="%d/%m/%Y"):
    """
    Valida si una cadena representa una fecha válida.
    
    Args:
        fecha_str (str): Fecha en formato string
        formato (str): Formato esperado de la fecha
        
    Returns:
        bool: True si es válida, False en caso contrario
    """
    try:
        from datetime import datetime
        datetime.strptime(fecha_str, formato)
        return True
    except (ValueError, TypeError):
        return False

# Uso de las funciones de validación
emails = ["usuario@ejemplo.com", "email.invalido", "otro@dominio", "test@test"]
for email in emails:
    es_valido = validar_email(email)
    print(f"{email}: {'Válido' if es_valido else 'Inválido'}")

contrasenas = ["Abc123", "contrasena", "12345678", "MiPassword123"]
for contrasena in contrasenas:
    valida, mensaje = validar_contrasena(contrasena)
    print(f"{contrasena}: {'Válida' if valida else mensaje}")

numeros = [5, 15, 25, "texto", 35]
for numero in numeros:
    en_rango = validar_rango(numero, 10, 30)
    print(f"{numero}: {'En rango' if en_rango else 'Fuera de rango'}")

fechas = ["25/12/2023", "31/02/2023", "2023-12-25", "15/13/2023"]
for fecha in fechas:
    valida = validar_fecha(fecha)
    print(f"{fecha}: {'Válida' if valida else 'Inválida'}")

Ejemplo 3: Funciones de Formateo de Texto

Crearemos funciones que ayuden a formatear y manipular texto de diferentes maneras.

def formatear_titulo(texto):
    """Convierte texto en formato de título."""
    return texto.title()

def formatear_moneda(numero, simbolo="$", decimales=2):
    """
    Formatea un número como moneda.
    
    Args:
        numero (float): Número a formatear
        simbolo (str): Símbolo de moneda
        decimales (int): Número de decimales
        
    Returns:
        str: Número formateado como moneda
    """
    return f"{simbolo}{numero:.{decimales}f}"

def formatear_porcentaje(numero, decimales=1):
    """
    Formatea un número como porcentaje.
    
    Args:
        numero (float): Número a formatear (ej: 0.85 para 85%)
        decimales (int): Número de decimales
        
    Returns:
        str: Número formateado como porcentaje
    """
    return f"{numero * 100:.{decimales}f}%"

def formatear_telefono(telefono, formato="internacional"):
    """
    Formatea un número de teléfono según diferentes formatos.
    
    Args:
        telefono (str): Número de teléfono sin formatear
        formato (str): Formato deseado
        
    Returns:
        str: Número formateado
    """
    # Limpiar el número de caracteres no numéricos
    digitos = ''.join(filter(str.isdigit, telefono))
    
    if formato == "internacional":
        if len(digitos) == 10:  # Número nacional
            return f"+52 {digitos[:3]} {digitos[3:6]} {digitos[6:]}"
        elif len(digitos) == 12 and digitos.startswith("52"):  # Ya tiene código de país
            return f"+{digitos[:2]} {digitos[2:5]} {digitos[5:8]} {digitos[8:]}"
    elif formato == "nacional":
        if len(digitos) == 10:
            return f"({digitos[:3]}) {digitos[3:6]}-{digitos[6:]}"
    
    return telefono  # Devolver original si no se puede formatear

def generar_acronimo(frase):
    """
    Genera un acrónimo a partir de una frase.
    
    Args:
        frase (str): Frase para generar acrónimo
        
    Returns:
        str: Acrónimo en mayúsculas
    """
    palabras = frase.split()
    acronimo = ''.join(palabra[0].upper() for palabra in palabras if palabra[0].isalpha())
    return acronimo

def formatear_tabla(datos, encabezados=None, alineacion="left"):
    """
    Formatea una lista de diccionarios como tabla de texto.
    
    Args:
        datos (list): Lista de diccionarios con los datos
        encabezados (list): Lista opcional de encabezados
        alineacion (str): Alineación de columnas
        
    Returns:
        str: Tabla formateada
    """
    if not datos:
        return "No hay datos para mostrar"
    
    # Obtener todas las claves únicas
    todas_claves = set()
    for fila in datos:
        todas_claves.update(fila.keys())
    
    claves_ordenadas = sorted(todas_claves)
    
    # Crear encabezados si no se proporcionan
    if encabezados is None:
        encabezados = {clave: formatear_titulo(clave.replace('_', ' ')) for clave in claves_ordenadas}
    else:
        encabezados = dict(zip(claves_ordenadas, encabezados))
    
    # Calcular anchos de columnas
    anchos = {}
    for clave in claves_ordenadas:
        ancho_encabezado = len(str(encabezados[clave]))
        ancho_datos = max(len(str(fila.get(clave, ''))) for fila in datos)
        anchos[clave] = max(ancho_encabezado, ancho_datos, len(clave))
    
    # Crear línea separadora
    separador = "+" + "+".join("-" * (anchos[clave] + 2) for clave in claves_ordenadas) + "+"
    
    # Crear líneas de la tabla
    lineas = [separador]
    
    # Línea de encabezados
    linea_encabezado = "|"
    for clave in claves_ordenadas:
        valor = str(encabezados[clave])
        if alineacion == "right":
            linea_encabezado += f" {valor:>{anchos[clave]}} |"
        else:
            linea_encabezado += f" {valor:<{anchos[clave]}} |"
    lineas.append(linea_encabezado)
    lineas.append(separador)
    
    # Líneas de datos
    for fila in datos:
        linea_datos = "|"
        for clave in claves_ordenadas:
            valor = str(fila.get(clave, ''))
            if alineacion == "right":
                linea_datos += f" {valor:>{anchos[clave]}} |"
            else:
                linea_datos += f" {valor:<{anchos[clave]}} |"
        lineas.append(linea_datos)
    
    lineas.append(separador)
    
    return "\n".join(lineas)

# Uso de las funciones de formateo

print(f"Título formateado: {titulo}")

precio = 1599.99
precio_formateado = formatear_moneda(precio)
print(f"Precio formateado: {precio_formateado}")

porcentaje = 0.856
porcentaje_formateado = formatear_porcentaje(porcentaje)
print(f"Porcentaje formateado: {porcentaje_formateado}")

telefono = "5551234567"
telefono_formateado = formatear_telefono(telefono)
print(f"Teléfono formateado: {telefono_formateado}")

acrónimo = generar_acronimo("Instituto Tecnológico Superior")
print(f"Acrónimo: {acrónimo}")

datos_tabla = [
    {"nombre": "Ana", "edad": 25, "ciudad": "Madrid"},
    {"nombre": "Luis", "edad": 30, "ciudad": "Barcelona"},
    {"nombre": "María", "edad": 28, "ciudad": "Valencia"}
]

tabla = formatear_tabla(datos_tabla, alineacion="left")
print("\nTabla formateada:")
print(tabla)
