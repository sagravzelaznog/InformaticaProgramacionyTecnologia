Guía Maestra de Soluciones

Vite Masterclass: De Zero a Superhéroe (Instructor Copy)

Sesión 01: El Despegue

Comando clave: npm create vite@latest mi-app -- --template vanilla

Solución: Asegurarse de entrar a la carpeta: cd mi-app y ejecutar npm install seguido de npm run dev.

Sesión 02: HMR y Activos

Código main.js:

import imgUrl from './logo.png'
document.querySelector('#app').innerHTML = `<img src="${imgUrl}" />`;
Nota: Vite convierte la importación en una URL válida automáticamente.

Sesión 03: .env y Config

Archivo .env: VITE_API_KEY=123456

Acceso: console.log(import.meta.env.VITE_API_KEY);

Sesión 04: Tailwind CSS

Instalación: npm install -D tailwindcss postcss autoprefixer

Inicialización: npx tailwindcss init -p

Sesión 05: Frameworks (React)

Comando: npm create vite@latest mi-react -- --template react

Solución: Explicar que main.jsx es el punto de entrada y no requiere configuración extra.

Sesión 06: Rutas (React Router)

Código base:

import { BrowserRouter, Routes, Route } from 'react-router-dom';
// Envolver App con BrowserRouter

Sesión 07: TypeScript

Interface:

interface User { id: number; name: string; }
const user: User = { id: 1, name: "Genio" };

Sesión 08: Plugins (PWA)

Configuración vite.config.js:

import { VitePWA } from 'vite-plugin-pwa'
export default { plugins: [VitePWA({ registerType: 'autoUpdate' })] }

Sesión 09: Build y Rollup

Comando: npm run build

Solución: Revisar la carpeta /dist. Explicar que el index.html está minificado.

Sesión 10: Despliegue

Pipeline: GitHub Repo -> Vercel Dashboard -> Import -> Auto-deploy.

Solución de errores: Asegurar que el "Build Command" sea npm run build y el "Output Directory" sea dist.
